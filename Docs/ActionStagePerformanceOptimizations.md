# アクションステージの性能改善（2026-10-25）

既存の画質・生成規模・ゲームルールを維持し、静的コライダーの再生成、同じ親への再設定による描画リストの破棄、採集遮蔽判定の全床走査、影キャッシュの全体無効化を改修した。

## 実装

- `SourceFiles/KashipanEngine/Objects/Collision/Collider.cpp`: 形状の種類・寸法・メッシュ内容・取り付け先RigidBodyが同じならRP3Dのボディと形状を再利用。位置・回転だけを更新し、同じ姿勢ならsetTransformも省略。enabled/trigger、衝突コールバック、フィルター、CCD情報は更新する。形状の種類変更時は旧variantで破棄してから再構築する。
- `SourceFiles/KashipanEngine/Objects/Components/Transform.h`: 同じ親、既に親なしの状態への設定を成功扱いのno-opにする。描画リスト・有効状態・ワールド行列のキャッシュを無意味に破棄しない。実際の親変更と循環拒否は維持。
- `GameProjects/JobHuntingGame/Assets/Application/Scripts/LightTown/ExpeditionHarvestVisibility.as`: 遠征開始時に固定床を8m単位の区画へ登録し、sin/cosを事前計算。従来の24点サンプリング、地形と閉じた扉による遮蔽は維持し、床だけを近傍検索へ置き換える。
- `SourceFiles/KashipanEngine/Graphics/Renderer/RendererShadow.cpp`: ライトとライトカメラのジョブ単位で、影に関係するキャスターとマテリアルの状態を記録。変更したジョブのスライスだけをクリア・再描画する。スキニング・透明/テクスチャ・未知の境界は関係するジョブを毎回更新し、GPUパーティクルは安全側で全ジョブ更新する。配列再生成・シーン/PSO変更・Nパスディザによる描き直しも無効化条件に含める。

前2点と影の改修は特定ゲームに依存しないエンジン側の変更。採集検索の改修はゲーム側。

## 比較条件

- Ryzen 7 7745HX / RTX 4070 Laptop GPU。Release、FHDオフスクリーン、1280×720の非表示ウィンドウ。影ON・解像度512、ポストエフェクトON。
- 各テーマとも遠征1回目の同一シード、通常64部屋＋特殊部屋4、資材ノード86。生成後約6秒を除外し、約12秒採取。
- 各テーマを変更前A→変更後→変更前Bの順に起動。変更前は改修前の実行ファイルとExpeditionController、変更後は今回のReleaseビルドとスクリプト。ゲームスピード、NPC、敵、アニメーションは通常通り。画質やオブジェクト数の削減は行っていない。
- FPSはプロファイラーのフレーム番号差と実時間から算出。msはサンプルフレームのCPU経過時間で、GPU実行時間ではない。親子スコープは合算しない。非表示ウィンドウの値であり、実際の表示時のFPS保証ではない。
- 変更前にも変動があるため、2回の範囲を併記。前回調査の数値をそのまま比較対象にはしていない。

影は部分再利用が動作している一方、CPU側では毎フレームのキャスター収集・状態比較・バッチ準備が残るため、今回の通常シーン計測では`Render.Shadows`のCPU時間はほぼ変わっていない。GPU実行時間は測定していないため、影のGPU改善量は断定しない。採石場は約55FPSで、全ステージ60FPS到達ではない。次の検討箇所は影の静的バッチ準備・バッファ転送の再利用と、GPU時間の内訳。

`Render.Shadows.JobCacheHit`と`Render.Shadows.JobRedraw`の呼び出し数でジョブ単位の再利用・再描画数を確認できる。ジョブは複数スライスを含むため、スライス数や描画回数そのものではない。

## 検証

- Releaseビルド成功。
- 実際のシーン・コンポーネントを使ったネイティブ回帰テスト成功。同じ親の設定で構造リビジョンが変わらないこと、静的ボディ/コライダーのRP3Dエンティティを120回の同期後も維持すること、位置・回転・enabled・trigger・寸法・形状種類変更と削除を確認。
- スクリプトの本番ローダーでタイトル・街・ステージ選択・遠征と既存ギミックをロード成功。採集検索は回転床を含む4,000点で従来の判定と一致。森・採石場・洞窟の各2シードで64部屋と特殊部屋の経路検証成功。使用した短縮fixtureは6シードであり、テスト共通の末尾メッセージにある128シードを今回すべて再実行したものではない。
- 専用の2ライトによる影テスト成功。静止時は2ジョブとも再利用、キャスター移動時・ライト移動時は1ジョブ再利用＋1ジョブ再描画、停止後は再び2ジョブ再利用。各フェーズ20～21サンプルで期待通り。`EngineTests/PartialShadowCacheRuntimeRegression.as`を使用。
- 森・採石場・洞窟の実行テスト成功。鍵なしでの扉維持、鍵取得と対応扉の解錠、閉じた別部屋の採集拒否、攻撃でのHP減少、破壊時の資材加算と保存を確認。各テーマで1個の資材ノードを破壊・回収。採石場の保存画像も目視で地形・プレイヤー・資材と照明の描画を確認。
- Outputs / Distribution / WorkCopyへRelease成果物を反映。ユーザーのセーブと設定は作業前の内容を保持。
