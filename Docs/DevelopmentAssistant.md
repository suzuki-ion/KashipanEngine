# Claude / Codex 開発支援（試験）

エディターの **試験機能 → AIによる開発支援** を開きます。**試験機能 → 短文からの挙動作成** は別のウィンドウとして個別に開閉できます。各項目の **(?)** にカーソルを合わせると詳細な説明が表示されます。状態・エラー・適用内容は画面内に残ります。エンジンへのモデル埋め込みやAPIキーの購入は必要ありません。ゲーム実行時にはCLIを必要としません。

## 接続

1. 利用者自身のPCに公式Claude CodeまたはCodex CLIを導入します。現実装はWindowsのネイティブ `.exe` を対象とします。npmの `.cmd` ラッパーやWSL実行は対象外です。
2. **選択したCLIでログイン** から公式CLIのコンソールとブラウザーを開き、利用者自身でログインします。エンジン独自のログイン画面やトークン取り出しはありません。
3. **ログイン状態を更新** を押します。Claudeは`auth status --json`の`claude.ai`/`firstParty`、Codexは`login status`のChatGPT認証を確認します。これはログイン方式の確認であり、残り利用枠やモデルの利用権限を保証するものではありません。
4. Claude Code / Codexを任意に選択します。両方のログインを維持したまま切り替えられます。一方の失敗時に他方を自動実行しません。

CLIはPATH、Claudeの標準インストール先、CodexデスクトップアプリのCLIディレクトリから検出します。検出できなければ **接続設定** に公式実行ファイルの絶対パスを指定します。指定後はログイン状態を再確認します。モデルはドロップダウンから選びます。**CLIの既定** はモデルを指定せず実行します。**モデル一覧を更新** は選択中のサービスの一覧を再取得します。ログイン状態の更新時にも両サービスの一覧を取得します。

**設定を保存** で現在のプロジェクトの`DevelopmentAssistant.json`に、CLIパス・モデル名・選択したサービスだけを保存します。認証情報は公式CLIが管理します。

## モデル一覧

Claudeは公式CLIのstream-json初期化応答にあるモデル一覧を使用し、CodexはApp Serverの`model/list`をページ送り付きで取得します。モデル名を固定のリストとしてコードに埋め込みません。非表示項目・重複・不正なIDを除外し、説明は候補にカーソルを合わせて確認できます。取得時に推論やコード編集は行いません。

一覧にあることは、その時点のモデル実行や残り利用枠を保証しません。CLIのカタログ・契約・管理者ポリシーに従い、実行時の拒否はエラーになります。取得できない場合は既定だけを選べます。保存済みモデルが現在の一覧にない場合は、更新するかモデルを選び直すまで実行できません。

## 短文の作成補助

対象オブジェクトを選択し、AIへの依頼を入力して実行します。選択対象の名前、登録済みプロパティ名、短文機能の説明を渡し、対応する短文をJSONで受け取ります。Claudeはツール無効、Codexは読み取り専用サンドボックスで動作します。

**短文作成ウィンドウへ送る** で別ウィンドウを開いて転記した後、従来の **解釈する → 適用内容を確認 → 適用** を使います。AIの回答を直接コンポーネントとして実行しません。解釈できない提案は既存の解析器が拒否します。対象・シーン・プロジェクトが変わった場合は転記できません。適用後は通常のUndoが使えます。

## エンジンAPIの参照

デフォルトはエンジンのソースコードを検索します。依頼の型名・英語の識別子・登録されたコンポーネントの別名から対象を絞り、`ScriptBindings.cpp`のスクリプト登録宣言と関連ヘッダーを優先します。APIがソースで見つからない場合は、同じエンジンルートの`Reference/Script`から関連する詳細ページを検索します。WFC、Wave Function Collapse、波動関数崩壊の表記も対象です。

エンジン側で必要な箇所を読み、上限付きの文脈としてAIへ渡します。ソースや資料に対するAIの編集権限は追加しません。C++内部の機能がAngelScriptに公開されているとは限らないため、登録されたスクリプト宣言を使うよう指示します。どちらにも情報がない場合はAPIを推測しないよう指示します。関連資料の抜粋が入力に加わる分、利用枠も消費します。

Developmentの配布スクリプトはReferenceを同梱します。ソースを含まない配布版でも参照できます。オンライン最新版は自動参照せず、同梱版を使います。

## エディター操作 API（MCP）

**操作 → エディター操作** を選び、**この依頼のエディター・Assets操作を許可** にチェックを入れて実行します。Claude/Codexの公式CLIへ、依頼専用のローカルMCP接続を渡します。31種類のツールで、次の12分野を扱います。

| 分野 | ツール・操作 |
| --- | --- |
| シーン管理 | `scene_files`：登録一覧、新規、JSON／フォルダー形式の保存・読込、登録済みシーンへの切替。未保存変更がある差し替えは保存、または明示的な`discard_unsaved`が必要 |
| 再生・検証 | `play`：開始・停止・一時停止・再開・単発ステップ・指定フレーム実行。`runtime_status`で状態と残りステップを取得。`input`はエンジン内のキー・マウスボタン・仮想ポインター・ホイール入力 |
| 選択・画面操作 | `selection`でUUIDによる単一／複数選択・解除。`view`でエディターカメラの取得・設定・対象へのフォーカス。`editor_window`で既知パネルを開閉 |
| 階層編集 | `hierarchy`：既存対象の親変更・親解除・並び順変更。循環参照を拒否。Transformのローカル値を保持 |
| 複製・Prefab | `duplicate`は子孫を含め新UUIDで複製し内部参照を張り替え。`prefab`は資産保存・配置・適用・復元・リンク解除 |
| シーンコンポーネント | `scene_components`：型一覧、安定IDによる取得・追加・削除・シリアライズデータ編集 |
| 複雑なプロパティ | `component_json`：ネイティブ保存形式の取得と、既存JSON pointerへの値設定。配列・辞書・構造体・列挙値・参照・行列・Quaternion等、各コンポーネントが保存／読み込みを実装した項目が対象 |
| スクリプト | `script`：設定・公開フィールドの取得／変更、再読み込みとエラー取得、Play中の関数呼び出し（対応する型の引数付き）。`asset write`で`.as`作成後、同じ依頼で`attach_script`による付与が可能 |
| アセット | `asset`：一覧、テキスト読込／作成／編集、プロジェクト内からのimport、移動、削除、再読込。上書きは`overwrite=true`が必要 |
| 詳細データ編集 | `keyframes`：KeyFrameAnimatorの埋め込みキー・補間・バインド・再生設定。`tilemap`：サイズ・セル編集・クリア。タイル種類などは`component_json`で編集 |
| 実行結果の確認 | `capture`：SceneビューまたはScreenBufferObjectの直近の描画済みPNGを保存しMCP画像として返す。`logs`：通常のロガー設定に従って直近のログを取得。スクリプトエラーも各取得APIから確認可能 |
| 履歴・一括処理 | `history`：状態・Undo・Redo。`batch`：最大64件のシーン編集をひとつのUndoとして実行し、失敗時は先行操作を逆順に取り消す |

オブジェクトはUUID、コンポーネントは配列番号ではなく追加IDで指定します。`object`で登録メンバーの値と書き込み可否を取得し、`set_property`でbool/int/uint/float/double/文字列/Vector2/3/4/Colorを登録済みセッター経由で設定できます。Transformの回転および`view`の角度はラジアンです。短文による部品・イベント・KeyframeAnimationのプレビュー／適用には従来の`apply_sentence`を利用します。

複雑な編集は先に`component_json`の`action=get`で保存形式を取得します。`action=patch`の`patches`は`[{"path":"/data/customData/translate/x","value":2.0}]`の形式です。存在しないパスや型違いを拒否し、ネイティブの読み込み処理が失敗した場合は元の状態を復元します。シーンコンポーネントのパスは`/data/`配下です。非公開かつ保存処理もないメンバーや任意のC++関数は対象外です。

`batch`は`operations=[{"tool":"create_object","arguments":{"name":"Player"},"as":"player"}, ...]`の形式です。後続の引数にある文字列`$player`を生成結果のUUIDに置き換えます。ファイル・シーン差し替え・再生・履歴操作・任意関数呼び出し・入れ子バッチは混在させません。取り消し自体にも失敗した場合は残存操作を履歴に保持し、APIは失敗を返します。

通常のシーン編集と`asset`のファイル編集はメインスレッドでUndo履歴へ追加します。ファイルUndoは内容を比較し、その後の手動・外部編集を上書きしません。シーン差し替え・保存、Prefab資産への保存／適用、画像保存、スクリプト再読み込み、Play中の関数呼び出しや入力などはUndo対象外です。各結果の`undoable`を確認してください。停止は再生前のシーン状態を復元しますが、スクリプト自身が行った外部への副作用を取り消す機能ではありません。

シーン保存で現在の保存先とは別の既存ファイルを上書きする場合も、`overwrite=true`が必要です。

再生中に編集用APIは利用できません。通常の保存は再生前の編集状態を保存します。生成処理の結果を保存したい場合だけ、`scene_files`の`action=save,runtime=true`でランタイムの状態を別パスに保存し、停止後にそのファイルを読み込みます。ステップ実行は非同期で予約されるため、`runtime_status.pending_steps`が0になったことと、フレームが進んだことを確認してから結果を判定してください。画像は直近の描画完了フレームを使用します。

APIから予約したシーン切替ではAI接続を次のSceneEditorへ引き継ぎます。切替中は操作を拒否し、切替後は`scene`の再取得を要求します。手動でのシーン差し替え・履歴クリア、プロジェクト切替では古い接続を無効にします。中止はCLI・将来の操作を停止し、仮想入力と継続ステップを解除します。中止までに適用済みの操作は残ります。

ファイルは現在のプロジェクトの`Assets/`内に限定し、相対パスの逸脱・隠しパス・リンク経由の範囲外アクセスを拒否します。import元もプロジェクト内に置いてください。OS入力送信・外部アプリの操作・任意のシェル実行は提供しません。ファイルUndo／importは16MiB、テキスト読込／作成は約100KB、Tilemapのサイズ変更は512×512、バッチは64操作が上限です。通常の再生入力は3600フレーム、一時停止中の入力テストと指定ステップは600フレームまでです。キャプチャ画像が2MiBを超えた場合は保存先のみ返します。GPUが未初期化、または未描画なら撮影失敗を返し、成功を装いません。

接続は`127.0.0.1`の動的ポートのみで待ち受け、暗号学的乱数の依頼専用Bearerトークンで認証します。接続設定・トークンをファイルに保存せず、ブラウザーOrigin・異なるHost・未認証要求を拒否します。タイムアウトした未実行の要求を後から実行しません。MCP Streamable HTTPの`initialize`、`ping`、`tools/list`、`tools/call`、PNG image contentに対応します。[Claude MCP](https://code.claude.com/docs/en/mcp)、[Codex MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)、[MCP仕様](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)。

## コード・ファイル編集

**操作 → コード・ファイル編集** を選び、その依頼の編集許可にチェックを入れます。作業場所は現在のゲームプロジェクトです。保存済みのスクリプトやアセットを操作します。AIにはコミット・push・無関係な変更の破棄・認証ファイルの読み取り・編集中のシーンファイルの書き換えを行わないよう指示します。

- Claude: 公式`--restricted`モードで作業ディレクトリ内のRead/Edit/Write/Glob/Grepのみを使用します。シェルやビルドコマンドは使えません。
- Codex: `workspace-write`サンドボックスで編集・コマンド実行を行います。追加承認が必要な操作は実行できません。Windowsの実装方式は **接続設定 → Codexサンドボックス** で選択します。自動は公式MXCを優先し、利用できない場合は`CODEX_HOME/config.toml`（通常は`~/.codex/config.toml`）の`[windows] sandbox`を引き継ぎます。未指定ならElevatedを選びます。APIプロバイダー等の利用者設定は引き続き読み込みません。明示選択では自動で別方式へ変更しません。

Codexは推論前に、実際の作業場所で同じWindowsサンドボックス方式を使って`echo`を実行します。セットアップ・OS対応・管理者ポリシーの問題で起動できなければ依頼を送信せず、**実行エラーの詳細** に原因を表示します。詳細はコピーできます。MXCが利用できないPCでElevatedのセットアップが必要な場合は、公式Codex側でセットアップを完了してください。管理者制限やファイアウォール設定をエンジンが勝手に変更することはありません。

ファイル変更はエディターのUndo対象外です。変更差分と回答を確認し、スクリプトの再読込等は通常のエンジンの操作で行います。未保存のInspector編集はAIに渡しません。中止しても既に書かれたファイルは残ります。

## 契約利用枠・失敗・終了

起動する子プロセスからAPIキー・APIエンドポイント・クラウドプロバイダー・外部トークンの環境変数を除外し、実行直前にも公式CLIでログイン方式を再確認します。Codexの利用者設定とClaudeの利用者・プロジェクト設定からAPIプロバイダーやAPIキーヘルパーを取り込まない構成です。管理者ポリシーは公式CLIに従います。

APIキー認証・未ログインの場合は実行せず、契約の利用制限・モデル制限・管理者による拒否もエラーとして表示します。API課金への自動切替はありません。サービスの規約、管理者設定、CLIの将来の変更まではエンジンが上書きしません。

**「月額プランに含まれる枠だけ使い、追加利用は絶対に消費しない」という保証はありません。** 例えばCodexは含まれる枠の終了後に保有クレジットを使う場合があります。契約アカウント側の追加利用・クレジット設定はそのまま適用され、エンジンは購入や設定変更を行いません。追加消費を避ける場合はサービス側で利用制限・追加利用の設定を確認してください。[Codexの利用枠・クレジット](https://learn.chatgpt.com/docs/pricing)

サンドボックス確認とAI実行はUIを停止せずバックグラウンドで処理し、回答を表示します。応答の完了は依頼した作業・テストの成功を保証しません。通信は選択した公式CLIが行うため、指示・渡した仕様やCLIが読む内容はそのサービスへ送信されます。実行には20分の上限があります。中止・プロジェクト切替・エディター終了時はWindows Job ObjectでCLIの子プロセスも終了します。ログイン用の公式コンソールは利用者が閉じます。

## 検証

追加分はDevelopmentビルド後、`Tests/RunShortTextDomainRegression.ps1 -SourceFile DevelopmentAssistantExtendedRegression.cpp`で検証します。実際のSceneEditor・シーン・Undo・スクリプトVMと、Generated内の独立したテストプロジェクトを使います。GPU無しでの撮影失敗を含みますが、描画画像の内容・マウスによるGUI操作の証明ではありません。`KASHIPAN_EDITOR_API_EXTENDED_LIVE=1`を明示すると、契約済みCodexの`gpt-6-luna`でバッチ作成・選択・スクリプト作成／付与を実際に試します（利用枠を消費）。

エディターAPIはDevelopmentビルド後、`Tests/RunShortTextDomainRegression.ps1 -SourceFile DevelopmentAssistantEditorRegression.cpp`で実シーン・本物のUndo履歴・ループバックMCPを検証します。作成／階層／削除、型付きプロパティ、4成分の色、短文からのKeyframeAnimation、削除Undoをまたぐ参照、未認証・ブラウザーOriginの拒否、タイムアウト後の実行抑止、中止を扱います。ウィンドウ・GPU・モデルは不要ですが、ローカルTCP通信を許す環境が必要です。環境変数`KASHIPAN_EDITOR_API_LIVE=1`を明示した場合だけ、契約済みCodexの`gpt-6-luna`を使用し、メモリー内テストシーンへの作成・取得を実際に依頼します（利用枠を消費）。既存プロジェクトのシーンを保存しません。`KASHIPAN_EDITOR_API_LIVE=claude`ではClaudeのCLI既定モデルで同じ検証を行います。サービスの組織設定による拒否は、CLI引数の回帰・ローカルMCPの検証結果と分けて扱います。

`Tests/RunDevelopmentAssistantRegression.ps1`はVisual Studio x64開発者PowerShellで実行します。偽CLIで認証方式、課金環境変数の除外、日本語とシェル文字を含むstdin、JSON成功／失敗、不完全終了、モデル一覧の初期化・ページ送り・重複/非表示除外、CLI未導入、サンドボックス確認失敗時の推論抑止、ファイル編集の作業場所、中止時の子プロセス終了を検証します。API取得の回帰も実行し、ソース優先、Referenceへの切替、詳細ページの優先、HTML除去とサイズ制限を確認します。モデル利用枠やネットワークは使いません。
