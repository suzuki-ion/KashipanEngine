AudioListener 最大1個

音声の受聴位置となるコンポーネントです。使用フラグ（Used）のみを持ちます。

Inspectorに表示される項目

ラベルウィジェット内容
Usedチェックボックスこのリスナーを使用中にするかどうか。オンにすると、同一シーン内の他のAudioListenerの使用フラグが自動でオフになる
シーン内で同時に使用中のAudioListenerは常に高々1つです。オブジェクト生成時に使用フラグが立っている場合はもちろん、シーン内に他に使用中のリスナーが1つも無い場合も自動的にこのリスナーが使用中になります（明示操作なしでも動作するように）。

Add Componentでの位置

Add Component → Audio → AudioListener。
