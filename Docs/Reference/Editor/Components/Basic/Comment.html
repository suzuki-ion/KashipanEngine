Comment 最大1個

デバッグ用のコメントを保持するだけのコンポーネントです。実行時の動作には一切関与しません。

Inspectorに表示される項目

ラベルウィジェット内容
Comment複数行テキスト入力欄（ImGui::InputTextMultiline）自由記述のコメント文字列
ここに保持したコメントの内容は、エディターのScene Object Hierarchyで対象オブジェクトにカーソルを合わせた際、ツールチップとして表示されます。

Add Componentでの位置

Add Component → Debug → Comment。
