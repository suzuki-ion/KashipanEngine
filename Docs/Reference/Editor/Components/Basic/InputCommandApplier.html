InputCommandApplier

InputCommandの入力値を、同オブジェクトの他コンポーネントのパラメータへ適用するコンポーネントです。毎フレーム条件を評価し、満たしたときだけ値（固定値または入力コマンドの値）をバインド先へ書き込みます。複数のコマンド設定を登録でき、それぞれに評価するコマンド名・条件・複数の適用先を設定できます。

全体の項目

ラベルウィジェット内容
Add Commandボタン新しいコマンド設定を1件追加する。名前は "Cmd0", "Cmd1"... のように重複しない名前が自動で割り当てられる

登録済みの各コマンド設定は、名前をタイトルにしたImGui::CollapsingHeader（折りたたみ可能な見出し）として一覧表示されます。

コマンド設定1件分の項目（見出しを開いた中身）

ラベルウィジェット内容
Nameテキスト入力欄識別名。WasApplied/TryGetLastValue等をコードから呼ぶ際に指定する名前
Command Nameコンボ（(None) + InputCommandに登録済みのコマンド名一覧）評価する入力コマンド名
（未登録警告）警告テキスト（オレンジ色）Command Nameが空でなく、かつ現在InputCommandに登録されているコマンド名の中に見つからない場合に "The selected command is not registered in InputCommand." と表示される
Conditionコンボ（Command == true / Command == false / Value >= Threshold / Value <= Threshold / Value == Threshold）値を適用する条件。条件を満たしたフレームだけ書き込みが行われる
Thresholdドラッグ入力欄（ステップ0.01）Conditionが比較系（Value >= / <= / ==）の場合のみ表示。比較する閾値（==は誤差1e-6以内で判定）
Value Sourceコンボ（Command Value / Fixed Value）書き込む値の種類。Command Value: 入力コマンドの評価値。Fixed Value: 固定値
Fixed Valueドラッグ入力欄（ステップ0.01）Value SourceがFixed Valueの場合のみ表示。書き込む固定値
Value Scaleドラッグ入力欄（ステップ0.01）書き込む値にかけるスケール。Value Offsetの加算より先に適用される（適用値 = 値 × Scale + Offset）
Value Offsetドラッグ入力欄（ステップ0.01）書き込む値へ加算するデフォルト値オフセット
（適用状態表示）読み取り専用テキスト直前のUpdateで条件を満たして適用した場合は "Applied: N.NNN"、そうでなければグレー文字で "Not Applied"
Bindings (N) / Add Binding見出しテキスト ＋ ボタン値の適用先一覧。Add Bindingで1件追加する
（バインド先選択コンボ ×N ＋ X削除ボタン）コンボ ＋ 小ボタン同オブジェクトの他コンポーネントのfloat/double/Vector成分パラメータ、またはScriptComponentの[SerializeField]付きfloat変数から適用先を選択する
Delete Command小ボタンこのコマンド設定を削除する
1つのコンポーネントに複数のコマンド設定を登録できます（コマンド名・条件ごとに個別の適用先を持てます）。同じオブジェクトへ複数アタッチする必要はありません。

Add Componentでの位置

Add Component → Input → InputCommandApplier。最大付与数の制限はありません。
