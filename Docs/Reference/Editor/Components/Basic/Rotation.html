Rotation 最大1個

同オブジェクトのTransformに対して、毎フレーム角速度・角加速度による回転を適用するコンポーネントです。

Inspectorに表示される項目

ラベルウィジェット内容
Angular VelocityXYZのドラッグ入力欄（ステップ0.01）角速度（ラジアン/秒）。Transformのオイラー角欄と異なり、度への変換はされずラジアンのまま表示・入力します
Angular AccelerationXYZのドラッグ入力欄（ステップ0.01）角加速度（ラジアン/秒2）
数値の単位はラジアンです。度で指定したい場合は、値を入力する前に 度 × π / 180 で換算してください。
毎フレームのUpdateで、angularVelocity += angularAcceleration * dt、続けて Transform.rotate += angularVelocity * dt（オイラー角への直接加算）が行われます。Transformコンポーネントが同オブジェクトに存在しない場合は何も起こりません。

Add Componentでの位置

Add Component → Physics → Rotation。
