Velocity 最大1個

同オブジェクトのTransformに対して、毎フレーム速度・加速度による移動を適用するコンポーネントです。

Inspectorに表示される項目

ラベルウィジェット内容
VelocityXYZのドラッグ入力欄（ステップ0.01）速度（単位/秒）。毎フレーム Acceleration × dt が加算され続ける
AccelerationXYZのドラッグ入力欄（ステップ0.01）加速度（単位/秒2）
毎フレームのUpdateで、velocity += acceleration * dt、続けて Transform.translate += velocity * dt が行われます。Transformコンポーネントが同オブジェクトに存在しない場合は何も起こりません。

Add Componentでの位置

Add Component → Physics → Velocity。
