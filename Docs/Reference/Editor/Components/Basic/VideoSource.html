VideoSource

動画を再生するコンポーネントです（UnityのVideo Playerに相当）。同じオブジェクトにSpriteRenderer/MeshRendererが付いている場合、再生開始時にそのレンダラーが使用しているマテリアルを複製し、複製したマテリアルのテクスチャを再生中の動画へ差し替えて割り当てます（元のマテリアルアセット自体は書き換えません）。再生していない間（未再生・停止後）も、動画の最初の1フレームがプレースホルダーとして表示され続けます。

基本設定

ラベルウィジェット内容
Videoコンボ（(None) + 読み込み済み動画のアセットパス一覧）再生する動画。Assets Windowから動画ファイルをこの項目へドラッグ&ドロップして割り当てることもできる。選び直すと、再生中・一時停止中でなければ新しい動画の最初の1フレームへプレビューが更新される
Loopチェックボックスループ再生するか
Volumeドラッグ入力欄（ステップ0.01、範囲0〜1）音量
Play On Awakeチェックボックスシーン開始時に自動で再生を開始するか
Route Audio Through AudioSourceチェックボックス有効にすると、再生開始時に同オブジェクトのAudioSourceへ動画の音声再生ハンドルを渡し、そのAudioSourceが持つ距離減衰・パン・各種エフェクトを動画の音声にも適用する（同オブジェクトにAudioSourceが無い場合は何もしない）。カーソルを合わせるとツールチップで説明が表示される

再生操作

ラベルウィジェット内容
Play / Resume / Pauseボタン状態に応じて表示が切り替わる。未再生時は"Play"、一時停止中は"Resume"、再生中は"Pause"
Stopボタン再生・一時停止のどちらでもない場合は無効化（グレーアウト）される。停止すると動画の最初の1フレームがレンダラーに表示され続ける
Play On Awakeが有効な場合でも、実際の再生開始はシーン再生（ゲームループ）が始まった最初のUpdateまで遅延されます。それまでの間（シーン読み込み直後やエディター編集中）は、動画の最初の1フレームがプレースホルダーとして表示されます。

Add Componentでの位置

Add Component → Video → VideoSource。最大付与数の制限はありません。
