Capsule2DCollider

カプセル（線分＋半径）形状の2D用コライダーです。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/06_Collision.htmlを参照してください。

Inspectorに表示される項目

基底クラスIColliderの共通項目を先頭に表示し、その下に形状固有の項目が続きます（表示順はソースコードのShowImGui()呼び出し順と同じ）。2D用コライダーはSync With Transformの項目がX/Yの2軸分のみになります。

ラベルウィジェット内容
IsTriggerチェックボックス有効にすると物理的な押し戻しを行わない「トリガー」として扱う。OnCollisionEnter等のコールバックは通常どおり発生する。既定 false
Continuous Detectionチェックボックス連続衝突判定（CCD）の有効/無効。ホバーすると「高速移動時のすり抜けでも衝突イベントを発生させる（連続衝突判定）」というツールチップが表示される。既定 false
Sync With Transform（区切り線の下の見出し）テキスト見出し以下のPos/Rotation/Scale同期チェック群のセクション見出し（クリック不可）
Pos X / Pos Yチェックボックス（2個、横並び）同オブジェクトのTransformのX/Y位置へ追従させるか。既定は全てtrue
RotationチェックボックスTransformのZ回転へ追従させるか。既定true
Scale X / Scale Yチェックボックス（2個、横並び）TransformのX/Yスケールへ追従させるか。既定は全てfalse（既存挙動を変えないための後方互換）
StartXYのドラッグ入力欄（ステップ0.01）カプセルの中心線の始点（ローカルオフセット、Syncされたスケールが乗算される）。既定 (0, -0.5)
EndXYのドラッグ入力欄（ステップ0.01）カプセルの中心線の終点（ローカルオフセット、Syncされたスケールが乗算される）。既定 (0, 0.5)
Radiusドラッグ入力欄（ステップ0.01、下限0）中心線からの半径。既定 0.5。実際の判定半径はこれにSyncされたTransformスケールのX・Y成分の大きい方を掛けた値
StartとEndはCenterではなく2点指定
他の2DコライダーのCenterとは異なり、Capsule2DColliderは中心線の両端点（Start / End）を個別に指定する方式です。Rotation同期が有効な場合、Start・Endともに同期後のZ回転で回転させたうえでワールド座標に反映されます。

Add Componentでの位置

Capsule2DColliderはCOMPONENT_CATEGORY("Collision")に属します。
