RigidBody3D

ReactPhysics3DのRigidBodyを内部で保持する3D用の物理挙動コンポーネントです。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/06_Collision.htmlを参照してください。

ICollider派生ではない
形状コライダー（BoxCollider等）は全てIColliderを継承しますが、RigidBody3DはIObjectComponentを直接継承する別系統のコンポーネントです（カテゴリは同じ"Collision"）。そのためIsTrigger・Continuous Detection・Sync With TransformといったICollider共通のInspector項目はRigidBody3Dには表示されません。「形状」はコライダー側、「物理的な動き（質量・重力・速度）」はRigidBody側という役割分担です。

Inspectorに表示される項目

見出しテキストの下に、開閉式のSettingsヘッダーで主要パラメータをまとめ、その外側にコライダー選択欄が続く構成です（表示順はソースコードのShowImGui()呼び出し順と同じ）。

ラベルウィジェット内容
RigidBody3D Component（見出しテキスト）読み取り専用テキストコンポーネント名を示す固定文言
Settings開閉式ヘッダー（CollapsingHeader）以下4項目を内包する。デフォルトは閉じた状態
Body Typeドロップダウン（コンボボックス、Static/Kinematic/Dynamic）物理ボディの種別。既定 Dynamic。変更すると即座に生成済みの物理ボディへsetType()で反映される
Massスライダー（範囲 0.1〜100）質量。既定 1.0。変更すると即座に生成済みの物理ボディへ反映される
Use Gravityチェックボックス重力の影響を受けるか。既定 true。変更すると即座に生成済みの物理ボディへenableGravity()で反映される
Interpolateチェックボックス既定 true。変更すると即座に生成済みの物理ボディのsetIsSleeping(!値)を呼ぶ（オフにするとボディをスリープ状態にする）
Collider Shapeドロップダウン（コンボボックス）物理ボディの形状として使う、同オブジェクト上の3D用IColliderコンポーネントを選択する。先頭の(Any)は未選択（どのコライダーでも使用可）を表す。候補はIs2D()がfalseのコライダーのみに絞られる
移動させただけでは物理ボディへ反映されない
エディタでオブジェクトをTransform経由で移動させても、既に生成済みの物理ボディの位置は自動的には追従しません（毎フレームのUpdateで行われるのは物理→Transformへの反映のみ）。Play開始時に古い位置（多くの場合は物理ボディ生成時点の位置）へ戻ってしまうのを防ぐため、C++側でSyncFromTransform()を呼んで同期を取る必要があります。この操作にInspector上のボタンはありません。

Add Componentでの位置

RigidBody3DはCOMPONENT_CATEGORY("Collision")に属します。
