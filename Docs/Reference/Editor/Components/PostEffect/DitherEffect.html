DitherEffect

4x4 Bayer行列のディザパターンを使って画面をフェードさせる、ディゾルブ風のポストエフェクトです。単一パスの宣言的エフェクトとして実装されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ DitherEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Intensityドラッグ入力欄（ステップ0.01、範囲0.0〜1.0）ディゾルブの進行度。0で無適用（元の画面のまま）、1で画面全体が消える。既定値 0.0
Colorチェックボックス消え残るピクセルを元の色のまま表示する（有効）か、輝度のみのグレースケールで表示する（無効）か。既定値 有効
仕組み
4x4 Bayer行列が持つ16段階の閾値を、ピクセルごとの「消える順番」として使います。Intensityがそのピクセルの閾値を超えると、そのピクセルは透明（アルファ0）になります。Intensityを0→1へ滑らかに変化させることで、市松模様が徐々に広がりながら画面全体が消えていくディゾルブ表現になります。
"Color" はブール値
Params::color という名前ですが、実体は色ではなく bool 型で、チェックボックス1つとしてのみ表示されます。オフにすると輝度のみにディザをかける（RGB共通のパターン）動作に切り替わります。色そのものを指定するColorPickerは表示されません。

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
