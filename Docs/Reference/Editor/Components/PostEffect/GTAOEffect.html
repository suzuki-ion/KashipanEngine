GTAOEffect

深度から位置と法線を再構成し、画面スライスごとの地平線角を積分する半解像度GTAOポストエフェクトです。時間蓄積を使わず、深度対応の分離フィルターとアップサンプルで安定した陰影を生成します。

付与の前提
同一オブジェクトに ScreenBufferObject が必要です。既存の SSAOEffect とは独立したエフェクトであり、通常はどちらか一方だけを有効にします。

Inspectorに表示される項目

ラベル内容
Radius遮蔽を探索するワールド空間半径。既定値 0.5
Intensity遮蔽の強さ。既定値 1.0
PowerAOコントラスト。既定値 1.0
Bias自己遮蔽を避けるワールド距離。既定値 0.02
Direction Count画面上の探索方向数（2〜8）。既定値 4
Steps Per Direction各方向の深度探索ステップ数（2〜12）。既定値 6
Blur Radius半解像度AOへ適用する分離フィルター半径（0〜8）。既定値 3
Depth Thresholdフィルターとアップサンプルの深度差許容値。既定値 0.5
Show AO Only合成前のAO係数をグレースケール表示するデバッグ切り替え。既定値 OFF

各項目にマウスホバーすると、効果と品質・負荷への影響を説明するツールチップが表示されます。

品質と負荷

AOは縦横1/2の中間ターゲットへ描画されます。負荷を下げる場合は Direction Count を先に減らし、品質を上げる場合は Steps Per Direction を増やします。専用法線バッファを持たないため、シルエット付近では深度から再構成した近似法線の精度に依存します。
