GaussianFilterEffect

ガウシアンぼかしポストエフェクトです。単一パスの宣言的エフェクトとして実装されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ GaussianFilterEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Radius整数ドラッグ入力欄（ステップ1、範囲0〜32）サンプリング半径（ピクセル）。既定値 3
Sigmaドラッグ入力欄（ステップ0.01、範囲0.01〜32.0）ガウス分布の標準偏差。値が大きいほどぼけが強くなだらかになる。既定値 1.0

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
