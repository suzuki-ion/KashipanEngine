MotionBlurEffect

前フレームのView-Projectionへ再投影して求めたスクリーンスペース速度をもとにブラーをかける、カメラ動作由来のモーションブラーです。オブジェクトごとの速度G-bufferは持たないため、カメラの移動・回転によるブラーのみが対象で、オブジェクト自身の動きには追従しません。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ MotionBlurEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Intensityドラッグ入力欄（ステップ0.01、範囲0.0〜5.0）ブラー全体の強さ。既定値 1.0
Velocity Scaleドラッグ入力欄（ステップ0.01、範囲0.0〜10.0）速度からブラー量への倍率。既定値 1.0
Max Blur Pixelsドラッグ入力欄（ステップ0.5、範囲0.0〜256.0、小数点以下1桁表示）ブラー量の上限（ピクセル）。既定値 32.0
Samples整数ドラッグ入力欄（2〜32にクランプ）ブラーのサンプル数。既定値 8

各項目にマウスホバーすると、上表の内容と同じ説明がツールチップとして表示されます。

カメラが未解決の場合の警告表示
このスクリーンバッファへ実際に描画したカメラが解決できていない場合、Inspector上に No camera resolved for this ScreenBuffer yet: Motion Blur will not be applied.（オレンジ色のテキスト）が表示されます。この状態ではモーションブラーは適用されず、元の描画結果がそのまま残ります。カメラ情報は Renderer が毎フレーム自動で注入するため、ユーザー側でNear/Far等を手動設定する必要はありません。

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
