VignetteEffect

画面周辺を減光するビネットポストエフェクトです。単一パスの宣言的エフェクトとして実装されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ VignetteEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
CenterXYのドラッグ入力欄（ステップ0.001、範囲-2.0〜2.0）減光の中心となるUV座標。既定値 (0.5, 0.5)（画面中央）
ColorRGBAカラーピッカー周辺減光の色（Vector4、アルファ含む）。既定値 (0, 0, 0, 1)
Intensityドラッグ入力欄（ステップ0.01、範囲0.0〜1.0）減光の強さ。既定値 0.0
Inner Radiusドラッグ入力欄（ステップ0.001、範囲0.0〜1.0）減光が始まらない中心からの半径。既定値 0.3
Smoothnessドラッグ入力欄（ステップ0.001、範囲0.0001〜2.0）Inner Radiusから外側にかけての減光の滑らかさ。既定値 0.3

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
