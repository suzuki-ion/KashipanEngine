LightRenderer

同一オブジェクトのLightとTransformからライト情報を取得し、Rendererが使う構造化バッファへ実際に送るコンポーネントです。Inspector上のUIはMeshRendererやCameraRenderer等と同じ「適用先の描画先／パイプライン」の指定のみで、Light固有のパラメータ編集項目はありません。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Targetコンボボックス（None選択可）適用先の描画先オブジェクトをシーン上から選択。ヒエラルキーからのドラッグ&ドロップにも対応。未指定（None）の場合は全ての描画先に適用される
Render Target Filter（折りたたみツリー）描画先ごとのチェックボックスTargetを指定し、かつそのオブジェクトが複数の描画先コンポーネントを持つ場合のみ表示
Pipelineコンボボックス（None選択可）読み込み済みのレンダーパイプライン名から選択。未指定（None）の場合は全パイプラインに適用される（既定は未指定）
これ自体にはLightのパラメータ編集項目が無い
色・強度・種類・シャドウ設定等はすべてLightコンポーネント側のInspectorで編集する。LightRendererのInspectorは「どの描画先／パイプラインに適用するか」だけを扱う。

Add Componentでの位置

Add Component›Render›LightRenderer から追加する。同一オブジェクトに複数付与可能。
