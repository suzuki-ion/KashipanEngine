ShadowMapObject

シャドウマップ専用のバッファ（ShadowMapBuffer）を1枚所有し、描画先として扱えるようにするコンポーネントです。UIはScreenBufferObjectとよく似ていますが、画像ファイル保存機能はありません。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlおよびEngine/11_Window.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Nameテキスト入力欄（Enterキーで確定）TextureManagerへの登録名。Enterキーを押すまでは値が確定しない（ImGuiInputTextFlags_EnterReturnsTrue）
Width整数のドラッグ入力欄バッファの幅（既定2048、下限1にクランプ）。変更すると生成済みバッファが実際にリサイズされる
Height整数のドラッグ入力欄バッファの高さ（既定2048、下限1にクランプ）
Open Viewer / Close Viewerトグルボタン押すたびに開閉する、バッファの内容を確認できる別のImGuiウィンドウ（"ShadowMapBuffer Viewer: 名前"）の表示状態を切り替える。SRVが未準備の間は「SRV not ready.」と表示される
ScreenBufferObjectと違い「Save to File」機能は無い
ScreenBufferObjectにある画像保存関連の項目（Directory/File Name Prefix/Format/Save Screenshot）はShadowMapObjectには存在しない。
Viewerはポーズ中も表示され続ける
ScreenBufferObjectと同様、ViewerウィンドウはShowPersistentImGui()経由で表示されるため、Inspectorが閉じていてもゲームがポーズ中でも表示され続ける。

Add Componentでの位置

Add Component›Render›RenderTarget›ShadowMapObject から追加する。同一オブジェクトに複数付与可能。
