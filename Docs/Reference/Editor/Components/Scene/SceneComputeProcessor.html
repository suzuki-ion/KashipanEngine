SceneComputeProcessor 最大1個

シーン内のComputeShaderProcessingコンポーネントを収集するシーンコンポーネントです。実際のDispatch呼び出しはRendererが毎フレーム、このコンポーネントが保持するリストを参照して行います。Scene Component Inspector上での見え方を説明します。C++側のAPIはEngine/02_Scenes.htmlを参照してください。

Inspectorに表示される項目

読み取り専用のテキスト表示のみです（ImGui::Text）。編集可能な項目はありません。

表示内容
ComputeShaderProcessing: N登録済みComputeShaderProcessingコンポーネントの数
一覧はComputeShaderProcessingを持つオブジェクトのInitialize時に自動追加され（未追加のシーンへは自動でこのコンポーネントが追加される）、Finalize時に自動で解除されます。Inspector上から個別のComputeShaderProcessingを増減させることはできません。

Add Scene Componentでの位置

Add Scene Component → Compute → SceneComputeProcessor。通常はComputeShaderProcessingを初めてオブジェクトへ付与した時点で自動的に追加されるため、手動でAdd Scene Componentから追加する機会は多くありません。
