ScenePreTransform 最大1個

シーン内のPreTransformコンポーネントを収集し、毎フレーム最後に前フレーム値を更新するシーンコンポーネントです。Scene Component Inspector上での見え方を説明します。C++側のAPIはEngine/02_Scenes.htmlを参照してください。

このコンポーネントに編集可能なInspector項目はありません
専用のShowImGui実装を持たないため、コンポーネント一覧を開いても基底クラス既定の None というテキストが表示されるだけです。更新優先度がSceneRenderer（1000）より大きい値（1001）に設定されており、そのフレームの全オブジェクト更新・全シーンコンポーネントの更新（描画を含む）が完了した後に、各PreTransformへ現在のTransform値を「前フレームの値」として書き込みます。

Add Scene Componentでの位置

Add Scene Component → Physics → ScenePreTransform。PreTransformコンポーネントを持つオブジェクトが機能するために必要なシーンコンポーネントです。
