InputCommandApplier

InputCommandの入力を、同オブジェクトの他コンポーネントのパラメータへ適用するコンポーネントです。1つのコンポーネントに複数の入力コマンド設定（コマンド名・条件・バインド先）を名前付きで登録できます。

  • 各設定エントリは識別名・評価するCommand Name・条件（Condition）・書き込む値（Value Source）・バインド先（Bindings）を持ち、インスペクターから登録します（スクリプトからの動的な追加/変更はできません）。
  • 条件（Condition）: コマンドがtrue / コマンドがfalse / 入力値が閾値以上 / 入力値が閾値以下 / 入力値が閾値と等しい（誤差1e-6以内）
  • 書き込む値（Value Source）: 入力コマンドの評価値 or 固定値。適用値は 値 × Value Scale + Value Offset です。
  • 適用先（Bindings・複数指定可）は KeyFrameAnimator と同じ仕組みで、同オブジェクトのコンポーネントのfloat系パラメータまたは ScriptComponent の [SerializeField] 付き float 変数をコンボから選択します。
  • 毎フレーム条件を評価し、条件を満たしたフレームだけ値をバインド先へ書き込みます。
メソッド説明
bool WasApplied(const string &in name) const指定した名前の設定エントリが、前回のUpdateで条件を満たして値を適用したかどうか
bool TryGetLastValue(const string &in name, float &out value) const指定した名前の設定エントリが前回適用した値（Scale/Offset適用後）を取得する。名前が一致するエントリが見つかった場合にtrueを返す（未適用の間は前回値を保持する）
uint GetCommandCount() const登録されている設定エントリの数を取得する
