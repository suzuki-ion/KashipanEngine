Capsule2DCollider

カプセル形状の2D用コライダーです。コンポーネント共通メソッドと、コライダー共通メソッド（07_ColliderAndPostEffect.html参照）に加えて以下を持ちます。

メソッド説明
GetStart/SetStart（Vector2）カプセルの始点
GetEnd/SetEnd（Vector2）カプセルの終点
GetRadius/SetRadius（float）半径
