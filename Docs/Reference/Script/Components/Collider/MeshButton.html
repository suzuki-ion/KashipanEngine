MeshButton

3Dオブジェクト（MeshRenderer/SkinnedMeshRenderer）に対するマウスのホバー・押下・クリック判定を行うコンポーネントです（UIButtonの3D版）。見た目の描画は一切行いません（同一オブジェクトのメッシュを、そのまま当たり判定に使う「透明な当たり判定レイヤー」）。

同オブジェクトにMeshRendererまたはSkinnedMeshRendererがあれば（MeshRendererを優先）、同じくMeshFilterが持つメッシュのローカル空間バウンディングボックスへ、マウス位置から表示カメラ（Camera3D）を通したレイを飛ばして交差判定します。SkinnedMeshRendererは常にこのバウンディングボックス判定のみで、ボーン変形後の見た目には追従しません（GPU側でスキニングした結果をCPUから直接読めないため）。
