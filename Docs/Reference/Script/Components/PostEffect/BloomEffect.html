BloomEffect

ScreenBufferObjectが付与されたオブジェクトに追加すると、そのスクリーンバッファへエフェクトがかかるポストプロセスエフェクトです。

コンポーネント共通メソッドに加えて以下のGet/Setを持ちます。

メソッド
GetThreshold/SetThreshold, GetSoftKnee/SetSoftKnee, GetIntensity/SetIntensity, GetBlurRadius/SetBlurRadius（すべてfloat）, GetIterations/SetIterations（uint、ダウンサンプル段数1〜16）
