Camera2D

2D用の平行投影カメラのパラメータを保持するコンポーネントです。

メソッド説明
void SetSize(float width, float height)表示範囲サイズを設定する
void SetNearClip(float) / float GetNearClip() const近クリップ距離
void SetFarClip(float) / float GetFarClip() const遠クリップ距離
float GetWidth() const / float GetHeight() const表示範囲サイズを取得する
void SetAutoSyncSize(bool) / bool GetAutoSyncSize() const描画先バッファの解像度へ表示範囲サイズ（width/height）を毎フレーム自動追従させるかどうか（描画先が単一に定まらない場合は手動設定値のまま何もしない）
