TilemapRenderer

RPGツクール風のオートタイル（隣接する同種タイルに応じてテクスチャを自動で切り替える）に対応したタイルマップ描画コンポーネントです。自身はSceneRendererへ描画登録せず、同一オブジェクトのMeshFilter/SpriteRendererを自動追加して駆動します（ScreenBufferViewportと同じパターン）。タイル配置が変わるたびに1枚の結合メッシュを再構築するため、タイル数が多くても描画コストは1オブジェクト分のドローコールに収まります。

タイルセット・オートタイル設定

メソッド説明
void SetMaterialName(const string &in) / const string &GetMaterialName() const使用マテリアル名
void SetPipelineName(const string &in) / const string &GetPipelineName() const使用パイプライン名
void SetTileSize(const Vector2 &in) / const Vector2 &GetTileSize() const1タイルのワールド空間サイズ
void SetTilePixelSize(const Vector2 &in) / const Vector2 &GetTilePixelSize() constタイルセット画像上での1タイルのピクセルサイズ
void SetGenerateColliders(bool) / bool GetGenerateColliders() constSolidなタイル種類のセルへ2D当たり判定を自動生成するかどうか
void SetAutotileMode(int) / int GetAutotileMode() constオートタイルの判定方向。0=FourDirection（既定、上下左右4方向のみで判定） / 1=EightDirection（斜め4方向も含めて判定し、4分割合成する）
タイルセット画像のレイアウトはAutotileModeで異なる
FourDirectionは1タイル種類につき4x4=16パターンのブロックを、EightDirectionは2列×3行のブロック（Isolated/Cross/2×2の角4種）を前提とします。切り替えると見た目が変わります。
