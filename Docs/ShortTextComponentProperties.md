# 短文から実際のコンポーネントを付与する（「〇〇の〇〇」文法）

短文の挙動ウィンドウ（**試験機能 → 短文の挙動**）で、コンポーネントの項目を名指しする文章を入力すると、
汎用レシピ（ShortTextBehavior）ではなく、**実際のコンポーネントを追加・設定**します。
解釈はローカルの文法と辞書だけで行い、実行時のAI・通信・生成スクリプト・外部キーフレームファイルは使いません。

## 入力できる文の例

| 入力 | 適用されるもの |
| --- | --- |
| Transformの移動X軸を-1.0fから1.0fの間で往復移動 | PropertyMotion（Transform.translate_.x を -1〜1 で往復） |
| Transformの回転Y軸を-90.0fから90.0fの間で往復 | PropertyMotion（Transform.rotate_.y を -90〜90 度で往復、内部はラジアン） |
| BoxColliderのサイズX軸を1.0fから3.0fの間で往復 | BoxCollider（無ければ追加）＋ PropertyMotion（size_.x を 1〜3） |
| BoxColliderのサイズX軸を2.0fにする | BoxCollider（無ければ追加）の size_.x を編集時に 2 に設定 |
| Transformの移動 X 軸を -1 から 1 まで往復移動 | 空白・f なし・「まで」も同じ意味 |
| Transformの移動Y軸を0から2の間で周期4秒でなめらかに往復 | 周期4秒・なめらか（サイン）方式 |
| Transformの回転Z軸を-1.5ラジアンから1.5ラジアンの間で往復 | ラジアンを明示（そのまま書き込み） |
| Box2DColliderのsize_ Y軸を0.5から1.5の間で往復 | 登録メンバー名（正式名）でも指定可能 |

数値だけが違う文（例：「Transformの移動X軸を-3.5から2の間で往復移動」）も、学習なしで文法として解析します。

## 文法

```
<コンポーネント>の<項目>[<軸>]を <A>から<B>の間で 往復[移動/回転]   … 往復（PropertyMotion）
<コンポーネント>の<項目>[<軸>]を <N>にする / に設定 / に変更         … 設定（編集時に一度だけ）
```

- **コンポーネント**：登録済みの型名（大文字小文字は区別しない）。別名：トランスフォーム、ボックスコライダー、ボックス2Dコライダー。
- **項目の別名**
  - Transform：移動・位置・座標・平行移動・position → `translate_`／回転・角度・向き・rotation → `rotate_`／大きさ・拡縮・拡大縮小・スケール → `scale_`
  - コライダーなど：サイズ・大きさ・寸法 → `size_`／中心・中心位置・センター → `center_`
  - 正式名（`translate_`、`translate`、`size_` など、登録メンバー名）も使えます。`translate.x` のように成分を続けても構いません。
- **軸**：X軸／Y軸／Z軸（全角・空白可）。「移動X軸を」「X軸の移動を」どちらでも可。Vector2 にZ軸は指定できません。
- **数値**：負数・正数・小数、末尾の `f`/`F` は任意（`-1.0f`）。全角数字・全角マイナスも可。
- **範囲**：「AからBの間」「AからBまで」「AからBまでの間」「AからBの範囲」。**A < B** が必要です（逆順や同値は拒否）。
- **周期**：「周期N秒」「N秒周期」「1往復N秒」。**未指定なら1往復2秒**。
- **方式**：既定は一定速度（三角波）。「なめらかに／滑らかに」でサイン、「一定速度で／等速で」で三角波を明示。
- **単位**：Transformの回転は**度**として解釈し、内部ではラジアンに変換して書き込みます。「ラジアン」「rad」を付けた場合だけ、そのまま書き込みます。度・ラジアンの指定は回転以外には使えません。

## 往復の意味（PropertyMotion）

- 端点は**ローカルの絶対値**です。初期 X=5 の対象でも、再生中の X は -1〜1 の範囲に収まります。
  既存の「X軸で振幅1で往復」（現在値を中心とした加算往復）とは別物です。
- 時刻0で開始値、周期の半分で終了値、1周期で開始値へ戻ります。
- **再生中だけ**動作します。適用しても編集中の値は動かさず、停止すると再生前の値へ戻ります。
- 指定した成分だけを書き込みます（Y/Z や他のコンポーネントはそのまま）。書き込みは登録済みのセッター経由です。

PropertyMotion は通常のコンポーネント（カテゴリ Animation）で、Add Component からも追加できます。
Inspector で **対象コンポーネント／同じ型の番号／プロパティ／成分／単位／開始値／終了値／周期（1往復の秒数）／方式** を確認・編集できます。
不正な値（開始値 ≥ 終了値、サイズ等が0以下、周期が0.05〜3600秒の外）は反映しません。
Clone・シーン保存/読込・Undo/Redo に対応しています。

## 適用時の構成（Undo 1回で戻せる）

「解釈する」を押すと、適用内容と、自動では設定しない内容をプレビューします。適用は1つの CompositeCommand です。

- 対象のコンポーネントが無ければ既定値で追加します（例：BoxCollider）。あれば再利用します。
  素材・参照先が必要な型（AudioSource 等）は追加しても素材は設定しないことを明示します。
- 「Nにする」は実コンポーネントの値を編集時に直接設定します（Inspector で確認できます）。実行用の部品は作りません。
- 往復は、同じ項目（型・番号・メンバー・成分）の PropertyMotion があれば**更新**し、なければ追加します。同じ文を再適用しても増えません。
- 短文由来（shortTextManaged）の PropertyMotion と、旧方式の ShortTextBehavior（往復・回転・移動）が同じ Transform の項目を動かす場合、
  新しく適用した方へ置き換えます（旧い方を Undo 可能な形で削除）。手動で作った PropertyMotion や、別の項目を動かす部品は削除しません。
- 「Nにする」を適用すると、同じ項目を往復させていた短文由来の PropertyMotion は削除します（手動のものは残し、上書きされる旨を表示）。

## 拒否する入力（シーンは一切変更しない）

範囲の逆転・同値、±10000 を超える値・非有限値、未登録のコンポーネント/項目、読み取り専用の項目（`worldMatrix_` 等）、
数値以外の型、Vector の軸未指定（軸は推測しません）、Vector2 へのZ軸、コライダーのサイズ・半径や Transform のスケールの0以下、
周期の範囲外・重複、範囲なしの「往復」、度/ラジアンの誤用、PropertyMotion 自身を対象にする指定。

## 旧レシピ（ShortTextBehavior）の必要部品

既存の486例文・学習辞書のレシピはそのまま ShortTextBehavior として適用されます。適用時に必要部品を判断し、
素材や形状を推測せずに追加できるもの（Velocity、プロパティ指定で参照された BoxCollider / Box2DCollider / SphereCollider / Circle2DCollider）は
同じ CompositeCommand で事前に追加します。接触イベントのCollider（形状未指定）、音（AudioSource と音声ファイル）、文字表示、
RigidBody / CharacterController（2D/3D未指定）、パーティクル等はプレビューに「必要な設定」として表示し、自動では作りません。
他のオブジェクトを操作する動作は、適用時に相手の部品を確認しません。

## 制限

- 1文で1項目・1成分です。複数軸や複数項目は文を分けて適用してください。
- 往復以外の時間変化（片道・イージング曲線の詳細指定）や、同じ型の2番目以降のコンポーネントの文章指定は未対応です（Inspector では番号を指定できます）。
- 「〇〇の〇〇」文法の文は学習辞書への登録対象ではありません（文法が直接解析します）。学習済み・標準の例文が文章全体に一致した場合はそちらが優先されます。
- GUI・GPU・実機での見た目は、ヘッドレス回帰テストでは確認していません。

## 一回だけの変化（KeyframeAnimation の生成）

「1秒かけてTransformの移動Y軸を0.0fから4.0fまでEaseInOutCubicで移動」のように「N秒かけて」とイージングを付けると、
往復ではなく本物の KeyframeAnimation を KeyFrameAnimator に登録します。詳しくは [ShortTextKeyframeTween.md](ShortTextKeyframeTween.md) を参照してください。
