# コンポーネント・項目の別名と成分の一括指定

短文の「コンポーネント名の項目名」に、複数の別名を登録しています。
登録済み108コンポーネント（オブジェクト98・シーン10）の名称と、474公開登録メンバーの別名をカタログ化しました。正式な型名・メンバー名も使えます。

```text
Lightの色を(0.5f, 0.5f, 1.0f, 1.0f)にして
光源のカラーを(0.5, 0.5, 1, 1)に設定
ライトの光の色を(0.5, 0.5, 1, 1)にする
Transformの移動を(1, 2, 3)にする
Box2DColliderのサイズを(2, 3)にする
```

## 適用

- 成分の一括設定はVector2/Vector3/Vector4/Colorに対応します。項目の成分数と値の数は完全に一致する必要があります。数値1つの項目へ4成分を代入したり、足りない成分を推測して埋めたりしません。
- f/F付き数値、空白、全角数字・括弧・カンマを受け付けます。各成分は有限値かつ-10000～10000です。スケール・Colliderサイズなど既存の正値制約も守ります。
- 「X軸」と成分の一括指定は併用しません。一括指定は固定値設定です。ベクトル全体のTween/往復をこの文法で暗黙生成するものではありません。
- 適用は編集時に一度行います。必要なコンポーネントを追加し、登録セッター経由で設定します。コンポーネント追加・設定・同じ項目を駆動する短文由来アニメーションの置換をまとめてUndo/Redoできます。
- 手作りのアニメーションは削除せず、同じ項目を駆動する場合は注意を表示します。
- 別名は権限や対応型を変えません。読み取り専用、非公開、数値・ベクトル以外の未対応型には、この文法で書き込めません。シーンコンポーネントの名称もカタログに含みますが、選択オブジェクトのプロパティ設定はオブジェクトコンポーネントが対象です。

## 別名の管理

`EditorTools/ShortTextPropertyAliases.json` が編集用カタログ、`Utilities/ShortTextPropertyAliasCatalog.generated.h` が実行用の生成テーブルです。
GPT-6 Luna（medium）サブエージェントでサンプルを確認してから分担登録し、正式名・登録漏れ・同一範囲内の別名衝突を検証しています。要素名はコンポーネントごと、コンポーネント名はobject/scene範囲ごとに管理します。

別名を追加した場合は次を実行して生成テーブルを更新し、エンジンを再ビルドします。

```powershell
python EngineTools/GenerateShortTextPropertyAliases.py
```

存在しない型、source evidence不一致、重複、曖昧な別名は生成時に拒否します。実ネイティブレジストリと全公開メンバーの一致は`ShortTextPropertyAliasRegression.cpp`で検証します。将来コンポーネントや登録メンバーを増やした場合はこのテストが登録漏れを検出します。

## 検証

- `RunShortTextPropertyRequestRegression.ps1`: 別名、数値・全角4成分、Vector2/3、型・成分数・範囲の拒否、従来のscalar/往復/Tween文法。
- `RunShortTextDomainRegression.ps1 -SourceFile ShortTextPropertyAliasRegression.cpp`: 全実レジストリ、公開メンバー、実際のLight追加と色設定、Undo/Redo、保存・復元、成分数不一致の非変更。

これはソース・headless検証です。実際のGUI操作や照明の描画確認とは区別します。
