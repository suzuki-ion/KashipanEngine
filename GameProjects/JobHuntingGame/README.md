# Light Town 試作

横スクロールの素材収集と箱庭街づくりを往復する、仮モデルによるゲーム仕様検討用プロトタイプです。
エンジン側では、Letterbox表示時のUIButton座標変換を補正しています。

## 起動と操作

JobHuntingGameを開き、起動シーンの **TitleScene** をPlayしてください。
配布実行では `KashipanEngine.exe --project JobHuntingGame` を使用します。

| 場所 | 操作 |
|---|---|
| タイトル | 「はじめから」「つづきから」「設定」「終了」。セーブがなければ「つづきから」は無効 |
| タイトル | セーブがある場合の「はじめから」は、4秒以内の再クリックで上書き |
| 街 | Bまたは「建築」で建築メニューを開閉。表示中に行または数字1〜7で施設・道路を選択し、同じマスで左ボタンを押して離すと建築 |
| 街 | 建築メニュー上のホイールまたは▲▼で縦スクロール。「削除」を選び、施設・道路をクリックして削除（返金なし）。派遣中のギルドは帰還後に削除可能 |
| 街 | 右ボタンドラッグでカメラ自身の位置を中心に回転。中ボタン（ホイール押し込み）ドラッグでカメラの右・上方向へ移動 |
| 街 | WASDでカメラの右・前方向へ移動。上下角度も反映。設定表示中とウィンドウ非フォーカス時は停止 |
| 街 | マウスホイールで視線方向へ前進／後退。1ノッチ2.5。UI上のスクロールでは移動しない |
| 街 | 緑は稼働可能な建築、黄は建築できるが道路・照明不足、赤は占有・素材不足・条件不足 |
| 街 | Tabまたは「素材集めに出発」で遠征へ |
| 街 | 稼働中のショップがあれば「ショップ」で商品一覧を開く。変身は現在販売停止中 |
| 街 | 建築メニューを閉じ、マップのギルドをクリックして「NPC派遣」。ギルドごとに45秒後に素材獲得 |
| 街 | 「保存」で手動保存。「初期化」は3秒以内の再クリックで初期化 |
| 街 | 「設定」またはEscで設定画面を開く。設定表示中は街の時間を停止 |
| 遠征 | A/Dまたは左右矢印で移動、Spaceでジャンプ。変身入力は現在無効 |
| 遠征 | J／左クリック／ゲームパッドXで向いている側へ攻撃。資材の耐久値を0にすると採集 |
| 遠征 | ランダム位置の光の門に到着するかEscで街へ帰還。ゲート座標は左下に表示 |

ホイールは `GetCommandValue` が±1へ制限した値を使います。カメラはその値×2.5m、建築リストはその値×30の論理座標分を反映し、生のホイール単位120で再除算しません。

遠征では既存プレイヤーの移動・変身処理を利用しています。既存のゲームパッド用プレイヤー入力も残しています。
プレイヤーの移動・ジャンプ・接地・滑りの値、形態用コライダー、着地音・パーティクル・ライトは `GameDefaultObjects.prefab` を基準にしています。
通常形態の表示は更新版の添付 `box_humanoid_rigged.glb` を使用します。人型モデルを `PlayerHumanoid` 子オブジェクトへ配置し、判定は幅1m×高さ2m×奥行き1mのBoxCollider、SphereColliderは無効にしています。足元を判定の底へ揃え、モデルの静止時の高さも2mに合わせています。モデルだけを左右へ向けるため、通常形態の判定は直立したままです。遠征シーンとデフォルトプレハブに同じ構成を設定しています。
GLBは `Assets/Application/Models/Player/` に元ファイルのまま保存しています。AnimatorとSkinnedMeshRendererで28ボーンを再生し、通常のメッシュ描画は箱・円錐への変身時に使用します。
`Player/PlayerAnimation.as` がUAL_Idle_Loop・UAL_Walk_Loop・UAL_Sprint_Loopを移動状態で切り替え、採集対象が正面にある攻撃はUAL_Sword_Attack、それ以外はUAL_Punch_Crossを再生します。Sprintは水平速度5以上で選ばれる見た目の切替で、移動性能は変更しません。上昇中はJump_Startを1回再生して最終姿勢を保ち、頂点以降の落下中はFall_Loopをループ再生します。ジャンプ／落下クリップは元GLB内でUAL_接頭辞が付いていないため、そのままの名前で参照します。
確認用のRig_Checkや旧クリップを含む全13クリップを保持し、通常操作では上記7種類を使います。採集時のツルハシはGLBのWeaponSocket_Rへ接続し、手のアニメーションに追従します。人型の被ダメージ点滅もSkinnedMeshRendererへ反映します。
変身の実装・入力定義・既存セーブの解放情報は保持しますが、`LightTown/TownFeatures.as` の仕様フラグでプレイヤー入力と購入を無効化し、ショップの商品一覧から除外しています。旧解放済みセーブでも変身できません。
遠征カメラも同プレハブの軸別追従補間、オフセット、進行方向の先読みターゲットと `TargetLookAt` を使用します。
環境パーティクル・環境光・DeathLineも同プレハブから取り込み、参照先を現在のシーンへ接続しています。
街の建築操作はマウス・キーボード向けです。

## 仮のルール

- 資源：木材・石材・光結晶。初期資源あり。
- 街の4パラメータ：光エネルギー（0〜2046）・幸福度・治安・繁栄度（0〜100）。光の生産とセーブ読込の両方に上限を適用します。
- 10秒ごとに基礎収入。稼働中の工房があれば、光エネルギーが足りるときに追加生産。
- 道路は木材1・石材1で建築でき、上下左右の道路へ自動接続。施設には四方向いずれかの道路隣接と街灯の照明が必要。
- 街灯は道路に隣接すると点灯し、自身も照らす。最初は道路、街灯、その他の施設の順に建築できる。
- 稼働中の街灯は光の供給と治安、住宅は幸福度、稼働施設数と幸福・治安は繁栄度へ影響。
- 稼働中の工房・ショップ・ギルドは光を消費。道路または照明が不足する施設は灰色になり、生産・購入・派遣・目標条件に寄与しない。
- 40秒ごとに治安・幸福・光・繁栄に応じて盗難、寄付、光の祭りなどを抽選。
- 派遣中も街の生産も、遠征シーンへ移動した後に継続。
- ギルド1棟につきNPCを1組派遣でき、別々のギルドから同時派遣可能。帰還報酬は1組につき木材20・石材15・光結晶6。派遣開始後は、そのギルドが未稼働になっても帰還まで進行します。
- 最終目標は光の塔の稼働。先に稼働施設8棟（道路を除く）、光80、繁栄60、木180・石140・結晶65が必要。塔自身にも道路と照明が必要。
- クリアすると中央にCLEAR画面を表示して街の時間・操作を停止。「ゲームを続ける」で街づくりを再開、「保存して終了」でアプリを終了します。選択を保存し、続行後のシーン移動・再起動では再表示しません。未選択のまま終了した場合は再表示します。
- 基礎収入と工房だけでもクリア可能。遠征は素材収集を加速する手段。

施設コスト・初期資源・周期・派遣報酬・目標値は
`Assets/Application/Data/LightTownRules.json` で調整できます。
生産・イベントの計算式は `TownState.as` にあります。

- **TitleScene**：仮タイトル、セーブの有無の判定、新規開始・続行・設定・終了。

## WFCの試作範囲

遠征は標準で4×4の16部屋、幅66・高さ60の有限ステージです。接続口の位置を合わせ、洞窟・工場風の閉じた空間を通路と縦穴で接続します。部屋は平地・上段足場・斜面・上段の棚の4種類の構成から選びます。
横長の地面を各階に並べる構成から、壁・天井がある部屋を探索する構成へ変更しています。
ランダムな全域木へ接続を追加して分岐・行き止まり・周回路を作り、開始地点はランダム、ゴールは接続距離が最も遠い部屋から選びます。
岩盤／工場躯体の掘削マスクから地形を作り、連続する固体を矩形へまとめて描画と衝突に使用します。
縦穴は列ごとに軸を揃え、幅1.8の足場を左右交互に配置します。14の高低差を6段でつなぎ、各段の高さは約2.33です。足場を密に置きすぎて頭上を塞がないようにしています。
PlayerのjumpPower・gravity・maxVelocityを読み、通常形態のジャンプ軌道と頭上・着地面を検証します。重力は既存移動処理と同じgravity×60、水平速度は最大値の75%を使います。
歩行には連続した支持床を要求し、落下は足場の縁まで歩いてからの軌道を検証します。ジャンプは一定速・前半に横へ抜ける・後半に横へ進む3種類の軌道を120分割/秒で調べます。固定足場は実際に生成するBoxと同じデータ、斜面は保守的な外接矩形を使います。
開始から全採集部屋への到達と、ゴールから逆方向に探索した各部屋からの帰還可能性を確認します。不成立なら追加の斜面・段差を外して再検証し、それでも失敗した場合だけ平坦な連結廊下へ切り替えます。代替構成も同じ検証を通らなければ遠征を開始しません。
テレポートは近道として配置し、通常の接続経路は通路と縦穴で確保します。全ステージの手動走破確認は未実施です。

WFCは各部屋の草地・森林・採石地・結晶地のバイオームを決めます。通行の検証は接続グラフ・部屋テンプレート・移動可能な足場グラフが担当します。
部屋のバイオームに応じて背景、岩や配管・機械の装飾、収集素材を配置します。3種類の素材の部屋を毎回確保し、最大4回のWFC生成に失敗した場合も代替バイオームで地形を生成します。
`stageColumns` は12ごとに部屋列が1列増え、3〜5列に制限します（既定48で4列）。同じシードでは同じ配置になります。
旧GameSceneの蛍光灯（2本のチューブ光源）と壁掛けライト（スポット＋点光源）は、器具のモデル階層・材質・光源設定を取り込んだテンプレートから複製します。
蛍光灯は各部屋の天井に、壁掛けライトは部屋・接続通路・縦穴へ配置します。影のON/OFFと解像度は設定画面に連動します。
生成用の蛍光灯・壁掛けライトは階層内のコライダー自体を取り除いています。照明器具の見た目と光源を残し、上下移動を妨げない装飾として扱います。無効フラグだけでは複製後に衝突が残るため、生成テンプレートから除去しています。
敵・移動床・回転床・テレポート・チェックポイントは既存プレハブを取り込んだテンプレートから子階層ごと複製します。
メッシュ・マテリアル・軸・ライト・パーティクルを維持し、チェックポイントの回転部品と転送先は複製先へ再設定します。
移動床は `MoveGround.as`、回転床はプレハブの `Rotation`、テレポートは `TeleportFloor.as`、
チェックポイントは `Checkpoint.as`、敵は `Enemy.as` を使用します。
テレポートの出口は相手トリガーから離して配置し、プレイヤー以外の転送は制限しています。
生成する転送床はトリガーとして扱い、衝突通知後の更新で転送します。移動する1フレームだけ各プレイヤーコライダーのCCDを停止して元の設定へ戻し、転送経路上の壁による押し戻しを防ぎます。`TeleportFloor.as` の既定動作は維持し、遠征の生成時だけこの処理を有効にします。
開始地点・ゴール・チェックポイント・転送入口／出口の部屋には敵を重ねません。
落下やHP切れでは最後のチェックポイントへ復帰し、速度・HPをリセットします。
移動床と回転床は上下接続のない部屋の上段へ配置し、通常ルートの通行条件に含めません。既存プレハブを0.65倍にし、移動床の移動距離を1に抑えています。
到達判定は通常形態の移動を近似した幾何検証です。全シードで実際のプレイヤー入力・加速・衝突応答を再現する完全な自動走破や、敵との戦闘・可動床の待ち時間まで含めた検証ではありません。

生成地面は `ExpeditionGroundTemplate` を複製します。単位BoxColliderの位置・回転・スケールを全軸同期し、
平地・斜面・移動床・回転床で描画形状と衝突形状を一致させます。

## 攻撃と資材採集

木材は丸太の束、石材は岩塊、光結晶は結晶群のオリジナルOBJを使用します。生成元は `Tools/GenerateResourceModels.py`、モデルは `Assets/Application/Models/Resources/` です。
資材への接触だけでは獲得しません。J・左クリック・ゲームパッドXでツルハシを振り、0.09秒後に向いている側の近距離へ1回だけ命中判定を行います。攻撃間隔は0.45秒、表示は0.3秒です。壁や固定足場を挟む資材には当たりません。
耐久値は木材3・石材4・光結晶5です。命中時は揺れ・点滅と2.5秒間の耐久バーを表示します。0になった時だけ木材4・石材4・光結晶3の該当資材を加算・保存し、同じ資材から重複獲得しません。
通常の人型で攻撃・採集できます。既存の敵の踏みつけと変身時の衝突攻撃のコードは維持しますが、変身入力は現行仕様では無効です。今回の近距離攻撃の対象は採集用資材です。残り耐久値は遠征の作り直し時に初期化します。

## 街のグリッドとカーソル

グリッドは各交点の小さな正方形Boxと、その間の細長いBoxで構成します。
隣接セルでは角を共有します。角の幅は0.12、レール長は1.18、セル幅は1.5で、角とレールの間に0.10ずつ隙間があります。
角とレールの全833個には `TownGridUnlit.mat` を適用し、ライティングと影の投影を無効にしています。街の被写界深度は選択セルへ滑らかに合焦します。
旧グリッドの線と生成スクリプトは無効化して保持しています。

セルカーソルは専用の `TownCursor.mat` と `Town.Cursor` パイプラインを使用します。
アルファブレンドで半透明にし、1.2秒周期でアルファを0.16〜0.44の間で変化させます。深度には書き込まず、影を落としません。
右・中ドラッグ中およびWASD移動中は建築クリックをキャンセルします。

## 保存と現在の制限

実行時の `SaveData/LightTown.json` に建物の種類・セル、素材、4パラメータ、変身解放、派遣残り時間などを保存します。
派遣中フラグ・残り時間・所要時間は各ギルドの建物データに保持します。旧形式の街全体で1件の派遣データは、既存ギルド1棟へ一度だけ移行します。
このフォルダはGit管理対象外です。建築・購入・収集・帰還・周期更新時に保存します。
初期化はこの試作ゲームの進行状況だけを対象とし、CitySceneの元データは削除しません。

ゲーム終了中の経過時間は計算しません。建物は1マス固定で、撤去・複数マス占有・住民の経路探索は未実装です。道路は局所的な隣接判定で、拠点までの道路網接続は要求しません。
道路も既存のセーブ形式に種類6として保存します。旧セーブの施設は保持されますが、道路がない施設は道路と照明を整えるまで灰色になります。
光は街全体の数値資源として扱い、影や反射を測って供給量を計算する方式ではありません。
施設は `Application/Models/Town/` の6種類のオリジナルOBJモデルです。街灯はランタン付き支柱、住宅は切妻屋根と窓、工房は煙突、ショップは庇と看板、ギルドは正面柱と旗、光の塔は段状台座と結晶の尖塔で区別します。
生成元は `Tools/GenerateTownModels.py` です。建築セルとセーブ形式は維持し、旧セーブの施設も新モデルで表示します。
画面は1280×720の固定論理座標です。3Dカメラは透視投影を使います。
グリッドはCityScene内に保存されているため、Play前の編集時にも表示されます。各セルの下には薄い地面Boxを生成します。シーン開始時は地面・グリッド・施設をセル単位でまとめ、中心から距離に応じて遅延させて下から上へ移動します。`EaseOutBack` で少し行き過ぎてから目標位置へ収束し、登場中はセルへの建築を抑止します。

街と遠征の共通平行光源・色補正・Bloom・背景色を揃え、街だけの追加平行光源を無効化しています。稼働中の各施設には補助ポイントライト（強度0.06・半径2.7・影なし）を追加し、未稼働施設は消灯します。この補助光は施設の稼働条件に含めません。街灯は強度1.3、浮遊光は半径2.2・強度0.0312〜0.048で明滅します。
街灯は強度1.0の暖色ポイントライトです。光源のXZ位置をセル中心に揃え、地表の半径4.5に合わせて3D半径を約4.82に設定します。稼働判定はセル中心からの水平距離で左右対称の円形にし、円形の範囲表示と対象セルの半透明色で示します。影や遮蔽物による照度の測定は行いません。
ホタルは画面上の「光」エネルギー1につき1匹、最大2046匹です（光結晶の個数ではありません）。弱いポイントライトと、カメラに正対する黄色い発光円盤・ハローを同じ位置で移動させます。減少時は余ったホタルを休止し、再増加時は再利用します。個数が変化しても既存ホタルの軌道は維持し、ホタルには影を生成しません。

### 街のUI

木材・石材・光結晶・光は専用の透過PNGアイコンとともに画面上部に表示します。アイコンの生成元は `Tools/GenerateTownResourceIcons.py` です。増加は緑の「+32」、減少は赤の「-16」のように表示し、1.3秒で上へ移動しながら消えます。
幸福・治安・繁栄にも専用アイコンを表示します。光は資材行の光アイコンと兼用します。
施設設置時はカメラに正対するビルボードで効果予告を表示し、2.6秒かけて上昇・フェードアウトします。街灯は光+12と治安+2を10秒ごと、住宅は幸福+1を10秒ごとの効果として示します。施設による繁栄への寄与は+5と表示します。いずれも既存の生産・計算式を維持した効果予告で、建築時の即時加算ではありません。上限や街全体の収支により実際の増減値は変化します。未稼働の施設には「稼働時」と付記します。
工房の上には実際の共通生産周期に連動する緑色のバーと残り秒数を表示します。未稼働時は「停止中」、光が10未満のときは「光不足」を付記します。派遣中のギルドには、そのギルド固有の帰還時間に連動する青色のバーを表示します。
建築メニューを閉じた状態でマップのギルドをクリックすると専用パネルが開き、座標・帰還までの時間・報酬を確認してNPCを派遣できます。複数ギルドの同時派遣に対応し、同じギルドの派遣中の再派遣は拒否します。下部の「ギルド選択」ボタンは選択方法を案内します。建物の高さを含む選択範囲で、屋根や壁を押しても対象施設を選びます。
建築メニューは初期状態で非表示です。専用のFHD `TownBuildScreen` に370×550の論理座標で描き、幅370×高さ550のパネルとして表示します。0.28秒で左の画面外からスライドし、閉じる際も画面外へ移動します。移動中の見えている範囲だけを描き、Letterboxの余白へはみ出さないようにしています。
施設・道路7種類と「削除」の計8行があり、ホイール・▲▼で上下にスクロールできます。ヘッダー・フッターは固定し、リスト部分のボタンだけを選択できます。施設・道路の名称・費用の横には、専用256×256オフスクリーンで回転させたモデルを56×56で表示します。各行全体の350×56領域をUIButtonで選択でき、選択行には背景色と矢印カーソルを表示します。非表示中はアイコン・パネル描画も停止します。削除項目にはごみ箱アイコンと返金なしの説明を表示します。
施設設置時、道路への隣接または照明が不足していれば、該当する理由を赤字と警告アイコンで効果予告と同じビルボードに表示し、上昇しながらフェードアウトします。
ランダムイベントは右端から0.4秒で滑り込み、約5秒の表示時間で退出します。左上の×ボタンで即座に閉じられ、残りの通知が滑らかに詰まります。同時表示は最大3件で、残りは順番に表示します。未表示イベントはシーン移動とセーブをまたいで保持します。
ショップは専用のFHDオフスクリーンへ商品名・価格・購入ボタンを描画し、背景には街を表示します。商品は `LightTownRules.json` の `shopItems` で定義し、5件ごとにページ分けします。変身商品は現在一覧から除外しており、旧商品データを渡しても購入を拒否します。商品が空のときは販売中の商品がないことを表示します。

## 設定

タイトルと街から設定画面を開けます。変更はゲーム進行とは独立した `PlayerSettings.json` に自動保存します。

| 項目 | 操作と反映先 |
|---|---|
| 表示言語 | 日本語／英語をクリックで切替。街は設定を閉じる際に保存して再表示 |
| 効果音の音量 | UIButtonを付けたバーをドラッグ。SEカテゴリへ反映 |
| BGMの音量 | 同様のスライダー。BGMカテゴリへ反映 |
| ライトの影 | ON／OFF。既存ライトと新しく建てた施設のライトへ反映 |
| 影の解像度 | 512／1024／2048をクリックで切替 |
| ポストエフェクト | GTAO・FXAA・被写界深度・モーションブラー・色収差・Bloom・ビネットを一括ON／OFF。街も設定に連動。SSAOは既定のOFF |
| 画面の明るさ | スライダーで3D描画先のColorAdjustEffectを調整。UIの読みやすさは維持 |

UIはCamera2Dの左下原点へ変換して配置し、フォントアトラス拡張後もラベルを再評価します。
3シーンすべてで、3D用 `TownScreen` とUI合成用 `TownCanvas` を1920×1080に固定しています。ショップも1920×1080、建築アイコンだけは256×256の正方形です。
全オフスクリーンのクリアカラーのアルファは255（保存値1.0）です。街のクリアカラーはRGBA(32,64,64,255)です。
`TownScreen` のScreenBuffer設定と各ポストエフェクトは `GameDefaultObjects.prefab` の `MainScreen` を基にしています。
同プレハブの平行光源は各シーンの `SceneLight` として配置し、それぞれの `TownScreen` へ接続しています（旧名 `TownAmbient`）。
Gitの `12c150b4c2d6` に残る旧Stage1を基準に、平行光源を背面向き（X=πラジアン）・強度0.2・影なしへ戻しています。元プレハブにも同じ設定を反映しています。
旧シーンの見え方は平行光源だけでなく、白いDefault材質の地面と街灯の局所照明によるものです。遠征の地面を同じ材質・白色に揃え、旧Stage1の街灯に加えて旧GameSceneの蛍光灯・壁掛けライトを部屋や通路へ配置しています。
影設定をONにしても、旧構成で影なしだった補助光源（SceneLightと街灯の補助球状光源）は影なしを維持します。
コンポーネントの順序・パラメータ・既定の有効状態を取り込み、UI合成先には効果を適用しません。
既存の `PostEffectController.as` を3D描画先へ追加し、被写界深度の焦点を遠征のプレイヤー・タイトルの中央へ追従させます。
街はGTAO・被写界深度・モーションブラーとセル合焦用のPostEffectControllerを有効にしています。カーソルの指すセルを焦点対象にし、カメラ空間の奥行きへ応答速度8の指数補間で追従します。建築メニューを閉じている間も合焦し、UI上や街の外では直前の焦点対象を保持します。設定画面でポストエフェクトをOFFにすることも可能です。
汎用の焦点計算・補間処理は遠征・タイトル等のために保持しています。
`TownDisplayViewport` の `ScreenBufferViewport`（Letterbox）と `ScreenAnchor` により、
ウィンドウのリサイズ時も画面全体を中央の16:9に保ち、上下または左右に余白を付けます。
UIは1280×720の論理座標を維持し、UIButtonと街のセル選択は余白を除いた座標で判定します。
ゲーム画面は画面全体を背景として描画し、メニュー・ヘッダー・フッターを半透明パネルで重ねています。
パネルは専用の `TownUIOverlay.mat` でアルファブレンドし、設定画面の背景も不透明度0.68で背後のゲーム画面を透かします。
配列と補助クラスのフィールドはハンドル構文に統一し、エンジンのScriptComponent安全性チェックに対応しています。
