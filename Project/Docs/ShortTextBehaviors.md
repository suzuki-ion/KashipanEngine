# 短文から作る小さな挙動（試験機能）

`codex/short-text-behaviors` で試す、言語モデルを使わない日本語の挙動作成機能です。
辞書と規則で文章全体を解釈します。AIサービス、APIキー、通信、生成スクリプトは不要です。

## 使い方

1. Development / Debug のエディターで、Transformを持つオブジェクトをひとつ選択します。
2. メニューバーの **試験機能 → 短文の挙動** を開きます。
3. 短い文章を入力し、**解釈する** を押します。例文も選べます。
4. 表示された軸・速度・振幅・周期を確認し、**適用** または **適用して再生** を押します。
5. 動作は通常のPlay/Stopで試します。停止すると、再生前の位置・回転へ戻ります。
6. 追加・置換は既存の編集履歴に入り、停止後に通常のUndo/Redoで戻せます。

解釈後に対象を変更した場合は再解釈が必要です。再生中の適用はできません。
1オブジェクトにつき短文挙動は1件で、再適用はそのレシピを置換します。
速度・加速度を使うレシピでは、Velocityがなければ適用時に追加します。追加とレシピ変更は一回のUndoで戻せます。
Inspectorで振幅・周期・軸・速度・逆方向も編集できます。
文章は作成時の記録であり、Inspectorでの調整後は数値が実際の設定です。

### コンポーネントの項目を名指しする文（実コンポーネントを付与）

「Transformの移動X軸を-1.0fから1.0fの間で往復移動」「BoxColliderのサイズX軸を2.0fにする」のように
「コンポーネントの項目」を指定すると、ShortTextBehavior ではなく実際のコンポーネントを追加・設定します。
往復は新しい汎用コンポーネント **PropertyMotion**（ローカル絶対値の範囲、既定は1往復2秒・一定速度、回転は度で指定）、
値の設定は対象コンポーネントへの編集時の直接設定です。不足しているコンポーネント（例：BoxCollider）は同じUndo操作で追加します。
解釈時に適用内容と自動では設定しない内容をプレビューします。詳細は [ShortTextComponentProperties.md](ShortTextComponentProperties.md) を参照してください。
旧来の文章・学習内容・標準例文は従来どおり優先して解釈し、必要な部品（Velocity等）の事前追加と、素材などが必要な部品の案内も行います。

## ローカルで言葉を教える

短文の挙動ウィンドウの **言葉を教える（ローカル）** から登録できます。
保存先は、現在開いているプロジェクト直下の `ShortTextLearning.json` です。
このファイルはウィンドウを最初に開いたときに読み込まれ、再起動後も登録を再利用できます。
クラウド保存や通信は行いません。

### 文章全体に挙動を登録する

1. **入力中の文章を教える** を押して、例えば「宇宙遊泳させて」を入力します。
2. **文章全体に挙動を登録** を選び、往復・回転・移動、軸、振幅・周期・速度を設定します。
3. 既に調整した対象があれば、**選択対象の挙動を取り込む** でInspectorの設定を取り込めます。
4. **登録 / 更新** で保存し、文章をもう一度解釈して、結果を確認して適用します。

文章全体が登録内容と一致すると、設定したひとつの挙動が選ばれます。
空白・全角数字/XYZ・句読点などは標準の解釈器と同じように正規化します。
同じ正規化済み文章を再登録すると更新します。文の一部分に一致しただけでは適用しません。
登録済みの文章全体は標準の解釈より優先されます。
別の言葉への変更は新しい登録になります。古い登録を不要にする場合は削除してください。

### 言い回しを言い換える

**言い回しを言い換える** を選び、「教える言葉：ぷかぷか」「言い換え先：ふわふわ」を登録します。
「周期3秒でぷかぷかさせて」のように標準の数値指定・助詞・方向指定と組み合わせられます。
言い換え先は標準の解釈器が理解できる語句に限ります（例：ふわふわ、回転、右に移動）。
登録同士を再帰的に言い換える処理はありません。
標準の文章だけで解釈できる場合は標準の解釈を使い、失敗したときに言い換えを試します。
重なった言い回しは長い方を優先します。ひとつの文章で複数の登録を使う場合や、
言い換え後に未解釈の語が残る場合は拒否します。

### 管理と保存

- 登録一覧から選ぶと編集フォームに読み込みます。**登録 / 更新** で変更を保存します。
- **選択した学習内容を削除** で登録を削除できます。
- **学習内容を再読み込み** で外部編集を反映できます。別のプロジェクトの辞書は混ざりません。
- 学習内容の更新・削除は、既にシーンに作った挙動を変更しません。必要な対象へ再解釈・再適用してください。
- 最大1024件、各言葉/言い換え先はUTF-8で512バイト以下、ファイルは1MB以下です。
- 不正なファイルの再読み込みや保存失敗では、現在の辞書を保持します。初回に不正なファイルを検出した場合は登録を止め、修正またはファイルの退避後に再読み込みする必要があります。
- 外部でファイルが変わっていた場合は上書きせず、再読み込みを促します。

往復・回転・移動に加え、イベント・条件・動作を組み合わせたレシピも登録できます。
未登録の条件文を推測したり、任意のスクリプトを生成・実行したりする機能はありません。
条件文は、対応するルールを明示して登録した文章全体に限って利用できます。

## 標準で対応する文章

| 入力例 | 解釈 |
| --- | --- |
| 上下にふわふわ動かして | Y軸の往復、振幅0.5、周期2秒 |
| ゆっくり浮いたり沈んだりして | Y軸の往復、周期4秒 |
| 左右に振幅2で周期3秒で往復して | X軸の往復、振幅2、周期3秒 |
| 前後にゆらゆら動かして | Z軸の往復 |
| ゆっくり右に回して | Z軸、毎秒-45度 |
| Y軸で毎秒90度回転して | Y軸、毎秒90度 |
| 反時計回りに回転して | Z軸、毎秒90度 |
| 右に毎秒2で動かして | X軸、毎秒+2単位 |
| 後ろに速度2で移動して | Z軸、毎秒-2単位 |

方向はTransformのローカル座標です。親の回転・スケールの影響を受けます。
移動：右/左=Xの正/負、上/下=Yの正/負、前/後ろ=Zの正/負。
回転：既定はZ軸で、右/時計回りは負、左/反時計回りは正です。
X/Y軸の回転は軸を明示してください。
振幅は初期位置から片側への最大変位です。往復は加算式の正弦波です。
速度の初期値は移動1単位/秒、回転90度/秒です。
「ゆっくり」は速度を半分/往復周期4秒、「速く」は速度を2倍/往復周期1秒にします。
明示数値と速さの形容詞は同時に指定できません。
全角数字・小数点・XYZと空白にも対応します。

## 範囲と失敗時の扱い

- 対応範囲は往復・回転・一定方向への移動と、下記のイベント・条件・動作・83種類の拡張コマンドです。物理・追従・色変更も対応部品を明示した登録レシピから利用できます。会話の文脈を推測した修正は行いません。
- 文脈や常識を推測する機能ではありません。数値・軸・方向・定番の言い換えを解釈する限定的な文法です。
- 未登録の条件・否定・複数動作は拒否します。登録済みのイベントレシピは指定したルールを実行します。
- 未解釈の語が残った場合も拒否します。文の一部分だけを勝手に適用しません。
- 振幅・速度は0より大きく10000以下、周期は0.05〜3600秒、入力はUTF-8で512バイト以下です。
- 既存のVelocity、Rotation、Animator、スクリプト、物理などもTransformを変更している場合、競合の自動解決はありません。最初はTransformと表示用コンポーネントだけの対象で試してください。
- 適用結果は `ShortTextBehavior` コンポーネントとしてシーン/Prefabへ保存され、Releaseでも動作します。試作を含まない旧ビルドではそのコンポーネントを読み込めません。

## イベント・条件・動作を組み合わせる

「言葉を教える」の動きで **イベントと動作** を選び、ルールを追加します。
初期設定は **Spaceを押した瞬間 → Y方向の速度を16にする** です。
「スペースキーを押したらvelocityに16.0fを代入する」などの文章を登録すると、その文章で適用できます。

| 部品 | 対応内容 |
| --- | --- |
| イベント（15種類） | 毎フレーム、開始時、キーを押した瞬間、押している間、離した瞬間、一定間隔、接触開始・継続・終了、マウス押下・長押し・解放、UIButtonクリック、変数変化、条件成立の瞬間 |
| 条件（9種類） | 位置/速度・数値シーン変数・ワールド距離の以下/以上判定に加え、型付きの式条件（等値・範囲・AND/OR/NOT・存在・コンポーネント有無） |
| 動作（35種類） | 速度の代入/加算/停止、加速度の代入、移動、回転、スケール・位置・回転角度の代入、シーン変数の代入/加算、音の再生/停止/音量設定、表示/有効状態、空オブジェクト生成/複製/削除、シーン遷移、テキスト/数値表示、追従/接近、位置/回転/拡縮の補間、待機、拡張コマンド、プロパティ補間、並列、繰り返し、分岐、シーケンス制御、状態変更 |

条件はすべて満たした場合に実行します。条件なしは無条件です。
ルールと動作は表示順に実行します。位置・速度・数値変数など純粋ランタイム内で変更する値は後続の従来条件へ反映します。型付き変数・プロパティ・接触・入力・距離などの式条件はフレーム開始時のスナップショットを使います。一方、拡張コマンドの引数に書いた式はネイティブ適用時に評価するため、前のコマンドで更新した変数やプロパティ、問い合わせ結果を同じ動作列から読めます。
最大16ルール、1ルールに4条件・8動作です。対応キーはA〜Z、0〜9、矢印、Space、Enter、Shift、Control、Escape、Tabです。

- 移動は単位/秒、回転は度/秒で、フレーム時間を掛けます。
- その他の動作はイベント1回ごとの代入・加算です。長押しイベントは毎フレーム発火します。
- 開始時は再生後の最初の更新に一度だけ発火します。タイマーは0.05〜3600秒、1フレームに最大1回で余り時間を保持します。
- ルールを実行してから、通常のVelocityコンポーネントが加速度・速度・位置を更新します（既定の更新優先度を前提）。
- キー入力はエンジンのKeyboardから取得します。ルールの実行は再生中だけです。
- 速度16の代入だけでは、重力や接地判定は付きません。重力はY加速度を設定する別の動作です。
- 「簡易床Y=0」の標準例は位置と速度を比較して位置/速度/加速度を戻す構成です。物理コライダーによる接地判定ではありません。
- 保存されたプログラムの実行には0〜1秒のフレーム時間を使用します。これを超える更新ではルールの実行をスキップします。

## 接触・音・スコアの部品

接触イベントには、対象と相手のオブジェクトにColliderが必要です。
SceneObjectColliderの重なりクエリで2D/3Dを読み取り、接触相手のオブジェクトIDを追跡します。
タグは相手の **オブジェクトタグ** です。Collider自身のタグではありません。
空欄は全タグで、1ルールあたり最大32相手です。
同じ相手の複数Colliderは1件にまとめ、別の相手が加わると新しい開始イベントになります。
開始/終了は相手ごと、継続は毎フレーム相手ごとに発火します。
条件も相手ごとに評価します。高速で通過する対象の連続衝突判定や、物理的な押し戻しではありません。

シーン変数操作の **変数名** に `score` / `hp` などを指定します。
未作成の変数への加算は0から始め、float型で作成します。
既存のint/float/doubleは型を保って更新し、intへの小数値は整数へ変換します。
この従来の数値操作は文字列・boolなどを書き換えません。型付きの文字列・bool・ベクトル・色・オブジェクト参照には拡張コマンド variable.* と式条件を使います。従来の数値条件では未作成・非数値は不成立です。
扱う値は有限な±10億の範囲です。加算結果はこの範囲に制限します。
従来の数値操作の対象はシーン内の値です。グローバル変数は variable.* の scope:global、保存・読込は save.write/read で別途操作します。

従来の音声操作は、対象オブジェクトの **最初のAudioSource** を使用します。複数音源の選択・一時停止・再開・ピッチ・ループ・空間音響には audio.* を使います。
音声を設定し、`playOnAwake`を無効にしてください。音源がなければ音声操作は行えません。
再生は現在の音を止めて再生し直す動作で、重なった複数の音を作る機能ではありません。
音量は0〜1です。音声ファイルの生成や取得はありません。

例えば「Playerに触れたらscoreを1増やして音を鳴らす」は、接触開始をきっかけに
`score`へ1を加算し、設定済みAudioSourceを再生するレシピです。
既存のスクリプトやAudioSourceの自動再生も同じ値・音を操作する場合、競合の自動解決はありません。

## 対象指定・UI・時間をまたぐ処理

動作ごとに操作対象を **自分 / 接触相手 / 名前 / タグ / 親 / 子 / 子孫 / ID / 生成結果 / 最寄り / 範囲内 / 候補番号** から選べます。
名前は一意である必要があります。タグは最大32対象です。
待機や補間を始める時点でIDを固定します。対象が消えた場合はその動作をスキップし、
同名で作り直された別の対象へは適用しません。接触相手の指定は接触イベントで使用します。

- **表示切り替え**：MeshRenderer・SkinnedMeshRenderer・SpriteRenderer・TextRenderer・BitmapTextRendererの有効状態を切り替えます。スクリプトやColliderは動き続けます。
- **有効状態**：オブジェクト全体を切り替えます。自分を無効にすると自分のタイマーや入力処理も停止するため、復帰は別のコントローラーから行ってください。
- **生成**：空オブジェクト作成、または既存のテンプレートオブジェクトの子なし複製です。Prefabファイルからの生成は拡張コマンド prefab.spawn を使います。所有者のワールド位置＋指定軸のオフセットへ置き、生成物は有効にします。1更新16個、シーン4096個までです。
- **削除**：対象IDを解決して、動作列の最後に削除します。エンジンの更新中は既存の遅延破棄経路を使います。
- **マウス**：左/右/中の押下・長押し・解放に対応します。エンジンのMouse入力全体を使用します。
- **ボタン**：所有者自身のUIButtonの直近のクリック結果を使用します。初回は編集時のクリックを消費しません。再生中はUIButtonがこのレシピより先に更新されるよう優先度を調整し、連続するクリック通知も落としません。停止すると編集時のスナップショットへ戻ります。
- **シーン遷移**：指定した名前への遷移要求です。そのシーンがSceneListに登録されている必要があります。
- **テキスト**：対象のTextRendererまたはBitmapTextRendererへ文字列を設定し、数値変数を接頭辞付きで表示できます。描画コンポーネント・フォント等を事前に設定してください。
- **追従**：参照名の一意なオブジェクトのワールド位置へ、指定軸のオフセットを加えて移します。**接近**は指定速度でそこへ近づきます。親の変換を考慮します。この従来の追従/接近は衝突回避を行いません。物理移動は controller_move、格子経路探索・巡回は grid_path/waypoint_move を使います。
- **距離条件**：更新開始時のワールド位置を使います。同じ動作列で移動した結果の距離判定は次の更新から反映します。
- **補間**：位置・回転・スケールの指定軸を、現在値から指定値へ補間します。data.from に明示開始値を指定でき、data.easing で linear/ease_in/ease_out/ease_in_out/smoothstep/curve を選べます。curve は2〜64個の数値サンプルを等間隔に線形接続します。回転は度、位置とスケールはローカル値です。回転の data.shortest:true は最短角度を使います。任意の数値・ベクトル・色の登録プロパティは tween_property で補間します。
- **待機・順番**：待機/補間が完了してから次の動作へ進みます。1ルールに実行中のシーケンスは1件で、実行中の再トリガーを溜めません。1更新の命令上限は512件です。
- **一度だけ**：ルールの条件が成立して初めて実行した後、その再生中は再実行しません。再生停止/再開では状態をリセットします。
- **変数変化**：数値・bool・文字列・ベクトル・色・オブジェクト参照、または存在状態が変わると発火します。variable に scene:名前 / global:名前 / property:self:パス などを指定します。初回は基準を記録するだけです。
- **条件成立の瞬間**：条件が不成立から成立へ変わると発火し、初回に成立していた場合も発火します。一生に一回だけなら「一度だけ」を併用してください。

標準の新しい例には `Door` / `Enemy` / `HUD` / `Player` / `BulletTemplate` といった名前を使用します。
これらは利用するシーンで準備する対象名です。例文を解釈しただけで、扉のモデルやHUD・テンプレートが自動作成されるわけではありません。
生成テンプレート自身に再帰的な生成処理を付けないでください。

## 標準の例文辞書とClaude生成

標準例文はエンジン共通の `EditorTools/ShortTextDefaults.json` から読み込みます。
「例文」メニューから選べます。プロジェクトの学習内容を先に試し、解釈できない場合に標準辞書を試します。
標準辞書も **学習内容を再読み込み** で更新できます。実行時にClaudeや通信は使いません。

`Tools/GenerateShortTextExamples.py` は、実装済み部品の名前をソースから取得し、Claude CLIの
`claude-opus-5-5`へ仕様とJSON Schemaを渡して候補を生成します。
`--batch orchestration`（既定）は今回の10分野の追加例文を作り、既存分へ追加する候補を作ります。
`--batch interactions`は接触・音・スコアの新規例文を作り、既存の標準辞書を保持したまま候補へ追加します。
`--batch baseline`は従来の移動系18種類の生成です。必要な部品の網羅は取り込み前に検証してください。
同じ正規化済み例文と同じレシピは重複追加しません。同じ例文で異なるレシピになった場合は、候補作成を止めて既存の標準辞書を保持します。
標準辞書へ取り込む前に、全例文と新しい部品の網羅を検証します。
標準辞書の収録数は辞書ファイルおよび生成レポートで確認してください。拡張部品の追加と例文の追加は別々に検証します。
CLIのツール/MCPを無効化し、候補は `Generated/ShortTextDefaults.candidate.json` に保存します。
モデルの出力を直接標準辞書へ書き込みません。

生成後は `Tests/RunShortTextDefaultsRegression.ps1 -CandidatePath <候補の絶対パス>` で検証し、
合格した候補を標準辞書へコピーします。検証は全例文の解釈、実装部品の網羅、保存形式、

|---|---:|---|
| `Docs/ShortTextExtendedCommands.json` | 12 | 型付き変数、グローバル変数、プロパティ、Tilemap |
| `Docs/ShortTextRenderingCommands.json` | 17 | 描画、素材、UV、レイアウト、テキスト、カメラ |

学習フォームでイベント・条件・動作を選び、式条件は「条件式 JSON」、拡張動作の引数は「部品の引数 JSON」へ入力します。以下のJSONはレシピの保存形式です。全文を外部編集する場合は、ShortTextLearning.jsonのentries内に {"mode":"recipe","phrase":"登録する短文","recipe":以下のレシピ} として保存し、「学習内容を再読み込み」で反映します。`operation`と`target`は文字列、拡張コマンド名は`name`、コマンドの引数は`data`です。素材や対象オブジェクトは各カタログの前提条件に従って準備してください。

### 型付き変数・OR・NOTとフェード

以下は、シーン変数`goal`またはグローバル変数`forceFade`がtrueで、グローバル変数`paused`がtrueではないとき、スプライトのアルファを1秒で0から1へ補間します。各変数はboolで用意してください。条件成立の瞬間だけ実行し、値がtrueのままでも繰り返しません。

```json
{
  "kind": 3,
  "rules": [{
    "event": "conditions_entered",
    "conditions": [{
      "test": "expression",
      "data": {
        "op": "and",
        "args": [
          {"op": "or", "args": [
            {"op": "eq", "args": [{"read": "scene:goal"}, true]},
            {"op": "eq", "args": [{"read": "global:forceFade"}, true]}
          ]},
          {"op": "not", "args": [
            {"op": "eq", "args": [{"read": "global:paused"}, true]}
          ]}
        ]
      }
    }],
    "actions": [{
      "operation": "tween_property",
      "name": "SpriteRenderer.instanceColor_.a",
      "duration": 1,
      "data": {"from": 0, "to": 1, "easing": "smoothstep"}
    }]
  }]
}
```

`from`を省略すると対象プロパティの現在値から開始します。`to`は数値、同じ長さの数値配列、または式です。例えば色全体やVector3を1つの動作で補間できます。`curve`はベジェ曲線ではなく、`data.curve:[0,0.1,0.6,1]`のような等間隔サンプルの接続です。対象の削除後は同名の別対象に乗り換えません。

型付き変数の設定は、例えば次の動作を使います。

```json
{
  "operation": "engine_command",
  "name": "variable.set",
  "data": {
    "scope": "global", "name": "direction", "type": "vector3",
    "value": {"op": "mul", "args": [[1, 0, 0], 3]}
  }
}
```

`variable.*`はbool/string/int/uint/int64/uint64/float/double/vector2/vector3/vector4/color/objectを扱います。`object`はUUID文字列です。`read`には`scene:score`、`global:hp`、`property:self:Transform.translate_.x`などを指定します。`eq/ne/between/lt/le/gt/ge`、`and/or/not`（AND/ORは左から短絡評価）、`exists/contains`、`add/sub/mul/div/min/max/clamp`、`vector/color/component/get/concat/random`を利用できます。ベクトル演算は要素ごとで、スカラーとの四則演算も可能です。`contains`で`object:Player.components`に`Velocity`があるか調べられます。問い合わせ配列は `read:results.contacts.0.depth` や `read:results.contacts.0.normal.1` のように、ドット区切りで要素番号とフィールドを読めます。このcontactsはcollision_queryのresult名をcontactsにした結果です。get演算子でもオブジェクトのキーや配列の番号を指定できます。不在や無効な番号はnullとなり、existsで確認できます。

### 並列・繰り返し・分岐とシーケンス制御

```json
{
  "operation": "parallel",
  "data": {"branches": [
    [{"operation": "tween_position", "axis": 0, "value": 5, "duration": 1,
      "data": {"easing": "ease_out"}}],
    [{"operation": "tween_scale", "axis": 0, "value": 2, "duration": 1}]
  ]}
}
```

各branchは動作の配列です。すべてが終了してから次の動作へ進みます。`repeat`は`data:{"count":3,"actions":[...]}`、`branch`は`data:{"condition":式,"then":[...],"else":[...]}`を指定します。`then/else`内も通常と同じ動作JSONです。branchの条件は、そのステップに到達したフレームのスナップショットで判定します。

```json
{
  "operation": "sequence_control",
  "data": {"rule": 0, "mode": "pause"}
}
```

`rule`は0から始まるルール番号です。`mode`は`cancel/pause/resume/restart/replace`。`replace`には`actions`配列を追加します。制御はそのフレームのルール評価が終わった後に適用し、再開始・置換した列は次の更新から進みます。各ルールの同時実行列は1つで、入力イベントの無制限な待ち行列は作りません。

ルールの`cooldown`は開始間隔の最小秒数（0〜3600）です。`windowStart/windowEnd`は再生開始からの入力受付期間（秒）で、既定は`0/-1`（終了制限なし）。期間終了後も既に始めた列は進行します。`elapsed`を式で読んで条件に使うこともできます。入力の先行予約バッファではありません。

`set_state`動作の`name`に`idle/chase/attack`などを設定し、ルールの`state`に実行を許す状態を指定できます。状態はそのオブジェクトのShortTextBehavior内にあり、再生停止やレシピ再読み込みでリセットします。別の状態へ移ると、前の状態だけで動く列は次の評価で停止します。`set_state`の対象は自分のみです。

### 対象指定

| target | 指定 |
|---|---|
| `self/contact` | 自分、接触相手 |
| `name/tag` | `targetName`に一意名またはタグ |
| `parent/children/descendants` | 所有者の親、直接の子、子孫 |
| `id` | `targetName`にUUID |
| `last_created` | 直前に生成した対象。適用時に解決するため、同じ動作列内の生成後にも使用可能 |
| `nearest/range` | `targetName`にタグ（空欄は全候補）、rangeは`data.radius` |
| `index` | `targetName`でタグ候補を絞り、`data.index`で0から始まるシーン順の候補番号 |

対象集合は最大32件です。最寄り・範囲・番号の候補は有効な別オブジェクトです。`last_created`へスナップショット値を必要とする移動量・回転量・速度加算は指定できません。絶対値設定や拡張コマンドを使ってください。通常の対象は列の開始時にIDを固定します。

### 制限と前提条件

- 1オブジェクト最大16ルール、各4条件・8動作。並列branchは最大8、繰り返しは1〜32回、展開後の列は最大256ステップ、1更新最大512命令です。JSONの式・登録データは深さ8まで、配列64要素までなどの検証があります。
- CharacterController移動は対応ColliderとSceneObjectColliderが必要です。接地・壁・天井は前回の移動解決結果を読みます。力・衝撃には初期化済RigidBodyが必要です。
- 3Dレイは有限レイの実交点順です。2Dレイは線分重なり問い合わせで、交点/fractionを返しません。
- 経路は最大128×128の4近傍格子BFSです。Tilemap固体セル、明示したblockedセル、2Dコライダーの円形プローブを使えます。動的障害物は再計算してください。waypoint_moveは最大256地点ですが、レシピJSONに直接埋める配列は64要素までです。
- `render.layout`はrootのXY単位quad、無回転・等倍のroot Camera2Dなどの前提があります。共有マテリアルの変更には`shared:true`が必要です。GPU・ウィンドウ・素材を自動的に用意する機能ではありません。
- `script.call`は既存ScriptComponentの引数なし関数だけです。`event.emit`はシーン内serial変数を増やし、変化イベントで受信します。
- `object.persist/restore`はrootオブジェクトの保存状態を別シーンで復元します。同じネイティブオブジェクトをシーン間に常駐させる方式ではありません。保存した構成やアセットが復元先でも有効である必要があります。
- グローバル変数はSceneManagerが保持します（エディター・ゲーム実行時は常に存在）。`variable.set`等の`scope:"global"`は既存キーを置き換えます。`save.write/read`はグローバル変数全体をプロジェクトルート基準の`ShortTextSaves/<slot>.json`へ保存・読込します。
- 音・アニメーションの完了判定は再生から停止への変化です。明示停止と自然終了を厳密に区別しません。ロード完了の代わりに開始イベントを使う例は、シーンの最初の更新を意味し、非同期ロード全体の完了保証ではありません。
- 語彙とレシピが増えても、未登録の意図を自由に推測する機能にはなりません。学習は文章と実行可能なレシピの対応付けです。

## 拡張例文のClaude生成と追加検証

`Tools/MakeShortTextExtendedSeeds.py`は、実装済みコマンドと共通ランタイムを使う種レシピを作ります。`Tools/GenerateShortTextExtendedExamples.py`は、そのレシピを変更しない条件でClaude CLIの`claude-opus-5-5`へ説明と前提を渡し、各レシピに対応する日本語例文を生成します。候補辞書とレポートは`Generated/ShortTextExtendedDefaults.candidate.json` / `Generated/ShortTextExtendedDefaults.report.json`へ保存します。検証前に標準辞書へ直接書き込みません。

./Project/Tests/RunShortTextExtendedProgramRegression.ps1
