# 短文から作る小さな挙動（試験機能）

`codex/short-text-behaviors` で試す、言語モデルを使わない日本語の挙動作成機能です。
辞書と規則で文章全体を解釈します。AIサービス、APIキー、通信、生成スクリプトは不要です。

## 使い方

1. Development / Debug のエディターで、Transformを持つオブジェクトをひとつ選択します。
2. メニューバーの **試験機能 → 短文の挙動** を開きます。
3. 短い文章を入力し、**解釈する** を押します。例文も選べます。
4. 表示された軸・速度・振幅・周期を確認し、**適用** または **適用して再生** を押します。
5. 動作は通常のPlay/Stopで試します。停止すると、再生前の位置・回転へ戻ります。
6. 追加・置換は既存の編集履歴に入り、停止後に通常のUndo/Redoで戻せます。

解釈後に対象を変更した場合は再解釈が必要です。再生中の適用はできません。
1オブジェクトにつき短文挙動は1件で、再適用はそのレシピを置換します。
速度・加速度を使うレシピでは、Velocityがなければ適用時に追加します。追加とレシピ変更は一回のUndoで戻せます。
Inspectorで振幅・周期・軸・速度・逆方向も編集できます。
文章は作成時の記録であり、Inspectorでの調整後は数値が実際の設定です。

## ローカルで言葉を教える

短文の挙動ウィンドウの **言葉を教える（ローカル）** から登録できます。
保存先は、現在開いているプロジェクト直下の `ShortTextLearning.json` です。
このファイルはウィンドウを最初に開いたときに読み込まれ、再起動後も登録を再利用できます。
クラウド保存や通信は行いません。

### 文章全体に挙動を登録する

1. **入力中の文章を教える** を押して、例えば「宇宙遊泳させて」を入力します。
2. **文章全体に挙動を登録** を選び、往復・回転・移動、軸、振幅・周期・速度を設定します。
3. 既に調整した対象があれば、**選択対象の挙動を取り込む** でInspectorの設定を取り込めます。
4. **登録 / 更新** で保存し、文章をもう一度解釈して、結果を確認して適用します。

文章全体が登録内容と一致すると、設定したひとつの挙動が選ばれます。
空白・全角数字/XYZ・句読点などは標準の解釈器と同じように正規化します。
同じ正規化済み文章を再登録すると更新します。文の一部分に一致しただけでは適用しません。
登録済みの文章全体は標準の解釈より優先されます。
別の言葉への変更は新しい登録になります。古い登録を不要にする場合は削除してください。

### 言い回しを言い換える

**言い回しを言い換える** を選び、「教える言葉：ぷかぷか」「言い換え先：ふわふわ」を登録します。
「周期3秒でぷかぷかさせて」のように標準の数値指定・助詞・方向指定と組み合わせられます。
言い換え先は標準の解釈器が理解できる語句に限ります（例：ふわふわ、回転、右に移動）。
登録同士を再帰的に言い換える処理はありません。
標準の文章だけで解釈できる場合は標準の解釈を使い、失敗したときに言い換えを試します。
重なった言い回しは長い方を優先します。ひとつの文章で複数の登録を使う場合や、
言い換え後に未解釈の語が残る場合は拒否します。

### 管理と保存

- 登録一覧から選ぶと編集フォームに読み込みます。**登録 / 更新** で変更を保存します。
- **選択した学習内容を削除** で登録を削除できます。
- **学習内容を再読み込み** で外部編集を反映できます。別のプロジェクトの辞書は混ざりません。
- 学習内容の更新・削除は、既にシーンに作った挙動を変更しません。必要な対象へ再解釈・再適用してください。
- 最大256件、各言葉/言い換え先はUTF-8で512バイト以下、ファイルは1MB以下です。
- 不正なファイルの再読み込みや保存失敗では、現在の辞書を保持します。初回に不正なファイルを検出した場合は登録を止め、修正またはファイルの退避後に再読み込みする必要があります。
- 外部でファイルが変わっていた場合は上書きせず、再読み込みを促します。

往復・回転・移動に加え、イベント・条件・動作を組み合わせたレシピも登録できます。
未登録の条件文を推測したり、任意のスクリプトを生成・実行したりする機能はありません。
条件文は、対応するルールを明示して登録した文章全体に限って利用できます。

## 標準で対応する文章

| 入力例 | 解釈 |
| --- | --- |
| 上下にふわふわ動かして | Y軸の往復、振幅0.5、周期2秒 |
| ゆっくり浮いたり沈んだりして | Y軸の往復、周期4秒 |
| 左右に振幅2で周期3秒で往復して | X軸の往復、振幅2、周期3秒 |
| 前後にゆらゆら動かして | Z軸の往復 |
| ゆっくり右に回して | Z軸、毎秒-45度 |
| Y軸で毎秒90度回転して | Y軸、毎秒90度 |
| 反時計回りに回転して | Z軸、毎秒90度 |
| 右に毎秒2で動かして | X軸、毎秒+2単位 |
| 後ろに速度2で移動して | Z軸、毎秒-2単位 |

方向はTransformのローカル座標です。親の回転・スケールの影響を受けます。
移動：右/左=Xの正/負、上/下=Yの正/負、前/後ろ=Zの正/負。
回転：既定はZ軸で、右/時計回りは負、左/反時計回りは正です。
X/Y軸の回転は軸を明示してください。
振幅は初期位置から片側への最大変位です。往復は加算式の正弦波です。
速度の初期値は移動1単位/秒、回転90度/秒です。
「ゆっくり」は速度を半分/往復周期4秒、「速く」は速度を2倍/往復周期1秒にします。
明示数値と速さの形容詞は同時に指定できません。
全角数字・小数点・XYZと空白にも対応します。

## 範囲と失敗時の扱い

- 対応範囲は往復・回転・一定方向への移動と、下記のイベント・条件・動作です。物理衝突、追従、色変更、会話による修正は未対応です。
- 文脈や常識を推測する機能ではありません。数値・軸・方向・定番の言い換えを解釈する限定的な文法です。
- 未登録の条件・否定・複数動作は拒否します。登録済みのイベントレシピは指定したルールを実行します。
- 未解釈の語が残った場合も拒否します。文の一部分だけを勝手に適用しません。
- 振幅・速度は0より大きく10000以下、周期は0.05〜3600秒、入力はUTF-8で512バイト以下です。
- 既存のVelocity、Rotation、Animator、スクリプト、物理などもTransformを変更している場合、競合の自動解決はありません。最初はTransformと表示用コンポーネントだけの対象で試してください。
- 適用結果は `ShortTextBehavior` コンポーネントとしてシーン/Prefabへ保存され、Releaseでも動作します。試作を含まない旧ビルドではそのコンポーネントを読み込めません。

## イベント・条件・動作を組み合わせる

「言葉を教える」の動きで **イベントと動作** を選び、ルールを追加します。
初期設定は **Spaceを押した瞬間 → Y方向の速度を16にする** です。
「スペースキーを押したらvelocityに16.0fを代入する」などの文章を登録すると、その文章で適用できます。

| 部品 | 対応内容 |
| --- | --- |
| イベント（6種類） | 毎フレーム、開始時、キーを押した瞬間、押している間、離した瞬間、一定間隔 |
| 条件（4種類） | 指定軸の位置/速度が、指定値以下/以上 |
| 動作（9種類） | 速度の代入/加算/停止、加速度の代入、移動、回転、スケール・位置・回転角度の代入 |

条件はすべて満たした場合に実行します。条件なしは無条件です。
ルールと動作は表示順に実行し、先の動作の結果を後の条件で参照できます。
最大16ルール、1ルールに4条件・8動作です。対応キーはA〜Z、0〜9、矢印、Space、Enter、Shift、Control、Escape、Tabです。

- 移動は単位/秒、回転は度/秒で、フレーム時間を掛けます。
- その他の動作はイベント1回ごとの代入・加算です。長押しイベントは毎フレーム発火します。
- 開始時は再生後の最初の更新に一度だけ発火します。タイマーは0.05〜3600秒、1フレームに最大1回で余り時間を保持します。
- ルールを実行してから、通常のVelocityコンポーネントが加速度・速度・位置を更新します（既定の更新優先度を前提）。
- キー入力はエンジンのKeyboardから取得します。ルールの実行は再生中だけです。
- 速度16の代入だけでは、重力や接地判定は付きません。重力はY加速度を設定する別の動作です。
- 「簡易床Y=0」の標準例は位置と速度を比較して位置/速度/加速度を戻す構成です。物理コライダーによる接地判定ではありません。
- 保存されたプログラムの実行には0〜1秒のフレーム時間を使用します。これを超える更新ではルールの実行をスキップします。

## 標準の例文辞書とClaude生成

標準例文はエンジン共通の `EditorTools/ShortTextDefaults.json` から読み込みます。
「例文」メニューから選べます。プロジェクトの学習内容を先に試し、解釈できない場合に標準辞書を試します。
標準辞書も **学習内容を再読み込み** で更新できます。実行時にClaudeや通信は使いません。

`Tools/GenerateShortTextExamples.py` は、実装済み部品の名前をソースから取得し、Claude CLIの
`claude-opus-5-5`へ仕様とJSON Schemaを渡して候補を生成します。
CLIのツール/MCPを無効化し、候補は `Generated/ShortTextDefaults.candidate.json` に保存します。
モデルの出力を直接標準辞書へ書き込みません。

生成後は `Tests/RunShortTextDefaultsRegression.ps1 -CandidatePath <候補の絶対パス>` で検証し、
合格した候補を標準辞書へコピーします。検証は全例文の解釈、実装部品の網羅、保存形式、
合成入力による実行を確認します。文章の意図や見た目のすべてを保証するものではありません。

## 実装と検証

- `Utilities/ShortTextBehavior.h`：副作用のない文章解釈、レシピ検証、時間ごとの変位計算。
- `Objects/Components/ShortTextBehavior.*`：保存・復元と再生時のTransform操作。
- `Scene/Editor/ShortTextBehaviorEditor.*`：対象の確認、解釈表示、既存コマンドによる追加/置換。
- `Utilities/ShortTextProgram.h` / `ShortTextRecipeJson.h`：イベント・条件・動作の実行と検証付き保存形式。
- `Tests/RunShortTextProgramRegression.ps1`：6イベント・4条件・9動作の実行テスト。
- `Tests/RunShortTextDefaultsRegression.ps1`：Claude生成の候補をエンジンの辞書読み込み・実行処理で検証。
- `Utilities/ShortTextLearning.*`：プロジェクト単位の辞書、文章レシピ・言い換え、検証付き読み込みと保存。
- `Tests/RunShortTextLearningRegression.ps1`：ローカル学習、数値との組み合わせ、更新・削除、再起動、壊れたデータや保存失敗の回帰テスト。
- `Tests/RunShortTextBehaviorRegression.ps1`：Visual Studio x64開発者PowerShellから実行する文章・数値・変位の回帰テスト。
- `Tests/RunShortTextBehaviorSceneRegression.ps1`：Development/x64エンジンのビルド後に実行する、シーン保存・複製・不正設定の拒否・編集コマンド選択のヘッドレステスト。実際のUI操作やUndo/Redo操作の確認とは別です。

Undo/Redoは `AddComponentCommand` / `ComponentEditCommand` を使用します。
試作UIは選択と編集履歴を利用する独立したC++ウィンドウとして追加しています。
今後EditorToolから再利用する場合は、この編集窓口をスクリプトへ公開する形にできます。
