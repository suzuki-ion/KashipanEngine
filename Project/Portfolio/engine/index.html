トップ/Kashipan Engine

PERSONAL GAME ENGINE / C++ · DIRECTX 12

Kashipan Engine

作品で使う機能と、作品を作るための環境を。小規模〜中規模のゲーム制作を目指した、Windows向けの自作ゲームエンジンです。

エンジンリファレンスを見るGitHubでソースを見る（新しいタブ）

CONCEPT

手に取りやすい
制作環境を目指して

「菓子パンのように安っちいが手に取りやすく、ちょっとしたことであれば簡単に実装できる」をコンセプトにしています。ゲーム内の挙動、画面の描画、制作ツールをつなぎ、必要な機能を自分の作品で使いながら開発しています。

対象
Windows / 小規模〜中規模のゲーム
基盤
C++ / DirectX 12
制作環境
ImGuiシーンエディター / AngelScript
利用例
CLUBOM / グランナー / 制作中の就活作品

ENGINE STRUCTURE

ゲーム制作をつなぐ3つの層

エンジン本体

EmptyObjectと各種コンポーネント、シーン管理、アセット管理を基盤に、C++からゲームの機能を構成できます。

C++ APIリファレンス

シーンエディター

ImGuiを使ったヒエラルキー、シーンビュー、インスペクター、アセットブラウザーを備え、配置とパラメーター調整を視覚的に行います。

エディターリファレンス

スクリプティング

AngelScriptのScriptComponentでゲームロジックを記述。ライフサイクル、SerializeField、コンポーネント型の参照、EditorToolによるツール拡張を用意しています。

スクリプトリファレンス

MAKING GAMES

作品の表現と制作を支える

必要な機能を組み合わせる

コンポーネントを単位にオブジェクトの機能を構成し、作品ごとの挙動とギミックを作ります。

描画結果をゲーム内へ

複数ライトや複数オフスクリーンを活用。CLUBOMでは、別の描画結果をステージ内の画面へ表示しました。

制作の試行錯誤を支える

エディターで配置と調整を行い、スクリプトで挙動を作る制作環境を用意しています。

SCOPE & DEVELOPMENT

開発の範囲

Windows向けのミニゲーム、複数ステージのパズルやアクション、小規模なプロトタイプを対象にしています。広大なステージや数万個規模のオブジェクト、本格的な流体シミュレーション、Windows以外でのゲーム実行は対象としていません。

エンジン紹介の概要は、リポジトリのREADMEとリファレンスに基づきます。開発ではClaude CodeとCodexを補助的に使用し、実装方針の検討と設計は開発者自身が行っています。
