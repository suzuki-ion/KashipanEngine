担当と工夫

UIも含めた専用エディター

ゲームの基盤が揃った段階で、ステージ制作のためのエディターをUIも含めて制作しました。ブロックを配置するだけでなく、スイッチを押したときにどこが動作するかも設定できます。

作る側が調整できる仕組み

ステージに必要な要素をエディターで配置・設定できるようにし、ゲーム内の挙動と制作ツールをつなぎました。

STAGE EDITOR

ステージ制作を支えるエディター
