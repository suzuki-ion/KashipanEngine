シーン (Scene / SceneManager)

ゲームの1画面・1ステージに相当する「シーン」を管理する仕組みです。Scene・SceneManager・SceneContext・ISceneComponentの役割と、シーンがJSON＋シーンエディタでデータとして作られる設計思想を解説します。

重要: シーンはC++で継承して作らない
Scene クラスは final 指定されており、ゲーム側で class TitleScene : public Scene のような継承をすることはできません。シーンの内容（オブジェクト・シーンコンポーネント・シーン変数）は基本的にシーンエディタ上で編集し、シーンJSONファイルとして保存します。C++側で行うのは SceneManager::RegisterScene / RegisterSceneFile によるシーンの登録と、ChangeScene による切り替えだけです。振る舞いを追加したい場合はオブジェクトコンポーネントを組み合わせるか、AngelScriptスクリプトを書きます。

Scene クラス final

Scene/Scene.h に定義されています。1つの Scene インスタンスが1つのシーン（オブジェクトの集合＋シーンコンポーネント＋シーン変数）を表します。コンストラクタはシーン名またはJSONデータを受け取りますが、通常は SceneManager が内部で生成するため、ゲーム側から直接 new Scene(...) することはありません。

シーン内オブジェクト管理

EmptyObject *CreateEmptyObject(const std::string &name = "", const UUID128 &objectID = UUID128(), size_t index = MAXSIZE_T); EmptyObject *CloneObject(EmptyObject *source, const std::string &name = ""); bool DeleteObject(EmptyObject *obj); bool ReleaseObject(EmptyObject *obj); bool MoveObject(EmptyObject *obj, size_t newIndex); const std::vector<std::unique_ptr<EmptyObject>> &GetSceneObjects() const; std::vector<EmptyObject *> GetSceneObjects(const std::string &objectName) const; EmptyObject *GetSceneObject(const std::string &objectName) const; EmptyObject *GetSceneObject(EmptyObject *obj) const; EmptyObject *GetSceneObject(const UUID128 &uuid) const; void ClearSceneObjects(); void DeleteEditorOnlyObjects();

CreateEmptyObject は空の EmptyObject を生成してシーンに追加します。CloneObject は複製元オブジェクト自身のコンポーネントのみを複製し、親子関係や子オブジェクトは複製しません（EmptyObject::Clone() の仕様に準じます）。DeleteEditorOnlyObjects は再生開始時（PlayStart）およびエディター無しビルドでのシーン読み込み時に、EditorOnly フラグの立ったオブジェクトを子孫ごと削除します。

シーンコンポーネント管理

template<typename T> std::vector<T *> GetComponents() const; template<typename T> T *GetComponent() const; ISceneComponent *GetComponent(const ISceneComponent *component) const; template<typename T> size_t HasComponents() const; template<typename T> T *AddComponent(std::unique_ptr<T> comp); template<typename T, typename... Args> T *AddComponent(Args&&... args); bool RemoveComponent(const ISceneComponent *component); template<typename T> bool RemoveComponent(); template<typename T> bool RemoveComponents(); void ClearSceneComponents();

EmptyObject のオブジェクトコンポーネントと同じ形の API を、シーン自身に付けるコンポーネント（ISceneComponent 派生）に対して提供します。AddComponent<T>(args...) は内部で T を make_unique し、失敗時（例外発生時）は nullptr を返します。

シーン変数 / グローバルシーン変数

template<typename T> MyAny *AddSceneVariable(const std::string &key, const T &value = T()); bool RemoveSceneVariable(const std::string &key); MyAny *GetSceneVariable(const std::string &key); const TypeInfo &GetSceneVariableTypeInfo(const std::string &key); const std::unordered_map<std::string, MyAny> &GetSceneVariables() const; template<typename T> MyAny *AddGlobalSceneVariable(const std::string &key, const T &value = T()); bool RemoveGlobalSceneVariable(const std::string &key); MyAny *GetGlobalSceneVariable(const std::string &key);

シーン変数は MyAny（型消去された値）としてキーで管理され、そのシーン固有のスコープを持ちます。グローバルシーン変数は SceneManager 側に保持され、シーンをまたいで共有されます（内部的に Scene 側のメソッドは SceneManager へ委譲しています）。SceneVariableApplier コンポーネントを使うと、C++コードを書かずにシーン変数の値を他コンポーネントのパラメータへ適用できます。

シーン切り替え

void SetNextSceneName(const std::string &nextSceneName); bool ChangeToNextScene(); void ClearNextSceneName(); bool HasNextSceneName() const;

シーン内部（コンポーネントやスクリプト）から次に遷移したいシーン名だけを予約しておき、都合のよいタイミングで ChangeToNextScene() を呼んで実際の切り替えをトリガーする、という2段階の使い方を想定しています。

各種マネージャーへの静的アクセス

アセット管理系・入力系の各マネージャーへは、Scene の静的メソッド経由でどこからでもアクセスできます。詳細は 09_Assets.html・08_Input.html を参照してください。

エディター再生制御 USE_IMGUI

USE_IMGUI ビルドでは、Unity風のPlay/Pause/Stopに相当する再生制御メソッドが追加されます。

bool IsPlaying() const; bool IsPaused() const; void PlayStart(); // 開始前のシーン状態を保存する void PlayStop(); // 開始前のシーン状態へ復元する void PlayPause(); void PlayResume(); void RequestStepFrame(); // 一時停止中のみ有効

非エディタービルドではシーンは常に再生状態として更新され、これらのメソッドは存在しません。Scene::UpdateInterface はエディタービルドの場合、isPlaying_ が false か、一時停止中かつステップ実行の要求が無い間は内部の更新処理をスキップします。

SceneManager クラス

Scene/SceneManager.h に定義されています。GameEngine::Context::sceneManager として AppInitialize() に渡され、登録済みシーンの管理・現在のシーンの保持・シーン切り替えの仲介を行います。

シーンの登録・登録情報の編集

bool RegisterScene(const std::string &sceneName, const JSON &factoryData = JSON()); bool RegisterSceneFile(const std::string &sceneName, const std::string &filePath); bool UnregisterScene(const std::string &sceneName); bool RenameRegisteredScene(const std::string &oldName, const std::string &newName); bool SetRegisteredSceneFilePath(const std::string &sceneName, const std::string &filePath); bool UpdateRegisteredSceneData(const std::string &sceneName, const JSON &factoryData); const std::vector<SceneEntry> &GetRegisteredScenes() const; bool IsSceneRegistered(const std::string &sceneName) const;

RegisterScene はJSONデータを直接渡す方式（factoryData）、RegisterSceneFile は切り替え時にファイルを読み込む方式です。通常は後者を使い、シーンエディタで保存したシーンJSON（またはシーンフォルダ）のパスを指定します。

シーンリスト定義ファイル（SceneList.json）

static constexpr const char *kDefaultSceneListFilePath = "Assets/KashipanEngine/SceneList.json"; bool LoadSceneList(const std::string &filePath = kDefaultSceneListFilePath); bool SaveSceneList(const std::string &filePath = kDefaultSceneListFilePath) const; const std::string &GetStartupSceneName() const; void SetStartupSceneName(const std::string &sceneName); bool ChangeToStartupScene();

Assets/KashipanEngine/SceneList.json には登録されているシーンの一覧と起動時に切り替えるシーン名（startupScene）が記載されます。実例: 

{
    "scenes": [
        { "filePath": "Assets/Scenes/GameScene.json", "name": "GameScene" },
        { "filePath": "Assets/Scenes/TestScene.json", "name": "TestScene" }
    ],
    "startupScene": "GameScene"
}

このファイルはシーンエディタから自動的に読み書きされるため、通常は手編集の必要はありません。

シーン切り替え

bool ChangeScene(const std::string &sceneName); bool HasPendingSceneChange() const; bool CommitPendingSceneChange(Passkey<GameEngine>);

ChangeScene を呼んだ時点ではシーンはまだ切り替わりません。GameEngine が管理するゲームループの中で次のフレームになった時に CommitPendingSceneChange（Passkeyにより GameEngine 専用）が実行され、そこで実際に現在のシーンが破棄・新しいシーンが生成されます。

ポイント
ChangeScene は「次のフレームで反映される」非同期の予約であることに注意してください。呼び出し直後に GetCurrentScene() を参照しても、まだ古いシーンが返ります。

グローバルシーン変数

template <typename T> MyAny *AddGlobalSceneVariable(const std::string &key, const T &value = T()); MyAny *AddGlobalSceneVariable(const std::string &key, const MyAny &value, const TypeInfo &typeInfo); bool RemoveGlobalSceneVariable(const std::string &key); MyAny *GetGlobalSceneVariable(const std::string &key); const std::unordered_map<std::string, MyAny> &GetGlobalSceneVariables() const;

SceneManager がシーンをまたいで保持する変数です。Scene::AddGlobalSceneVariable 等はこのメソッド群への委譲になっています。

SceneContext クラス

Scene/SceneContext.h に定義される final クラスです。各シーンコンポーネント・オブジェクトコンポーネントの Initialize() 等から GetOwnerSceneContext() 経由で取得でき、Scene が持つオブジェクト管理・コンポーネント管理・シーン変数・シーン切り替え・マネージャーアクセスのAPIをほぼそのままミラーしています（内部で owner_->Xxx(...) に委譲するだけの薄いラッパーです）。コンポーネント側のコードは Scene の完全な型を知らなくても、SceneContext 経由でシーンを操作できます。

ISceneComponent 基底クラス

Scene/Components/ISceneComponent.h に定義される、全シーンコンポーネントの基底です。オブジェクトコンポーネントの基底 IObjectComponent とほぼ対になる設計です。

const std::string &GetComponentType() const; size_t GetMaxComponentCountPerObject() const; size_t GetComponentTypeID() const; int GetUpdatePriority() const; bool IsActive() const; void SetActive(bool active); // 有効化時にInitialize、無効化時にFinalizeが走る void SetTag(const std::string &tagName); const Tag &GetTag() const noexcept; const std::string &GetTagName() const noexcept; virtual std::unique_ptr<ISceneComponent> Clone() const = 0;

protected な仮想関数（派生クラスがオーバーライドする部分）:

virtual void Initialize(); virtual void Finalize(); virtual void Update(); virtual JSON SaveToJson() const; virtual bool LoadFromJson(const JSON &json); #if defined(USE_IMGUI) virtual void ShowImGui(); #endif

派生クラスの定義には SCENE_COMPONENT_CONSTRUCTOR(typeName, maxCount, initializeCode) マクロを使い、REGISTER_COMPONENT_SCENE によってファクトリ関数がコンポーネントレジストリへ自動登録されます（このあたりのマクロの詳細はオブジェクトコンポーネント版と共通の仕組みなので 04_ObjectComponents.html を参照してください）。

シーンJSONの実例

シーンは Assets/Scenes/<シーン名>.scene/ フォルダとして保存されます（1シーン1フォルダ）。フォルダ直下の scene.json にシーン自体の情報（シーンコンポーネント・シーンID・シーン変数）が、Objects/<objectID>/object.json にオブジェクト1体ずつの情報が分割保存されます（1オブジェクト1フォルダ）。これは複数人で同じシーンを編集した際に、別々のオブジェクトを触っていればコンフリクトが起きないようにするための構成です。 

Assets/Scenes/GameScene.scene/
├── scene.json                          … シーンコンポーネント・シーン変数など
└── Objects/
    ├── c479e6eb-e0e5-4bab-.../object.json
    ├── 93fa416e-4174-41b0-.../object.json
    └── ...（オブジェクトごとに1フォルダ）

scene.json の抜粋（シーンコンポーネントとシーン変数の並び）:

{
    "sceneComponents": [
        { "data": { "data": {}, "isActive": true, "priority": 1000, "tag": "" }, "type": "SceneRenderer" },
        { "data": { "data": {}, "isActive": true, "priority": 1,    "tag": "" }, "type": "SceneObjectCollider" },
        { "data": { "data": {}, "isActive": true, "priority": 1,    "tag": "" }, "type": "SceneScriptEngine" }
    ],
    "sceneID": "75d12f47-b107-4a8e-88fb-217a67e2a17f",
    "sceneName": "GameScene",
    "sceneVariables": [
        { "key": "testFloat", "type": "Float", "value": 0.0 },
        { "key": "CheckpointPosition", "type": "Vector3", "value": { "x": 30.62, "y": 6.44, "z": 0.0 } }
    ]
}

従来の1ファイル完結型のシーンJSON（Assets/Scenes/GameScene.json のような形式）もバックアップ用として引き続き存在しますが、新規のシーン保存はフォルダ分割形式が既定です。
