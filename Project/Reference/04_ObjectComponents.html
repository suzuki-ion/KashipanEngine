オブジェクトコンポーネント基礎

EmptyObject へ機能を積むための単位が「オブジェクトコンポーネント」です。全コンポーネントの基底クラス IObjectComponent、コンポーネント定義に使うマクロ群、そして最も基本的な Transform コンポーネントを解説します。

IObjectComponent 基底クラス

Objects/IObjectComponent.h に定義されています。Transform・MeshFilter・Velocity など、EmptyObject に付けられる全てのコンポーネントはこのクラスを継承します（シーンコンポーネント ISceneComponent とほぼ対になる設計です）。

公開メソッド

const std::string &GetComponentType() const; size_t GetMaxComponentCountPerObject() const; size_t GetComponentTypeID() const; int GetUpdatePriority() const; void SetUpdatePriority(int priority); bool IsActive() const; void SetActive(bool active); // 有効化時にInitialize、無効化時にFinalizeが走る void SetTag(const std::string &tagName); const Tag &GetTag() const noexcept; const std::string &GetTagName() const noexcept; const EmptyObject *GetOwnerObject() const; // 未所属の場合は nullptr virtual std::unique_ptr<IObjectComponent> Clone() const = 0; MemberVariable *GetMemberVariable(const std::string &key); const std::unordered_map<std::string, MemberVariable> &GetAllMemberVariables() const;

GetUpdatePriority() は数値が小さいほど先に更新される優先度です。GetOwnerObject() で自身が付いている EmptyObject を辿れます。GetMemberVariable / GetAllMemberVariables は、あとで説明する ADD_MEMBER_VARIABLE で登録した「メンバ変数への汎用アクセス」（ImGuiエディタやKeyFrameAnimatorのような外部システムが、具体的な型を知らずに値を読み書きするための仕組み）です。

派生クラスが実装する protected 仮想関数

protected: virtual void Initialize(); // 生成・有効化時 virtual void Finalize(); // 削除・無効化時 virtual void Update(); // 毎フレーム（IsActive()の場合のみ） virtual JSON SaveToJson() const; // JSONへの保存 virtual bool LoadFromJson(const JSON &json); // JSONからの読み込み #if defined(USE_IMGUI) virtual void ShowImGui(); // インスペクタ表示 virtual void ShowPersistentImGui(); // ポーズ中も毎フレーム表示したい内容 #endif

いずれも既定実装は「何もしない」（SaveToJsonは空オブジェクト、LoadFromJsonはtrueを返す）ため、必要なものだけをオーバーライドします。Initialize/Finalize/Updateを直接外から呼ぶことはなく、常にInitializeInterface/FinalizeInterface/UpdateInterface（Passkey<EmptyObject>経由）を介してEmptyObject側から呼ばれます。

コンポーネント定義マクロ

実際のコンポーネント定義は ComponentSerialize/ComponentRegistry.h と IObjectComponent.h で定義されるいくつかのマクロを使って書きます。

OBJECT_COMPONENT_CONSTRUCTOR(typeName, maxCount, initializeCode)

#define OBJECT_COMPONENT_CONSTRUCTOR(typeName, maxCount, initializeCode) \ typeName() : IObjectComponent(#typeName, maxCount, GetComponentTypeID<typeName>()) { \ REGISTER_COMPONENT_OBJECT(typeName); initializeCode }

デフォルトコンストラクタを1行で生成するマクロです。第1引数はコンポーネントのクラス名（#typeName で文字列化され、JSONの "type" やエディタ表示名になります）、第2引数は同じオブジェクトへ付けられる最大数、第3引数はコンストラクタ本体（多くの場合 ADD_MEMBER_VARIABLE の呼び出し列）です。

REGISTER_COMPONENT_OBJECT(ComponentClass) / COMPONENT_CATEGORY(...)

#define REGISTER_COMPONENT_OBJECT(ComponentClass) \ static const bool is##ComponentClass##RegisteredInObject = RegisterComponentTypeObject( \ #ComponentClass, \ []() -> std::unique_ptr<IObjectComponent> { return std::make_unique<ComponentClass>(); }, \ ComponentCategoryOf<ComponentClass>::Get() \ ); #define COMPONENT_CATEGORY(...) \ static std::vector<std::string> GetComponentCategory() { return { __VA_ARGS__ }; }

REGISTER_COMPONENT_OBJECT はコンポーネント型を「型名文字列 → 生成関数」のレジストリへ登録する静的初期化トリックです。OBJECT_COMPONENT_CONSTRUCTOR マクロの中でも自動的に呼ばれますが、名前空間スコープでクラス定義の直後にも REGISTER_COMPONENT_OBJECT(Transform) のように書かれます（重複登録は問題ありません）。これにより AddComponentFromJson のようにJSONの型名文字列だけからインスタンスを生成できます。COMPONENT_CATEGORY("Physics") のようにクラス定義内の public 部に書くと、シーンエディタの「Add Component」メニューでカテゴリ階層（例: COMPONENT_CATEGORY("Collision", "Collider")）としてツリー表示されます。

ADD_MEMBER_VARIABLE / ADD_MEMBER_VARIABLE_WITH_CALLBACK

#define ADD_MEMBER_VARIABLE(var) AddMemberVariable(#var, &var) #define ADD_MEMBER_VARIABLE_WITH_CALLBACK(var, ...) AddMemberVariable(#var, &var, __VA_ARGS__)

コンストラクタ内で自身のメンバ変数を「外部から汎用的に読み書きできる変数」として登録します。ADD_MEMBER_VARIABLE_WITH_CALLBACK は、外部（ImGuiやアニメーションシステムなど）がポインタ経由で値を直接書き換えた後に呼ばれるコールバックを追加で登録でき、セッターを迂回した書き込みに伴う副作用（例: Transformのワールド行列キャッシュの無効化）を処理するために使われます。

実例（Objects/Components/Rotation.h）:

class Rotation final : public IObjectComponent {
public:
    OBJECT_COMPONENT_CONSTRUCTOR(Rotation, 1,
        ADD_MEMBER_VARIABLE(angularVelocity_);
        ADD_MEMBER_VARIABLE(angularAcceleration_);
    )
    COMPONENT_CATEGORY("Physics")
    ~Rotation() override = default;
    // ...
private:
    Vector3 angularVelocity_{ 0.0f, 0.0f, 0.0f };
    Vector3 angularAcceleration_{ 0.0f, 0.0f, 0.0f };
};

REGISTER_COMPONENT_OBJECT(Rotation)

Transform コンポーネント

Objects/Components/Transform.h に定義される、位置・回転・スケールを持つ最も基本的なコンポーネントです。最大付与数は1（OBJECT_COMPONENT_CONSTRUCTOR(Transform, 1, ...)）。回転は内部的にクォータニオンで保持され、オイラー角はクォータニオンから都度変換される互換用のAPIです。

親子関係

bool SetParentObject(EmptyObject *parent); // nullptr で親を解除 bool SetParentObject(const UUID128 &parentUUID); EmptyObject *GetParentObject() const;

Transform を持たないオブジェクトを親にすることはできません。また循環参照（自分自身や自分の子孫を親にする）になる設定は失敗（false）します。

ローカル変換

void SetTranslate(const Vector3 &translate); void SetTranslateY(const float &translateY); void SetRotate(const Vector3 &rotate); // オイラー角（ラジアン） void SetRotateQuaternion(const Quaternion &quat); void SetScale(const Vector3 &scale); const Vector3 &GetTranslate() const; const Vector3 &GetRotate() const; // オイラー角（ラジアン） const Quaternion &GetRotateQuaternion() const; const Vector3 &GetScale() const;

ワールド変換

Vector3 GetWorldPosition(); Vector3 GetWorldScale(); Quaternion GetWorldRotateQuaternion() const; Vector3 GetWorldRotate() const; // オイラー角（ラジアン） const Matrix4x4 &GetWorldMatrix();

親を持つ場合、ワールド行列は親のワールド行列を再帰的に合成して求められます。計算結果はバージョン管理付きでキャッシュされ（worldMatrixVersion_ / cachedParentVersion_）、親子どちらも変更が無い限り再計算されません。GetWorldRotateQuaternion は親のローカル回転を再帰的に合成する近似値（スケールの歪みは無視）であることに注意してください。

基本的なオブジェクトコンポーネント一覧

Objects/Components/ 配下にある代表的なコンポーネントです。描画専用・当たり判定専用のものは 05_Rendering.html・06_Collision.html で詳しく扱うため、ここでは名前と役割のみ紹介します。

クラス名最大付与数カテゴリ役割
Transform1-位置・回転・スケール、親子関係とワールド行列
PreTransform255Physics1フレーム前のTransform情報を保持（モーションブラー・補間用）
Velocity1Physics速度・加速度から毎フレーム Transform の位置を更新
Rotation1Physics角速度・角加速度から毎フレーム Transform の回転を更新

最大付与数（maxCount）について
OBJECT_COMPONENT_CONSTRUCTOR の第2引数が、そのコンポーネントを同一オブジェクトへ何個まで付けられるかの上限です。Transform や Velocity のように「1個だけ意味がある」ものは 1、Comment のように複数あっても構わないが用途上は基本1個のものも 1、PreTransform や Shake のように内部的な制約が緩いものは 0xFF（255）が指定されています。上限は IObjectComponent::GetMaxComponentCountPerObject() で取得できます。
