ユーティリティ

ファイル入出力、数学ユーティリティ、時間管理、乱数、タグ、UUID、多言語対応など、エンジン全体で使う細々としたヘルパー群です。多くは KashipanEngine/Utilities/ 配下にあります。

ファイル入出力 (FileIO)

Utilities/FileIO.h は以下のヘッダを束ねたインクルード用ヘッダで、種類別に読み書き関数がまとまっています。すべて構造体を返す/受け取るシンプルな関数群です。

JSON — Utilities/FileIO/JSON.h

using JSON = nlohmann::json; // Json / json も同じ別名 JSON LoadJSON(const std::string &filepath); bool SaveJSON(const JSON &jsonData, const std::string &filepath, int indent = 4); template<typename T> std::optional<T> GetJSONValue(const JSON &json, const std::string &key); template<typename T> T GetJSONValueOrDefault(const JSON &json, const std::string &key, const T &defaultValue); std::optional<JSON> GetNestedJSONValue(const JSON &json, const std::string &path); // 例: "object.array[0].value" bool ValidateJSONStructure(const JSON &json, const std::vector<std::string> &requiredKeys); bool IsJSONFileValid(const std::string &filepath); JSON MergeJSON(const JSON &base, const JSON &overlay, bool deepMerge = true); bool AppendToJSONArray(JSON &json, const std::string &arrayKey, const JSON &value); bool RemoveFromJSONArray(JSON &json, const std::string &arrayKey, size_t index); std::string JSONToFormattedString(const JSON &json, int indent = 4); void PrintJSON(const JSON &json, const std::string &title = "JSON Data");

タグ (Tag)

Utilities/Tag.h

文字列をFNV-1a(64bit)ハッシュへ変換して保持する軽量クラス。内部はハッシュ値のみで、比較(==/!=)は文字列比較よりも高速です。オブジェクトやコライダーの分類・判別に使われます(03_GameObjects.html、06_Collision.html 参照)。

Passkeyイディオム (Passkeys)

Utilities/Passkeys.h

「特定のクラスからしか呼び出せないpublicメソッド」を実現するテンプレート。Passkey<T>のコンストラクタはprivateで、friend T;によりTだけがインスタンス化できます。詳しい設計思想は 01_Overview.html を参照してください。

template <typename T> class Passkey final { friend T; Passkey() = default; }; // エンジン起動処理専用の特別なPasskeyも用意されている class PasskeyForWinMain final { /* friend int ::WinMain(...); */ }; class PasskeyForGameEngineMain final { /* friend int Execute(PasskeyForWinMain, const std::string&); */ }; class PasskeyForCrashHandler final { /* friend LONG WINAPI CrashHandler(EXCEPTION_POINTERS*); */ };

例えば EmptyObject::SaveToJson(Passkey<Scene>) は、呼び出し側が Passkey<Scene>型の値を用意する必要がありますが、そのコンストラクタはSceneクラスの中でしか呼べないため、事実上「Sceneクラスの内部からしか呼べないメソッド」になります。

文字列テンプレート (TemplateLiteral)

Utilities/TemplateLiteral.h

JavaScriptのテンプレートリテラルのように、${name} というプレースホルダーを含む文字列に値を差し込むためのクラスです。翻訳テキストへのパラメータ埋め込みなどに使われます。

TemplateLiteral tpl("こんにちは、${name}さん！ 所持金: ${gold}G"); tpl["name"] = "プレイヤー"; tpl["gold"] = 1200; std::string text = tpl.Render(); // "こんにちは、プレイヤーさん！ 所持金: 1200G"

Set(key, value)は文字列化可能な型（std::ostreamへ出力可能な型）や、std::vector等のコンテナ型（", "区切りで結合）に対応しています。Placeholders()でテンプレート内のプレースホルダー名一覧を、HasPlaceholder(key)で存在確認ができます。

文字コード・色変換 (Conversion)

文字列変換 — Utilities/Conversion/ConvertString.h

std::wstring ConvertString(const std::string &str); std::string ConvertString(const std::wstring &str); std::wstring ShiftJISToUTF16(const std::string &sjis); std::string UTF16ToUTF8(const std::wstring &utf16); std::string ShiftJISToUTF8(const std::string &sjis); std::vector<char32_t> Utf8ToCodepoints(const std::string &utf8); std::string PathToUtf8String(const std::filesystem::path &path); std::filesystem::path Utf8StringToPath(const std::string &utf8String);
重要
