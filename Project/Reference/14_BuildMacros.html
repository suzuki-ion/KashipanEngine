ビルドマクロ

KashipanEngineのビルド構成(Configuration)ごとに定義されるプリプロセッサマクロと、それによってコードの挙動がどう切り替わるかをまとめます。

ビルド構成とマクロの対応

KashipanEngine.vcxproj のビルド構成ごとに、以下のプリプロセッサマクロが自動的に定義されます(実際の PreprocessorDefinitions 設定から確認)。

ビルド構成 (Configuration)定義されるマクロ備考
DebugDEBUG_BUILD, USE_IMGUI, _DEBUG最適化なし、デバッグ情報あり
DevelopmentDEVELOPMENT_BUILD, USE_IMGUI_ITERATOR_DEBUG_LEVEL=0。エディタ機能ありで動作確認する構成
ReleaseRELEASE_BUILD, NDEBUGUSE_IMGUIは定義されない。エディタ機能なしの製品版構成
3つの構成の使い分け
DEBUG_BUILD・DEVELOPMENT_BUILD・RELEASE_BUILD は互いに排他的で、必ずどれか1つだけが定義されます。USE_IMGUIはDebugとDevelopmentの両方で定義され、Releaseでは定義されません。

USE_IMGUI — エディタ機能の有効化

コードベース全体で最も多くの箇所に登場するマクロです。シーンエディタ(12_SceneEditor.html)、各コンポーネントのインスペクタ表示(ShowImGui()相当の処理)、デバッグログのImGuiウィンドウ表示など、開発中にしか使わないツール機能はすべて#if defined(USE_IMGUI)ブロックで囲まれています。 

// 例: KashipanEngine/Core/GameEngine.h や GameEngine.cpp、Window.h、Input.h、
// AudioManager.h/cpp、Debug/ImGuiManager.h/cpp など、非常に多くのファイルで使用されている
#if defined(USE_IMGUI)
    // シーンエディタのUI更新、ImGuiウィンドウの描画、
    // デバッグ用のオブジェクト/コンポーネントインスペクタ表示 など
#endif
Releaseビルドでの注意
USE_IMGUIが定義されないRelease構成では、シーンエディタやImGuiベースのデバッグ表示は一切コンパイルされません。エディタでシーンを編集する開発時はDebugまたはDevelopment構成でビルドしてください。

DEBUG_BUILD / DEVELOPMENT_BUILD / RELEASE_BUILD

これらはログの出力形式や、デバッグ用の追加処理を切り替えるために使われます。例えば Debug/Logger.cpp ではビルド種別を表す文字列をログの先頭に付与しています。 

// KashipanEngine/Debug/Logger.cpp
const std::string kBuildTypeString =
#ifdef DEBUG_BUILD
    "[Debug]";
#elif defined(DEVELOPMENT_BUILD)
    "[Develop]";
#elif defined(RELEASE_BUILD)
    "[Release]";
#else
    "[Unknown]";
#endif

また Core/Window.cpp では #if defined(DEBUG_BUILD) || defined(DEVELOPMENT_BUILD) という形で、「エディタ用構成(DebugまたはDevelopment)でのみ有効にしたい処理」と「USE_IMGUIの有無で切り替えたい処理」を使い分けています。両者はほぼ同じ意味になることが多いですが、USE_IMGUIは「ImGui自体を使うかどうか」、DEBUG_BUILD/DEVELOPMENT_BUILDは「製品版でないビルドかどうか」という異なる軸のマクロなので、新しくコードを書く際はどちらの意図で分岐したいかを意識してください。

マクロ切り分けの目安

目的使うべきマクロ
ImGuiのAPIやシーンエディタ機能そのものを呼び出す/呼び出さないUSE_IMGUI
製品版(Release)には含めたくないデバッグ専用処理全般!defined(RELEASE_BUILD) あるいは defined(DEBUG_BUILD) || defined(DEVELOPMENT_BUILD)
Debug構成だけで有効にしたい重い検証処理DEBUG_BUILD
ログの表示形式など、ビルド種別を人間向けに区別したいだけの場合DEBUG_BUILD/DEVELOPMENT_BUILD/RELEASE_BUILD の3分岐
