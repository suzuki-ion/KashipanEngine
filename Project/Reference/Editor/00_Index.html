KashipanEngine エディタリファレンス

ImGuiベースのシーンエディタ（KashipanEngine/Scene/Editor/ 配下）についてのリファレンスです。ここではエディタというツールの使い方・画面構成・各コンポーネントのInspector表示を扱います。エンジン本体のC++ API（クラス・関数）は別サイトのエンジン本体リファレンスを参照してください。

初めての方へ
まずは使い方ガイドに沿って、シーン作成からスクリプトでキャラクターを動かすところまでを一通り体験することをおすすめします。個別の画面・コンポーネントの詳しい項目は、慣れてきたら下記の各リファレンスを辞書的に参照してください。

このリファレンスの構成

読者（想定する利用シーン）によって4つのセクションに分かれています。

セクション対象読者内容
内部アーキテクチャエディタ機能自体を実装・拡張するエンジン開発者SceneEditor・各ウィンドウクラス・SceneEditorCommands（Undo/Redo）・PrefabUtility などC++クラス構成
ウィンドウ（下記目次）エディタでゲームを作る利用者各ImGuiウィンドウのメニュー・ボタン・操作方法
コンポーネント（下記目次）エディタでゲームを作る利用者Inspector上に表示されるコンポーネントごとの項目・入力欄の説明
使い方ガイド初めてこのエンジンでゲームを作る利用者シーン作成からシーン遷移まで、手順を追って学ぶチュートリアル

コンポーネント

Inspector上でのコンポーネントごとの項目リファレンスです。C++側のクラス・メソッドの詳細は各ページからエンジン本体リファレンスへリンクしています。

カテゴリ内容
BasicTransform・Velocity・Shake・ScriptComponent・AudioSource など基礎コンポーネント
RenderMeshRenderer・Light・Camera3D など描画コンポーネント
UIUIButton など、画面上の矩形に対するマウス判定を行うUI用コンポーネント
ColliderBoxCollider・RigidBody3D など当たり判定・物理コンポーネント
PostEffectBloomEffect・OutlineEffect などScreenBufferObject用ポストエフェクト
ComputeComputeShaderProcessing
SceneSceneRenderer など、Scene Component Inspectorに表示されるシーン直下のコンポーネント

左のサイドバーからカテゴリごとに個別のコンポーネントページへ移動できます。
