エディタ内部アーキテクチャ

KashipanEngine/Scene/Editor/ 配下のImGuiベースのシーンエディタについて、構成クラスと基本操作フローを解説します。対象読者はエディタ機能自体を実装・拡張するエンジン開発者です。エディタの使い方（ボタン操作・メニュー）はウィンドウ別リファレンスを、コンポーネントのInspector項目はコンポーネントリファレンスを参照してください。

USE_IMGUI 限定機能
このページで扱うクラスは全て #ifdef USE_IMGUI ブロックの中で定義されており、USE_IMGUI マクロが有効な構成（Debug / Development）でのみコンパイル・動作します。Release構成では丸ごと存在しません。詳しくは Engine/14_BuildMacros.html を参照してください。

SceneEditor — 統括クラス

Scene/SceneEditor.h の SceneEditor は各シーンが1つずつ保持する（Scene クラスの sceneEditor_）エディタ本体です。コンストラクタは Passkey<Scene> を要求するため、Scene クラスの内部からのみ生成できます。

SceneEditor final

SceneEditor(Passkey<Scene>, SceneEditorContext *context); void ShowImGui(); // 毎フレーム呼ばれ、メインメニュー・各ウィンドウ・再生コントロールを描画する

内部で下記の各ウィンドウ用クラスをまとめて保持し、Undo/Redoショートカット処理（HandleShortcuts）や、間隔指定の自動バックアップ（HandleAutoSave、既定は SceneBackups/ 以下へ保存）、新規シーン作成の確認モーダルなども担当します。

Undo/Redo — SceneEditorCommands

Scene/Editor/SceneEditorCommands.h はコマンドパターンによるUndo/Redo管理です。全ての編集操作は IEditorCommand を実装したコマンドとして表現されます。

IEditorCommand

class IEditorCommand { public: virtual bool Execute(SceneEditorContext *context) = 0; virtual bool Undo(SceneEditorContext *context) = 0; virtual std::string GetName() const = 0; };
コマンド用途
CreateObjectCommand / CreateSiblingObjectCommand / CreateChildObjectCommandオブジェクトの新規作成
PasteObjectCommandJSONスナップショット（部分木、pre-order）からの貼り付け/複製。コピー&ペースト・プレハブ配置・削除のUndoが全てこの形式を共有する
DeleteObjectCommand / MoveObjectCommand / ObjectPropertyCommand削除・並び替え・名前/アクティブ状態の変更
AddComponentCommand / RemoveComponentCommand / ComponentEditCommandコンポーネントの追加・削除・パラメータ編集
CompositeCommand複数コマンドを1つの操作としてまとめる複合コマンド

SceneEditorCommands final

bool Execute(std::unique_ptr<IEditorCommand> command); void PushExecuted(std::unique_ptr<IEditorCommand> command); // 適用済み操作をスタックへ積む（パラメータ編集のコアレス用） bool Undo(); bool Redo(); bool CanUndo() const noexcept; bool CanRedo() const noexcept; void Clear(); void BeginPlaySession(); // 再生中のコマンドを専用の一時履歴へ分離する void EndPlaySession(); // 再生停止時に一時履歴を破棄する bool IsPlaySession() const noexcept;

再生（Play）中に積まれたコマンドは停止時のシーン復元で巻き戻されるため、編集時の履歴とは互換性がありません。BeginPlaySession/EndPlaySession により専用の一時履歴へ分離し、編集時の履歴を再生を跨いでも安全に保持できるようにしています。

オブジェクト階層 — SceneObjectHierarchy

オブジェクトツリーの表示、単一/複数選択（Ctrlでトグル追加、Shiftで範囲選択）、ドラッグ&ドロップによる並び替え・親子付け替え、コピー/貼り付け/複製/削除、キーボードショートカット（HandleKeyboardShortcuts()）を担当します。

SceneObjectHierarchy 主要API

EmptyObject *GetSelectedObject() const; // 最後に操作したオブジェクト const std::unordered_set<EmptyObject *> &GetSelectedObjects() const; // 選択中の全オブジェクト void SelectObject(EmptyObject *obj, bool additive = false); // シーンビュー等の外部からの選択操作 void InstantiateNodes(const std::vector<PasteObjectCommand::Node> &nodes, const std::string &name, EmptyObject *attachParent = nullptr); bool InstantiatePrefabFile(const std::string &filePath, EmptyObject *attachParent = nullptr);

プレハブ — PrefabUtility

Scene/Editor/PrefabUtility.h はプレハブ（.prefab）ファイルの作成・読み込みユーティリティです。中身はシーン保存時のオブジェクトJSONと同じ形式を部分木（pre-order、先頭が根）として並べたただのJSONで、配置時はヒエラルキーのコピー/貼り付けと同じ機構（PasteObjectCommand）で新しいオブジェクトIDを割り当てて生成されます。

JSON BuildPrefabJson(SceneEditorContext *context, EmptyObject *rootObject); std::vector<PasteObjectCommand::Node> LoadPrefabNodes(const JSON &prefabJson); std::vector<PasteObjectCommand::Node> PrepareNodesForInstantiation( const std::vector<PasteObjectCommand::Node> &source, bool preserveRootParent);

インスペクター

SceneObjectInspector は選択中オブジェクトのコンポーネントを処理優先順位順に表示し、ドラッグ&ドロップでの並び替えにも対応します。複数選択時は「プライマリ（最後に操作したオブジェクト）」の値を編集すると、他の選択オブジェクトの対応するコンポーネント（同じ型のordinal番目）へ差分を一括適用します。新規コンポーネントの追加には ComponentAddMenu::Show()（カテゴリ階層のツリーメニュー）を使います。

// ComponentAddMenu.h bool Show(const std::vector<std::string> &types, const std::function<const std::vector<std::string> &(const std::string &)> &getCategory, std::string &outSelectedType);

シーンビュー — SceneEditorView

専用の ScreenBuffer とオービット型のデバッグカメラを持ち、シーン上の全 MeshRenderer をこの ScreenBuffer に描画してImGuiウィンドウへ表示します。選択中オブジェクトには ImGuizmo によるギズモ操作（移動/回転/スケール、単一選択はLocal/World切替可、複数選択時は選択群の平均位置を中心としたグループ操作）が行えます。画像上のクリックでは、レイとメッシュ三角形の交差判定によるピッキングでオブジェクトを選択できます（Ctrlクリックでトグル追加）。グリッド・当たり判定ワイヤーフレーム・ライト/カメラのアイコン表示・ボーン表示の有効無効も切り替えられます。

アセットブラウザ — AssetsWindow

Unity の Assets ウィンドウ風のファイルブラウザです。左側にフォルダツリー、右側に選択中フォルダ内のファイルをグリッド表示し、対応拡張子のファイルをダブルクリックで専用の編集/プレビューウィンドウ（JSON編集、マテリアル編集、画像プレビュー、オーディオプレビュー）に開きます。ヒエラルキーからオブジェクトをドラッグ&ドロップすると、その場で .prefab ファイルとして書き出せます。

Play / Pause / Stop 制御（Unity風）

Scene.h にはエディター実行を前提としたUnity風の再生制御メソッドがあります。

Scene 再生制御 USE_IMGUI

bool IsPlaying() const; bool IsPaused() const; void PlayStart(); void PlayStop(); void PlayPause(); void PlayResume(); void RequestStepFrame(); // 一時停止中に1フレームだけ進める

エディター実行時、シーンの毎フレーム更新は「再生中（isPlaying_）かつ（一時停止していない、または1フレーム進める要求がある）」場合のみ行われます。SceneEditor::ShowPlayControls() がツールバーのPlay/Pause/Stopボタンとしてこれらを呼び出します。停止（PlayStop）時にはシーン状態が再生開始前へ復元され、再生セッション用のUndo履歴（SceneEditorCommands::EndPlaySession）も破棄されます。

基本操作フロー

  1. ヒエラルキーの右クリックメニュー、または SceneObjectHierarchy の作成メニューからオブジェクトを新規作成する（テンプレート化されたコンポーネント一式を最初から持たせることも可能）
  2. 作成したオブジェクトを選択し、インスペクターの Add Component（ComponentAddMenu）からカテゴリツリーを辿って必要なコンポーネントを追加する
  3. インスペクターでコンポーネントのパラメータを編集する（編集はUndo履歴へ自動的に積まれる）
  4. シーンビューでギズモを使って位置・回転・スケールを調整する
  5. Playボタンで実際の挙動を確認し、必要なら Pause / Step Frame で1フレームずつ確認する
  6. SceneSaver でシーンをファイルへ保存する（自動バックアップも別途 SceneBackups/ 以下へ行われる）

各手順のボタン・メニュー項目の詳細は Windows/02_SceneObjectHierarchy.html・Windows/03_ObjectInspector.html・Windows/04_SceneView.html を参照してください。
