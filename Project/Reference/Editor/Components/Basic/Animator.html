Animator 最大1個

スケルトンアニメーションの再生を管理するコンポーネントです。同オブジェクトのMeshFilterが指すメッシュのスケルトンへアニメーションクリップを適用します（UnityのAnimatorに近い役割）。

Inspectorに表示される項目

ラベルウィジェット内容
Root Boneオブジェクト選択欄（コンボ＋ドラッグ&ドロップ）アーマチュア同期の探索起点となるオブジェクト。未設定の場合は所有オブジェクト自身の最上位の祖先が起点になる
Animation Clipコンボ（(None) + 取得元アセット内のクリップ名一覧）再生するアニメーションクリップ名。空（(None)）の場合はバインドポーズのまま静止する。選択を変更すると再生位置が先頭へ戻る
Animation Sourceコンボ（(None) + 読み込み済みアニメーションアセットのパス一覧）アニメーション取得元のアセットパス。空の場合はMeshFilterが指すメッシュ自身のファイルから取得する。別ファイルを指定すると、そのファイルのアニメーションを（ボーン名が一致する範囲で）このスケルトンへ適用できる
Play On Startチェックボックスゲームループ開始時に自動で再生を開始するか
Loopチェックボックス末端に到達したらループするか
Playback Speedドラッグ入力欄（ステップ0.01、範囲0〜10）再生速度の倍率
Play / Stop（トグルボタン）ボタン再生中は"Stop"、停止中は"Play"と表示され、押すと再生状態を切り替える
Joint Count: N（テキスト表示のみ）読み取り専用テキスト解決済みスケルトンのジョイント（ボーン）数
Animation Sourceの項目にカーソルを合わせると、取得元の意味についてのツールチップが表示されます。

Add Componentでの位置

Add Component → Animation → Animator。
