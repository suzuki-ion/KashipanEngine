AudioSource

音声を再生するコンポーネントです。使用する音声・ボリューム・ピッチ・ループ・距離減衰に加え、フィルター/リバーブ/エコー/イコライザー/リミッターの各エフェクトを個別に有効化して複数同時にかけられます。

基本設定

ラベルウィジェット内容
Soundコンボ（(None) + 読み込み済みサウンドのアセットパス一覧）再生する音声
Volumeドラッグ入力欄（ステップ0.01、範囲0〜1）音量
Pitch(semitones)ドラッグ入力欄（ステップ0.1、範囲-24〜24）ピッチ（半音単位）
Loopチェックボックスループ再生するか
Min Distanceドラッグ入力欄（ステップ0.1、範囲0〜Max Distance）距離減衰が始まる距離
Max Distanceドラッグ入力欄（ステップ0.1、範囲Min Distance〜10000）この距離を超えると音量が0になる

Effects（各エフェクトは個別に有効/無効を切り替え、複数同時にかけられる）

ラベルウィジェット内容
Filterチェックボックス特定の周波数帯域を削るフィルター。音を籠らせたり、軽くしたりできる
　Filter Typeコンボ（LowPass / HighPass / BandPass / Notch）LowPass: 高音を削って籠らせる。HighPass: 低音を削って軽くする。BandPass: カットオフ周波数付近のみを通す。Notch: カットオフ周波数付近のみを削る
　Frequencyドラッグ入力欄（ステップ0.005、範囲0.0005〜1.0）正規化カットオフ周波数。0に近いほど強くかかり、1.0でほぼ無効
　Q (Resonance)ドラッグ入力欄（ステップ0.01、範囲0.0005〜1.5）共鳴の鋭さ(1/Q)。小さいほどカットオフ周波数付近の音が強調される
Reverbチェックボックス残響。ホールや洞窟の中で鳴っているような響きを付加する
　Reverb Mixドラッグ入力欄（ステップ0.005、範囲0〜1）残響への送り量。大きいほど響きが強くなる（0.0: 残響無し 〜 1.0: 最大）
Echoチェックボックスやまびこ。遅延した音を繰り返し重ねる
　Wet/Dry Mixドラッグ入力欄（ステップ0.005、範囲0〜1）原音とエコー音の混合比（0.0: 原音のみ 〜 1.0: エコー音のみ）
　Feedbackドラッグ入力欄（ステップ0.005、範囲0〜1）エコーの繰り返し量。大きいほど長く繰り返される（1.0で減衰しない）
　Delay (ms)ドラッグ入力欄（ステップ1、範囲1〜2000）エコーの遅延時間（ミリ秒）
Equalizerチェックボックス4バンドイコライザー。周波数帯域ごとに音量を増減できる
　Band 1〜4: Frequency (Hz)ドラッグ入力欄（ステップ10、範囲20〜20000）そのバンドの中心周波数
　Band 1〜4: Gainドラッグ入力欄（ステップ0.01、範囲0.126〜7.94）そのバンドの増幅率。1.0で等倍、小さいほど削り、大きいほど持ち上げる
　Band 1〜4: Bandwidthドラッグ入力欄（ステップ0.01、範囲0.1〜2.0）そのバンドの帯域幅（中心周波数を基準としたオクターブ幅）。大きいほど広い範囲に影響する
Limiterチェックボックスマスタリングリミッター。音量が大きくなりすぎないよう圧縮し、音割れを防ぐ
　Release整数ドラッグ入力欄（ステップ0.1、範囲1〜20）圧縮を解除するまでの時間。大きいほどゆっくり戻る
　Loudness整数ドラッグ入力欄（ステップ1、範囲1〜1800）音量の閾値。小さいほど強く圧縮される

各エフェクトの見出し（Filter/Reverb/Echo/Equalizer/Limiter）にカーソルを合わせると説明がツールチップで表示され、有効化した場合のみサブ項目がインデント表示されます。

その他・再生操作

ラベルウィジェット内容
Auto Pan / Muffle (Spatial Audio)チェックボックス有効にすると、使用中のAudioListenerとの位置関係から左右への振り分け（パン）と音の籠り具合を毎フレーム自動計算する。音源が受聴者の背後にあるほど強く籠る
Play / Resume / Pauseボタン状態に応じて表示が切り替わる。未再生時は"Play"、一時停止中は"Resume"、再生中は"Pause"
Stopボタン再生・一時停止のどちらでもない場合は無効化（グレーアウト）される

Add Componentでの位置

Add Component → Audio → AudioSource。最大付与数の制限はありません。
