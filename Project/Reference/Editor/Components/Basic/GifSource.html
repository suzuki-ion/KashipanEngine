GifSource

アニメーションGIFを再生するコンポーネントです。同じオブジェクトにSpriteRenderer/MeshRendererが付いている場合、再生開始時にそのレンダラーが使用しているマテリアルを複製し、複製したマテリアルのテクスチャを再生中のGIFへ差し替えて割り当てます（元のマテリアルアセット自体は書き換えません）。停止時はGIFの最初の1フレームを表示し続けます。

Inspectorに表示される項目

ラベルウィジェット内容
GIFコンボ（(None) + 読み込み済みGIFのアセットパス一覧）再生するGIF。Assets WindowからGIFファイルをこの項目へドラッグ&ドロップして割り当てることもできる
Loopチェックボックスループ再生するか
Play On Awakeチェックボックスシーン開始時に自動で再生を開始するか
Play / Resume / Pauseボタン状態に応じて表示が切り替わる。未再生時は"Play"、一時停止中は"Resume"、再生中は"Pause"
Stopボタン再生・一時停止のどちらでもない場合は無効化（グレーアウト）される。停止するとGIFの最初の1フレームがレンダラーに表示され続ける
GIFを切り替えた（Value変更・ドラッグ&ドロップ）直後は、再生・一時停止中でなければ自動的にStopが呼ばれ、新しいGIFの最初の1フレームがプレビュー表示されます。

Add Componentでの位置

Add Component → Animation → GifSource。最大付与数の制限はありません。
