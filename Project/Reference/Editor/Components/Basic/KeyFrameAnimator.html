KeyFrameAnimator

キーフレームアニメーション（json）のfloat値を、同オブジェクトの他コンポーネントのパラメータへ適用するコンポーネントです。複数のアニメーションを登録でき、それぞれに再生速度・時間オフセット・値オフセット・複数の適用先を設定できます。

全体の項目

ラベルウィジェット内容
Add Animationボタン新しいアニメーション登録を1件追加する。名前は "Anim0", "Anim1"... のように重複しない名前が自動で割り当てられる

登録済みの各アニメーションは、名前をタイトルにしたImGui::CollapsingHeader（折りたたみ可能な見出し）として一覧表示されます。

アニメーション1件分の項目（見出しを開いた中身）

ラベルウィジェット内容
Nameテキスト入力欄識別名。Play/Stop等をコードから呼ぶ際に指定する名前
Json Pathテキスト入力欄 ＋ Reloadボタンキーフレームjsonのパス（Keyframe Animation Editorで作成できる）。Reloadボタンを押すと、そのパスから読み込み直す
（読み込み状態表示）読み取り専用テキスト読み込み済みなら "Keys: N Duration: N.NNs"、失敗していれば赤文字で "読み込み失敗: パスを確認してReloadしてください"、未読み込みなら "未読み込み"
Playback Speedドラッグ入力欄（ステップ0.01）再生速度の倍率（負の値で逆再生）
Time Offsetドラッグ入力欄（ステップ0.01）評価時刻へ加算する再生時オフセット（秒）。同じアニメを複数オブジェクトで位相をずらして再生する用途等
Value Scaleドラッグ入力欄（ステップ0.01）評価値にかけるスケール。Value Offsetの加算より先に適用される（適用値 = 評価値 × Scale + Offset）
Value Offsetドラッグ入力欄（ステップ0.01）評価値へ加算するデフォルト値オフセット。適用先ごとの基準値の違いを吸収する
Loop / Play On Startチェックボックス（横並び）Loop: ループ再生するか（無効なら末端到達で自動停止）。Play On Start: ゲームループ開始時に自動再生するか
Play / Stop（トグルボタン）ボタン再生中は"Stop"＋"Time: N.NNs Value: N.NNN"のテキスト、停止中は"Play"ボタン
Bindings (N) / Add Binding見出しテキスト ＋ ボタン評価値の適用先一覧。Add Bindingで1件追加する
（バインド先選択コンボ ×N ＋ X削除ボタン）コンボ ＋ 小ボタン同オブジェクトの他コンポーネントのfloat/double/Vector成分パラメータ、またはScriptComponentの[SerializeField]付きfloat変数から適用先を選択する
Delete Animation小ボタンこのアニメーション登録を削除する
評価値が実際にバインド先へ書き込まれるのは、そのアニメーションが再生中（Playing）かつゲームループ実行中のみです。エディタが一時停止中は値は適用されません。

Add Componentでの位置

Add Component → Animation → KeyFrameAnimator。最大付与数の制限はありません。
