MeshFilter 最大1個

使用するメッシュを保持するだけのコンポーネントです。MeshRenderer/SpriteRenderer等の描画コンポーネントがこのハンドルを参照します。

Inspectorに表示される項目

ラベルウィジェット内容
Meshコンボ（(None) + 読み込み済みモデルのAssetsルートからの相対パス一覧）使用するメッシュ。選択すると、同シーンのSceneRendererの描画リストキャッシュが再構築される
重複名を避けるため、コンボの候補・保存データともにハンドル値ではなくAssetsルートからの相対パス（文字列）で管理されます。サブメッシュ（"モデルパス:ノード名"形式）もこの一覧に含まれます。

Add Componentでの位置

Add Component → Render → MeshFilter。
