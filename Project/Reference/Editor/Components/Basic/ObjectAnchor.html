ObjectAnchor

参照先オブジェクトの「範囲」（メッシュ・スプライト・テキストの大きさ）の中の基準点へ、自身の位置を毎フレーム追従させるコンポーネントです。基準点は範囲に対する割合で指定するため、参照先の大きさや向きが変わっても「右上の角」「上辺の中央」といった同じ場所に付いていきます。2D（スプライト・テキスト）と3D（メッシュ）のどちらにも同じ設定で使えます。

Inspectorに表示される項目

ラベルウィジェット内容
参照先 (Target)オブジェクト選択欄（検索付きコンボ＋ヒエラルキーからのドラッグ&ドロップ）基準にするオブジェクト。未設定の場合は追従しない。自分自身や自分の子孫は指定できません（指定すると警告が表示され、追従しない）
範囲の基準 (Bounds Source)コンボ参照先の範囲を何から求めるか（下表）。下に「使用中: 〜」として実際に使われている種類が表示される
基準点 (Anchor Point)XYZのドラッグ入力欄（ステップ0.01）範囲内の位置を割合で指定する。(0,0,0)=範囲の最小側の角、(1,1,1)=最大側の角、既定値は(0.5,0.5,0.5)=中心。0〜1の範囲外も指定でき、範囲の外側に置くこともできる
プリセット (X/Y)3×3のボタン基準点のX/Yを、左上・上・右上・左・中央・右・左下・下・右下から選ぶ（Zは変更しない）。現在の値と一致するボタンが強調表示される
オフセット (Offset)XYZのドラッグ入力欄（ステップ0.01）基準点から更にずらす量（ワールド単位）
オフセットを参照先の回転に合わせるチェックボックス有効にすると、オフセットを参照先のワールド回転で回してから加える（既定: 無効＝ワールド軸のまま加える）
反映する軸 (Apply Axes)X / Y / Z のチェックボックス追従結果を反映する軸。外した軸は自身の現在の値を保つ（既定: すべて有効）
回転も追従 (Follow Rotation)チェックボックス有効にすると、位置に加えて回転も参照先のワールド回転に合わせる（既定: 無効）

範囲の基準

選択肢範囲
自動 (Auto)メッシュ・スプライト → テキスト → Transform の順に、参照先が持っているものを使う
メッシュ・スプライト (Mesh / Sprite)MeshFilterのメッシュの外接箱。SpriteRendererを持つ場合は、スプライトのAnchor/Pivot補正込みの矩形（見た目の矩形と一致する）
テキスト (Text)TextRendererの全文字を囲む矩形
Transform（1×1×1の箱）参照先の位置を中心とした1×1×1の箱を、参照先のスケールで拡大したもの。描画コンポーネントを持たないオブジェクト用

指定した種類を参照先が持っていない場合（例: テキストを指定したがTextRendererが無い）は、Transformの箱が使われます。

2Dで使う場合
スプライトやテキストは奥行き（Z）の厚みを持たないため、基準点のZは結果に影響せず、追従先のZは参照先と同じになります。描画順のために自分でZを決めたい場合は「反映する軸」のZを外してください。
範囲は参照先のローカル空間で求めるため、参照先が回転・拡縮していても範囲上の同じ点に追従します。自身に親オブジェクトがある場合は、求めたワールド座標を親のローカル空間へ変換してから書き込みます。実際のシーン階層上の親子関係は変更しません。
エディターで再生していない間も追従するため、追従中はギズモや数値入力でこのオブジェクトの位置（反映する軸）を動かしても上書きされます。位置を調整したい場合は「オフセット」を使ってください。

Add Componentでの位置

Add Component → Utility → ObjectAnchor。最大付与数は255です。
