ParticleSystem2D

2D用パーティクルシステムです。付与されたオブジェクトの子オブジェクトとして、MeshFilter + SpriteRendererを持つパーティクルを一定間隔で生成します。共通ロジックは基底クラスParticleSystemBaseにあり、Inspectorの表示内容はParticleSystem3Dとほぼ同一です（スポーン形状の選択肢のみ異なります）。既定のメッシュは PrimitiveMesh-Circle2D。

再生状態・基本設定

ラベルウィジェット内容
PlayingチェックボックスオンでPlay()、オフでStop()を呼ぶ
Clearボタン（Playingの右）生存中の全パーティクルを即座に削除する
（生存数表示）読み取り専用テキストGPU Simulation有効時は "GPU Simulation: capacity N"、無効時は "Live Particles: N"（現在生存中のパーティクル数）
Total Emitted: N（テキスト表示のみ）読み取り専用テキストこれまでに発生させた総パーティクル数
GPU Simulationチェックボックス有効にすると、パーティクルオブジェクトを一切生成せず、コンピュートシェーダーが移動・寿命計算を行う（Max Particlesが多いほど効果が大きい）。切り替え時にシミュレーション方式のリソースを破棄・再初期化する
Play On Startチェックボックスゲームループ開始時に自動で再生を開始するか
Loopチェックボックス無効の場合、Total Spawn Countで指定した数だけ発生したら自動的に再生を停止する
Emission Rateドラッグ入力欄（ステップ0.1、下限0）1秒あたりの発生回数
Max Particles整数ドラッグ入力欄（ステップ1、下限0）同時に生存できるパーティクルの最大数
Total Spawn Count整数ドラッグ入力欄（ステップ1、範囲0〜1000000）Loopが有効な間は編集不可（グレーアウト）。Loop無効時、この数だけスポーンすると自動的に再生を停止する（Max Particlesとは独立した「総発生数」の上限）

発生パラメータ（Randomizable項目）

以下はいずれも「ラベル ＋ Randomチェックボックス」の行の下に、RandomオフならValue（固定値）、オンならMin/Max（範囲）のドラッグ入力欄が並ぶ共通形式（ShowRandomizableImGui）で表示されます。

ラベル型・ステップ内容
Spawn Countint、ステップ1、範囲0〜1001回のスポーンで生成するオブジェクト数
Lifetimefloat、ステップ0.01、範囲0〜60パーティクルの寿命（秒）
Initial VelocityVector3、ステップ0.01初速（各軸）。生成したパーティクルのVelocityコンポーネントへそのまま渡される
AccelerationVector3、ステップ0.01加速度。同じくVelocityコンポーネントへ渡される
Start ScaleVector3、ステップ0.01生成直後のスケール
End ScaleVector3、ステップ0.01寿命を迎える時点のスケール。Start Scaleから寿命に応じて線形補間される（値はパーティクルごとに1回抽選）
Initial Rotation (deg)Vector3、ステップ0.5初期回転。度単位で入力し、内部でラジアンへ変換される
Initial Rotation Speed (deg/s)Vector3、ステップ0.5初期角速度（度/秒）
Rotation Acceleration (deg/s^2)Vector3、ステップ0.5角加速度（度/秒2）

Spawn Area（スポーン範囲）

「含める形状（Include Shapes）」の和集合から、「除外する形状（Exclude Shapes）」の和集合を取り除いた領域にスポーンします。含める形状が1つも無い、または有効な範囲が無い場合は原点（スポーン基準位置そのもの）にスポーンします。

ラベルウィジェット内容
Include Shapes (spawn inside union) / Add Include Shape形状リスト ＋ 追加ボタンスポーンを許可する形状の一覧
Exclude Shapes (never spawn inside) / Add Exclude Shape形状リスト ＋ 追加ボタンスポーンを禁止する形状の一覧
　Typeコンボ（2D: Point / Rect / Circle）形状の種類。ParticleSystem2Dでは3D版のBox/SphereがそれぞれRect/Circleとして扱われ、Capsuleは選択できない（Z軸は無視される）
　CenterXYZのドラッグ入力欄（ステップ0.01）形状の中心（Pointの場合はこの座標そのもの）
　Size（Rectのみ）XYのドラッグ入力欄（ステップ0.01、下限0）全辺のサイズ（中心から±size/2の範囲）
　Radius（Circleのみ）ドラッグ入力欄（ステップ0.01、下限0）半径
　Removeボタンこの形状エントリを削除する

Spawn Origin（パーティクルオブジェクトの生成方法）

ラベルウィジェット内容
Originコンボ（Child of Self / Child of Other Object / At Owner Position (Unparented) / At Fixed Position）Child of Self: 自身の子として生成。Child of Other Object: 指定した他オブジェクトの子として生成。At Owner Position: 自身の現在のワールド座標を起点に、どの親にも属さず生成（生成後は自身が動いても追従しない）。At Fixed Position: 指定したワールド座標を起点に生成
Parent Object（Child of Other Object選択時）オブジェクト選択欄親にする対象オブジェクト。未設定の場合は自身の子として生成される
Fixed Position（At Fixed Position選択時）XYZのドラッグ入力欄（ステップ0.01）生成先のワールド座標
GPU Simulation有効時にChild of Self/Child of Other Objectを選ぶと、「親のワールド行列を毎フレーム反映し、位置・回転・スケールとも追従する。ビルボード有効時は見た目を常にカメラへ向けるため、親の回転は追従先の平行移動にのみ反映される」旨の注記がグレー文字で表示されます。

Rendering（描画設定）

ラベルウィジェット内容
Targetオブジェクト選択欄描画先とするオブジェクト（生成したSpriteRendererへ渡される）
Meshコンボ（読み込み済みモデル一覧）パーティクルに使うメッシュ（既定 PrimitiveMesh-Circle2D）
Pipelineコンボ（読み込み済みレンダーパイプライン一覧）使用する描画パイプライン（既定 Object2D.DoubleSidedCulling.BlendNormal）
Materialコンボ（読み込み済みマテリアル一覧）使用するマテリアル
Cast Shadowsチェックボックス有効にすると生成したパーティクルがシャドウキャスターとして扱われる。2D（SpriteRenderer）はそもそも影を落とせないため、この項目は実質的に効果がない
Billboardチェックボックス有効にすると、生成した各パーティクルが指定オブジェクトの方を向く（内部でTargetLookAt相当のロジックを利用）
　Billboard Target（Billboard有効時）オブジェクト選択欄向き先オブジェクト。未設定の場合はシーン内のCamera2Dを自動で使用する
　Rotation Mode（Billboard有効時）コンボ（Sync Target Rotation / Look At Target）Sync Target Rotation: 向き先のワールド回転と同期する。Look At Target: 自身の+Z軸が常に向き先の方向を向く

Add Componentでの位置

Add Component → Effect → ParticleSystem2D。最大付与数の制限はありません。
