PreTransform

1フレーム前のTransform情報を保持するコンポーネントです。Inspector上には値の閲覧用のテキストのみが表示され、編集可能な項目はありません。

同オブジェクトのTransformの値を、ScenePreTransformが毎フレーム最後（全オブジェクト・全シーンコンポーネントの更新後）に「前フレームの値」としてこのコンポーネントへ書き込みます。モーションブラー等のGPU用途（ワールド行列）と、スクリプトからの補間・速度計算用途の両方に使われます。

Inspectorに表示される項目

全て読み取り専用のテキスト表示です（ImGui::Text）。編集用のウィジェットはありません。

表示内容
Previous Translate: (x, y, z)前フレームのローカル座標
Previous Rotate (rad): (x, y, z)前フレームのローカル回転（オイラー角）。ラジアンのまま表示され、Transformのように度への変換はされません
Previous Scale: (x, y, z)前フレームのローカルスケール
Previous World Position: (x, y, z)前フレームのワールド座標
Previous World Rotate (rad): (x, y, z)前フレームのワールド回転（オイラー角、ラジアン）
Previous World Scale: (x, y, z)前フレームのワールドスケール
表示専用のため、Inspector上でこれらの値を書き換えることはできません。値は毎フレーム自動的に上書きされます。

Add Componentでの位置

Add Component → Physics → PreTransform。最大付与数の制限はありません。
