PrefabInstanceComponent 最大1個

Prefabインスタンスのサブツリー根にのみ付与される、元のPrefabアセットとの対応関係を示すマーカーコンポーネントです。エディター上でPrefabをシーンへ配置した際に自動で付与され、通常は手動で追加するものではありません。

Inspectorに表示される項目

表示内容
Prefab: パス読み取り専用テキスト（ImGui::TextUnformatted）。対応する元の.prefabファイルのパス
このコンポーネント自体のInspector表示は上記のパス表示のみです。「元のPrefabへ変更を反映する（Apply All）」「元のPrefabの内容に戻す（Revert All）」といった同期操作のUIは、このコンポーネントの項目としてではなく、Scene Object InspectorのPrefabセクション（対象オブジェクトがPrefabインスタンスの場合のみ表示）にまとめて用意されています。
このコンポーネントをユーザーが手動で削除すると、そのオブジェクトはPrefabとのリンクを失います（Unityの「Unpack Prefab Instance」に相当する操作です）。

Add Componentでの位置

Add Component → Prefab → PrefabInstanceComponentのカテゴリに属しますが、通常はAdd Componentメニューから手動で追加する対象ではありません（Prefab配置時にエディターが自動付与します）。
