SceneVariableApplier

シーン変数の値を、同オブジェクトの他コンポーネントのパラメータへ適用するコンポーネントです。InputCommandApplier/KeyFrameAnimatorがfloat値のみを扱うのに対し、シーン変数が持つ型（Bool/Int/Float/Double/String/Vector2/3/4/Quaternion/Matrix4x4）をそのままバインド先へ適用できます。

Inspectorに表示される項目

ラベルウィジェット内容
Variable Nameテキスト入力欄読み取るシーン変数名（Scene Variablesウィンドウで追加済みのもの）
Scopeコンボ（Scene / Global）Scene: 現在のシーン内のシーン変数。Global: シーンをまたいで保持されるグローバルシーン変数
Type: ...（テキスト表示のみ）読み取り専用テキスト指定した変数名が見つかった場合、その型名を表示する。見つからない場合はオレンジ文字で "Variable "名前" not found" と表示される
（適用状態表示）読み取り専用テキスト直前のUpdateで1件以上の適用に成功した場合は緑文字で "Applied"、そうでなければグレー文字で "Not Applied"
Bindings (N) / Add Binding見出しテキスト ＋ ボタン値の適用先一覧。Add Bindingで1件追加する
（バインド先選択コンボ ×N ＋ X削除ボタン）コンボ ＋ 小ボタン変数の型と互換性のある適用先のみが候補に並ぶ。数値系の型ならfloat/double/Vector成分パラメータおよびScriptComponentの[SerializeField]付きfloat変数、それ以外（Vector2/3/4・String・Quaternion・Matrix4x4）は完全に同じ型のメンバ変数のみが値全体の適用先として候補になる
変数がまだ見つからない間（未設定・変数名が空）は、バインド候補はfloat扱いの既定候補が表示されます。実際に適用できるかどうかは、実行時に変数が見つかってからの型一致で決まります。

Add Componentでの位置

Add Component → Utility → SceneVariableApplier。最大付与数の制限はありません。
