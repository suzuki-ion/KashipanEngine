ScriptComponent

AngelScriptのスクリプトファイル（.as）をコンパイルして実行するコンポーネントです。スクリプト内でScriptComponentBehaviorを実装したクラスがインスタンス化され、Awake/Start/Update/End等のライフサイクル関数が呼び出されます。

スクリプトの割り当て

ラベルウィジェット内容
Script Pathコンボ（(None) + 検出済み.asファイルのパス一覧）実行するスクリプトファイルのパス。Assetsウィンドウから.asファイルをこの項目へドラッグ＆ドロップして割り当てることもできる（その場合はReloadまで自動で行われる）
Refresh Listボタン（Script Pathの右）プロジェクト内の.asファイル一覧を再スキャンする。新規作成したスクリプトをScript Pathの候補に出すには、まずこれを押す必要がある
Reloadボタン現在のScript Pathでスクリプトを（再）コンパイルする。成功すると Awake() が呼ばれる。スクリプトの内容を編集した後も、変更を反映するにはこれを押す必要がある

状態表示

表示内容
Behavior: 名前 / (None)ビルドに成功し検出されたScriptComponentBehavior実装クラスの名前
Awake: o/- Start: o/- Update: o/- End: o/-各ライフサイクルメソッドが実装（検出）されているか（o）いないか（-）
OnCollision Enter: o/- Stay: o/- Exit: o/-衝突コールバックメソッドが実装されているか
OnWindowMessage: o/-ウィンドウメッセージコールバックが実装されているか
（エラーメッセージ、赤文字）直近のコンパイル/実行時エラー内容。ビルド失敗時はさらにその下へコンパイラの出力メッセージがオレンジ文字でインデント表示される

Serialize Fields（[SerializeField]付き変数）

スクリプトのBehaviorクラス（またはグローバル変数）に [SerializeField] を付けた変数は、"Serialize Fields" という区切り線の下に自動で編集UIが生成されます。ウィジェットは変数の型と付与された属性（Unity互換のメタデータ）によって決まります。

変数の型 / 属性ウィジェット
boolチェックボックス
int / uint（[Range(min,max)]なし）整数ドラッグ入力欄
int / uint（[Range(min,max)]あり）整数スライダー（min〜max）
float（Rangeなし）ドラッグ入力欄（ステップ0.01）
float（Rangeあり）スライダー（min〜max）
doubleドラッグ入力欄（Rangeありならスライダー）
string（[Multiline]/[TextArea(min,max)]なし）1行テキスト入力欄
string（Multiline/TextAreaあり）複数行テキスト入力欄。内容の行数に応じてminLines〜maxLinesの範囲で高さが自動調整される
Vector2 / Vector3XY・XYZのドラッグ入力欄（ステップ0.01）
Vector4（[ColorPicker]なし）XYZWのドラッグ入力欄（ステップ0.01）
Vector4（ColorPickerあり）カラーピッカー（RGBA）
QuaternionXYZWのドラッグ入力欄（ステップ0.01）
Object@（シーン内オブジェクト参照）オブジェクト選択欄（コンボ＋ヒエラルキーからのドラッグ&ドロップ）
[System.Serializable]クラスツリーノードとして展開し、子フィールドを再帰的に同じ規則で表示する
array<T>（Tは上記いずれか対応型）ツリーノード。Size入力欄で要素数を変更でき、各要素の右に削除ボタン（-）、末尾に追加ボタン（+）が並ぶ

さらに次の表示系メタデータが利用できます。

属性効果
[Header("見出し")]そのフィールドの直前に区切り線付きの見出しを表示する
[Space(高さpx)]そのフィールドの直前に指定した高さの空白を挿入する
[Tooltip("説明")]フィールドにカーソルを合わせたときにツールチップを表示する
array<T>@のようなハンドル構文＋null初期値で宣言する必要があります。値的構文（array<T> 変数名;）で宣言するとAngelScript側のGC追跡が壊れ、Inspector表示時やエンジン終了時にクラッシュする可能性があります。
スクリプトの書き方・利用可能なAPIの一覧はエディターガイド 9. スクリプトを書くとEngine/07_Scripting.htmlを参照してください。ガイドの手順（Script Pathを選ぶ → Refresh List → Reload）はこのページの内容と一致しています。

Add Componentでの位置

Add Component → Script → ScriptComponent。最大付与数の制限はありません。
