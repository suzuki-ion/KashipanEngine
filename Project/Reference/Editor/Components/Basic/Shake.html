Shake

オブジェクトを揺らすコンポーネントです。位置・回転それぞれXYZ軸ごとに有効/無効・振れ幅・速度・イージングを設定でき、各軸が独立にランダムな目標値へ向かって遷移し続けることで揺れを表現します。

再生状態・再生設定

ラベルウィジェット内容
（状態表示）"Playing"（緑）＋Stopボタン、または"Stopped"（グレー）＋Playボタン現在再生中かどうか。PlayボタンはDurationの値でPlay()を呼び出す
Auto Playチェックボックスオブジェクト生成（Initialize）時に自動で再生を開始するか
Duration (0=Infinite)ドラッグ入力欄（ステップ0.01、範囲0〜60）Auto Play時の再生時間（秒）。0以下でStop()が呼ばれるまで無期限に再生する
Process Timingコンボ（Immediate / Deferred (End of Frame)）Immediate: 自身のUpdate内でその場処理する。Deferred（既定）: SceneShakeApplierへ登録し、全オブジェクトのUpdate/衝突解決が終わった後にまとめて処理する（他のスクリプトのTransform操作と競合しない）
Apply Targetコンボ（To Transform / Render Only）To Transform: Transformへ直接オフセットを加算する（終了後は元に戻る）。Render Only（既定）: Transform自体は変更せず、描画時にのみオフセットを乗算する

Position Shake（位置の揺れ）

ラベルウィジェット内容
Pos X / Pos Y / Pos Zチェックボックス（横並び）各軸を揺らすかどうか
Position AmplitudeXYZのドラッグ入力欄（ステップ0.01、下限0）各軸の振れ幅
Position SpeedXYZのドラッグ入力欄（ステップ0.1、下限0）目標値へ到達する速度。大きいほど揺れが速く切り替わる
Position Easeコンボ（Linear他、全40種）目標値へ向かう際のイージング種類
Amplitude Start/End Multiplierドラッグ入力欄（ステップ0.01、範囲0〜10）再生進行度0%時／100%時に振れ幅へ掛かる倍率。既定は両方1.0（変化なし）
Speed Start/End Multiplierドラッグ入力欄（ステップ0.01、範囲0〜10）再生進行度0%時／100%時にスピードへ掛かる倍率。既定は両方1.0（変化なし）
Position Envelope Easeコンボ（Linear他、全40種）上記Start→Endの倍率変化に使うイージング種類（軸ごとの目標値遷移とは別設定）

Rotation Shake（回転の揺れ）

ラベルウィジェット内容
Rot X / Rot Y / Rot Zチェックボックス（横並び）各軸を揺らすかどうか
Rotation Amplitude (deg)XYZのドラッグ入力欄（ステップ0.1、下限0）各軸の振れ幅。度単位で保持され、適用時に内部でラジアンへ変換されます
Rotation SpeedXYZのドラッグ入力欄（ステップ0.1、下限0）目標値へ到達する速度
Rotation Easeコンボ（Linear他、全40種）目標値へ向かう際のイージング種類
Amplitude Start/End Multiplierドラッグ入力欄（ステップ0.01、範囲0〜10）再生進行度0%時／100%時に振れ幅へ掛かる倍率。既定は両方1.0（変化なし）
Speed Start/End Multiplierドラッグ入力欄（ステップ0.01、範囲0〜10）再生進行度0%時／100%時にスピードへ掛かる倍率。既定は両方1.0（変化なし）
Rotation Envelope Easeコンボ（Linear他、全40種）上記Start→Endの倍率変化に使うイージング種類（軸ごとの目標値遷移とは別設定）
Position/Rotation ShakeともAmplitude/Speedの入力欄はImGuiCustom::EditValue（Drag系）で表示されます。各軸は無効化されると、目標値追従をリセットしつつ現在値を滑らかに0へ戻します。
振れ幅・スピードの時間変化（エンベロープ）は再生進行度（elapsedPlayTime / duration、0.0〜1.0）に応じてStart値→End値へイージング補間されます。Durationが0以下（無期限再生）の場合、進行度は常に0%扱いとなりStart値のまま変化しません。
Apply Targetが「To Transform」の場合、前回加算したオフセットを必ず先に差し引いてから今回分を加算する仕組みになっています。そのため、Shake以外のスクリプトが同じフレームでTransformを直接書き換えていると、揺れの差し引きと競合する可能性があります（この用途にはProcess TimingをDeferredのままにしておくことを推奨）。

Add Componentでの位置

Add Component → Utility → Shake。最大付与数の制限はありません（1オブジェクトに複数付与し、それぞれ独立した揺れを重ねがけできます）。
