TargetLookAt 最大1個

指定したオブジェクトへ向き続ける（ビルボードのような動作をする）コンポーネントです。

Inspectorに表示される項目

ラベルウィジェット内容
Targetオブジェクト選択欄（コンボ＋ヒエラルキーからのドラッグ&ドロップ）向き続ける対象オブジェクト。未設定の場合は「(No target: rotation is not controlled)」と表示され、回転は制御されない
Rotation Modeコンボ（Sync Target Rotation / Look At Target）Sync Target Rotation: ターゲットのワールド回転と同期する（カメラをターゲットにすると常に画面と正対するビルボードになる）。Look At Target: 自身の+Z軸が常にターゲットの方向を向くよう回転する
Rotation OffsetXYZのドラッグ入力欄（ステップ0.1）算出した回転へ追加で適用するオフセット。度単位で表示・入力し、内部ではラジアンとして保持されます
Follow Strengthドラッグ入力欄（ステップ0.01、範囲0〜1）目標の回転へ追従する速さ（1フレーム(60fps換算)あたりに近づく割合）。1.0で毎フレーム即座に追従し、小さくするほど遅れて滑らかに追従する
Rotation Modeのコンボにカーソルを合わせると、各モードの説明がツールチップで表示されます。
回転オフセットが0のTransformコンポーネントを別名で用意したい等の理由から、このコンポーネントはCOMPONENT_CATEGORY("Utility")に分類されています（"Transform"にすると、無カテゴリのTransform型とAdd Componentメニュー上で名前が重複しImGuiのIDが衝突するため）。

Add Componentでの位置

Add Component → Utility → TargetLookAt。
