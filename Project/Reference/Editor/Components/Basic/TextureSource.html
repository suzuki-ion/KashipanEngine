TextureSource

同一オブジェクトのSpriteRenderer/MeshRendererが表示するテクスチャを、マテリアルアセット自体を編集せずに差し替えられるようにするコンポーネントです。内部では使用中のマテリアルを複製し、複製先のテクスチャだけを差し替えて割り当てます（複数オブジェクトで共有されている可能性のある元のマテリアルアセット自体は書き換えません）。コンポーネントが無効化・削除されると元のマテリアルへ戻ります。

Inspectorに表示される項目

ラベルウィジェット内容
Textureコンボボックス＋アセットのドラッグ&ドロップ受付読み込み済みテクスチャから選択。Assets Windowからテクスチャファイルをドラッグ&ドロップして設定することもできる。選択・変更すると即座に同オブジェクトのSpriteRenderer/MeshRendererへ反映される
同一オブジェクトにSpriteRendererまたはMeshRendererが無い場合は何も起こりません（両方ある場合はSpriteRenderer側が優先されます）。

Add Componentでの位置

Add Component → Render → TextureSource。最大付与数の制限はありません。
