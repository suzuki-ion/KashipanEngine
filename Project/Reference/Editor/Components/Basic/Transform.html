Transform 最大1個

位置・回転・スケールを持つ最も基本的なコンポーネントです。ほぼ全てのオブジェクトに付与されます。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/04_ObjectComponents.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
移動XYZのドラッグ入力欄（ステップ0.01）ローカル座標。ワールド座標ではなく、親オブジェクトからの相対位置
回転XYZのドラッグ入力欄（ステップ0.01、-180〜180の範囲）オイラー角。内部の値はラジアンですが、Inspector上は度（degree）で表示・入力します
拡大縮小XYZのドラッグ入力欄（ステップ0.01）ローカルスケール
親（テキスト表示のみ）読み取り専用テキスト現在の親オブジェクト名。未設定の場合は (None)。この欄自体から親を変更することはできない
回転は内部的にクォータニオン
Inspectorに表示・入力するオイラー角（度）は、内部で保持しているクォータニオンとの相互変換値です。回転を大きく・複雑に変更すると、オイラー角の分解方法によって表示上の角度が想定と異なる形（例: 180度を超える回転が別の角度の組み合わせで表現される）になることがあります。

親子関係の変更方法

Inspector上に親を変更するUIはありません。親子関係はScene Object Hierarchyでのドラッグ&ドロップによって変更します。Transformを持たないオブジェクトを親にすることはできません。

Add Componentでの位置

Transformは特別扱いのコンポーネントで、通常はオブジェクト作成時に自動的に付与されています。Add Componentメニューのカテゴリツリー上には表示されません。
