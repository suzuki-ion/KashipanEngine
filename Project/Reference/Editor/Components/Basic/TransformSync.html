TransformSync

他オブジェクトのTransform（位置・回転・スケール）を、実際に親子付けすることなく自身へ同期するコンポーネントです。毎フレーム、ターゲットのワールド位置・回転・スケールに個別のオフセットを加えた値を自身のTransformへ書き込みます。同期する項目はチェックボックスで個別に有効/無効を切り替えられます。

Inspectorに表示される項目

ラベルウィジェット内容
Targetオブジェクト選択欄（コンボ＋ヒエラルキーからのドラッグ&ドロップ）同期元のターゲットオブジェクト。未設定の場合は「(No target: sync is not applied)」と表示され、同期は行われない
Sync Positionチェックボックス位置を同期するかどうか（既定: 有効）
Position OffsetXYZのドラッグ入力欄（ステップ0.01）Sync Position有効時のみ表示。ターゲットのワールド座標に加算するオフセット
Sync Rotationチェックボックス回転を同期するかどうか（既定: 有効）
Rotation OffsetXYZのドラッグ入力欄（ステップ0.1）Sync Rotation有効時のみ表示。ターゲットのワールド回転に加算するオフセット。度単位で表示・入力し、内部ではラジアンとして保持されます
Sync Scaleチェックボックススケールを同期するかどうか（既定: 無効）
Scale OffsetXYZのドラッグ入力欄（ステップ0.01）Sync Scale有効時のみ表示。ターゲットのワールドスケールに加算するオフセット
自身に親オブジェクトが設定されている場合、算出したワールド値は親のワールド行列で変換してからローカルTransformへ書き込まれます（親子付けされた場合と同じ見た目になるよう配慮されています）。ターゲットに自分自身を指定した場合は無限フィードバックを避けるため同期を行いません。
実際のシーン階層上の親子関係（Transform::SetParentObject）は変更しません。1オブジェクトに複数付与することもでき、例えば位置だけを別のターゲットから、回転だけを別のターゲットから同期する、といった組み合わせが可能です。

Add Componentでの位置

Add Component → Utility → TransformSync。最大付与数の制限はありません。
