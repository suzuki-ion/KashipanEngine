MeshButton

3Dオブジェクト（MeshRenderer/SkinnedMeshRenderer）に対するマウスのホバー・押下・クリック判定を行うコンポーネントです（UIButtonの3D版）。見た目の描画は一切行いません（同一オブジェクトのメッシュを、そのまま当たり判定に使う「透明な当たり判定レイヤー」）。Scene Object Inspector上での見え方を説明します。

前提となる構成

このコンポーネントは判定のみを行うため、実際にボタンとして機能させるには同一オブジェクトへ以下を組み合わせて付与します。

  • MeshFilter ＋ MeshRendererまたはSkinnedMeshRenderer（MeshRendererを優先） — ボタンの見た目と、描画先ウィンドウの指定（対象のRenderer側のTargetをそのまま利用する）
  • MeshButton — 上記メッシュに対する当たり判定
既定はバウンディングボックス判定、SkinnedMeshRendererは常にそれのみ
既定ではMeshFilterが持つメッシュ（バインドポーズ）のローカル空間バウンディングボックスへ、マウス位置からDisplay Cameraを通したレイを飛ばして交差判定します。MeshRendererに限り、Precise Mesh Triangle Testを有効にすることでバウンディングボックス通過後にメッシュの全三角形との正確な交差判定へ切り替えられます。SkinnedMeshRendererはGPU側でスキニングした変形後の頂点をCPUから直接読み出す手段が無いため、このオプションを有効にしても常にバインドポーズのバウンディングボックス判定のまま（ボーン変形後の見た目には追従しない）です。
マウス座標変換のパイプラインはScreenBufferViewport/UIButtonと共通（射影のみ透視）
Windowクライアント座標 → NDC → Display Camera（Camera3D）の逆ビュー射影で近平面・遠平面上の点を求めてワールド空間のレイを作る、という変換を行います。ScreenBufferViewportと同じく、対象の描画先が実ウィンドウではなく独立したScreenBufferObject（オフスクリーン中間バッファ）の場合でも、それを表示しているScreenBufferViewportの表示先を辿って正しいウィンドウ・マウス座標を解決します。詳細はScreenBufferViewportを参照してください。

Inspectorに表示される項目

表示順はソースコードのShowImGui()呼び出し順と同じです。

ラベルウィジェット内容
Display Cameraコンボボックス（シーン上のオブジェクトから選択）マウス座標変換の基準にするCamera3Dを持つオブジェクト
Precise Mesh Triangle Testチェックボックスメッシュの三角形との正確な交差判定を行うか。既定 false（バウンディングボックスのみ）。MeshRendererの場合のみ効果を持つ
Drag AxisXYZのドラッグ入力欄（ステップ0.01、範囲制限なし）掴んで軸沿いにドラッグする操作の基準にする、オブジェクトのローカル軸。既定 (1, 0, 0)

Precise Mesh Triangle TestとDrag Axisの各項目の下には、その説明を補足するグレー表示のテキストが1行ずつ続き、さらにコンポーネント全体の説明文が続きます。実行中は現在の判定状態（Hovered / Pressed / Clicked）が確認用にそのまま表示され、一度でも掴んだことがある場合は直近のAxis Drag Offsetの値（小数点以下3桁）も追加で表示されます。

スクリプトAPI

メソッド説明
void SetDisplayCameraObject(Object@)Display Cameraを設定する
Object@ GetDisplayCameraObject() const設定中のDisplay Cameraオブジェクトを取得する（未設定時はnull）
string GetDisplayCameraObjectID() const設定中のDisplay CameraオブジェクトのUUID文字列を取得する
void SetPreciseMeshTest(bool)Precise Mesh Triangle Testを設定する
bool GetPreciseMeshTest() constPrecise Mesh Triangle Testの現在値を取得する
bool IsHovered() constマウスカーソルがオブジェクトの当たり判定内にあるかどうか
bool IsPressed() constオブジェクト上で左クリックが押され、まだ離されていないかどうか。押下開始はオブジェクト上である必要があるが、離すまでの間はカーソルが判定外へ出ても保持される（UIButtonと同じ挙動。ドラッグして判定外で離すとクリック扱いにはならない）
bool IsClicked() constこのフレームでクリックが確定した瞬間だけtrue（オブジェクト上で押して、オブジェクト上で離した時のみ）
void SetDragAxis(const Vector3 &in)掴んで軸沿いにドラッグする操作の基準にする、ローカル軸を設定する
const Vector3 &GetDragAxis() const設定中のローカル軸を取得する
bool TryGetAxisDragOffset(float &out)掴んで軸沿いにドラッグしている間の、軸原点（掴んだ瞬間のワールド座標）からの符号付きオフセット（ワールド単位）を取得する。軸方向は掴んだ瞬間のワールド回転で固定される。一度も掴んでいない、またはカメラ視線とドラッグ軸がほぼ平行で計算が不安定な場合はfalseを返す
class DraggableHandle : ScriptComponentBehavior {
    void Update() {
        MeshButton@ button;
        GetComponent(@button);
        if (button is null) return;

        float offset;
        if (button.IsPressed() && button.TryGetAxisDragOffset(offset)) {
            Log("ドラッグオフセット: " + offset);
        }

        if (button.IsClicked()) {
            Log("オブジェクトがクリックされました");
        }
    }
}
