MeshCollider

メッシュ形状をそのまま当たり判定に使う3D用コライダーです（UnityのMeshColliderに相当）。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/06_Collision.htmlを参照してください。

Inspectorに表示される項目

基底クラスIColliderの共通項目を先頭に表示し、その下に形状固有の項目が続きます（表示順はソースコードのShowImGui()呼び出し順と同じ）。

ラベルウィジェット内容
IsTriggerチェックボックス有効にすると物理的な押し戻しを行わない「トリガー」として扱う。OnCollisionEnter等のコールバックは通常どおり発生する。既定 false
Continuous Detectionチェックボックス連続衝突判定（CCD）の有効/無効。ホバーすると「高速移動時のすり抜けでも衝突イベントを発生させる（連続衝突判定）」というツールチップが表示される。既定 false
Sync With Transform（区切り線の下の見出し）テキスト見出し以下のPos/Rotation/Scale同期チェック群のセクション見出し（クリック不可）
Pos X / Pos Y / Pos Zチェックボックス（3個、横並び）同オブジェクトのTransformの各軸位置へ追従させるか。既定は全てtrue
RotationチェックボックスTransformの回転へ追従させるか。既定true。ホバーすると「回転は軸ごとの部分同期をサポートしない（数学的に反転・不連続が避けられないため）」というツールチップが表示される
Scale X / Scale Y / Scale Zチェックボックス（3個、横並び）Transformの各軸スケールへ追従させるか。既定は全てfalse（既存挙動を変えないための後方互換）
Convexチェックボックス凸包として扱うか。既定 true。オフにすると描画メッシュの三角形形状をそのまま当たり判定に使う。非凸形状は静的な地形・壁向けで、他のMeshColliderとの衝突およびDynamic/Kinematic RigidBodyへの取り付けには対応しない
Mesh (optional)ドロップダウン（コンボボックス）読み込み済みモデルの一覧から明示的に使用メッシュを選択する。先頭に(None)があり、選択すると明示指定を解除する。(None)の場合は同オブジェクトのMeshFilterコンポーネントのメッシュにフォールバックする
読み込み済みモデルのみ選択可能
Meshドロップダウンの候補はModelManagerに現在ロードされているモデルの一覧です。対象のモデルアセットが一度もロードされていない場合は候補に出てきません。
回転は内部的に全軸同期か非同期の二択
Sync With TransformのRotationは軸ごとの部分同期をサポートしません。オイラー角分解の順序依存とジンバルロックにより、部分同期を許すと反対向きの回転や不連続なジャンプが発生してしまうためです。

Add Componentでの位置

MeshColliderはCOMPONENT_CATEGORY("Collision")に属します。
