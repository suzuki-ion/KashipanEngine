RayCollider

3D用のレイキャスト専用コライダーです。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/06_Collision.htmlを参照してください。

常駐する当たり判定形状を持たない
他のコライダーと違い、BuildColliderInfo3D()は常に空を返すため、シーンに常駐する当たり判定形状（RigidBody上のシェイプ同士の接触判定システム）には乗りません。代わりに、OnCollisionEnter/OnCollisionStay/OnCollisionExitのいずれかがC++側から設定されている間だけ、毎フレームのUpdateで内部的にレイキャストを行い、前フレームのヒット対象との比較からEnter/Stay/Exitを自前で判定・発火します（コールバックが1つも設定されていなければレイキャスト自体を省略します）。他のコライダーと異なりStay中でも接触点は常に1点（ヒットした面の法線のみ。penetrationは常に0）で、経路上に複数ヒットしても最も近い1つだけが対象になります。CastRay()を呼び出せば、この自動判定とは独立して任意のタイミングで単発のレイキャストも行えます。IsTrigger欄は他のコライダーとの表示統一のため表示されますが、レイキャスト専用のため物理的な押し戻しという概念自体は働きません（Enter/Stay/Exit通知の可否には影響しません）。

Inspectorに表示される項目

基底クラスIColliderの共通項目を先頭に表示し、その下に形状固有の項目が続きます（表示順はソースコードのShowImGui()呼び出し順と同じ）。

ラベルウィジェット内容
IsTriggerチェックボックス他のコライダーと共通の項目として表示される。既定 false
Continuous Detectionチェックボックス連続衝突判定（CCD）の有効/無効。ホバーすると「高速移動時のすり抜けでも衝突イベントを発生させる（連続衝突判定）」というツールチップが表示される。既定 false。RayColliderは常駐形状を持たないため実質的に影響しない
Sync With Transform（区切り線の下の見出し）テキスト見出し以下のPos/Rotation/Scale同期チェック群のセクション見出し（クリック不可）
Pos X / Pos Y / Pos Zチェックボックス（3個、横並び）同オブジェクトのTransformの各軸位置へ追従させるか。既定は全てtrue。レイの発射origin（ワールド座標）に影響する
RotationチェックボックスTransformの回転へ追従させるか。既定true。CastRay()実行時にDirectionをこの回転で回転させる
Scale X / Scale Y / Scale Zチェックボックス（3個、横並び）Transformの各軸スケールへ追従させるか。既定は全てfalse
DirectionXYZのドラッグ入力欄（ステップ0.01）レイのローカル方向（正規化はCastRay()実行時に行われる）。既定 (0, -1, 0)
MaxDistanceドラッグ入力欄（ステップ0.01、下限0）レイの最大到達距離。既定 10.0
