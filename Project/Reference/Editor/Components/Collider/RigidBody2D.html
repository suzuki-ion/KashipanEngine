RigidBody2D

2D用の物理挙動（質量・重力・反発・摩擦）を持たせるコンポーネントです。内部ではBox2Dのb2BodyIdを薄くラップしています。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/06_Collision.htmlを参照してください。

ICollider派生ではない
形状コライダー（Box2DCollider等）は全てIColliderを継承しますが、RigidBody2DはIObjectComponentを直接継承する別系統のコンポーネントです（カテゴリは同じ"Collision"）。そのためIsTrigger・Continuous Detection・Sync With TransformといったICollider共通のInspector項目はRigidBody2Dには表示されません。「形状」はコライダー側、「物理的な動き」はRigidBody側という役割分担です。

Inspectorに表示される項目

ラベルウィジェット内容
Massドラッグ入力欄（ステップ0.01、範囲0.001〜1000）質量。既定 1.0。変更すると即座に生成済みの物理ボディへ反映される（形状由来の慣性モーメント分布は保ったまま質量だけ上書きされる）
UseGravityチェックボックス重力の影響を受けるか。既定 true
Restitutionドラッグ入力欄（ステップ0.01、範囲0〜1）反発係数。0で衝突後に反発しない、1で完全弾性衝突相当。既定 0.3。ボディに取り付いている全シェイプへ反映される
Frictionドラッグ入力欄（ステップ0.01、範囲0〜10）摩擦係数（クーロン摩擦）。0で無摩擦。既定 0.3。ボディに取り付いている全シェイプへ反映される
Collider Shapeドロップダウン（コンボボックス）物理ボディの形状として使う、同オブジェクト上の2D用IColliderコンポーネントを選択する。先頭の(Any)は未選択（どのコライダーでも使用可）を表す。候補はIs2D()がtrueのコライダーのみに絞られる
Velocity/AngularVelocityはInspector非表示
速度はSetVelocity()/GetVelocity()、角速度（Z軸周り、ラジアン/秒）はSetAngularVelocity()/GetAngularVelocity()でC++・スクリプトの両方から操作できますが、いずれもInspector上の直接編集項目としては表示されません。

Add Componentでの位置

RigidBody2DはCOMPONENT_CATEGORY("Collision")に属します。

Add Component›Collision›RigidBody2D
