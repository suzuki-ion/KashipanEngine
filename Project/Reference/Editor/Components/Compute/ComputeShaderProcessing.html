ComputeShaderProcessing

Computeシェーダーをオブジェクトのスクリプトのように扱うためのコンポーネントです。使用するComputeパイプライン名・ディスパッチするスレッドグループ数・バインドしたいテクスチャ／定数バッファをInspector上で設定するだけで、エンジン専用のコマンドリスト上で毎フレームComputeシェーダーが実行されます。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/04_ObjectComponents.htmlを参照してください。

このコンポーネントを付与すると、内部的にシーンへSceneComputeProcessor（未追加なら自動追加）が登録され、実際のDispatch呼び出しはそちら経由でRendererが毎フレーム行います。詳細はコンポーネント: Scene / SceneComputeProcessorを参照してください。

基本設定

ラベルウィジェット内容
Pipelineコンボ（読み込み済みComputeパイプライン名の一覧から選択）ディスパッチするComputeパイプライン名
GroupCountX / GroupCountY / GroupCountZドラッグ入力欄（int）ディスパッチするスレッドグループ数。1未満の値を入力しても保存時に1未満にならないようクランプされる

Textures (SRV)

Textures (SRV)ツリーを開くと、読み取り専用テクスチャのバインド要求を一覧・編集できます。

ラベルウィジェット内容
Variableテキスト入力シェーダー側の変数名
Textureコンボ（読み込み済みテクスチャの一覧、先頭に「(None)」あり）バインドするテクスチャのアセットパス
Removeボタンこの行のバインド要求を削除
Add Texture Bindボタン新規バインド要求を1件追加（空の状態で追加される）

UAV Textures

UAV Texturesツリーでは、読み書き可能なUAVテクスチャをエンジン側にサイズ指定で生成させるためのバインド要求を編集します。

ラベルウィジェット内容
Variableテキスト入力シェーダー側の変数名
Width / Heightドラッグ入力欄（int）生成するUAVテクスチャのサイズ（1未満にならないようクランプ）
Formatコンボ（RGBA8_UNORM / R32_FLOAT / RGBA32_FLOAT）UAVテクスチャのフォーマット種別
Removeボタンこの行のバインド要求を削除
Add UAV Texture Bindボタン新規バインド要求を1件追加（既定: 256x256, RGBA8_UNORM）

Constant Buffers

Constant Buffersツリーでは、float配列をそのまま定数バッファとして送るバインド要求を編集します。

ラベルウィジェット内容
Variableテキスト入力シェーダー側の変数名
[各値]ドラッグ入力欄（float、ステップ0.01）＋「-」ボタン定数バッファへ順番に詰め込まれるfloat値。「-」でその値のみ削除
Add Valueボタン値を1つ（初期値0.0）追加
Remove Bufferボタンこの定数バッファのバインド要求自体を削除
Add Constant Buffer Bindボタン新規バインド要求を1件追加（値0個の状態で追加される）
バインド用のGPUリソース（定数バッファ・UAVテクスチャ本体）はここでは確保されません。実際の生成・管理はエンジン側（Renderer）が行います。

Add Componentでの位置

Add Component → Compute → ComputeShaderProcessing。1オブジェクトへの付与数に実質的な制限はありません。
