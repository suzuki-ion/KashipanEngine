BloomEffect

しきい値を超える明部を抽出し、縮小ピラミッドでぼかして加算合成するブルームポストエフェクトです。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ BloomEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Thresholdドラッグ入力欄（ステップ0.01、範囲0.0〜10.0）ブルームとして抽出する明部の輝度しきい値。既定値 1.0
SoftKneeドラッグ入力欄（ステップ0.01、範囲0.0〜1.0）しきい値付近の抽出をなだらかにする度合い。既定値 0.5
Intensityドラッグ入力欄（ステップ0.01、範囲0.0〜5.0）最終合成時のブルームの強さ。既定値 0.8
BlurRadiusドラッグ入力欄（ステップ0.01、範囲0.0〜10.0）各段のぼかし量。既定値 1.0
Iterations整数ドラッグ入力欄（1〜16にクランプ）ダウンサンプル段数（縮小ピラミッドの段数）。既定値 4
多段パス構成
Prefilter → Blur → Downsample/Blurのチェーン → Upsample累積 → Compositeという多段のレンダーターゲットを内部で確保して描画するため、Iterations を大きくするほど負荷が増えます。ツールチップは表示されません。

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
