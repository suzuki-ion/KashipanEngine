ColorAdjustEffect

明度・コントラスト・彩度・色温度・カラーバランスを調整するポストエフェクトです。単一パスの宣言的エフェクトとして実装されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ ColorAdjustEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Brightnessドラッグ入力欄（ステップ0.01、範囲-1.0〜1.0）明度の加算量。既定値 0.0
Contrastドラッグ入力欄（ステップ0.01、範囲0.0〜4.0）コントラストの倍率。既定値 1.0
Saturationドラッグ入力欄（ステップ0.01、範囲0.0〜4.0）彩度の倍率。既定値 1.0
Temperatureドラッグ入力欄（ステップ0.01、範囲-2.0〜2.0）色温度の調整量。既定値 0.0
ColorBalanceXYZのドラッグ入力欄（ステップ0.01、範囲-1.0〜1.0）RGB各チャンネルへのカラーバランス補正。既定値 (0.0, 0.0, 0.0)

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
