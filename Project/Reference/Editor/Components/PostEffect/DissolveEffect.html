DissolveEffect

マスクテクスチャのしきい値で画面を切り取り、境界にエッジ色を乗せるディゾルブポストエフェクトです。単一パスの宣言的エフェクトとして実装されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ DissolveEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Mask Thresholdドラッグ入力欄（ステップ0.001、範囲0.0〜1.0）マスクテクスチャの値をこのしきい値で切り取る。既定値 0.5
Edge Thicknessドラッグ入力欄（ステップ0.001、範囲0.0〜1.0）しきい値境界に乗せるエッジ色の厚み。既定値 0.1
Base Texture ColorRGBAカラーピッカーベーステクスチャに乗算する色。既定値 (1, 1, 1, 1)
Edge ColorRGBAカラーピッカー境界に乗せるエッジの色。既定値 (1, 1, 1, 1)
Base Textureコンボボックス（読み込み済みテクスチャから選択、先頭に "(None)"）ディゾルブ対象のベーステクスチャ
Mask Textureコンボボックス（読み込み済みテクスチャから選択、先頭に "(None)"）切り取りに使うマスクテクスチャ
テクスチャ選択の表示名
Base Texture / Mask Texture のコンボボックスには、既に読み込み済みのテクスチャが Assets フォルダからの相対パス（assetPath）で列挙されます。ファイル名単体を表示名にすると同名ファイルが複数フォルダにある場合にImGuiのID重複警告が出るため、あえてフルの相対パスを表示・選択キーとして使っています。どちらも "(None)" を選ぶとテクスチャ未指定（TextureManager::kInvalidHandle）に戻せます。

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
