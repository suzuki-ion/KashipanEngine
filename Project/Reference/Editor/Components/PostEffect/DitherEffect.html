DitherEffect

バンディングの低減やレトロ表現に使えるディザリングポストエフェクトです。単一パスの宣言的エフェクトとして実装されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ DitherEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Intensityドラッグ入力欄（ステップ0.01、範囲0.0〜1.0）ディザリングの合成強度。既定値 1.0
ColorチェックボックスRGB各チャンネルへ個別にディザをかける（カラーディザ）かどうか。既定値 有効
"Color" はブール値
Params::color という名前ですが、実体は色ではなく bool 型で、チェックボックス1つとしてのみ表示されます。オフにすると輝度のみにディザをかける（RGB共通のパターン）動作に切り替わります。色そのものを指定するColorPickerは表示されません。

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
