DotMatrixEffect

LEDパネルや新聞印刷風のドット化を行うドットマトリクスポストエフェクトです。単一パスの宣言的エフェクトとして実装されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ DotMatrixEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Dot Spacingドラッグ入力欄（ステップ0.1、範囲1.0〜64.0、小数点以下1桁表示）ドットの間隔（ピクセル）。既定値 8.0
Dot Radiusドラッグ入力欄（ステップ0.1、範囲0.0〜64.0、小数点以下1桁表示）ドットの半径（ピクセル）。既定値 3.5
Thresholdドラッグ入力欄（ステップ0.01、範囲0.0〜1.0）ドット化する輝度のしきい値。既定値 0.0
Intensityドラッグ入力欄（ステップ0.01、範囲0.0〜4.0）エフェクトの合成強度。既定値 1.0
Monochromeチェックボックスドットを単色（モノクロ）にするかどうか。既定値 無効

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
