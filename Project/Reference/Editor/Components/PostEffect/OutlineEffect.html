OutlineEffect

深度の差分から輪郭線を検出して描画するポストエフェクトです。単一パスの宣言的エフェクトとして実装されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ OutlineEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
Thresholdドラッグ入力欄（ステップ0.001、範囲0.0〜10.0、小数点以下4桁表示）輪郭として検出する深度差のしきい値。既定値 0.1
Thicknessドラッグ入力欄（ステップ0.1、範囲0.0〜16.0、小数点以下1桁表示）輪郭線の太さ。既定値 1.0
ColorRGBAカラーピッカー輪郭線の色。既定値 (1, 1, 1, 1)
カメラが未解決の場合の警告表示
このスクリーンバッファへ実際に描画したカメラが解決できていない場合、Inspector上に No camera resolved for this ScreenBuffer yet: depth linearization may be inaccurate.（オレンジ色のテキスト）が表示されます。OutlineEffect は深度の線形化にカメラのNear/Farを使用しますが、他のカメラ依存エフェクトと異なり、カメラが未解決でも描画自体は行われ続けます（Near/Farの既定値 0.1 / 1000.0 が使われるため、輪郭の見え方が実際のカメラと合わなくなる可能性があるという意味の警告です）。カメラ情報は Renderer が毎フレーム自動で注入するため、ユーザー側でNear/Farを手動設定する必要はありません。

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。
