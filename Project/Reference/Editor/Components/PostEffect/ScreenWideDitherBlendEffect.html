ScreenWideDitherBlendEffect

画面全体（シャドウマップの再生成を含む）を位相違いでNパス再描画し、その結果を平均することでディザリングの粒状感を1フレーム内で滑らかにするための設定コンポーネントです。DitherEffectが持つオブジェクト単位のマルチパスディザ（enableMultiPassDither）が特定のマテリアルのみを対象とするのに対し、こちらは対象を限定せず描画先（ScreenBuffer）全体を丸ごと撮り直す、画面全体版の相当機能です。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ ScreenWideDitherBlendEffect を追加しても効果は発生しません。
他のポストエフェクトとは実装経路が異なる
このコンポーネント自身は BuildPasses() が空を返すのみで、GPU処理を一切持ちません。実際のNパス再描画・ブレンド処理は Renderer::RenderFrame が、通常のポストエフェクトパイプライン（BuildPasses/RenderCustom）より前の段階で、このコンポーネントの有無とパス数を検査した上で直接実装しています（シャドウマップの再生成を伴うため）。付与するとその描画先の描画コストがほぼパス数倍になるため、常時有効にする用途ではなく、スクリーンショットや一時停止中の高品質表示等での利用を想定しています。

Inspectorに表示される項目

ラベルウィジェット内容
Pass Count整数スライダー（範囲1〜8）影も含めて画面全体を撮り直す回数N。既定値 4。設定値は常に1〜8にクランプされる

パラメータの下には、パフォーマンスコストについての警告文が常時オレンジ色で表示されます。警告文にカーソルを合わせると、詳細説明がツールチップとして表示されます。

表示位置内容
警告文（常時表示）「Warning: redraws the entire screen (including shadow regeneration) this many times per frame」
ツールチップ（警告文にホバー時）「Shadow map generation and the full scene draw are repeated "Pass Count" times every frame, so GPU cost scales roughly linearly with it. Prefer using this only where frame time has headroom (screenshots, paused high-quality preview, etc.) rather than leaving it on at all times」

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。

Add Componentでの位置

ScreenWideDitherBlendEffectはIPostProcessComponentを継承しており、COMPONENT_CATEGORY("PostProcessing")に属します。
