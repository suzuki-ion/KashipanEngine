TemporalBlendEffect

画面全体を数フレームにわたる指数移動平均でならす、汎用の軽量な時間的ブレンド・ポストエフェクトです。半透明のディザリングパターンのちらつきをならす用途を主眼に導入されていますが、それに限らずフレーム間でちらつく表現全般（ノイズベースの演出、低サンプル数のスクリーンスペース効果など）を滑らかにする目的で汎用的に使えます。モーションベクター・リプロジェクション・ディスオクルージョン処理は持たない簡易実装で、いわゆる本来のTAA（カメラジッター＋モーションベクター＋リプロジェクション＋近傍クランプ）とは別物（単純な時間的ブレンド/フレーム蓄積）です。画面全体に対して一様にブレンドするため、対象以外の動く物体やカメラ操作時にも同じ強さで残像（ゴースト）が乗る点はトレードオフとして許容されています。C++側のAPIはEngine/10_PostEffects.htmlを参照してください。

付与の前提
ポストエフェクトは同一オブジェクトの ScreenBufferObject が持つ ScreenBuffer に対して適用されます。ScreenBufferObject が付与されていないオブジェクトへ TemporalBlendEffect を追加しても効果は発生しません。

Inspectorに表示される項目

ラベルウィジェット内容
History Weightドラッグ入力欄（ステップ0.01、範囲0.0〜0.98、表示形式 %.3f）ヒストリー（過去フレーム）をどれだけ強く残すか。0でブレンドなし、1に近いほど滑らかになる代わりに動く物体の残像も強くなる。既定値 0.5

"History Weight" にカーソルを合わせると、上記と同内容の説明がツールチップとして表示されます。

内部実装: ヒストリーバッファのping-pong 2パス構成
このコンポーネントは BuildPasses() が空を返し、宣言的なパス定義ではなく RenderCustom() によるカスタム描画で実装されています。ヒストリーを2枚（ping-pong）保持し、毎フレーム「現在のシーン色＋前フレームのヒストリー」をブレンドして新しいヒストリーへ描画するパスと、その結果をオーナーの書き込み面へコピーするパスの2段構成です（MotionBlurEffect/BloomEffectと同様の構成）。解像度が変化した場合はヒストリーが破棄され、次フレームはヒストリー無し（History Weightを0扱い）から再開されます。

適用先の除外設定 USE_IMGUI

同一オブジェクトに ScreenBufferObject が2つ以上ある場合のみ、パラメータ項目の前に "Apply Target Filter" というツリーノードが表示されます。展開すると各 ScreenBuffer 名のチェックボックスが並び、チェックを外すとそのスクリーンバッファへはこのエフェクトが適用されなくなります（ScreenBufferObject が1つ以下の場合はこの項目自体が表示されません）。

Add Componentでの位置

TemporalBlendEffectはIPostProcessComponentを継承しており、COMPONENT_CATEGORY("PostProcessing")に属します。
