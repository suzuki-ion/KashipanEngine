BitmapTextRenderer

BMFont形式（.fnt、テキスト形式）の事前生成済みビットマップアトラスを使ってテキストを描画するコンポーネントです。TTF/OTFをSDFとしてランタイムベイクするTextRendererとは完全に独立した、もう一つのテキスト描画手段です。Scene Object Inspector上での見え方を説明します。

TextRendererとの違い

項目TextRendererBitmapTextRenderer
フォント形式TTF / OTF（FontManagerがSDFとしてランタイムベイク）BMFont .fnt（テキスト形式）＋ページ画像（BitmapFontManagerが読み込み）
描画パイプライン専用SDFパイプライン（既定 Text2D.BlendNormal）SpriteRenderer/MeshRendererと同じObject2D系パイプライン（既定 Object2D.DoubleSidedCulling.BlendNormal）
リッチテキストタグ対応（<i> <b> <color> <size> <s> <u> <sub> <sup>）非対応（改行のみ解釈するプレーンテキスト）
太字/斜体/アウトライン対応非対応（ビットマップアトラスのため形状加工ができない）
文字ごとのTransform上書き対応（Character Overrides）対応（Character Overrides。位置/回転/スケールのみ。アンカー/ピボットの個別上書きは無し）
複数ページフォント該当なし（単一アトラス）非対応。pages>1の.fntは先頭ページのみ使用（警告ログ）

Inspectorに表示される項目

ラベルウィジェット内容
Targetコンボボックス描画先コンポーネントを持つオブジェクトのみが候補。ヒエラルキーからのドラッグ&ドロップにも対応
Render Target Filter（折りたたみツリー）描画先ごとのチェックボックス対象オブジェクトが複数の描画先コンポーネントを持つ場合のみ表示
Text複数行テキスト入力（InputTextMultiline）表示する文字列。改行のみ解釈する（リッチテキストタグは無し）
Fontコンボボックス（None選択可）BitmapFontManagerに読み込み済みの.fntから選択
Font Sizeドラッグ入力欄（ステップ0.01、0.01～1000）既定値32。.fntのinfo sizeを基準にスケールされる
Instance Color / Blend ModeColorEdit4（RGBA）/ コンボボックスマテリアル色へテキスト全体に適用する色と合成方法
Materialコンボボックス文字へ適用するマテリアル。マテリアルのテクスチャとUVは無視され、フォントのページ画像が使用される
Horizontal Alignコンボボックス（Left / Center / Right）行の横方向アライメント
Vertical Alignコンボボックス（Top / Middle / Bottom）テキストブロック全体の縦方向アライメント
Point Samplingチェックボックス有効時はページ画像をポイント（ニアレスト）サンプリングする（既定true）。ドット絵フォントを拡大縮小してもにじませたくない場合に有効にする
Pipelineコンボボックス読み込み済みの2D向けレンダーパイプライン名から選択（既定値 Object2D.DoubleSidedCulling.BlendNormal）
Render Priority整数ドラッグ入力（DragInt）描画順を制御する優先度（既定0）。値が小さいほど先（奥）、大きいほど後（手前）に描画される
Allow Instancingチェックボックス他のオブジェクトとのインスタンシング対象にするか（既定true）
Character Overrides（折りたたみツリー）文字インデックスごとの Offset（XYドラッグ、ステップ0.1）/ Rotation（ドラッグ、ステップ0.01、ラジアン）/ Scale（XYドラッグ、ステップ0.01）Text（改行含む実文字数）と同じ数だけ[0],[1],...の項目が並ぶ。Textが空の場合はツリー自体が表示されない。TextRendererと同じ仕組み（アンカー/ピボットの個別上書きは無い点のみ異なる）
Character Overridesはシーンへ保存されない
文字ごとの位置・回転・スケール上書き（Character Overrides）はランタイム専用のデータで、SaveToJsonの対象外。Inspector上で調整した値はPlay終了やシーン再読み込みでリセットされる。
フォントの配置
.fntファイルはAssetsフォルダ内のどこかに配置すれば起動時に自動で読み込まれる（FontManagerのTTF/OTF走査と同じ方式）。ページ画像（例: xxx_0.png）は通常のテクスチャアセットとしてTextureManagerが既に読み込み済みである必要があり、.fnt内のpage file=...のファイル名で検索される（ディレクトリは問わないが、Assetsフォルダ内のどこかに1つだけ存在すること。同名の画像が複数の場所にあると意図しない方が見つかる場合がある）。
AngelScriptからは未対応
本コンポーネントは現時点でAngelScriptバインディング（ScriptBindings）を持たない。スクリプトから文字列を動的に更新する用途にはC++側から直接BitmapTextRenderer::SetText等を呼ぶ必要がある。

Add Componentでの位置

Add Component›Render›BitmapTextRenderer から追加する。同一オブジェクトに複数付与可能。

ヒエラルキーの右クリックメニューからはCreate Object›2D›Bitmap Text Object（Text Objectの隣）で、本コンポーネントのみを付与したオブジェクトを既定値のまま生成できる。
