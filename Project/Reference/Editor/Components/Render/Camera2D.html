Camera2D 最大1個

2Dカメラの射影パラメータ（常に平行投影）だけを保持するコンポーネントです。パラメータの保持のみを行い、実際に描画へ反映するには同一オブジェクトにCameraRendererを併せて付与する必要があります。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Camera2Dだけでは何も起きない
Camera3Dと同様、Camera2Dはパラメータの入れ物でしかない。ビュー射影行列を計算して定数バッファへアップロードするのはCameraRendererの役割で、両方を同一オブジェクトへ付与して初めて描画に反映される。同一オブジェクトにCamera2Dが存在すると、CameraRendererはバインド先の既定値を2D用（gCamera2D）に切り替える。

Inspectorに表示される項目

ラベルウィジェット内容
Widthドラッグ入力欄（ステップ1.0）投影の横幅（既定1280.0）
Heightドラッグ入力欄（ステップ1.0）投影の縦幅（既定720.0）
Nearドラッグ入力欄（ステップ0.01）ニアクリップ距離（既定0.0）
Farドラッグ入力欄（ステップ1.0）ファークリップ距離（既定1000.0）
Camera3Dとの違い
Camera2DにはOrthographicの切り替えが無く常に平行投影。またFovYやAspectといった透視投影用のパラメータも存在しない。

Add Componentでの位置

Add Component›Render›Camera2D から追加する。1オブジェクトに付与できるのは最大1個。
