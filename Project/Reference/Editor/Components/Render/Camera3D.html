Camera3D 最大1個

3Dカメラの射影パラメータだけを保持するコンポーネントです。パラメータの保持のみでビュー射影行列の計算・アップロードは行わず、実際に描画へ反映するには同一オブジェクトにCameraRendererを併せて付与する必要があります。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Camera3Dだけでは何も起きない
Lightと同様、Camera3Dはパラメータの入れ物でしかない。ビュー射影行列を計算して定数バッファへアップロードするのはCameraRendererの役割で、両方を同一オブジェクトへ付与して初めて描画に反映される。

Inspectorに表示される項目

ラベルウィジェット内容
Orthographicチェックボックス有効にすると平行投影、無効だと透視投影（既定false＝透視投影）
FovYドラッグ入力欄（ステップ0.01）垂直画角。単位はラジアン（既定値0.45＝約25.8°）。Transformの回転と異なり度への変換は行われない
Nearドラッグ入力欄（ステップ0.01）ニアクリップ距離（既定0.1）
Farドラッグ入力欄（ステップ1.0）ファークリップ距離（既定1000.0）
Aspectドラッグ入力欄（ステップ0.01）アスペクト比（既定16:9＝約1.778）
OrthoSizeドラッグ入力欄（ステップ0.1）平行投影時の縦半径（ワールド単位、既定10.0）
FovYはラジアン表示、範囲制限も無い
Transformの回転欄は内部ラジアン→表示度で変換されるが、Camera3DのFovYはラジアンのまま直接ドラッグ入力する。DragFloatに上限・下限も設定されていないため、意図しない極端な値（0以下やπ以上）も入力できてしまう点に注意。
OrthographicチェックでFovYは無視される
Orthographicが有効な場合、CameraRendererが計算する投影行列はOrthoSizeとAspectのみを使い、FovYの値は使用されない。ただしFovY欄自体は非表示にはならず、常に編集可能な状態で残る。

Add Componentでの位置

Add Component›Render›Camera3D から追加する。1オブジェクトに付与できるのは最大1個。
