CameraBoundsZone2D 最大1個

CameraController2Dの移動範囲制限（Camera Bounds Zone）機能で参照される、境界データ専用コンポーネントです。単純な1矩形のmin/maxクランプではなく、「グループ」を複数持て、各グループはさらに複数の矩形から成ります。追従ターゲットが今どのグループの範囲内にいるかで、カメラのクランプに使うグループが自動的に切り替わります（部屋Aにいる間は部屋Aの矩形群でクランプ、部屋Bへ移動したら部屋Bの矩形群に切り替わる、といった使い方を想定）。

データ構造

用語内容
Group（グループ）複数の矩形（Rect）から成る。何個でも追加できる
Rect（矩形）min/max（Vector2）で定義される軸並行の矩形。コンポーネントを持つオブジェクト自身のTransformのローカル空間で定義される（オブジェクトを移動・回転させると矩形群も一緒に動く）

クランプの仕組み

1グループ内に複数の矩形がある場合、各矩形ごとに個別にクランプ計算を行い、元の位置から最も近い結果を採用する。これにより、複数の矩形を隣接・重複させることでL字型などの凹形状の範囲を表現でき、その形状に沿ったクランプが行われる。矩形同士が離れている（隙間がある）場合、その隙間にターゲットが入り込むと最も近い矩形へスナップする。

ラベルウィジェット内容

シーンビューでの可視化・編集

すべてのCameraBoundsZone2Dの矩形群は、Scene Viewの「表示」タブの「境界ゾーン」トグルが有効な間、常時（選択の有無に関わらず）2Dモードでオーバーレイ表示される（グループごとに色分け）。

未選択の矩形は、シーンビュー上で境界線（4辺）付近をクリックすると選択できる（内部をクリックしても反応しない）。これにより、矩形の内側に他のオブジェクトがあっても、そのクリック判定を妨げない。境界線のヒットは通常のオブジェクトピッキングより優先される。境界線をクリックすると、その矩形の所有オブジェクトが選択され、その矩形が編集対象になり、矩形編集も自動的に有効化される。あるいは、対象オブジェクトを単体で選択したうえでScene Viewの「境界ゾーン」タブから「矩形編集を有効化」をオンにし、Inspector側で編集したい矩形の行をクリックして選択することもできる。選択中の矩形はシーンビュー上に黄色い枠とハンドル（四隅・四辺）が表示され、四隅ドラッグでサイズ変更（縦横同時）、四辺ドラッグで片軸のみのサイズ変更、矩形内部のドラッグで矩形全体の移動ができる（選択中は内部も含めて判定されるため、移動がしやすい）。ドラッグの確定はUndo履歴に1操作として積まれる。

矩形のドラッグ操作は、シーンビューの「ギズモ」タブにある移動スナップ設定（有効/無効・間隔）にも従う（Ctrlキーで一時的に反転できる点も含め、通常のTransformギズモと同じ挙動）。ドラッグ量（開始位置からの移動量）がスナップ間隔の倍数に丸められる。

Add Componentでの位置

Add Component›Render›CameraBoundsZone2D から追加する。1オブジェクトに付与できるのは最大1個。
