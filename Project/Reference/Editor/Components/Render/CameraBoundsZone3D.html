CameraBoundsZone3D 最大1個

CameraController（3D用）の移動範囲制限（Camera Bounds Zone）機能で参照される、境界データ専用コンポーネントです。CameraBoundsZone2Dの3D版で、判定・クランプの考え方（複数グループ・矩形ごとにクランプして最近傍を採用）は共通です。矩形は軸並行の直方体（min/maxのVector3）で、コンポーネントを持つオブジェクト自身のTransformのローカル空間で定義されます。

2D版との違い（フットプリント編集）

3D空間中で直方体の全頂点をドラッグ編集対象にするのはコストが高いため、意図的にスコープを絞っている。シーンビュー上でドラッグ編集できるのはXZ平面上のフットプリント（min.x/max.x, min.z/max.z）のみで、高さ方向（min.y/max.y）はInspectorの数値入力でのみ編集する。フットプリントのドラッグ編集は、選択中矩形のY範囲の中央の高さに置いた水平面上でカーソル位置を判定する。ワイヤーフレーム自体は高さも含めた直方体として常時表示される。

シーンビューでの可視化・編集

すべてのCameraBoundsZone3Dの矩形群は、Scene Viewの「表示」タブの「境界ゾーン」トグルが有効な間、3D/Combinedモードで直方体のワイヤーフレームとして常時（選択の有無に関わらず）表示される（グループごとに色分け）。

未選択の矩形は、シーンビュー上でフットプリント（XZ）の境界線（4辺）付近をクリックすると選択できる（内部をクリックしても反応しない）。これにより、直方体の内側に他のオブジェクトがあっても、そのクリック判定を妨げない。境界線のヒットは通常のオブジェクトピッキングより優先される。境界線をクリックすると、その所有オブジェクトが選択され、その矩形が編集対象になり、矩形編集も自動的に有効化される。あるいは、対象オブジェクトを単体で選択したうえでScene Viewの「境界ゾーン」タブから「矩形編集を有効化」をオンにし、Inspector側で編集したい矩形の行をクリックして選択することもできる。選択中の矩形は、Y中央高さの水平面上に黄色い枠とハンドル（四隅・四辺）が表示され、四隅ドラッグでXZ両方のサイズ変更、四辺ドラッグでX・Zいずれか片方のみのサイズ変更、矩形内部のドラッグでフットプリント全体の移動ができる（選択中は内部も含めて判定されるため、移動がしやすい）。ドラッグの確定はUndo履歴に1操作として積まれる。

矩形のドラッグ操作は、シーンビューの「ギズモ」タブにある移動スナップ設定（有効/無効・間隔）にも従う（Ctrlキーで一時的に反転できる点も含め、通常のTransformギズモと同じ挙動）。ドラッグ量（開始位置からの移動量）がスナップ間隔の倍数に丸められる。

Add Componentでの位置

Add Component›Render›CameraBoundsZone3D から追加する。1オブジェクトに付与できるのは最大1個。
