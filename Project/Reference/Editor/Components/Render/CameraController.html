CameraController 最大1個

同一オブジェクトのCamera3Dを、複数の追従先オブジェクトへ滑らかに追従させるコンポーネントです。位置・回転はそれぞれ軸ごとに追従するかどうかを選べ、FovYの遷移も扱います。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Inspectorに表示される項目

状態表示

表示内容
"Controllable (Camera3D found)"（緑文字）同一オブジェクトにCamera3Dコンポーネントがある場合
"Not controllable (Camera3D component required)"（赤文字）Camera3Dが無い場合。この状態でもUI自体は操作できるが、Update()内でCamera3Dが取得できないため実際には何も適用されない

Follow Targets（追従先オブジェクトのリスト）

登録済みの追従先ごとに、以下の項目が縦に並んで繰り返し表示される。

ラベルウィジェット内容
Targetコンボボックス（None選択可）追従先オブジェクトを選択。MeshRenderer等のTargetとは異なり、描画先コンポーネントを持つオブジェクトに限定されない（任意のオブジェクトを選択可能）。ヒエラルキーからのドラッグ&ドロップにも対応
Follow Position: X / Y / Zチェックボックス3つ（横並び）この追従先のワールド座標のうち、どの軸を追従に使うか（既定は全てtrue）。複数の追従先が同じ軸を指定した場合は平均を取る
Follow Rotation: X / Y / Zチェックボックス3つ（横並び）この追従先のワールド回転（オイラー角）のうち、どの軸を追従に使うか（既定は全てfalse）
Remove Targetボタンこのリスト項目を削除する

リストの下に「Add Follow Target」ボタンがあり、押すと空の追従先（未選択・Follow Positionのみ全軸true）がリストへ追加される。追従先が1件も無い場合は「(No target: following own Transform)」というグレー文字が表示される。

追従先が空の場合は自身のTransformを追従する
Follow Targetsが1件も無いと、Update()はこのコンポーネントが付与されたオブジェクト自身のTransformを唯一の追従先として扱う（＝オフセットだけが効く静止カメラのような挙動になる）。

オフセット・目標値

ラベルウィジェット内容
Position OffsetXYZのドラッグ入力欄（ステップ0.01）追従先の座標へ加算するオフセット（寄与する軸にのみ適用される）
Rotation OffsetXYZのドラッグ入力欄（ステップ0.1、度表示）追従先の回転へ加算するオフセット。内部はラジアンで保持するが、Inspector上はTransformの回転同様に度で表示・入力する
Target FovYドラッグ入力欄（ステップ0.01、0.01～π-0.01）目標のFovY。こちらはラジアンのまま表示・入力する（Rotation Offsetとは扱いが異なる点に注意）

追従の強さ

ラベルウィジェット内容
Move: Per-Axisチェックボックス有効にすると移動の追従強さを軸ごとに個別設定できる
Move X/Y/Z（Per-Axis有効時） / Move All（無効時）XYZまたは単一のドラッグ入力欄（ステップ0.01、0～1）値が大きいほど毎フレームの追従（Lerp）が速くなる
Rotate: Per-Axisチェックボックス有効にすると回転の追従強さを軸ごとに個別設定できる
Rotate X/Y/Z（Per-Axis有効時） / Rotate All（無効時）XYZまたは単一のドラッグ入力欄（ステップ0.01、0～1）回転版の追従強さ
Fov Transition Strengthドラッグ入力欄（ステップ0.01、0～1）Target FovYへの遷移速度

Add Componentでの位置

Add Component›Render›CameraController から追加する。1オブジェクトに付与できるのは最大1個。
