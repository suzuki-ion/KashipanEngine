CameraController2D 最大1個

CameraController（3D用）の2D版。同一オブジェクトのCamera2Dを、複数の追従先オブジェクトへ滑らかに追従させるコンポーネントです。追従に使うのは位置X/Yと画面内回転（Z軸）のみで、FovYの代わりにwidth/height（表示範囲＝ズーム相当）の遷移を扱います。Scene Object Inspector上での見え方を説明します。

Inspectorに表示される項目

状態表示

表示内容
"Controllable (Camera2D found)"（緑文字）同一オブジェクトにCamera2Dコンポーネントがある場合
"Not controllable (Camera2D component required)"（赤文字）Camera2Dが無い場合。この状態でもUI自体は操作できるが、Update()内でCamera2Dが取得できないため実際には何も適用されない

Follow Targets（追従先オブジェクトのリスト）

登録済みの追従先ごとに、以下の項目が縦に並んで繰り返し表示される。

ラベルウィジェット内容
Targetコンボボックス（None選択可）追従先オブジェクトを選択。任意のオブジェクトを選択可能。ヒエラルキーからのドラッグ&ドロップにも対応
Follow Position: X / Yチェックボックス2つ（横並び）この追従先のワールド座標のうち、どの軸を追従に使うか（既定はどちらもtrue）。複数の追従先が同じ軸を指定した場合は平均を取る
Follow Rotationチェックボックス1つこの追従先のワールド回転（画面内回転＝Z軸）を追従に使うか（既定false）
Remove Targetボタンこのリスト項目を削除する

リストの下に「Add Follow Target」ボタンがあり、押すと空の追従先（未選択・Follow Positionのみ全軸true）がリストへ追加される。追従先が1件も無い場合は「(No target: following own Transform)」というグレー文字が表示される。

追従先が空の場合は自身のTransformを追従する
Follow Targetsが1件も無いと、Update()はこのコンポーネントが付与されたオブジェクト自身のTransformを唯一の追従先として扱う（＝オフセットだけが効く静止カメラのような挙動になる）。

オフセット・目標値

ラベルウィジェット内容
Position OffsetXYのドラッグ入力欄（ステップ0.01）追従先の座標へ加算するオフセット（寄与する軸にのみ適用される）
Rotation Offsetドラッグ入力欄（ステップ0.1、度表示）追従先の回転へ加算するオフセット。内部はラジアンで保持するが、Inspector上はTransformの回転同様に度で表示・入力する
Target SizeXY（width/height）のドラッグ入力欄（ステップ1.0）目標のCamera2D width/height（ズーム相当）
AutoSyncSizeとの併用に注意
対象のCamera2DでAutoSyncSizeを有効にしている場合、width/heightは毎フレーム描画先の実解像度へ上書きされるため、Target Sizeによるズーム遷移は実質無効になる。

追従の強さ

ラベルウィジェット内容
Move: Per-Axisチェックボックス有効にすると移動の追従強さを軸ごとに個別設定できる
Move X/Y（Per-Axis有効時） / Move All（無効時）XYまたは単一のドラッグ入力欄（ステップ0.01、0～1）値が大きいほど毎フレームの追従（Lerp）が速くなる
Rotate Follow Strengthドラッグ入力欄（ステップ0.01、0～1）回転（Z軸）の追従の強さ
Size Transition Strengthドラッグ入力欄（ステップ0.01、0～1）Target Sizeへの遷移速度

Add Componentでの位置

Add Component›Render›CameraController2D から追加する。1オブジェクトに付与できるのは最大1個。
