CameraRenderer

同一オブジェクトのTransformとCamera3D（またはCamera2D）からビュー射影行列を計算し、指定した定数バッファへアップロードするコンポーネントです。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Targetコンボボックス（None選択可）適用先の描画先オブジェクトをシーン上から選択。ヒエラルキーからのドラッグ&ドロップにも対応。未指定（None）の場合は全ての描画先に適用される
Render Target Filter（折りたたみツリー）描画先ごとのチェックボックスTargetを指定し、かつそのオブジェクトが複数の描画先コンポーネントを持つ場合のみ表示
Pipelineコンボボックス（None選択可）読み込み済みのレンダーパイプライン名から選択。未指定（None）の場合は全パイプラインに適用される
（バインド先変数名の一覧）読み取り専用の箇条書き（BulletText）定数バッファのバインド先変数名（例: Vertex:gCamera3D）を1行ずつ列挙するだけの表示。Inspector上に編集用のUIは無い
バインド先変数名はInspectorから編集できない
一覧表示のみで追加・削除・変更を行うUIコントロールは存在しない。初期値はInitialize時に自動決定される（同一オブジェクトにCamera2DがあればVertex:gCamera2D/Pixel:gCamera2D、無ければVertex:gCamera3D/Pixel:gCamera3D）。変更したい場合はスクリプトからSetBindVariableNames()を呼ぶか、シーンJSONを直接編集する必要がある。

Add Componentでの位置

Add Component›Render›CameraRenderer から追加する。同一オブジェクトに複数付与可能。
