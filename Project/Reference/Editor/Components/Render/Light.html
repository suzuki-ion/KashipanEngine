Light

ライトのパラメータ（種類・色・強度・減衰・形状・シャドウ設定）だけを保持するコンポーネントです。実際に描画へ反映するには同一オブジェクトにLightRendererを併せて付与する必要があります。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Lightだけでは何も起きない
LightはTransform同様パラメータの入れ物でしかなく、Rendererへ実際にライト情報を送るのはLightRendererの役割。両方を同一オブジェクトへ付与して初めて描画に反映される。

共通項目

ラベルウィジェット内容
TypeコンボボックスDirectional / Point / Spot / Rect / Sphere / Disc / Tube / Box の8種類。既定はDirectional
ColorColorEdit4（RGBA）ライトの色
Intensityドラッグ入力欄（ステップ0.01、下限0）強度（既定1.0）

Typeごとに出現する項目

Colorの下、Shadowの区切り線より上に、選択中のTypeに応じて以下の項目が追加表示される（Directionalは追加項目なし）。

Type追加される項目
Directional（無し）
PointRadius（ドラッグ、ステップ0.1、0～1000、届く範囲）／ Decay（ドラッグ、ステップ0.01、0～10、減衰指数）
SpotDistance（届く範囲）／ Decay ／ Inner Angle（SliderAngle、0～90°）／ Outer Angle（SliderAngle、0～90°）
SphereRadius (Range)（届く範囲）／ Source Radius（球の物理的な半径。ステップ0.01、0.001～100。ホバーで説明ツールチップ）／ Decay
TubeRadius (Range) ／ Source Radius（円柱半径）／ Source Length（チューブの長さ＝Transformローカル+X方向。ホバーでツールチップ）／ Decay
DiscDistance (Range) ／ Source Radius ／ Decay（ホバーで「Transformの+Z方向が発光面の法線（片面発光）」というツールチップ）
RectDistance (Range) ／ Source Width ／ Source Height ／ Decay（ホバーで「+Z方向が法線、+Xが幅、+Yが高さ方向」というツールチップ）
BoxRadius (Range)（ボックス表面からさらに届く減衰距離。ホバーでツールチップ）／ Source Width ／ Source Height ／ Source Depth（ホバーで「ローカルX/Y/Z方向の幅・高さ・奥行き」というツールチップ）／ Decay
RadiusとDistanceは同じ意味で名前だけが違う
Point/Sphere/Tube/Boxは「Radius (Range)」、Spot/Disc/Rectは「Distance (Range)」という項目名になるが、内部的にはどちらも減衰距離（届く範囲）を表す別々のメンバ変数（radius_/distance_）。Rect/Sphere/Disc/Tubeは面光源として形状上の代表点法で近似され、Boxは全方位（体積）発光として扱われる。

Shadow（区切り線以下）

ラベルウィジェット内容
Cast Shadowsチェックボックス有効にすると以下の項目が追加表示される（既定false）
Shadow Distanceドラッグ入力欄（ステップ1.0、1～10000）Type=Directionalの場合のみ表示。カスケードシャドウの適用範囲
Shadow Resolutionコンボボックス（512 / 1024 / 2048 / 4096）シャドウマップの解像度（1カスケードあたり）
Shadow Biasドラッグ入力欄（ステップ0.01、0～5）自動計算されるテクセル基準の深度バイアスへの倍率（既定1.0）。下げると影が近づく代わりにシャドウアクネが出やすく、上げると影が浮きやすくなる（ツールチップに説明あり）
Shadow Softnessドラッグ入力欄（ステップ0.01、0～100）Type=Directional/Point/Spotの場合のみ編集可能。PCSS半影ソフト化に使うワールド単位の光源サイズ（0で硬い影）
Softness: %.3f (Source Radiusから自動算出)（読み取り専用）テキスト表示Type=Rect/Sphere/Disc/Tube/Boxの場合、Shadow Softnessの代わりにこの読み取り専用テキストが表示される。値は形状の物理サイズ（Source Radius等）から自動計算され、編集不可

Add Componentでの位置

Add Component›Render›Light から追加する。同一オブジェクトに複数付与可能（通常は1つのライトにつき1つ）。
