MeshRenderer

3Dメッシュを描画するコンポーネントです。描画するメッシュ自体は同一オブジェクトのMeshFilterから取得し、このコンポーネントは描画先・パイプライン・マテリアル・シャドウ関連の設定を持ちます。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Targetコンボボックス（シーン上のオブジェクトから選択）描画先コンポーネント（NormalWindowObject / OverlayWindowObject / ScreenBufferObject / ShadowMapObject のいずれか）を持つオブジェクトのみが候補に並ぶ。Scene Object Hierarchyからのドラッグ&ドロップでも設定できる
Render Target Filter（折りたたみツリー）描画先ごとのチェックボックスTargetに指定したオブジェクトが複数の描画先コンポーネントを持つ場合のみ表示。各描画先の名前の先頭に[Window]/[ScreenBuffer]/[ShadowMapBuffer]の種類が付く。チェックを外すとその描画先への描画から除外される
Pipelineコンボボックス読み込み済みのレンダーパイプライン名から選択（既定値 Object3D.Solid.BlendNormal）。None選択肢は無い
Pipeline Variant Builder（折りたたみツリー）Base/Toonチェックボックス/シェーダーモジュールのチェックボックス群/Raster/Blendのコンボボックス＋Applyボタン事前列挙された組み合わせに無いパイプライン名が欲しい場合に、トークンを組み立てて動的生成するビルダー。Base（Object3D/Object2D）、Toon（Object3D選択時のみ）、対応するシェーダーモジュール群、Raster（Solid/DoubleSidedCulling）、Blend（Add/Exclusion/Multiply/None/Normal/Screen/Subtract/Translucent）を選ぶと組み立て後のパイプライン名がプレビュー表示され、Applyボタンを押すと生成/取得に成功した場合のみ上のPipelineへ反映される（失敗時は何も起きない）
Cast Shadowsチェックボックス有効にすると、このメッシュがシャドウマッピングのシャドウキャスターとして扱われる（既定true）
Instance ColorColorEdit4（RGBA）オブジェクト単体の色。マテリアルは共有したまま、下のBlend Modeで指定した方法でマテリアルの色へ適用される。既定の白(1,1,1,1)＋Multiplyでは見た目に影響しない
Instance Color Blend Modeコンボボックス（Override / Multiply / Add / Subtract）Instance Colorをマテリアルの色へ適用する方法。既定はMultiply
Material（スロット数が1の場合） / Material 0, Material 1, ...（複数スロットの場合）コンボボックス＋アセットのドラッグ&ドロップ受付読み込み済みマテリアルから選択。Assets Windowからマテリアルファイルをドラッグ&ドロップして設定することもできる
マテリアルスロットはサブメッシュ数から自動決定される
MeshFilterが参照しているメッシュのサブメッシュ数に合わせて、マテリアルスロットの数がInspector表示のたびに自動調整される（Unityのマテリアルスロットと同様、スロットi＝サブメッシュi）。スロット数を手動で増減させるUIは無い。サブメッシュ数がスロット数を超える場合は最後のスロットのマテリアルで描画される。
Instance ColorはUnityのMaterialPropertyBlockに近い
マテリアル自体（共有アセット）を変更せずに、オブジェクト単位で色味だけを変えたい場合に使う。既定値のままなら見た目に影響しないため、通常は無視して構わない。

Add Componentでの位置

Add Component›Render›MeshRenderer から追加する。同一オブジェクトに複数付与することも可能（1オブジェクトに複数のマテリアル構成で描画したい場合等）。
