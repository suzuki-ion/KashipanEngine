NormalWindowObject

通常のOS標準ウィンドウを1枚生成・所有し、描画先として扱えるようにするコンポーネントです。共通のウィンドウ設定UIは基底クラスIWindowObjectComponentが提供します。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlおよびEngine/11_Window.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Titleテキスト入力欄ウィンドウタイトル（既定値 "Normal Window"）。変更すると生成済みウィンドウのタイトルにも即座に反映される
Width整数のドラッグ入力欄ウィンドウの幅（既定1280、下限1にクランプ）
Height整数のドラッグ入力欄ウィンドウの高さ（既定720、下限1にクランプ）
Sync With Transformチェックボックス有効にすると、同一オブジェクトのTransformのワールド座標・スケールをウィンドウの位置・サイズへ毎フレーム反映する（既定true）

Intercepted Messages（折りたたみツリー、基底クラス共通のUI）

ラベルウィジェット内容
（説明文）グレーの折り返しテキスト「横取り対象のメッセージは既定処理が実行されず、スクリプトのOnWindowMessage通知のみ行われます」
Intercept Close (WM_CLOSE)チェックボックス有効にするとXボタン・Alt+F4でウィンドウが閉じなくなる（ツールチップで警告表示）。閉じたい場合はスクリプトからCloseWindow()を呼ぶ必要がある
（横取り中のメッセージ一覧）各行「0x%04X (%u)」表示 ＋ Removeボタン現在横取り設定されているウィンドウメッセージ番号の一覧
（メッセージ番号入力）＋ Add整数入力欄＋ボタン任意のメッセージ番号を横取り対象へ追加する

Respawn Window（NormalWindowObject固有）

ラベルウィジェット内容
Respawn Windowボタン所有ウィンドウが存在しない状態（ユーザーがXボタン等で閉じてしまった場合等）のときにのみ表示される。押すとウィンドウを再生成する
OverlayWindowObjectとの違い
Respawn WindowボタンはOverlayWindowObjectには無く、NormalWindowObjectだけが持つ項目。

Add Componentでの位置

Add Component›Render›RenderTarget›NormalWindowObject から追加する（基底クラスIWindowObjectComponentのCOMPONENT_CATEGORY("Render", "RenderTarget")により Render サブカテゴリの RenderTarget 配下に分類される）。同一オブジェクトに複数付与可能。
