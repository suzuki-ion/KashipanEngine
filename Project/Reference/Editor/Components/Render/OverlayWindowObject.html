OverlayWindowObject

オーバーレイ（透過・最前面）ウィンドウを1枚生成・所有し、描画先として扱えるようにするコンポーネントです。共通のウィンドウ設定UIは基底クラスIWindowObjectComponentが提供し、Inspector上のUIはNormalWindowObjectとほぼ同じです。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlおよびEngine/11_Window.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Titleテキスト入力欄ウィンドウタイトル（既定値 "Overlay Window"）
Width整数のドラッグ入力欄ウィンドウの幅（既定1280、下限1にクランプ）
Height整数のドラッグ入力欄ウィンドウの高さ（既定720、下限1にクランプ）
Sync With Transformチェックボックス有効にすると、同一オブジェクトのTransformのワールド座標・スケールをウィンドウの位置・サイズへ毎フレーム反映する（既定true）

Intercepted Messages（折りたたみツリー、基底クラス共通のUI）

ラベルウィジェット内容
（説明文）グレーの折り返しテキスト「横取り対象のメッセージは既定処理が実行されず、スクリプトのOnWindowMessage通知のみ行われます」
Intercept Close (WM_CLOSE)チェックボックス有効にするとXボタン・Alt+F4でウィンドウが閉じなくなる（ツールチップで警告表示）
（横取り中のメッセージ一覧）各行「0x%04X (%u)」表示 ＋ Removeボタン現在横取り設定されているウィンドウメッセージ番号の一覧
（メッセージ番号入力）＋ Add整数入力欄＋ボタン任意のメッセージ番号を横取り対象へ追加する
NormalWindowObjectと違い「Respawn Window」ボタンが無い
NormalWindowObjectにはウィンドウが存在しない状態のときに再生成する「Respawn Window」ボタンがあるが、OverlayWindowObjectのShowImGui()にはこれに相当するボタンが実装されていない。

Add Componentでの位置

Add Component›Render›RenderTarget›OverlayWindowObject から追加する。同一オブジェクトに複数付与可能。
