ScreenAnchor

同一オブジェクトのTransformを、指定したCamera2Dの画面（width/height）上の基準点へ毎フレーム追従させるコンポーネントです。UI要素を画面端やコーナーに固定し、解像度が変化しても正しい位置を保ちたい場合に使います。Scene Object Inspector上での見え方を説明します。

Inspectorに表示される項目

ラベルウィジェット内容
Anchor Cameraコンボボックス（シーン上のオブジェクトから選択）基準にするCamera2Dを持つオブジェクト。描画先の指定には使わない
Anchor PointXYのドラッグ入力欄（ステップ0.01、範囲0.0～1.0）画面上の基準点の正規化座標（既定(0.5, 0.5)）。(0,0)＝画面左下、(1,1)＝画面右上（Camera2Dのワールド空間そのままの向きで、Y軸は上方向が正）
OffsetXYのドラッグ入力欄（ステップ1.0）基準点からのオフセット（ピクセル、Camera2Dのワールド単位＝Y上方向が正、既定(0.0, 0.0)）

直下にグレーのヒント文「Every frame, rewrites this Transform's X/Y (Z is left unchanged) from the anchor camera's width/height plus the anchor point and offset. Anchor point: (0,0) = bottom-left of screen, (1,1) = top-right.」が表示される。

Transformの計算式
毎フレームUpdate()で、同一オブジェクトのTransformのTranslateへ以下を書き込みます（Zは変更しません）。
  • Translate.X = Anchor Point.X × Camera2D.Width + Offset.X
  • Translate.Y = Anchor Point.Y × Camera2D.Height + Offset.Y
Anchor CameraにCamera2Dが見つからない場合、または同一オブジェクトにTransformが無い場合は何もしません（Translateは変更されず、直前の値のまま）。
Camera2DのAuto-Sync To Resolutionと組み合わせて使う
ScreenAnchor自身は描画先の解像度を一切問い合わせません。Anchor Cameraに指定したCamera2D側でAuto-Sync To Resolutionを有効にしておけば、Camera2DのWidth/Heightが描画先の実解像度に自動追従するため、結果としてScreenAnchorの計算結果も解像度変化に連動します。Auto-Sync To Resolutionを使わない場合は、Camera2DのWidth/Heightの手動設定値がそのまま基準になります。
SpriteRenderer/TextRendererのAnchor/Pivotとは別の概念
ScreenAnchorが扱う基準点はあくまで「画面のどこにTransformを置くか」で、SpriteRenderer/TextRendererが持つAnchor/Pivot（スプライトやテキスト自身の矩形内のどこを基準に描画するか）とは独立した別の値です。両者を組み合わせて使うこともできます。

Add Componentでの位置

Add Component›Render›ScreenAnchor から追加する。同一オブジェクトに複数付与可能。
