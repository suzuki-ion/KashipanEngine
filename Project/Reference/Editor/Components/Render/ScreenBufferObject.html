ScreenBufferObject

オフスクリーンレンダリング用のバッファ（ScreenBuffer）を1枚所有し、描画先として扱えるようにするコンポーネントです。ポストエフェクトの適用先やレンダーテクスチャとして使う、画面キャプチャ保存機能、内容確認用のプレビューウィンドウを持ちます。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlおよびEngine/11_Window.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Nameテキスト入力欄（Enterキーで確定）TextureManagerへの登録名。他のフィールドと違い、Enterキーを押すまでは値が確定しない（ImGuiInputTextFlags_EnterReturnsTrue）
Width整数のドラッグ入力欄バッファの幅（既定1280、下限1にクランプ）。変更すると生成済みバッファが実際にリサイズされる
Height整数のドラッグ入力欄バッファの高さ（既定720、下限1にクランプ）
Open Viewer / Close Viewerトグルボタン押すたびに開閉する、バッファの描画内容を確認できる別のImGuiウィンドウ（"ScreenBuffer Viewer: 名前"）の表示状態を切り替える。SRVが未準備の間は「SRV not ready.」と表示される

Save to File（折りたたみツリー）

ラベルウィジェット内容
Directoryテキスト入力欄自動生成される保存先パスのディレクトリ部分（既定 "Screenshots"）
File Name Prefixテキスト入力欄保存ファイル名の接頭辞（既定 "Screenshot"）
Formatコンボボックス（png / jpg / bmp）保存形式（既定 "png"）
Save Screenshotボタン直近で確定した描画結果を、上記Directory/File Name Prefix/タイムスタンプ/Formatから自動生成したパスへ画像ファイルとして保存する。失敗した場合は警告ログが出力される
Viewerはポーズ中も表示され続ける
ViewerウィンドウはShowPersistentImGui()経由で表示されるため、Inspector自体が閉じていても、またゲームがポーズ中でも表示され続ける（Inspectorの通常のShowImGuiとは別枠の常時表示）。
プレビュー画像は前フレームまでの確定結果
Viewerが参照するSRVはGetPreviewSrvHandle()による「前フレームまでに描画完了した面」で、現在フレームのポストエフェクト適用途中の中間結果を意図せず表示してしまわないよう配慮されている。

Add Componentでの位置

Add Component›Render›RenderTarget›ScreenBufferObject から追加する。同一オブジェクトに複数付与可能。
