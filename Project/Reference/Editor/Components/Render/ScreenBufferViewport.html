ScreenBufferViewport

ScreenBufferObject（オフスクリーン）の内容を、指定した描画先（Windowなど）へ2Dスプライトとして表示するコンポーネントです。内部でMeshFilter（"Rect2D"固定）とSpriteRendererを自動生成・管理し、新規の描画コードは持たず既存のSpriteRenderer描画パイプラインにそのまま乗せる薄いラッパーです。Scene Object Inspector上での見え方を説明します。

Inspectorに表示される項目

ラベルウィジェット内容
Sourceコンボボックス（シーン上のオブジェクトから選択）表示するオフスクリーンの内容を持つ、ScreenBufferObjectを付与したオブジェクト
Display Cameraコンボボックス（シーン上のオブジェクトから選択）マウス座標変換（後述のTryGetOffscreenMousePosition）の基準にするCamera2Dを持つオブジェクト。描画先の指定には使わない
描画先・アンカー/ピボット・パイプライン等は内部SpriteRenderer側で編集する
このコンポーネント自体はそれらの委譲用ウィジェットを持ちません。自動生成された同一オブジェクトのSpriteRendererコンポーネント（Inspector上には通常のコンポーネントとして表示される）で、Target（描画先ウィンドウ）・Anchor/Pivot・Pipeline等を直接編集してください。
自動生成されたMeshFilter/SpriteRendererは削除しないこと
これらはこのコンポーネントを削除しても自動では削除されません（他コンポーネントと同様、ユーザーが明示的に削除可能な通常コンポーネントとして扱われます）。誤って削除するとViewportが機能しなくなります。またMeshFilterは1オブジェクトにつき1つまでのため、既存のMeshFilterを持つオブジェクトに付けると流用（メッシュがRect2Dに上書き）されます。専用オブジェクトへの付与を推奨します。

マウス座標変換（オフスクリーンのピクセル座標）

表示先ウィンドウ上のマウス座標を、Display Camera（Camera2D）の逆射影とスプライトの逆ワールド行列を通して、ソースScreenBufferの解像度基準のピクセル座標へ変換できます。

メソッド説明
bool TryGetOffscreenMousePosition(Vector2 &out)変換に成功し、かつマウスがスプライトの表示範囲内にある場合はtrueを返し、outへScreenBufferのピクセル座標（左上原点、X右・Y下方向）を書き込む
bool IsMouseOverOffscreen() constマウスカーソルが表示範囲内にあるかどうか
class MinimapClick : ScriptComponentBehavior {
    void Update() {
        ScreenBufferViewport@ viewport;
        GetComponent(@viewport);
        Vector2 pixel;
        if (viewport.TryGetOffscreenMousePosition(pixel)) {
            Log("Offscreen pixel: " + pixel.x + ", " + pixel.y);
        }
    }
}
Camera2Dのシェイクは反映されない
Shakeコンポーネントによる演出用の位置オフセットは描画のみの見た目上の効果のため、マウス座標変換の計算には含まれません。

Add Componentでの位置

Add Component›Render›ScreenBufferViewport から追加する。同一オブジェクトに1つのみ付与可能。
