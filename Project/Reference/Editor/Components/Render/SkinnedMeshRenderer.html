SkinnedMeshRenderer

ボーンアニメーションで変形するメッシュ（スキンメッシュ）を描画するコンポーネントです。描画先・パイプライン・マテリアルの指定はMeshRendererと同じですが、GPUスキニングの品質設定とBlendShape（モーフターゲット）のウェイト編集が加わります。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Inspectorに表示される項目

描画先・パイプライン・マテリアル（MeshRendererと共通）

ラベルウィジェット内容
Targetコンボボックス（シーン上のオブジェクトから選択）描画先コンポーネントを持つオブジェクトのみが候補。ヒエラルキーからのドラッグ&ドロップにも対応
Render Target Filter（折りたたみツリー）描画先ごとのチェックボックス対象オブジェクトが複数の描画先コンポーネントを持つ場合のみ表示
Pipelineコンボボックス読み込み済みのレンダーパイプライン名から選択（既定値 Object3D.Solid.BlendNormal）
Pipeline Variant Builder（折りたたみツリー）Base/Toonチェックボックス/シェーダーモジュールのチェックボックス群/Raster/Blendのコンボボックス＋Applyボタン事前列挙された組み合わせに無いパイプライン名を動的に組み立てるビルダー。MeshRendererと共通のUI。Applyボタンを押すと生成/取得に成功した場合のみ上のPipelineへ反映される
Cast Shadowsチェックボックス有効にすると、このメッシュがシャドウマッピングのシャドウキャスターとして扱われる（既定true）
Instance ColorColorEdit4（RGBA）オブジェクト単体の色。マテリアルは共有したまま、下のBlend Modeで指定した方法でマテリアルの色へ適用される。既定の白(1,1,1,1)＋Multiplyでは見た目に影響しない
Instance Color Blend Modeコンボボックス（Override / Multiply / Add / Subtract）Instance Colorをマテリアルの色へ適用する方法。既定はMultiply
Material（1スロット時） / Material 0, 1, ...（複数スロット時）コンボボックス＋アセットのドラッグ&ドロップ受付サブメッシュ数に合わせてスロット数が自動調整される。Assetsウィンドウからのマテリアルファイルのドラッグ&ドロップにも対応
Instance ColorはMeshRendererと共通の機能
以前はSkinnedMeshRendererに無かった機能だが、現在はMeshRendererと同じ仕様のInstance Color / Instance Color Blend Modeが追加されている。既定値のままなら見た目に影響しないため、通常は無視して構わない。

Skinning（区切り線以下、SkinnedMeshRenderer固有）

ラベルウィジェット内容
Qualityコンボボックス（Auto / Bone1 / Bone2 / Bone4）頂点あたりの参照ボーン数の上限（UnityのSkin Quality相当）。Autoは内部的にBone4と同じ扱い
（Animator未検出時の警告文）グレーアウトしたテキスト同一オブジェクトにAnimatorコンポーネントが無い場合「(No Animator on this object: bind pose only)」と表示され、以降バインドポーズのまま描画される
Vertex Count読み取り専用テキストスキニング対象の頂点数
Joint Count読み取り専用テキストスキニングに使うジョイント数
Blend Shapes（折りたたみツリー）ジョイント名ごとのドラッグ入力欄（0～100、ステップ0.1）メッシュに含まれるBlendShapeが自動的に一覧同期される。編集できるのはウェイトのみで、一覧の追加・削除はできない（Unityと同様）。BlendShapeが無いメッシュの場合「(No blend shapes on this mesh)」と表示される
アニメーションの再生はこのコンポーネントの責務ではない
クリップの選択・再生状態・スケルトン姿勢の更新は同一オブジェクトのAnimatorコンポーネントが担う（Unityの Animator / SkinnedMeshRenderer の役割分担と同様）。SkinnedMeshRendererは、Animatorが計算した姿勢を使ってGPUスキニングを行い描画するだけ。

Add Componentでの位置

Add Component›Render›SkinnedMeshRenderer から追加する。同一オブジェクトに複数付与可能。
