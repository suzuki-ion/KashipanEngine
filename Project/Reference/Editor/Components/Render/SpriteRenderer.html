SpriteRenderer

2Dスプライトを描画するコンポーネントです。描画するメッシュ（通常は単位クアッド）は同一オブジェクトのMeshFilterから取得します。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Targetコンボボックス（シーン上のオブジェクトから選択）描画先コンポーネントを持つオブジェクトのみが候補。ヒエラルキーからのドラッグ&ドロップにも対応
Render Target Filter（折りたたみツリー）描画先ごとのチェックボックス対象オブジェクトが複数の描画先コンポーネントを持つ場合のみ表示
Pipelineコンボボックス読み込み済みのレンダーパイプライン名から選択（既定値 Object2D.DoubleSidedCulling.BlendNormal）
Materialコンボボックス＋アセットのドラッグ&ドロップ受付読み込み済みマテリアルから選択（既定値 Default）。Assets Windowからマテリアルファイルをドラッグ&ドロップして設定することもできる。MeshRendererと違いマテリアルスロットは1つのみ
AnchorXYのドラッグ入力欄（ステップ0.01）Transformの座標に一致させるメッシュ上の点。単位クアッド内の正規化座標（(0,0)=左下 ～ (1,1)=右上）。既定値(0.5, 0.5)=中心
PivotXYのドラッグ入力欄（ステップ0.01）回転・拡縮の中心にするメッシュ上の点。正規化座標での指定はAnchorと同じ。既定値(0.5, 0.5)=中心
Instance Colorカラーピッカー共有マテリアルを変更せず、このSpriteRendererだけに適用する色。既定値は白
Instance Color Blend Modeコンボボックスマテリアル色との合成方法（Override / Multiply / Add / Subtract）。既定値はMultiply
AnchorとPivotを別々にする効果
両方とも既定値(0.5, 0.5)の場合は違いが出ない。Pivotだけをずらすと回転・拡縮の中心がTransformの座標（Anchorの位置）からずれ、AnchorだけをずらすとTransformの座標に一致させる点そのものが変わる（見た目上はスプライト全体が平行移動する）。

Instance UV（オブジェクト単位のUV変換）

共有マテリアルを変更せず、このSpriteRendererだけにUV変換（オフセット・回転・スケール）を追加で適用できる。マテリアル側のUV変換（MaterialManagerのUV Translate/Rotation/Scale/Pivot）とはUV Combine Modeの指定に従って合成され、既定値のまま（オフセット(0,0)・回転0・スケール(1,1)）であれば見た目に影響しない。

ラベルウィジェット内容
Instance UV TranslateXYのドラッグ入力欄（ステップ0.001）オブジェクト単位のUVオフセット。既定値(0, 0)
Instance UV Rotation (deg)ドラッグ入力欄（ステップ0.1、範囲-180〜180）オブジェクト単位のUV回転（度指定、内部はラジアンで保持）。既定値0
Instance UV ScaleXYのドラッグ入力欄（ステップ0.001）オブジェクト単位のUVスケール。既定値(1, 1)
Instance UV Rotation PivotXYのドラッグ入力欄（ステップ0.001）Instance UV Rotationの回転中心（UV基準の座標）。拡縮は常にUV原点(0, 0)基準のまま、回転のみこの点を中心に行われる。既定値(0.5, 0.5)
UV Combine Modeコンボ（Material-based（既定）/ Instance-based / Instance Only）Instance UVとマテリアル側のUV変換の合成方法。Material-based: マテリアルの変換の上にInstance UVを乗せる。Instance-based: Instance UVを基準にマテリアルの変換を後から適用する。Instance Only: マテリアルのUV変換を無視しInstance UVのみを使う
Instance UV Translate / Scale / Rotation Pivot (px)XYのドラッグ入力欄（ステップ0.5）上記Translate/Scale/Rotation Pivotの3項目を、マテリアルのテクスチャのピクセル単位で編集できる別表示。内部値（0〜1のUV基準）と相互に連動する。マテリアルにテクスチャが設定されていない場合は無効化（グレーアウト）される

描画順・インスタンシング制御

ラベルウィジェット内容
Render Priority整数ドラッグ入力欄（範囲制限なし）描画順を制御する優先度。値が小さいほど先に（奥に）、大きいほど後に（手前に）描画される。既定値0。パイプラインのRender Priorityより後、メッシュ/マテリアルによるグループ化より前に評価される
Allow Instancingチェックボックス無効にすると、他のオブジェクトとメッシュ/マテリアル/パイプラインが同じでも必ず単独のドローコールで描画される。既定true

Add Componentでの位置

Add Component›Render›SpriteRenderer から追加する。同一オブジェクトに複数付与可能。
