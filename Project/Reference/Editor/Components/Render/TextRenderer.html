TextRenderer

SDFフォントによるテキストを描画するコンポーネントです。Unity風のリッチテキストタグを解釈しながら1文字ずつ独立した矩形として描画し、文字ごとに位置・回転・スケールを個別に上書きできます。Scene Object Inspector上での見え方を説明します。C++側のAPIはEngine/05_Rendering.htmlを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Targetコンボボックス描画先コンポーネントを持つオブジェクトのみが候補。ヒエラルキーからのドラッグ&ドロップにも対応
Render Target Filter（折りたたみツリー）描画先ごとのチェックボックス対象オブジェクトが複数の描画先コンポーネントを持つ場合のみ表示
Use Localization Keyチェックボックス有効にすると、Textを直接編集する代わりに翻訳キーからテキストを解決するモードになる（既定false）
Localization Keyテキスト入力（InputText）Use Localization Keyが有効な場合のみ表示。Locales/またはAssets/Locales/のキーを指定する。入力するたび即座にそのキーの翻訳結果でTextが更新される
Text複数行テキスト入力（InputTextMultiline）表示する文字列。直下にグレーのヒント文で使用可能タグ一覧「<i> <b> <color=#RRGGBB(AA)> <size=N|N%> <s> <u> <sub> <sup>」が表示される（イタリック・太字・色・サイズ・取り消し線・下線・下付き・上付き）。Use Localization Keyが有効な間は無効化（グレーアウト）され直接編集できず、その下に「翻訳キーから解決されます（表示言語の変更に自動追従）」の説明文が表示される
Fontコンボボックス（None選択可）FontManagerに読み込み済みのフォントから選択
Font Sizeドラッグ入力欄（ステップ0.01、0.01～1000）既定値32
Instance Color / Blend ModeColorEdit4（RGBA）/ コンボボックスマテリアル色へ文字単位で適用する色と合成方法。<color=...>タグで部分的に上書きできる
Outline Width / Colorドラッグ入力 / ColorEdit4SDF文字アウトラインの太さ（0で無効）と色
Materialコンボボックス文字へ適用するマテリアル。マテリアルのテクスチャとUVは無視され、フォントアトラスが使用される
Horizontal Alignコンボボックス（Left / Center / Right）行の横方向アライメント
Vertical Alignコンボボックス（Top / Middle / Bottom）テキストブロック全体の縦方向アライメント
Default Character AnchorXYのドラッグ入力欄（ステップ0.01）各文字のデフォルトアンカー（単位クアッド内の正規化座標、既定(0.5, 0.5)）
Default Character PivotXYのドラッグ入力欄（ステップ0.01）各文字のデフォルトピボット（回転・拡縮の中心、既定(0.5, 0.5)）。意味はSpriteRendererのAnchor/Pivotと同じ
Pipelineコンボボックス読み込み済みのレンダーパイプライン名から選択（既定値 Text2D.BlendNormal）
Render Priority整数ドラッグ入力（DragInt）描画順を制御する優先度（既定0）。値が小さいほど先（奥）、大きいほど後（手前）に描画される。MeshRenderer/SpriteRendererと同じ仕組みで比較されるため、他種のRendererとの前後関係も統一的に制御できる。ホバーすると説明ツールチップが表示される
Allow Instancingチェックボックス他のオブジェクトとのインスタンシング（同一パイプライン・メッシュ・マテリアルを共有するインスタンスの1回のドローコールへの結合）対象にするか（既定true）。falseにするとこの文字インスタンス群は常に単独のドローコールで描画される。ホバーすると説明ツールチップが表示される
Character Overrides（折りたたみツリー）文字インデックスごとの Offset（XYドラッグ、ステップ0.1）/ Rotation（ドラッグ、ステップ0.01、ラジアン）/ Scale（XYドラッグ、ステップ0.01）Text（タグを除いた実文字数）と同じ数だけ[0],[1],...の項目が並ぶ。Textが空の場合はツリー自体が表示されない
Character Overridesはシーンへ保存されない
文字ごとの位置・回転・スケール上書き（Character Overrides）はランタイム専用のデータで、SaveToJsonの対象外。Inspector上で調整した値はPlay終了やシーン再読み込みでリセットされる。演出目的でスクリプトから毎フレーム設定する使い方を想定している。
Rotationのみラジアン表示
Character OverridesのRotationは度への変換をせず、内部値（ラジアン）がそのままドラッグ入力欄に表示・入力される。Transformの回転（度表示）とは扱いが異なる点に注意。
Use Localization Key有効時は表示言語の変化に自動追従する
Update()毎フレーム、直近に反映した表示言語と現在の表示言語（アプリケーション側の言語。エディター自身のUI言語とは独立した値）を比較し、変化していた場合のみ翻訳キーを再解決してTextへ反映する（未使用のTextRendererへの負荷はbool比較1回のみ）。そのため実行中に言語を切り替えても、対象のTextRendererへ改めて手を入れる必要はない。

Add Componentでの位置

Add Component›Render›TextRenderer から追加する。同一オブジェクトに複数付与可能。
