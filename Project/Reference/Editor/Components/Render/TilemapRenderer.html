TilemapRenderer

RPGツクール風のオートタイル（隣接する同種タイルに応じてテクスチャを自動で切り替える）に対応したタイルマップ描画コンポーネントです。自身はSceneRendererへ描画登録せず、同一オブジェクトのMeshFilter/SpriteRendererを自動追加して駆動します（ScreenBufferViewportと同じパターン）。タイル配置が変わるたびに1枚の結合メッシュを再構築するため、タイル数が多くても描画コストは1オブジェクト分のドローコールに収まります。

シーンビューでの配置
シーンビューの「Tile Paint」ツールタブ（SceneEditorView）から、選択中のTilemapRendererオブジェクトへクリック/ドラッグで直接タイルを配置できます（左クリック=選択中のブラシ、右クリック=常に消しゴム。右クリックは「2D」表示モード限定）。ブラシはタイルセット画像のサムネイルから選べます。Inspectorのセル一括編集欄やAngelScriptからのSetTile呼び出しでも配置可能です。
MeshRendererではなくSpriteRendererを使う理由
パイプライン名Object2D.*は、シーンビュー（エディター）上でgCamera3D投影の「Worldバリアント」へ差し替えられて初めて3Dシーンビュー内に正しく表示されます。この差し替えはSpriteRenderer由来の描画エントリにしか適用されないため、同じパイプラインをMeshRendererで使うとシーンビュー上でのみ真っ黒・位置ズレして表示されます（実際のゲーム画面では問題になりません）。TilemapRendererが自動追加するのがSpriteRendererである理由はこのためです。

オートタイルの仕組み

各タイル種類（Tile Type）は「接続先タイル種類インデックス」のリストを持てます（Connects Toリスト）。あるセルについて、上下左右の隣接セルのタイル種類インデックスが自分のConnects Toリストに含まれていれば、その方向のビットを立て、4bit（0〜15）のビットマスクを求めます。この判定は片方向です。例えば「草」（インデックス0）のConnects Toが{0, 1}、「土」（インデックス1）のConnects Toが{1}のみの場合、草は土と接続して見えますが（草のリストに1が含まれる）、土は草と接続しません（土のリストに0が含まれない）。相互に接続させたい場合は、両方のタイル種類のConnects Toリストへ互いのインデックスを追加する必要があります。ビットの意味は次の通りです。

ビット値方向
1北（+Y方向）のセルへ接続している（自分のConnects Toに含まれる）
2東（+X方向）のセルへ接続している
4南（-Y方向）のセルへ接続している
8西（-X方向）のセルへ接続している

タイルセット画像は、1つのタイル種類につき4x4=16パターンのブロックを敷き詰めたレイアウトを前提とします。ブロック内の位置は「列 = ビットマスク % 4」「行 = ビットマスク / 4」で、Tile TypeのTileset Origin (px)を左上原点として、その列・行にTile Pixel Size分だけオフセットした位置のタイルが使われます（RPGツクール互換の47パターンA2形式ではありません）。これはAutotile Modeが4-Direction（既定）の場合の仕様。

8方向オートタイル（4分割合成）

Autotile Modeを8-Directionに切り替えると、斜め4方向も含めた8方向で接続を判定する。1タイルを4つの角（左上/右上/左下/右下）に分割し、角ごとにタイルセット上のどのクォーター（1/4マス）を貼り付けるかを、周囲の接続状況から自動的に選ぶ方式。パラメーターは一切不要（Isolated Tile・Cross Tileの位置を除く）。RPGツクールの実ファイルとの互換性は無く、独自に定義したレイアウト。

タイルセット画像は、1つのタイル種類につき2列×3行のブロックを前提とする。

位置（列,行）内容
(0,0)Isolated Tile — 周囲8方向すべて非接続の時、まるごと1枚使う
(1,0)Cross Tile — 上下左右4方向のみ接続・斜め4つとも非接続の時、まるごと1枚使う
(0,1) / (1,1)2×2ブロックの上段（左上セル／右上セル）
(0,2) / (1,2)2×2ブロックの下段（左下セル／右下セル）

上記のIsolated Tile・Cross Tile以外のケース（4つの角を個別合成する場合）は、各角ごとに「その角に隣接する縦方向1つ・横方向1つの接続有無」「その角の斜め方向1つの接続有無」を見て、2×2ブロックのどのセルの・どのクォーターを使うかを次のルールで自動的に決める。参照するクォーターの位置は常に出力する角自身と同じ位置（左上の角なら参照元セルの左上クォーター、右下の角なら参照元セルの右下クォーター、というように反転・入れ替え無しでそのまま対応する）。

  • 縦方向・横方向とも非接続 → 2×2ブロックの自分と同じ位置のセル
  • 縦方向のみ接続 → 2×2ブロックの上下反転した位置のセル
  • 横方向のみ接続 → 2×2ブロックの左右反転した位置のセル
  • 縦方向・横方向・斜めすべて接続（完全に囲まれている） → 2×2ブロックの対角のセル
  • 縦方向・横方向は接続しているが斜めだけ非接続（凹み） → Cross Tile（この場合もその角と同じ位置のクォーターだけを使う）

Isolated Tile・Cross Tileの位置（タイル単位。Tileset Origin (px)からの整数タイル数オフセット）のみ、Inspectorの「Eight-Direction Layout (Advanced)」セクションから調整できる。2×2ブロックの位置は常にIsolated/Cross Tileの2行下・同じ2列に固定されており、調整項目は無い。

このアルゴリズムはRPGツクールのA2形式などとは異なる、KashipanEngine独自に導出したものです。実機でレンダリングしてみないと正確な見た目は確認できないため、水平/垂直のペア・L字・十字・2×2ブロック・3×3ブロックなど複数の配置パターンで実際にタイルを並べて見た目を確認すること。

Inspectorに表示される項目

ラベルウィジェット内容
Pipelineコンボボックス読み込み済みの2D用レンダーパイプライン名から選択（既定値 Object2D.DoubleSidedCulling.BlendNormal）。同一オブジェクトのSpriteRendererへそのまま反映される
Materialコンボボックス＋アセットのドラッグ&ドロップ受付タイルセット画像を含むマテリアル（既定値 Default）

Eight-Direction Layout (Advanced)折りたたみ可能なセクション（Isolated Tile・Cross Tileの計2個のXYドラッグ入力欄）Autotile Modeが8-Directionの時のみ表示。Isolated Tile・Cross Tileの位置（タイル単位）を調整する。それ以外の合成パターンは自動選択されるため調整項目は無い（上記「8方向オートタイル」参照）

Tile Typesタイル種類ごとに折りたたみ可能なセクション（Tileset Origin (px)・Solid・Connects To・削除ボタン）タイル種類の追加・編集・削除。タイル種類が増えても見やすいよう、1種類ごとに開閉できるセクションに分かれている。Add Tile Typeボタンで末尾に追加。SolidはGenerate 2D Collidersが有効な場合に当たり判定生成の対象にするかどうか（既定true）。Connects Toは接続先タイル種類インデックスの小さなリスト（Add Connection/削除ボタンで複数登録可能。片方向）

2D当たり判定の自動生成

Generate 2D Collidersを有効にすると、Solidなセルが隣接している範囲を貪欲法（左上から右方向に最大幅を求め、その幅の行が続く限り下方向へ高さを伸ばす）で矩形へまとめ、その矩形ごとにBox2DColliderを同一オブジェクトへ生成する。生成したBox2DColliderは内部的に追跡され、タイル配置や有効/無効の切り替えのたびに全て削除してから作り直される（ユーザーが手動で追加した無関係なBox2DColliderには触れない）。生成されたBox2DCollider個々をInspector上で手動編集する導線は無く、手で調整したい場合はGenerate 2D Collidersをオフにして自分で追加すること。

AngelScriptからの操作

実行時にブロックの設置・破壊などでタイル配置を変更したい場合は、AngelScript側から次のメソッドを呼び出せます（コンポーネント取得の仕組みは他コンポーネントと同様）。

メソッド内容
void SetTile(int x, int y, int tileTypeIndex)セルにタイル種類を設定する（-1で空にする）。範囲外の座標は無視される
int GetTile(int x, int y) constセルのタイル種類を取得する（範囲外・空セルは-1）
void Resize(int width, int height)グリッドサイズを変更する
void Clear()全セルを空にする
int AddTileType(const Vector2 &in tilesetOriginPx)タイル種類を追加し、新しいインデックスを返す（接続先は空で始まる。自分自身を含め、AddTileTypeConnectionで追加すること）
void RemoveTileType(int index)タイル種類を削除する（参照していたセルは空になり、他のタイル種類のConnects Toが参照していた場合もそちらも削除・繰り上げられる）
void AddTileTypeConnection(int index, int targetTileTypeIndex) / void RemoveTileTypeConnection(int index, int targetTileTypeIndex)タイル種類indexの接続先（片方向）へtargetTileTypeIndexを追加・削除する
int GetTileTypeConnectionCount(int index) const / int GetTileTypeConnectionAt(int index, int connectionIndex) constタイル種類が持つ接続先の数・各値（タイル種類インデックス）を取得する
void SetTileTypeSolid(int index, bool solid) / bool GetTileTypeSolid(int index) constタイル種類が2D当たり判定生成の対象かを設定・取得する
void SetGenerateColliders(bool enabled) / bool GetGenerateColliders() const2D当たり判定の自動生成を設定・取得する
void SetAutotileMode(int mode) / int GetAutotileMode() constオートタイルの判定方向を設定・取得する（0=4-Direction, 1=8-Direction）

タイル配置の変更は即座にメッシュを作り直すのではなく、変更フラグを立てるだけで次のフレームの更新処理で1回だけ再構築されるため、1フレーム内で複数回SetTileを呼んでも再構築は1回で済みます。

Add Componentでの位置

Add Component›Render›TilemapRenderer から追加する。追加時に同一オブジェクトへMeshFilter/SpriteRendererが無ければ自動的に追加される。
