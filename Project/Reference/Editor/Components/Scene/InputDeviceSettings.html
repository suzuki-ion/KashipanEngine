InputDeviceSettings 最大1個

入力デバイス判定（キーボード＋マウス / コントローラーのどちらで操作中か）のしきい値を、このシーンだけ上書きするシーンコンポーネントです。Scene Component Inspector上での見え方を説明します。判定の仕組みとC++側のAPIはEngine/08_Input.htmlを参照してください。

しきい値の上書き

各項目の左のチェックボックスをオンにした項目だけが、EngineSettings.jsonのinputセクションの値を上書きします。オフの項目は編集できず、下に既定値（EngineSettingsの値）が表示されます。値を変更するとその場で入力デバイス判定へ反映されます。

ラベルウィジェット内容
Mouse Move Threshold (px)チェックボックス＋ドラッグ入力欄（ステップ0.5、範囲0〜500）マウス移動をキーボード＋マウスへの切り替えとみなす累積移動量（ピクセル）。小さな揺れで切り替わらないようにするための値
Stick Thresholdチェックボックス＋スライダー（0.00〜1.00）スティックの傾きがこの値以上でコントローラーへの切り替えとみなす
Trigger Thresholdチェックボックス＋スライダー（0.00〜1.00）トリガーの押し込み量がこの値以上でコントローラーへの切り替えとみなす
値が元に戻るタイミング
シーン切り替え・Playの停止・エディターでのシーン再読み込みのたびに、しきい値は一度EngineSettings.jsonの値へ戻り、その後で読み込まれたシーンにこのコンポーネントがあれば上書きが適用されます。そのため、スクリプトからSetMouseMoveThreshold等で変更した値や、「入力状態」ウィンドウで一時的に調整した値は、次のシーンやPlay停止後には持ち越されません。このコンポーネントを削除・無効化した場合もEngineSettings.jsonの値へ戻ります。

Add Scene Componentでの位置

Add Scene Component → Input → InputDeviceSettings。
