KeyframeAnimator (シーン) 最大1個

キーフレーム（タイムライン）アニメーションを再生するシーンコンポーネント版のKeyframeAnimatorです。シーン全体のタイムライン再生を管理する点で、個々のオブジェクトへ付与するKeyFrameAnimator（オブジェクトコンポーネント）とは別クラスです。名前が非常に紛らわしいので、Add Scene Componentの一覧でこちらを選んでいるか確認してください。Scene Component Inspector上での見え方を説明します。C++側のAPIはEngine/02_Scenes.htmlを参照してください。

Inspector上には何も表示されません
このコンポーネントはShowImGui()を空実装でオーバーライドしているため、コンポーネント一覧を開いても中身が完全に空欄になります（他の「専用実装を持たない」シーンコンポーネントで表示される既定の None というテキストすら表示されません）。タイムライン（KeyframeTimeline）の追加・キー編集・再生制御は全てC++側のAPI（AddTimeline/AddTimelineKey/PlayFromAnimationHandle等）またはスクリプトから行う必要があり、現時点ではEditor上で編集する手段がありません。

役割

時間・値・イージング種別を持つKeyframeNodeの並び（KeyframeTimeline）を名前付きで保持し、Update()で経過時間に応じて値を評価し、タイムラインに登録された適用関数（KeyframeApplyFunction）へ書き戻します。値の型はfloat/Vector3/Quaternionのいずれかです。スケルトンアニメーションの再生（PlayFromAnimationHandle系）にも同じ仕組みが使われます。

設定の保存・読み込みは、シーンJSONに自動で乗る通常のSaveToJson/LoadFromJson経路ではなく、SaveSettings(filePath)/LoadSettings(filePath)という専用メソッドで個別のJSONファイルへ行います。

Add Scene Componentでの位置

他のシーンコンポーネントと異なりCOMPONENT_CATEGORYが指定されていないため、Add Scene Componentのカテゴリツリー上ではAdd Scene Component → KeyframeAnimatorのように、どのカテゴリにも属さずツリーの直下に表示されます。
