SceneAudioPlayer 最大1個

シーン内のAudioListener/AudioSourceを収集して音声再生を管理するシーンコンポーネントです。使用中（GetUsed()==true）のAudioListenerの位置・向きを基準に、登録済みの各AudioSourceの距離減衰・パン・ローパスフィルターを毎フレーム更新します。Scene Component Inspector上での見え方を説明します。C++側のAPIはEngine/02_Scenes.htmlを参照してください。

Inspectorに表示される項目

全て読み取り専用のテキスト表示です（ImGui::Text）。編集可能な項目はありません。

表示内容
Listeners: N登録済みAudioListenerの数
Sources: N登録済みAudioSourceの数
AudioListener/AudioSourceそれぞれのInitialize/Finalizeから自動でRegister/Unregisterされるため、Inspector上から個々のリスナー・ソースを増減させることはできません。同時に使用中扱いにできるAudioListenerは1つのみで、SetUsed(true)を呼ぶとそれ以外のリスナーの使用フラグは自動でオフになります。

Add Scene Componentでの位置

Add Scene Component → Audio → SceneAudioPlayer。最大付与数は1個です。
