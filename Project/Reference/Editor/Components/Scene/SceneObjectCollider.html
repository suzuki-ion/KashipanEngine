SceneObjectCollider 最大1個

シーン内のICollider派生コンポーネント（各種Collider）を収集し、実際の当たり判定処理（Collider）へ橋渡しするシーンコンポーネントです。Scene Component Inspector上での見え方を説明します。C++側のAPIはEngine/02_Scenes.htmlを参照してください。

このコンポーネントに編集可能なInspector項目はありません
専用のShowImGui実装を持たないため、コンポーネント一覧を開いても基底クラス既定の None というテキストが表示されるだけです。各ICollider派生コンポーネントのInitialize/Finalizeからポインタ登録されるだけで、以後は毎フレームこのコンポーネント側が各Colliderの現在の状態（形状・トリガー設定・コールバック等）を読み取って内部のColliderへ反映するため、Inspector上で触る設定値自体が存在しません。

Add Scene Componentでの位置

Add Scene Component → Collision → SceneObjectCollider。新規シーン作成時に自動で追加されるコンポーネントの1つで、誤って削除するとシーン内の当たり判定が一切動作しなくなります。
