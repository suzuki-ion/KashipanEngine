SceneRenderer 最大1個

シーン内の描画用コンポーネント（MeshRenderer・SpriteRenderer・TextRenderer・SkinnedMeshRenderer・CameraRenderer・LightRenderer等）を収集し、ソート済みの描画リストを構築するシーンコンポーネントです。Scene Component Inspector上での見え方を説明します。C++側のAPIはEngine/02_Scenes.htmlを参照してください。

Inspectorに表示される項目

全て読み取り専用のテキスト表示です（ImGui::Text）。編集可能な項目はありません。

表示内容
MeshRenderers: N登録済みMeshRendererの数
SpriteRenderers: N登録済みSpriteRendererの数
TextRenderers: N登録済みTextRendererの数
SkinnedMeshRenderers: N登録済みSkinnedMeshRendererの数
CameraRenderers: N登録済みCameraRendererの数
LightRenderers: N登録済みLightRendererの数
Cached Draw Entries: N (dirty: yes/no)エディター用描画先向けにキャッシュされている描画エントリ数と、次回BuildSortedDrawList時に再構築が必要かどうか
この一覧は各描画コンポーネントのInitialize/Finalizeから自動でRegister/Unregisterされたものであり、Inspector上から手動で増減させることはできません。GPUパーティクル（gpuParticleEmitters_）やポストエフェクトコンポーネントの登録数はこの表示には含まれません。

Add Scene Componentでの位置

Add Scene Component → Render → SceneRenderer。新規シーン作成時に自動で追加されるコンポーネントの1つで、誤って削除するとシーンの描画が行われなくなります。
