SceneScriptEngine 最大1個

シーン内でAngelScriptを実行するための共有スクリプトエンジン（asIScriptEngine）を管理するシーンコンポーネントです。ScriptComponentはこのコンポーネントを介してスクリプトエンジンを取得します。Scene Component Inspector上での見え方を説明します。C++側のAPIはEngine/02_Scenes.htmlを参照してください。

Inspectorに表示される項目

全て読み取り専用のテキスト表示です（ImGui::Text）。編集可能な項目はありません。

表示内容
AngelScript Version: N使用しているAngelScriptのバージョン番号（ANGELSCRIPT_VERSION）
Engine: Initialized / Not Initialized共有asIScriptEngineが初期化済みかどうか
Modules: NEngine初期化済みの場合のみ表示。現在ロードされているスクリプトモジュール数（GetModuleCount()）
シーンに未追加の場合はScriptComponent::Initialize時に自動で追加されるため、通常は手動でAdd Scene Componentから追加する機会は多くありません。現時点ではエンジン側の機能をスクリプトへ公開するための型/関数登録は行われていません。

Add Scene Componentでの位置

Add Scene Component → Script → SceneScriptEngine。新規シーン作成時に自動で追加されるコンポーネントの1つです。
