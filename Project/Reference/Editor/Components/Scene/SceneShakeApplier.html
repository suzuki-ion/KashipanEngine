SceneShakeApplier 最大1個

Shakeコンポーネント（Process Timing=Deferred）のTransformへの適用を、全オブジェクトのUpdate・衝突解決が終わった後にまとめて行うシーンコンポーネントです。Scene Component Inspector上での見え方を説明します。C++側のAPIはEngine/02_Scenes.htmlを参照してください。

このコンポーネントに編集可能なInspector項目はありません
専用のShowImGui実装を持たないため、コンポーネント一覧を開いても基底クラス既定の None というテキストが表示されるだけです。更新優先度が非常に大きい値（2000）に設定されており、他の全てのシーンコンポーネント（SceneObjectCollider等）より後に実行されることが保証されています。これにより、同フレーム中に他のスクリプト・物理押し戻し等がTransformを書き換えても、それらは常に「揺れていない」素のTransformに対して行われ、Shakeによるオフセットは最後に一度だけ上書きされずに乗ります。

Add Scene Componentでの位置

Add Scene Component → Utility → SceneShakeApplier。Process Timingが「Deferred」のShakeコンポーネント（既定設定）を使うために必要なシーンコンポーネントです。
