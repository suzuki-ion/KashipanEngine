UIButton

画面上の矩形に対するマウスのホバー・押下・クリック判定を行うUI用コンポーネントです。見た目の描画は一切行いません。同一オブジェクトにSpriteRendererがあればそのスプライトの矩形を、無くTextRendererがあればそのテキストの外接矩形（表示中の文字列・フォントサイズに応じて動的に変わる）を、そのまま当たり判定に使う「透明な当たり判定レイヤー」です（両方無い場合は常に判定false。SpriteRendererを優先）。Scene Object Inspector上での見え方を説明します。

前提となる構成

このコンポーネントは判定のみを行うため、実際にボタンとして機能させるには同一オブジェクトへ以下のいずれかを組み合わせて付与します。

  • MeshFilter（"Rect2D"等）＋ SpriteRenderer — ボタンの見た目と、描画先ウィンドウの指定（SpriteRenderer側のTargetをそのまま利用する）
  • TextRenderer — SpriteRendererが無い場合のみ使われる。表示中のテキストの外接矩形を当たり判定に使い、描画先ウィンドウの指定もTextRenderer側のTargetをそのまま利用する
  • UIButton — 上記いずれかの矩形に対する当たり判定
マウス座標変換のパイプラインはScreenBufferViewportと共通
Windowクライアント座標 → NDC → Display Cameraの逆ビュー射影でワールド座標、という変換を行うところまでは共通。そこから先のローカルUV座標（(0,0)=左下 ～ (1,1)=右上）への変換方法は対象コンポーネントで異なり、SpriteRendererはスプライトの逆ワールド行列でローカル座標へ変換（矩形サイズはTransformのスケールに追従）、TextRendererは表示中の文字列から都度測った外接矩形（ワールド空間）を基準にする（矩形サイズは文字列・フォントサイズに追従して動的に変わる）。ローカルUVが(0,0)～(1,1)の範囲内かどうかでHoveredを判定します。詳細はScreenBufferViewportを参照してください。
描画先がScreenBufferObjectでも正しく動作する
SpriteRenderer/TextRendererの描画先がWindowではなくScreenBufferObject（オフスクリーン中間バッファ）の場合でも、そのScreenBufferを表示しているScreenBufferViewportを自動的に辿って実ウィンドウを解決する（入れ子表示にも対応、チェーンの深さには上限がある）。そのため独立したレンダーターゲットへ描画されるSpriteRenderer/TextRendererにUIButtonを付与しても、座標変換が破綻しない。

Inspectorに表示される項目

ラベルウィジェット内容
Display Cameraコンボボックス（シーン上のオブジェクトから選択）マウス座標変換の基準にするCamera2Dを持つオブジェクト

実行中は現在の判定状態（Hovered / Pressed / Clicked）が確認用にそのまま表示されます。さらに、マウス座標の変換自体に成功している間（矩形の外にあってローカルUVが範囲外の場合を含む）は、その時点のローカルUV座標も「Local UV: (x, y)」として表示されます。

スクリプトAPI

メソッド説明
void SetDisplayCameraObject(Object@)Display Cameraを設定する
bool IsHovered() constマウスカーソルがボタンの矩形内にあるかどうか
bool IsPressed() constボタン上で左クリックが押され、まだ離されていないかどうか。押下開始はボタン上である必要があるが、離すまでの間はカーソルが矩形外へ出ても保持される（一般的なUIボタンと同じ挙動。ドラッグして矩形外で離すとクリック扱いにはならない）
bool IsClicked() constこのフレームでクリックが確定した瞬間だけtrue（ボタン上で押して、ボタン上で離した時のみ）
bool TryGetLocalHoverPosition(Vector2 &out)直近のUpdate()時点での、対象矩形基準のローカルUV座標を取得する。(0,0)=矩形の左下～(1,1)=矩形の右上で、矩形の外（負値や1超過）の値もそのまま返るため、IsPressed()中にカーソルが矩形の外へ出た場合でも位置を追い続けられる（スライダー等のドラッグ操作の実装に使える）。ウィンドウ/表示カメラ/対象コンポーネントのいずれかが解決できなかった場合はfalseを返す（outは変更しない）
class StartButton : ScriptComponentBehavior {
    void Update() {
        UIButton@ button;
        GetComponent(@button);
        if (button is null) return;

        if (button.IsClicked()) {
            Log("スタートボタンが押されました");
        }
    }
}

Add Componentでの位置

Add Component›UI›UIButton から追加する。同一オブジェクトに1つのみ付与可能。
