UIButton

画面上の矩形に対するマウスのホバー・押下・クリック判定を行うUI用コンポーネントです。見た目の描画は一切行いません（同一オブジェクトのSpriteRendererが描画するスプライトの矩形を、そのまま当たり判定に使う「透明な当たり判定レイヤー」）。Scene Object Inspector上での見え方を説明します。

前提となる構成

このコンポーネントは判定のみを行うため、実際にボタンとして機能させるには同一オブジェクトへ以下を組み合わせて付与します。

  • MeshFilter（"Rect2D"等）＋ SpriteRenderer — ボタンの見た目と、描画先ウィンドウの指定（SpriteRenderer側のTargetをそのまま利用する）
  • UIButton — 上記スプライトの矩形に対する当たり判定
マウス座標変換のパイプラインはScreenBufferViewportと共通
Windowクライアント座標 → NDC → Display Cameraの逆ビュー射影でワールド座標 → SpriteRendererの逆ワールド行列でローカル座標、という変換を行い、ローカル座標が単位クアッド範囲内（(0,0)=左下 ～ (1,1)=右上）かどうかで判定します。詳細はScreenBufferViewportを参照してください。

Inspectorに表示される項目

ラベルウィジェット内容
Display Cameraコンボボックス（シーン上のオブジェクトから選択）マウス座標変換の基準にするCamera2Dを持つオブジェクト

実行中は現在の判定状態（Hovered / Pressed / Clicked）が確認用にそのまま表示されます。

スクリプトAPI

メソッド説明
void SetDisplayCameraObject(Object@)Display Cameraを設定する
bool IsHovered() constマウスカーソルがボタンの矩形内にあるかどうか
bool IsPressed() constボタン上で左クリックが押され、まだ離されていないかどうか。押下開始はボタン上である必要があるが、離すまでの間はカーソルが矩形外へ出ても保持される（一般的なUIボタンと同じ挙動。ドラッグして矩形外で離すとクリック扱いにはならない）
bool IsClicked() constこのフレームでクリックが確定した瞬間だけtrue（ボタン上で押して、ボタン上で離した時のみ）
class StartButton : ScriptComponentBehavior {
    void Update() {
        UIButton@ button;
        GetComponent(@button);
        if (button is null) return;

        if (button.IsClicked()) {
            Log("スタートボタンが押されました");
        }
    }
}

Add Componentでの位置

Add Component›UI›UIButton から追加する。同一オブジェクトに1つのみ付与可能。
