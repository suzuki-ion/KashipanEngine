3. 描画先オブジェクトを作成する

カメラ、ライト、メッシュが共有して使用する描画結果の出力先を、Screen Buffer Objectとしてシーンへ追加します。

操作の起点: Scene Object Hierarchy追加: ScreenBufferObject完成条件: Viewerを開ける

1. Screen Buffer Objectを作成する

  1. Hierarchyの空白を右クリックするScene Object Hierarchy内の空白部分を右クリックします。
  2. 描画先テンプレートを選ぶCreate Object›Render Target›Screen Buffer Object を選択します。
  3. 名前を変更する作成されたオブジェクトを選択し、Inspector上部のNameをMainScreenへ変更します。

2. ScreenBufferObjectを設定する

Screen Buffer Objectテンプレートには、TransformとScreenBufferObjectが自動で追加されます。Inspectorで次の値を設定します。

項目設定例役割
NameMainScreenBuffer描画先を識別する一意の名前。テクスチャとして参照するときにも使う
Width1920描画バッファの横幅
Height1080描画バッファの高さ
Open Viewerクリック描画結果をエディター内のViewerへ表示する
Viewerが空でも作成失敗ではありません
この時点ではカメラや描画オブジェクトのTargetが未設定のため、Viewerに何も映らない場合があります。次のページでカメラを関連付けます。

3. 後続ページで描画対象を接続する

ここでは出力先だけを先に用意します。7. コンポーネントを追加するでMesh Objectを作成した後、MeshRendererのTargetへMainScreenを指定します。HierarchyからTarget欄へのドラッグ＆ドロップでも設定できます。

描画先オブジェクトが複数の描画先コンポーネントを持つ場合は、Targetの下に表示されるチェックボックスで出力先を個別に選択できます。

Window Objectとの使い分け

テンプレート追加される描画先主な用途
Screen Buffer ObjectScreenBufferObjectオフスクリーン描画、ポストエフェクト、エディター内Viewer
Window ObjectNormalWindowObject独立した通常ウィンドウへ直接表示

通常ウィンドウが必要な場合は、Create Object›Render Target›Window Object を選び、Title、Width、Heightを設定します。

  • HierarchyにMainScreenが存在する
  • ScreenBufferObjectのNameとサイズが設定されている
  • Open ViewerでViewerウィンドウを開ける
  • MainScreenが後続ページのTarget候補として表示される

描画先の種類、画像保存、シーン間の引き継ぎはウィンドウ／オフスクリーンのリファレンスを参照してください。
