4. カメラオブジェクトを作成する

3Dシーンをどの位置から、どの画角で、どの描画先へ映すかをCamera Objectで設定します。

操作の起点: Create Object → 3D追加: Camera3D・CameraRenderer描画先: MainScreen

1. Camera Objectを作成する

  1. カメラテンプレートを選ぶHierarchyの空白を右クリックし、Create Object›3D›Camera Object を選択します。
  2. 名前を変更するInspector上部のNameをMainCameraへ変更します。
  3. 位置を決めるTransformのTranslateを、対象がカメラの前方（ローカル+Z方向）に入る位置へ調整します。例として(0, 3, -10)から始めます。

2. Camera3Dを設定する

Camera ObjectテンプレートにはTransform、Camera3D、CameraRendererが自動で追加されます。

項目設定例役割
Orthographicオフオフなら遠近感のある透視投影、オンなら平行投影
FovY1.0縦方向の視野角。値はラジアン
Near0.1これより手前を描画しない距離
Far1000これより奥を描画しない距離
Aspect1.7778横幅÷縦幅。1920×1080なら16:9
OrthoSize10Orthographicがオンのときに使う縦方向の半径

3. CameraRendererへ描画先を設定する

  1. CameraRendererを展開します。
  2. Targetから前ページで作成したMainScreenを選択します。
  3. Pipelineは、まず空欄のまま全パイプラインへ適用するか、3D描画に合わせてObject3D.Solid.BlendNormalを選択します。
  4. CameraRenderer下部にVertex:gCamera3DとPixel:gCamera3Dが表示されることを確認します。
Scene Viewでカメラを見つける
Scene View上部のCamerasを有効にすると、カメラのアイコンと視錐台を確認できます。TransformのRotateを変更し、フラスタムが対象へ向くよう調整してください。

4. この段階で確認すること

  1. MainScreenのScreenBuffer Viewerを開きます。
  2. CameraRendererのTargetがMainScreenになっていることを確認します。
  3. Scene Viewでカメラの位置、向き、視錐台を確認します。
Viewerへの映像表示は手順7で確認します
この段階では描画対象のMesh Objectをまだ作っていないため、Viewerが空でも問題ありません。7. コンポーネントを追加するで描画対象をMainScreenへ接続すると、カメラ映像を確認できます。
  • MainCameraにCamera3DとCameraRendererがある
  • CameraRendererのTargetがMainScreenになっている
  • Scene Viewでカメラの位置と向きを確認できる
  • ScreenBuffer Viewerを開ける

2Dカメラ、追従カメラ、各APIの詳細は描画コンポーネントのリファレンスを参照してください。
