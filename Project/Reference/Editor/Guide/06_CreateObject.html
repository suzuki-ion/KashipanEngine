6. オブジェクトを作成する

Scene Object Hierarchyから空のオブジェクトを作り、Playerという名前を付けます。

操作: Scene Object Hierarchy作成名: Player目安: 2分

Playerを作る

  1. Hierarchyの空白を右クリックするScene Object Hierarchy内で、既存オブジェクトに重ならない空白部分を右クリックします。
  2. Empty Objectを選ぶCreate Object›Empty Object を選択します。
  3. 作成したオブジェクトを選択するHierarchyに追加された項目をクリックします。選択するとScene Object Inspectorにプロパティが表示されます。
  4. 名前をPlayerへ変更するInspector上部のNameへPlayerと入力し、Enterで確定します。

選択と階層操作

操作結果
クリック1つのオブジェクトを選択する
Ctrl + クリック複数選択へ追加／選択解除する
Shift + クリック範囲選択する
ドラッグ&ドロップ並び替え、または親子関係を変更する
Ctrl + D選択したオブジェクトを複製する
まだScene Viewには何も表示されません
Empty Objectはコンポーネントを持たない入れ物です。HierarchyへPlayerが表示されていれば、この手順は成功です。次のページで位置と見た目を追加します。

保存結果

Ctrl+Sで保存すると、TutorialScene.scene/Objects/<UUID>/object.jsonが作成されます。UUIDは自動採番されるため手入力しません。

{
  "object": {
    "components": [],
    "editorOnly": false,
    "isActive": true,
    "name": "Player",
    "objectID": "<自動生成されたUUID>",
    "tag": ""
  },
  "siblingIndex": 0
}

作成、複製、親子関係の詳細はゲームオブジェクトのリファレンスを参照してください。
