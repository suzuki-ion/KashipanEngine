Scene Editor ウィンドウ

Scene Editor という名前のウィンドウには、シーン名の編集欄と再生コントロールがまとまっています。

シーン名

先頭のScene Name入力欄にシーン名を入力してEnterを押すと、現在のシーンの名前（SceneContext::SetName）が変わります。

再生コントロール（Unity風のPlay/Pause/Stop）

ボタン表示条件動作
Play停止中再生前のシーン状態をバックアップ（PlayStart_プレフィックス）した上で PlayStart() を呼ぶ。選択オブジェクトは再生後も維持される
Stop再生中PlayStop() を呼び、再生開始前のシーン状態へ復元する。再生中に積まれたUndo履歴も破棄される
Pause再生中・非一時停止PlayPause() を呼ぶ
Resume再生中・一時停止PlayResume() を呼ぶ
Step Frame一時停止中のみ有効RequestStepFrame() を呼び、1フレームだけ進める
Playを押す前に保存する
Stopで再生開始前の状態へ戻るのは意図した挙動です。Play中に加えた変更（Inspectorでの値変更など）はStopで消えます。恒久的な変更はPlay前、またはStop後に行い、Ctrl+Sで保存してください。

新規シーンの作成（New Scene...）

  1. File > New Scene... を選ぶ現在のシーン（未保存の変更を含む）が破棄される旨の警告とともにモーダルが開きます。
  2. シーン名を入力する空欄の場合は既定で New Scene になります。
  3. Register to Scene Listのチェックを決めるオンにすると Assets/Scenes/<name>.scene へ保存し、Scene Listにも登録します（後からScene Listで切り替え可能）。オフの場合は保存・登録されないメモリ上だけのシーンになります。
  4. Createを押すシーン上の全オブジェクト・シーンコンポーネントがクリアされ、描画に最低限必要な SceneRenderer だけが再追加された空のシーンになります。

操作履歴（History ウィンドウ）

Window > History で表示できます。Undo/Redoスタックに積まれている操作の一覧を確認できます。オブジェクトの作成・削除・パラメータ変更・コンポーネントの追加/削除など、エディタ上のほぼ全ての編集操作はコマンドとして記録され、Ctrl+Z/Ctrl+Yで戻す・やり直すことができます。

再生中の変更は別履歴
Play中に行った変更は編集時のUndo履歴とは別の一時履歴に積まれ、Stop時にシーン状態の復元と一緒に破棄されます。Play中にCtrl+Zを押しても、Play開始前の編集履歴に影響しません。

自動バックアップ（Auto Save Settings）

File > Auto Save Settings... から設定します。設定は次回起動時も保持されます。

項目既定値内容
Interval (minutes)1.0分自動バックアップの間隔（最小0.1分）
Name Format${SceneName}ファイル名テンプレート。${SceneName} ${Year} ${Month} ${Day} ${Hour} ${Minute} ${Second} のプレースホルダーが使えます

保存先は常に SceneBackups/ ディレクトリで、ファイル名の先頭には状況に応じて自動的にプレフィックスが付きます（Stopped_ = 停止中の自動保存、Playing_ = 再生中の自動保存、PlayStart_ = Playボタンを押した瞬間のバックアップ）。File > Save Scene...で明示的に保存したファイルとは別に、常にバックグラウンドで保存され続けます。
