Scene Object Hierarchy

シーン上の全オブジェクトを親子関係を含むツリーとして表示するウィンドウです。オブジェクトの作成・選択・並び替え・複製・削除など、シーン編集の起点になります。Window›Object Hierarchy で表示/非表示を切り替えられます。

ツリー表示

各行は1つのオブジェクトです。Objectsヘッダーの開閉・各オブジェクトの開閉状態はエディター設定として保存され、次回起動時も復元されます。

表示色意味
通常（既定の文字色）アクティブな通常オブジェクト
グレー非アクティブなオブジェクト（Activeチェックが外れている）
水色Editor Onlyオブジェクト（自身または祖先がEditor Only）
青Prefabインスタンスに属するオブジェクト
オレンジ + 名前の末尾に *Prefabインスタンスのうち、元のPrefabから変更（オーバーライド）が入っているオブジェクト

Commentコンポーネントが付いたオブジェクトへマウスカーソルを重ねると、コメント内容がツールチップとして表示されます。

選択操作

操作結果
クリック単一選択に置き換える
Ctrl + クリックそのオブジェクトの選択を個別にトグル（追加/解除）する
Shift + クリック直前の操作位置（アンカー）から現在の表示順での範囲選択を行う
ドラッグ&ドロップ並び替え、または別オブジェクトへドロップして親子関係を変更する
選択の確定タイミング
クリックした瞬間ではなく、マウスを離した時点で選択が確定します（実際にドラッグへ発展した場合は選択より並び替え/D&Dが優先されます）。これはヒエラルキーの項目をInspectorの欄までドラッグして値を割り当てる操作（後述）と両立させるための仕様です。

ドラッグ&ドロップ

  • ヒエラルキー内でのD&D — 別のオブジェクトへドロップすると、そのオブジェクトの子として並び替えられます。
  • Assets Windowからのプレハブドロップ — Assets Windowの.prefabファイルをヒエラルキー上へドラッグ&ドロップすると、その位置（またはウィンドウの空きスペースへのドロップならルート直下）へPrefabがインスタンス化されます。
  • オブジェクトからフィールドへのD&D — ヒエラルキーの項目をObject Inspectorのオブジェクト参照欄（例: CameraControllerのフォロー対象）へドラッグすると、そのオブジェクトを値として設定できます。
複数選択したオブジェクトの一括移動
ドラッグしたオブジェクトが現在の複数選択に含まれている場合、選択中の全オブジェクト（他の選択オブジェクトの子孫を除いたルートのみ）がまとめて移動します。移動前の相対的な並び順を保ったまま、ドロップ先の前後/内側へ連続して挿入されます。Undo/Redoも1操作にまとまります。

右クリックメニュー（オブジェクト上）

項目ショートカット動作
Create Object-右クリックしたオブジェクトと同じ階層・次の位置に新規オブジェクトを作成する（サブメニューは下記「Create Objectメニュー」参照）
Create Child Object-右クリックしたオブジェクトの子として最後尾に新規オブジェクトを作成する
Copy Object(s)Ctrl+C選択中オブジェクト（複数選択時はまとめて）をクリップボードへコピーする
Paste ObjectCtrl+V右クリックしたオブジェクトと同じ階層・次の位置へ貼り付ける
Paste to Child ObjectCtrl+Shift+V右クリックしたオブジェクトの子として貼り付ける
Clone Object(s)Ctrl+D選択中オブジェクトを複製する
Delete Object(s)Delete選択中オブジェクトを削除する
Delete Object (Keep Children)-右クリックしたオブジェクト単体のみを削除し、その直接の子は削除せず、削除対象がいた親（祖父母）へ1階層繰り上げて付け替える。子が無い場合はグレーアウトされる（複数選択時は右クリックした1オブジェクトのみが対象）
Unparent All Children-右クリックしたオブジェクトを親としている全ての子オブジェクトの親子関係を一括で解除する（ルート直下へ移動）。子が無い場合はグレーアウトされる（複数選択時は右クリックした1オブジェクトのみが対象）
Apply All-（Prefabインスタンスのルートのみ）このインスタンスへの変更を元のPrefabアセットへ反映する。反映後は開いている他の全インスタンス・Scene Listに登録されている他の全シーンファイル（未オープンのものも含む）へ自動的に同期される
Revert All-（Prefabインスタンスのルートのみ）ローカルの変更を破棄し、元のPrefabの内容に戻す（確認ダイアログあり、1操作でのUndoはできない）

ウィンドウの何もない領域を右クリックすると、Create Object と Paste Object（ルート直下が対象）だけを含む簡略版メニューが表示されます。

Delete Object (Keep Children) / Unparent All Childrenは常に1オブジェクトが対象
Copy/Clone/Delete Object(s)と異なり、この2つの操作は複数選択の一括処理には対応していません（右クリックしたオブジェクト自身の直接の子のみを対象にした、単一オブジェクト向けの操作です）。どちらもUndo/Redoは1操作にまとまります。
Apply Allは他のシーンファイルも書き換えます
同じPrefabを使っている他のシーンが現在開いていなくても、ディスク上のシーンファイルが直接読み込み・同期・保存されます（ローカルなOverrideは維持されたままマージされます）。共同作業でシーンファイルをGit管理している場合は、他の人の未コミットの変更と衝突し得る操作であることに注意してください。

キーボードショートカット

ヒエラルキーウィンドウにフォーカスがある時のみ有効です（テキスト入力中は無効）。

キー動作
Delete選択中オブジェクトを削除する
Ctrl+C選択中オブジェクトをコピーする
Ctrl+V選択中オブジェクトの次の位置へ貼り付ける（未選択時はルート直下）
Ctrl+Shift+V選択中オブジェクトの子として貼り付ける
Ctrl+D選択中オブジェクトを複製する
複数選択時のCopy/Clone/Delete
複数オブジェクトを選択した状態でCopy/Clone/Deleteを行うと、選択された全オブジェクトのうち「他の選択オブジェクトの子孫でないもの（選択のルート）」だけが対象になります。子も選択されている場合、親を複製すれば子も一緒に複製されるため、二重に処理されることはありません。
