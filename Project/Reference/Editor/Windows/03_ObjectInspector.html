Scene Object Inspector

Scene Object Hierarchyで選択したオブジェクトの名前・タグ・コンポーネントを編集するウィンドウです。コンポーネントごとの具体的な入力欄は「コンポーネント」カテゴリの各ページを参照してください。

共通プロパティ

項目内容
Nameオブジェクト名。編集を終える（フォーカスを外す）とUndo履歴へ積まれる
Activeオブジェクトの有効/無効。チェックを外すとコンポーネントのUpdateが呼ばれなくなる（ヒエラルキー上ではグレー表示になる）
Editor Onlyエディター上でのみ存在するオブジェクトにする。PlayStart()時や非エディタービルドでのシーン読み込み時に子孫ごと削除される
Tag分類・判別用の任意文字列

Prefabセクション

選択したオブジェクトがPrefabインスタンスの場合のみ表示されます。

項目内容
Prefabパス（テキスト表示）元になっている.prefabファイルのパス
Apply Allこのインスタンスへのローカルな変更を、元のPrefabアセットへ反映する（現在開いているシーン内の他の全インスタンスだけでなく、Scene Listに登録されている他の全シーンファイルにも、開いていないものを含めて自動的に伝播する）
Revert Allローカルな変更（追加した子オブジェクトを含む）を破棄し、元のPrefabの内容に戻す。確認ダイアログが出る、1操作でのUndoはできない操作
Overrides 一覧元のPrefabから変更されているコンポーネントの一覧。各項目に Apply（そのコンポーネントだけ反映。Apply Allと同様に他インスタンス・他シーンへも伝播する）・Revert（そのコンポーネントだけ戻す）ボタンがある
Apply Allは他のシーンファイルも書き換えます
同じPrefabの他インスタンスを含むシーンが開いていなくても、ディスク上のファイルが直接読み書きされます。Gitでシーンファイルを共有している場合、他の人の未コミットの変更と衝突し得ることに注意してください。

コンポーネント一覧

付与されているコンポーネントが、処理優先順位（更新優先度）の順に上から並びます。各コンポーネントの見出しは開閉式（クリックで開閉、状態は種類ごとに保存される）です。

要素内容
左のチェックボックスそのコンポーネント単体の有効/無効を切り替える
見出し（コンポーネント型名）クリックで開閉。ドラッグ&ドロップで並び替えると処理優先順位が変わる
右クリック > Remove Componentそのコンポーネントを削除する
Tag欄コンポーネント単位のタグ（オブジェクトのタグとは別）
開いた中身コンポーネント固有の編集項目。詳細は「コンポーネント」カテゴリの各ページを参照
変更は自動的にUndo履歴へ積まれる
コンポーネントを開いている間、表示前後のJSON状態を比較しており、値が変わった場合だけ自動的にUndo/Redo可能な操作として記録されます。

コンポーネントの追加

一覧の下にあるAdd Componentボタンを押すと、コンポーネント種別をカテゴリのツリーメニューから選ぶポップアップが開きます。カテゴリは各コンポーネントがCOMPONENT_CATEGORY(...)で宣言している階層に対応します（例: Collision > Collider）。

複数選択時（Object Inspector (N objects)）

2つ以上のオブジェクトを選択している間は、最後に操作したオブジェクト（プライマリ）を基準にした一括編集モードになります。

  • 共通プロパティ（Active/Editor Only/Tag）はプライマリの値を表示し、変更すると選択中の全オブジェクトへ同じ値が適用されます。
  • 共通コンポーネント（全選択オブジェクトが同じ型を同じ順番目に持っている場合のみ）が一覧に表示されます。1つでも持っていないオブジェクトがあれば、そのコンポーネントは一覧から除外されます。
  • 共通コンポーネントの値を編集すると、プライマリで実際に変更された値の差分だけが他の選択オブジェクトの対応コンポーネントへ適用されます（値が同一のフィールドは上書きされません）。
  • Remove Component / Add Component も選択中の全オブジェクトへまとめて適用されます。
