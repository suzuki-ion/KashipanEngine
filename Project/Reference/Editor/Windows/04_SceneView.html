Scene View

編集中のシーンをデバッグカメラから見て、選択したオブジェクトをギズモで直接操作できるウィンドウです。専用のオフスクリーンバッファへ描画した結果を画像として表示しています。

デバッグカメラの操作

操作結果
マウスホイールズームイン/アウト（注視点までの距離を変更）
右ドラッグ注視点を中心にオービット回転
中ドラッグ視点の平行移動（パン）

ゲーム内のカメラ（Camera3D/Camera2D）とは独立した、エディター専用のカメラです。

オブジェクトの選択（ピッキング）

画像上で何も操作していない状態（ギズモをドラッグ中でない）で左クリックを離すと、クリック位置からのレイと各オブジェクトのメッシュ三角形との交差判定でオブジェクトを選択します。Ctrlを押しながらのクリックで複数選択へ追加できます。選択結果はScene Object Hierarchy・Scene Object Inspectorと共有されます。

LightRenderer/CameraRendererが付いたオブジェクトのようにMeshFilterのメッシュを持たないオブジェクトは、下記「Lights」「Cameras」チェックボックスで表示されるアイコン（マーカー）をクリックすることで選択できます。アイコンは深度テストせずメッシュより手前に表示されるため、クリック判定もメッシュの三角形判定より優先されます。マーカー表示を無効にしている種別はアイコンごとクリック判定からも除外されます。

選択オブジェクトのアウトライン表示

選択中のオブジェクト自身、またはその子孫がMeshRenderer/SkinnedMeshRendererを持つ場合、そのメッシュへ固定色の押し出しアウトラインが自動的に表示されます。複数選択時は選択している全オブジェクトにそれぞれ表示されます。オン/オフを切り替えるチェックボックスはなく、常時有効です。

このシーンビューだけの表示です
アウトラインはこのシーンビュー用の描画先にのみ適用され、ゲーム画面やScreenBufferObject/Window Objectなど他の描画先には一切影響しません。オブジェクト自身のマテリアルが持つアウトライン設定（lilToon風シェーダーのOutlineWidth等）とも独立しており、マテリアル側でアウトラインを無効にしていても選択中はこの表示が出ます。

ギズモ

選択中のオブジェクトには ImGuizmo による操作ハンドルが表示されます。ツールバーの上部で操作の種類と基準座標系を切り替えます。

ボタン内容
Translate移動モード
Rotate回転モード
Scale拡大縮小モード
Localオブジェクトのローカル軸基準で操作する
Worldワールド軸基準で操作する

単一オブジェクト選択時はLocal/World切替が有効ですが、複数オブジェクトを選択している場合は選択群の平均位置を中心としたWorld基準のグループ操作になります。

表示切替チェックボックス

項目内容
Grid基準グリッドの表示/非表示
LightsLightコンポーネントを持つオブジェクトのアイコン表示
CamerasCamera3D/Camera2Dコンポーネントを持つオブジェクトのアイコン表示
Colliders各種コライダーコンポーネントのワイヤーフレーム表示
BonesSkinnedMeshRendererのボーン構造の表示

これらの表示設定は次回起動時にも保持されます。
