Scene View

編集中のシーンをデバッグカメラから見て、選択したオブジェクトをギズモで直接操作できるウィンドウです。専用のオフスクリーンバッファへ描画した結果を画像として表示しています。

デバッグカメラの操作

ゲーム内のカメラ（Camera3D/Camera2D）とは独立した、エディター専用のカメラです。実体はシーンへ自動生成されるeditorOnlyな「Scene View」オブジェクト（Transform + Camera3D + ScreenBufferObject）で、Scene Object Hierarchy/Object Inspectorから通常のオブジェクトと同様に編集・コンポーネント追加ができ、シーンJSONへシーンごとに永続化されます。

InspectorでのTransform編集がそのまま反映される
Object Inspectorで「Scene View」オブジェクトのTransformを直接編集（またはUndo/Redo）すると、次のフレームでその値からオービット/フライの内部状態が自動的に再同期されます。

ツールバー上部のOrbit / Flyラジオボタンで、2つの操作モードを切り替えられます（次回起動時も設定が保持されます）。

モード操作結果
Orbit（既定）マウスホイールズームイン/アウト（注視点までの距離を変更）
右ドラッグ注視点を中心にオービット回転（カメラ側が動く）
中ドラッグ視点の平行移動（パン）
Fly右ドラッグその場で見回す（カメラ位置は変えず向きだけ変える）
右ボタンを押しながらWASD（+QEで上下、Shiftで加速）見ている方向基準にカメラ自身が移動する
マウスホイール移動速度の調整
回転すると注視点が向きに追従する（Flyモード）
Orbitモードは注視点が固定でカメラ側が軌道を描くのに対し、Flyモードはカメラ位置が固定で回転すると注視点がその向きの先へ再計算されます。カメラ位置・注視点の両方を常に維持しているため、モードを切り替えた瞬間から自然に続きの操作ができます（Orbitで作った向き・距離のままFlyへ切り替えられ、Flyで動き回った後Orbitへ戻せば今向いている方向の先に注視点が来ます）。
ロール（Z軸回転）は表現できない
このオービットカメラのモデルはyaw/pitchのみで構成されているため、Inspectorで明示的にロールを付けた回転を設定しても、次にカメラを操作した瞬間にロール成分は失われます。

オブジェクトの選択（ピッキング）

画像上で何も操作していない状態（ギズモをドラッグ中でない）で左クリックを離すと、クリック位置からのレイと各オブジェクトのメッシュ三角形との交差判定でオブジェクトを選択します。Ctrlを押しながらのクリックで複数選択へ追加できます。選択結果はScene Object Hierarchy・Scene Object Inspectorと共有されます。

LightRenderer/CameraRendererが付いたオブジェクトのようにMeshFilterのメッシュを持たないオブジェクトは、下記「Lights」「Cameras」チェックボックスで表示されるアイコン（マーカー）をクリックすることで選択できます。アイコンは深度テストせずメッシュより手前に表示されるため、クリック判定もメッシュの三角形判定より優先されます。マーカー表示を無効にしている種別はアイコンごとクリック判定からも除外されます。

選択オブジェクトのアウトライン表示

選択中のオブジェクト自身、またはその子孫がMeshRenderer/SkinnedMeshRendererを持つ場合、そのメッシュへ固定色の押し出しアウトラインが自動的に表示されます。複数選択時は選択している全オブジェクトにそれぞれ表示されます。オン/オフを切り替えるチェックボックスはなく、常時有効です。

このシーンビューだけの表示です
アウトラインはこのシーンビュー用の描画先にのみ適用され、ゲーム画面やScreenBufferObject/Window Objectなど他の描画先には一切影響しません。オブジェクト自身のマテリアルが持つアウトライン設定（lilToon風シェーダーのOutlineWidth等）とも独立しており、マテリアル側でアウトラインを無効にしていても選択中はこの表示が出ます。

ギズモ

選択中のオブジェクトには ImGuizmo による操作ハンドルが表示されます。ツールバーの上部で操作の種類と基準座標系を切り替えます。

ボタン内容
Translate移動モード
Rotate回転モード
Scale拡大縮小モード
Localオブジェクトのローカル軸基準で操作する
Worldワールド軸基準で操作する

単一オブジェクト選択時はLocal/World切替が有効ですが、複数オブジェクトを選択している場合は選択群の平均位置を中心としたWorld基準のグループ操作になります。

親子ともに選択している場合は親側だけが直接操作される
選択群の中に、他の選択オブジェクトの子孫であるものが含まれる場合、その子孫は直接のギズモ操作対象から除外されます（親が動けば階層継承で自動的に追従するため）。
