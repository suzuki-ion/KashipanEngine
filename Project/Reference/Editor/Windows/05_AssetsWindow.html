Assets Window

UnityのAssetsウィンドウ相当の、Assets/フォルダ以下を閲覧・操作するファイルブラウザです。左側にフォルダツリー、右側に選択中フォルダの内容がサムネイル付きグリッドで表示されます。

フォルダ移動

操作内容
フォルダのサムネイルをクリックそのフォルダへ移動する
Up One Level ボタン1階層上のフォルダへ戻る
Refresh ボタンファイルシステムを再スキャンして表示を更新する

ファイル一覧

各ファイルは拡張子ごとのサムネイル/アイコン付きグリッド表示です。ファイルにマウスを重ねると、フルパスがツールチップで表示されます。

右クリックメニュー（ファイル上）

項目内容
Open対応する拡張子であれば、専用の編集/プレビューウィンドウを開く（JSON編集、マテリアル編集、画像プレビュー、オーディオプレビュー等）
Renameファイル名を変更するモーダルを開く
Delete確認モーダルの上でファイルを削除する

右クリックメニュー（空きスペース）

項目内容

Create Material File新しいマテリアルファイルを作成する

ドラッグ&ドロップでのアサット割り当て

  • Object Inspectorへ — テクスチャ・マテリアル（.mat）・スクリプト（.as）・プレハブ（.prefab）のファイルをScene Object Inspector内の対応するアサット参照欄（MeshRendererのマテリアル、ScriptComponentのScript Pathなど）へドラッグ&ドロップすると、その場で割り当てられます。
  • ヒエラルキーへプレハブを配置 — .prefabファイルをScene Object Hierarchyへドラッグ&ドロップすると、その位置にPrefabがインスタンス化されます。
  • ヒエラルキーからプレハブを書き出す — 逆に、ヒエラルキー上のオブジェクトをAssets Windowへドラッグ&ドロップすると、その場で.prefabファイルとして書き出せます。
モデル・音声はドラッグ&ドロップで割り当てられません
MeshFilterのメッシュや音声再生系コンポーネントのクリップは、Assets Windowからのドラッグ&ドロップ対象になっていません。読み込み済みモデル/サウンドの一覧から選ぶドロップダウン欄で割り当てます（下記「OSからのファイル取り込み」で読み込んだ直後から一覧に表示されます）。

OSからのファイル取り込み（インポート）

OSのエクスプローラーなどから、テクスチャ・モデル・音声のファイルをAssets Windowへ直接ドラッグ&ドロップすると、現在開いているフォルダーへコピーされたうえで、拡張子に応じたアセットマネージャー（TextureManager/ModelManager/AudioManager）へ動的に読み込まれます。エンジン起動時にAssets/を走査して読み込む処理と同じ経路のため、取り込んだ直後から通常のアセットと同様に参照できます。

  • コピー先で同名ファイルが既に存在する場合は、末尾に連番を付けた名前になります（上書きはされません）。
  • フォルダごとのドロップには対応していません（フォルダは無視されます）。
  • 取り込んだファイルは自動的にAssets Windowの表示が更新されます。
