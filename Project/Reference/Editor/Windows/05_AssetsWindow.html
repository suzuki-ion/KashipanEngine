Assets Window

UnityのAssetsウィンドウ相当の、Assets/フォルダ以下を閲覧・操作するファイルブラウザです。左側にフォルダツリー、右側に選択中フォルダの内容がサムネイル付きグリッドで表示されます。

フォルダ移動

操作内容
フォルダのサムネイルをクリックそのフォルダへ移動する
Up One Level ボタン1階層上のフォルダへ戻る
Refresh ボタンファイルシステムを再スキャンして表示を更新する

ファイル一覧

各ファイルは拡張子ごとのサムネイル/アイコン付きグリッド表示です。ファイルにマウスを重ねると、フルパスがツールチップで表示されます。

右クリックメニュー（ファイル上）

項目内容
Open対応する拡張子であれば、専用の編集/プレビューウィンドウを開く（JSON編集、マテリアル編集、画像プレビュー、オーディオプレビュー等）
Renameファイル名を変更するモーダルを開く
Delete確認モーダルの上でファイルを削除する

右クリックメニュー（空きスペース）

項目内容
Create Folder現在のフォルダ内に新しいフォルダを作成する
Create JSON File空のJSONファイルを作成する
Create Material File新しいマテリアルファイルを作成する

ドラッグ&ドロップでのアサット割り当て

  • Object Inspectorへ — モデル・テクスチャ・音声・スクリプトなどのファイルをScene Object Inspector内の対応するアサット参照欄（MeshFilterのメッシュ、ScriptComponentのScript Pathなど）へドラッグ&ドロップすると、その場で割り当てられます。
  • ヒエラルキーへプレハブを配置 — .prefabファイルをScene Object Hierarchyへドラッグ&ドロップすると、その位置にPrefabがインスタンス化されます。
  • ヒエラルキーからプレハブを書き出す — 逆に、ヒエラルキー上のオブジェクトをAssets Windowへドラッグ&ドロップすると、その場で.prefabファイルとして書き出せます。
