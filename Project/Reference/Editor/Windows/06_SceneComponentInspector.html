Scene Component Inspector

個々のオブジェクトではなくシーン自身に付けるコンポーネント（SceneRendererなど、ISceneComponent派生）の一覧・追加・編集を行うウィンドウです。Scene Object Inspectorとほぼ同じ構造ですが、対象がオブジェクトではなくシーン全体である点が異なります。

コンポーネント一覧

シーンに付与されているシーンコンポーネントが一覧表示されます。各項目の構造はScene Object Inspectorのコンポーネント一覧と同様です。

要素内容
左のチェックボックスそのシーンコンポーネント単体の有効/無効を切り替える
見出し（コンポーネント型名）クリックで開閉。開閉状態は種類ごとに保存される
右クリック > Remove Componentそのシーンコンポーネントを削除する
Tag欄分類・判別用の任意文字列
開いた中身コンポーネント固有の編集項目。詳細は「コンポーネント: Scene」カテゴリの各ページを参照

コンポーネントの追加

一覧の下のAdd Scene Componentボタンから、カテゴリのツリーメニューで追加する型を選びます。仕組みはScene Object InspectorのAdd Componentと同じです。

通常は編集不要
SceneRenderer・SceneObjectCollider・SceneScriptEngineなど、シーンの基本動作に必須のシーンコンポーネントは新規シーン作成時に自動で追加されます。誤って削除すると描画や当たり判定が動作しなくなるため、通常の制作でこのウィンドウを触る機会は多くありません。
