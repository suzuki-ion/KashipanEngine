Scene Variables

現在のシーンが持つ「シーン変数」（キーと値のペア）を追加・編集・削除するウィンドウです。SceneVariableApplierコンポーネントと組み合わせることで、C++コードを書かずにシーン変数の値をコンポーネントのパラメータへ反映できます。

変数の追加

  1. 変数名を入力する先頭のテキスト欄に新しい変数名を入力します。
  2. 型を選ぶドロップダウンから型を選びます。選べる型は Bool / Int / Float / Double / String / Vector2 / Vector3 / Vector4 / Quaternion / Matrix4x4 です。
  3. Addを押す同名の変数が既に存在する場合、または変数名が空の場合は追加されません。

変数の一覧・編集・削除

追加済みの変数は、それぞれの型に応じたウィジェット（チェックボックス・ドラッグ入力欄など）で一覧表示され、その場で値を編集できます。各行の右にあるRemoveボタンでその変数を削除します。
