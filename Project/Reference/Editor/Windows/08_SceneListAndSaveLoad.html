Scene List / Save & Load

登録済みシーンの一覧管理を行う Scene List ウィンドウと、File›Save Scene... / File›Load Scene... の保存・読込モーダルについて説明します。

Scene List ウィンドウ

Window›Scene List から表示できます。SceneManagerに登録されているシーンの一覧を編集する画面です。

Startup Scene

先頭のドロップダウンで、アプリケーション起動時に自動的に読み込まれるシーンを選びます。(None)を選ぶと起動シーンの指定を解除します。変更は即座にシーンリスト定義ファイルへ保存されます。

登録シーン一覧テーブル

列内容
Nameシーン名。編集してEnterを押すと登録名が変わる（RenameRegisteredScene）
File Path読み込み元のJSON/フォルダパス。空の場合は切り替え時に空のシーンが作られる
Switch現在のシーンを破棄してこのシーンへ切り替える（次フレームで反映）。再生中は無効化される
Convert to Folder Format旧来の単一.json形式を、1オブジェクト1フォルダの.sceneフォルダ形式へ変換する。既にフォルダ形式、またはパス未設定の場合は無効化される
Deleteシーンリストから登録を削除する（シーンJSONファイル自体は削除されない）

Register New Scene

テーブル下部のName/File Path欄に入力しRegisterを押すと、新しいシーンとして登録されます（名前が空の場合はボタンが無効化されます）。

フォルダ形式への変換について
Convert to Folder Formatは、複数人で同じシーンを編集する際に別々のオブジェクトを触っていればGitのコンフリクトが起きないようにするための機能です。詳しいシーンJSONの保存形式はEngine/02_Scenes.htmlを参照してください。

Save Scene... モーダル

File›Save Scene...（またはCtrl+S）で開きます。Path欄に保存先パスを入力しSaveを押すと、現在のシーンをそのパスへ保存します。Cancelで閉じます。

Load Scene... モーダル

File›Load Scene...で開きます。既存の.sceneファイル一覧から選んで読み込むと、現在のシーン（未保存の変更を含む）が破棄され、選択と操作履歴（Undo/Redo）もクリアされます。
