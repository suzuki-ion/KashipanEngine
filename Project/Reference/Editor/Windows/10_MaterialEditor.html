Material Editor

MaterialManagerが管理するマテリアル（.mat）の色・テクスチャ・UV変換・シェーダー固有パラメータを編集する機能です。専用ウィンドウは無く、下記2つの入口のどちらから開いても同じ編集フィールド（MaterialManager::ShowMaterialEditorFields）が表示されます。

開き方

入口対象備考
Assets Windowで.matファイルをOpen（ダブルクリックまたは右クリック→Open）そのファイル1つだけ「Material: ファイル名」という浮動ウィンドウが開く。対応するマテリアルが読み込み済みで無い場合は赤字で「Material is not loaded: (パス)」とだけ表示される
メインメニュー Debug Windows›Materials読み込み済み全マテリアル「MaterialManager - Materials」ウィンドウ。一覧・新規作成・削除・全保存も行える（下記参照）。表示状態は次回起動時も復元される

Materialsウィンドウ（一覧・作成・削除）

Debug Windows›Materialsからのみ表示される機能です。

ラベルウィジェット内容
Materials: N読み取り専用テキスト読み込み済みマテリアルの総数
（名前入力欄）＋ Add Materialテキスト入力＋ボタン入力した名前で空のマテリアルを新規作成し、Assets/Materials/<名前>.matとして即座に保存する。名前が空、または既存の名前と重複する場合は何も起きない
Save Allボタン読み込み済み全マテリアルをそれぞれの元のファイルパスへ上書き保存する
一覧テーブル（Name / File / 操作列）選択可能な行＋Removeボタン行をクリックするとそのマテリアルが下の編集フィールドの対象になる。File列はAssets/からの相対パス。Removeボタンで即座に削除される（確認ダイアログ無し）
Nameテキスト入力（Enterで確定）選択中マテリアルの名前を変更する。空、または既存の名前と重複する場合は変更されない
Saveボタン選択中マテリアルを元のファイルパスへ上書き保存する
一覧が空のとき
マテリアルが1つも選択されていない状態では「No material selected.」とだけ表示され、下記の編集フィールドは表示されない。

マテリアル編集フィールド（共通）

Assets Windowからの単体編集・Materialsウィンドウからの一覧編集のどちらでも共通の内容です。上から順に、実装（ShowMaterialEditorFields）に現れる順で説明します。

ラベルウィジェット内容
ColorColorEdit4（RGBA）マテリアルの基本色。既定値は白(1,1,1,1)
Textureコンボ（読み込み済みテクスチャのアセットパス一覧）＋アセットのドラッグ&ドロップ受付使用するテクスチャ。未解決（読み込み時に見つからなかった）場合は保留中のファイル名がそのまま表示される
Samplerコンボ（Default (LinearWrap) / Point Clamp / Point Wrap / Linear Clamp / Linear Wrap / Anisotropic Clamp / Anisotropic Wrap）テクスチャサンプリング方式。選べるのはこの既定6種＋Defaultのみ（GPU側がバインドレス配列の固定長6要素で確保しているため）。Defaultを選ぶと明示的なハンドルを持たず、描画側でLinearWrapへフォールバックする
Shininessドラッグ入力欄（ステップ0.1、範囲0〜1024）鏡面反射の鋭さ。既定値32
Specular ColorColorEdit4（RGBA）鏡面反射色。既定値は白(1,1,1,1)
Rim ColorColorEdit4（RGBA）リムライト色（ライト方向を考慮した逆光縁取り）。既定値は白(1,1,1,1)
Rim Powerドラッグ入力欄（ステップ0.05、範囲0.1〜16）リムの鋭さ。大きいほど縁が細くなる。既定値2
Rim Intensityドラッグ入力欄（ステップ0.01、範囲0〜10）リムライトの強さ。既定値0（無効）。既存マテリアルの見た目を変えないよう、既定では無効のまま
Enable Lightingチェックボックスライティング計算を行うか。既定true
Enable ShadowMap Projectionチェックボックスシャドウマップへ投影されるか。既定true

UV Transform

ラベルウィジェット内容
UV TranslateXYのドラッグ入力欄（ステップ0.001）UV座標のオフセット。既定値(0, 0)
UV Rotation (deg)ドラッグ入力欄（ステップ0.1、範囲-180〜180）UV座標の回転（度指定、内部はラジアンで保持）。既定値0
UV ScaleXYのドラッグ入力欄（ステップ0.001）UV座標のスケール。既定値(1, 1)
UV Rotation PivotXYのドラッグ入力欄（ステップ0.001）UV回転の中心座標（UV基準）。拡縮は常にUV原点(0, 0)基準のまま、回転のみこの点を中心に行われる。既定値(0.5, 0.5)＝中心
UV Translate / Scale / Rotation Pivot (px)XYのドラッグ入力欄（ステップ0.5）上記3項目を、設定中のテクスチャのピクセル単位で編集できる別表示。内部値（0〜1のUV基準）と相互に連動する。テクスチャが未設定の場合は無効化（グレーアウト）される
UV変換はSpriteRenderer/MeshRenderer/SkinnedMeshRendererのInstance UVと合成される
ここで設定するUV変換はマテリアル（共有アセット）側の基準値。各レンダラーが持つオブジェクト単位のInstance UVと、レンダラー側のUV Combine Modeで指定した方法で合成される。詳細はComponents/Render/SpriteRenderer.html等の「Instance UV」節を参照。TextRendererはUV変換を使わず文字ごとのUV矩形を直接参照するため、このUV Transformの対象外。

Custom Parameters（シェーダー固有パラメータ）

Pixelシェーダー側のstruct Materialに、色・テクスチャ等の標準フィールドに無い名前のメンバーがある場合（カスタムシェーダーモジュール等）に、それをextraParametersとして個別に追加・編集する欄です。キー名はシェーダー側のフィールド名と完全に一致させる必要があり、対応するフィールドが無いキーは描画時に黙って無視されます。

ラベルウィジェット内容
Reference Shaderコンボ（読み込み済みの2D/3Dレンダーパイプライン名）下記「Add Missing Parameters」の参照先、および各パラメータのスライダー刻み幅/範囲注釈の参照先。この欄自体は.matには保存されない一時的なUI状態
Add Missing Parametersボタン（Reference Shader未選択時は無効）選択中シェーダーが持つフィールド・テクスチャ宣言のうち、標準フィールド（Color/UV Transform/Shininess等）ではなく、かつまだ追加されていないものを、型ごとの既定値（Bool: false、Int32: 0、Float: 0.0、Vector2/3/4: ゼロ、Color: 白、Matrix4x4: 単位行列、Texture/TextureCube: 未設定）で一括追加する
（名前入力欄）＋（型コンボ）＋ Addテキスト入力＋コンボ（Bool / Int32 / Float / Vector2 / Vector3 / Vector4 / Color / Texture / TextureCube）＋ボタン任意の名前・型でパラメータを1件だけ手動追加する。名前が空、または既存キーと重複する場合は追加されない
（パラメータ一覧、モジュール名の折りたたみヘッダーごとにグループ化）型に応じた編集ウィジェット＋Removeボタン登録済みシェーダーモジュールのフィールド名と一致するキーはモジュール名の折りたたみヘッダーの下にグループ表示され（既定で展開済み）、どのモジュールにも属さない手動追加パラメータはその下にフラットに並ぶ。Reference Shaderにそのキーのレンジ注釈がある場合、スライダーの刻み幅・範囲がそれに従う
