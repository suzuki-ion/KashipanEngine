KashipanEngine 使い方リファレンス

DirectX12ベースの独自C++ゲームエンジン「KashipanEngine」のAPIリファレンスです。エンジン本体はC++で実装されていますが、実際のゲームロジックは主に AngelScript（.as ファイル）と、JSONで記述するシーンによって組み立てます。

このリファレンスについて

KashipanEngine は「オブジェクト（EmptyObject）にコンポーネントを付け足していく」コンポジション方式のエンジンです。Unity のようにシーン内のオブジェクトへ Transform・MeshRenderer・BoxCollider・ScriptComponent といったコンポーネントをアタッチしてゲームを組み立てます。

  • シーンの内容（オブジェクト・コンポーネント配置）は JSON（Assets/Scenes/*.scene）に保存され、専用の シーンエディタ（ImGuiベース）で編集します。
  • ゲームプレイのロジック（移動・当たり判定応答・演出など）は C++ ではなく AngelScript で書き、ScriptComponent としてオブジェクトにアタッチします。
  • C++ 側のコードは主にエンジン本体の実装と、起動時フックである Application/AppInitialize.h に限られます。
初めての方へ
まずは チュートリアル に沿って、シーン作成からスクリプトでキャラクターを動かすところまでを一通り体験することをおすすめします。
