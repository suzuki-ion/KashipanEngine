描画コンポーネント

KashipanEngine/Objects/Components/Render/ 配下の各種描画コンポーネントをまとめます。メッシュ・スプライト・テキスト・ライト・カメラといった「描画に関わる情報」はすべて EmptyObject へアタッチするコンポーネントとして表現され、実際の描画処理自体は Renderer／SceneRenderer が毎フレーム収集して行います。

ディレクトリ構成

Objects/Components/Render/
├── MeshRenderer.h            … 3Dメッシュ描画
├── SkinnedMeshRenderer.h     … スキンメッシュ（ボーンアニメーション）描画
├── SpriteRenderer.h          … 2Dスプライト描画
├── TextRenderer.h            … SDFフォントによるテキスト描画
├── Light.h                   … ライトのパラメータ保持
├── LightRenderer.h           … Lightの情報をRendererへ渡す
├── Camera3D.h / Camera2D.h   … カメラの射影パラメータ保持
├── CameraRenderer.h          … Camera3D/2Dの情報をRendererへ渡す（ビュー射影行列の計算）
├── CameraController.h        … カメラを追従対象へ滑らかに追従させる
├── NormalWindowObject.h      … 通常ウィンドウを生成する描画先コンポーネント
├── OverlayWindowObject.h     … オーバーレイウィンドウを生成する描画先コンポーネント
├── IWindowObjectComponent.h  … 上記2つの共通基底（ウィンドウメッセージ通知の仕組み）
├── ScreenBufferObject.h      … オフスクリーンバッファへの描画先
├── ShadowMapObject.h         … シャドウマップの描画先
├── TargetObjectSelector.h    … （エディタ専用）描画先オブジェクト選択UIのヘルパー
└── CameraRenderer.h 等の関連クラスは Scene/Components/Render/SceneRenderer が集約する
ポイント
「メッシュ本体（MeshFilter）」と「どう描くか（MeshRenderer 等）」は別コンポーネントに分かれています。これは オブジェクトコンポーネント基礎 で説明したコンポジション方式の典型例で、同じメッシュを異なるマテリアル・パイプラインで描く、あるいは当たり判定用の MeshCollider（06_Collision.html 参照）と描画を独立させる、といったことが容易になります。

描画先の指定（共通の仕組み）

MeshRenderer・SpriteRenderer・TextRenderer・LightRenderer・CameraRenderer はいずれも SetTargetObject() で「どのオブジェクトへ描画するか」を指定します。ここで指定するオブジェクトには 描画先コンポーネント（NormalWindowObject / OverlayWindowObject / ScreenBufferObject / ShadowMapObject）のいずれかが付与されている必要があり、指定オブジェクトに付与された全ての描画先へ描画されます（IsRenderTargetIncluded() で個々の描画先を除外することも可能）。ウィンドウ系描画先コンポーネントの詳細は 11_Window.html を参照してください。

描画先指定の共通API（MeshRenderer/SpriteRenderer/TextRenderer 等が共通して持つ）

void SetTargetObject(const EmptyObject *targetObject); void SetTargetObject(const UUID128 &targetObjectID); const UUID128 &GetTargetObjectID() const noexcept; EmptyObject *GetTargetObject() const; bool IsRenderTargetIncluded(const IRenderTarget *target) const;

描画先オブジェクトが未指定の場合の挙動はコンポーネントごとに異なります（LightRenderer/CameraRenderer は「全描画先に適用」、MeshRenderer 等は「描画されない」）。

MeshRenderer — 3Dメッシュ描画

MeshRenderer は最も基本的な描画コンポーネントです。描画するメッシュ自体は同一オブジェクトの MeshFilter コンポーネントから取得し、MeshRenderer 側はパイプライン・マテリアル・インスタンスカラーなど「どう描くか」の情報のみを保持します。

MeshRenderer::ColorBlendMode

enum class ColorBlendMode : int { Override = 0, // マテリアルの色を無視してインスタンスカラーで置き換える Multiply, // マテリアルの色に乗算する（既定。白(1,1,1,1)なら見た目に影響しない） Add, // マテリアルの色に加算する Subtract, // マテリアルの色から減算する };

インスタンスカラー

void SetInstanceColor(const Vector4 &color) noexcept; const Vector4 &GetInstanceColor() const noexcept; void SetInstanceColorBlendMode(ColorBlendMode mode) noexcept; ColorBlendMode GetInstanceColorBlendMode() const noexcept;

マテリアルを共有したまま、オブジェクト単位で色味だけを変えたい場合に使います。既定値は白 (1,1,1,1) ＋ Multiply なので、そのままでは見た目に影響しません。

パイプライン・シャドウ設定

void SetPipelineName(const std::string &pipelineName); const std::string &GetPipelineName() const noexcept; void SetCastShadows(bool enabled) noexcept; bool GetCastShadows() const noexcept;

既定のパイプライン名は "Object3D.Solid.BlendNormal" です。SetCastShadows(false) にすると、このメッシュはシャドウマッピングのシャドウキャスターとして扱われなくなります。

マテリアルスロット（Unity同様、スロットi = サブメッシュi）

void SetMaterialName(const std::string &materialName); // スロット0 void SetMaterialHandle(MaterialManager::MaterialHandle handle); // スロット0 size_t GetMaterialSlotCount() const noexcept; void SetMaterialSlotCount(size_t count); void SetMaterialNameAt(size_t slot, const std::string &materialName); const std::string &GetMaterialNameAt(size_t slot) const noexcept; MaterialManager::MaterialHandle GetMaterialHandleAt(size_t slot) const noexcept;

マテリアルスロット数はメッシュのサブメッシュ数に合わせて拡張できます。スロット数を超えるサブメッシュは最後のスロットのマテリアルで描画されます。

マテリアル・シェーダーモジュール（lilToon風の合成シェーダー）
MaterialManager::Materialは色・テクスチャ・シャドウ等の標準フィールドに加え、extraParameters（std::unordered_map<std::string, MyAny>）でモジュール固有パラメータを保持します。マテリアルエディタ（USE_IMGUI限定）でモジュールを選択すると、選択の組み合わせごとにHLSLソースとパイプラインバリアントが自動生成され（Graphics/Pipeline/System/ShaderModuleComposer）、生成されたパイプライン名をMeshRenderer::SetPipelineName()／SpriteRenderer::SetPipelineName()へ渡すことで適用されます。extraParametersのキー名はシェーダー側struct Materialのフィールド名と一致させる必要があり、対応するフィールドが無いキーは黙って無視されます。

Object3D向けモジュール: NormalMap / SpecularMap / EnvironmentMap / DetailMap / AO / Matcap / Gradation / Emission / ColorGrading / OpacityMap / DistanceFade / Dissolve / MultiTone / RimShade / Backlight
Object2D向けモジュール（SpriteRenderer/TextRenderer用）: ColorGrading2D / Dissolve2D / Vignette2D / GradientOverlay2D / Pulse2D（周期的な明滅） / FlashColor2D（被弾時などのヒットフラッシュ） / MaskTexture2D

モジュール構成そのものをコードから動的に組み立てることは想定されておらず、モジュールの選択・シェーダー生成はエディタのマテリアルエディタで行います。ゲーム側は生成済みマテリアルのextraParametersを実行時に書き換えて演出を変化させる使い方が基本です（例: MaterialManager::GetMaterial("Enemy")->extraParameters["flashIntensity"] = 1.0f;でFlashColor2Dモジュールのヒットフラッシュ強度を点灯させる）。なお"Default"という名前のマテリアルアセットが存在しないプロジェクトでは、MaterialManagerが起動時に既定マテリアルを自動登録するため、SetMaterialName("Default")指定のオブジェクトが非表示になることはありません。

基本的な使い方

EmptyObject *obj = sceneContext->CreateEmptyObject("Cube"); // Transformは生成時に自動で付与される
obj->AddComponent<MeshFilter>(ModelManager::GetModelHandleFromAssetPath("Model/Cube.gltf"));

auto *renderer = obj->AddComponent<MeshRenderer>();
renderer->SetTargetObject(windowObject);              // NormalWindowObject等が付与されたオブジェクト
renderer->SetPipelineName("Object3D.Solid.BlendNormal");
renderer->SetMaterialName("Default");
renderer->SetCastShadows(true);

SkinnedMeshRenderer — スキンメッシュ描画

ボーンアニメーションで変形するメッシュを描画するコンポーネントです。描画先・パイプライン・マテリアル・インスタンスカラー指定は MeshRenderer と同じ API を持ちますが、加えて GPU スキニング（Computeシェーダー）とアニメーション再生の制御を行います。

インスタンスカラー

void SetInstanceColor(const Vector4 &color) noexcept; const Vector4 &GetInstanceColor() const noexcept; void SetInstanceColorBlendMode(ColorBlendMode mode) noexcept; ColorBlendMode GetInstanceColorBlendMode() const noexcept;

MeshRendererと同じAPI・既定値（白 (1,1,1,1) ＋ Multiply）です。SkinnedMeshRenderer::ColorBlendModeとして独立して定義されていますが、値の並びはMeshRenderer::ColorBlendModeと同一です。

Quality / BlendShape（SkinnedMeshRenderer自身が持つ設定）

void SetQuality(SkinQuality quality); // Auto / Bone1 / Bone2 / Bone4 void SetBlendShapeWeight(const std::string &name, float weight); float GetBlendShapeWeight(const std::string &name) const; const std::vector<BlendShapeWeight> &GetBlendShapes() const noexcept; Animator *GetAnimator() const;

BlendShape（モーフターゲット）の一覧はメッシュから自動同期され、ユーザーが編集できるのはウェイト（0～100）のみです。GetAnimator()は同一オブジェクトのAnimatorコンポーネントを取得します（無い場合はnullptrで、この場合バインドポーズのまま描画されます）。

アニメーション再生はAnimatorコンポーネントの責務
クリップの選択・再生状態（Play/Stop/Loop/再生速度）・Root Boneの設定はSkinnedMeshRenderer自身ではなく、同一オブジェクトに付与するAnimatorコンポーネント（Objects/Components/Animator.h、カテゴリ"Animation"）が担います。SkinnedMeshRendererはAnimatorが計算した姿勢（ボーンのワールド行列）を読み取ってGPUスキニングを行うのみで、再生状態そのものは持ちません。

Animator — アニメーション再生

void SetClipName(const std::string &clipName); // 空文字ならバインドポーズのまま静止 const std::string &GetClipName() const noexcept; void SetAnimationSourceAssetPath(const std::string &path); // 空文字ならMeshFilterのメッシュ自身から取得 const std::string &GetAnimationSourceAssetPath() const noexcept; void SetPlayOnStart(bool playOnStart); // 既定 true void SetLoop(bool loop); // 既定 true void SetPlaybackSpeed(float speed); // 既定 1.0 void Play(); void Stop(); bool IsPlaying() const noexcept; void SetRootBoneObject(const EmptyObject *rootBoneObject); EmptyObject *GetRootBoneObject() const; std::vector<std::string> GetAvailableClipNames() const;

再生するクリップは、既定ではMeshFilterのメッシュと同じアセットから読み込まれます。SetAnimationSourceAssetPath()で別ファイルを指定すると、ボーン名が一致する範囲でそのファイルのアニメーションを適用できます（同一リグでアニメーションのみ別ファイルのMixamo等のケース向け）。Root Bone を設定すると、そのオブジェクトの Transform に沿ってメッシュ全体が動きます（Unityと同様）。未設定の場合は所有オブジェクト自身の最上位の祖先が探索の起点として使われます。

ポイント
GPUスキニング用のバッファ取得系メソッド（GetSourceVerticesBuffer() 等）は Passkey<Renderer> で保護されており、ゲーム側から直接呼び出すことはありません（01_Overview.html のPasskeyイディオムを参照）。

SpriteRenderer — 2Dスプライト描画

Object2D系のパイプラインを使う2D描画コンポーネントです。描画するメッシュ（通常は平面）は MeshRenderer と同様に MeshFilter から取得します。既定パイプラインは "Object2D.DoubleSidedCulling.BlendNormal" です。

アンカー・ピボット

void SetAnchor(const Vector2 &anchor); // 既定(0.5, 0.5) const Vector2 &GetAnchor() const noexcept; void SetPivot(const Vector2 &pivot); // 既定(0.5, 0.5) const Vector2 &GetPivot() const noexcept;

メッシュはXY平面上の-0.5～0.5の単位クアッドを想定しており、アンカー・ピボットはその単位クアッド内の正規化座標 (0,0)=左下 ～ (1,1)=右上 で指定します。アンカーは「Transformの座標に一致させる点」、ピボットは「回転・拡縮の中心にする点」で、両者に異なる点を指定すると回転・拡縮の中心とTransform座標がずれた挙動になります。

インスタンスカラー

void SetInstanceColor(const Vector4 &color) noexcept; const Vector4 &GetInstanceColor() const noexcept; void SetInstanceColorBlendMode(ColorBlendMode mode) noexcept; ColorBlendMode GetInstanceColorBlendMode() const noexcept;

MeshRenderer・TextRendererと同じく、共有マテリアルを変更せずSpriteRenderer単位で色を適用します。合成方法はOverride / Multiply / Add / Subtractで、既定値は白＋Multiplyです。色とアルファの両方に同じ合成規則が適用されます。

時間ベースの2Dシェーダーモジュール
Object2D系パイプラインには、Rendererがゲーム内時刻（起動からの経過秒数 gTime、前フレームからの経過秒数 gDeltaTime）を毎フレーム自動的に注入します。Pulse2D（周期的な明滅）やFlashColor2D（ヒットフラッシュ）のような時間・パラメータ駆動の演出モジュールはこれを内部で利用しており、ゲーム側で時刻を渡すコードを書く必要はありません。マテリアルのextraParametersによるモジュールパラメータ制御については、前述の「MeshRenderer」節のマテリアル・シェーダーモジュールの説明を参照してください。

TextRenderer — テキスト描画

SDFフォント（FontManager 経由でTTF/OTFから読み込み・ベイク）を使ったテキスト描画コンポーネントです。Unity風のリッチテキストタグを解釈しながら、1文字ずつ独立した矩形インスタンスとして描画します。既定パイプラインは "Text2D.BlendNormal" です。

テキスト内容・見た目

void SetText(const std::string &text); void SetFontName(const std::string &fontName); void SetFontSize(float fontSize); void SetMaterialName(const std::string &materialName); void SetInstanceColor(const Vector4 &color); void SetInstanceColorBlendMode(ColorBlendMode mode); void SetOutlineWidth(float width); void SetOutlineColor(const Vector4 &color); void SetHorizontalAlign(HorizontalAlign align); // Left / Center / Right void SetVerticalAlign(VerticalAlign align); // Top / Middle / Bottom

任意マテリアルを割り当て、Textパイプライン側のMaterial構造体に存在するパラメーターを利用できます。文字形状を保持するため、マテリアル側のテクスチャとUV変換は無視され、フォントアトラスと文字ごとのUV矩形が常に使用されます。

対応リッチテキストタグ

<i> <b> <color=#RRGGBB(AA)> <size=N|N%> <s> <u> <sub> <sup>

斜体・太字・色・サイズ（絶対値または fontSize に対する割合）・取り消し線・下線・下付き/上付き文字に対応しています。閉じタグ（</color> 等）でスタイルスタックを1段階戻します。

文字ごとの調整（ランタイム専用・非シリアライズ）

size_t GetCharacterCount() const; void SetCharacterOffset(size_t index, const Vector2 &offset); void SetCharacterRotation(size_t index, float rotation); // ラジアン void SetCharacterScale(size_t index, const Vector2 &scale);

Transform的な調整を1文字単位で行えます。演出用の値なのでシーンJSONへは保存されません。

Light / LightRenderer — ライト

Light はライトの種類とパラメータを保持するだけのコンポーネントで、実際にRendererへ情報を渡すのは同一オブジェクトに付与する LightRenderer です。ライトの位置・向きは同一オブジェクトの Transform から取得されます。

Light::Type

enum class Type { Directional, Point, Spot, Rect, Sphere, Disc, Tube, Box };

Rect/Sphere/Disc/Tube は面光源（形状上の代表点法で近似）、Box は全方位発光の体積光源です。

共通パラメータ

void SetType(Type type); void SetColor(const Vector4 &color); void SetIntensity(float intensity); void SetRadius(float radius); // Point/Sphere/Tubeの減衰範囲 void SetDistance(float distance); // Spot/Disc/Rectの減衰範囲 void SetDecay(float decay); void SetInnerAngle(float innerAngle); // Spot用 void SetOuterAngle(float outerAngle); // Spot用

面光源のサイズ / シャドウ

void SetSourceRadius(float sourceRadius); // Sphere/Disc/Tubeの半径 void SetSourceWidth(float sourceWidth); // Rect/Boxの幅 void SetSourceHeight(float sourceHeight); // Rect/Boxの高さ void SetSourceLength(float sourceLength); // Tubeの長さ void SetSourceDepth(float sourceDepth); // Boxの奥行き void SetCastShadows(bool castShadows); void SetShadowDistance(float shadowDistance); void SetShadowMapResolution(std::uint32_t resolution); void SetShadowBias(float bias); void SetShadowSoftness(float softness); // Directional/Point/Spot用（PCSS半影ソフト化）

影を有効にすると、種類に応じたシャドウマップが自動生成されます（Directional=カスケード、Spot/Disc/Rect=1面、Point/Sphere/Tube=キューブ6面）。

LightRenderer

void SetPipelineName(const std::string &pipelineName); // 空文字なら全パイプラインに適用 Light *GetLight() const; Light::Type GetLightType() const; Vector3 GetWorldPosition() const; Vector3 GetWorldDirection() const; // Transformの+Z Vector3 GetWorldRight() const; // Rect/Tubeの軸方向に使用 Vector3 GetWorldUp() const; // Rectの高さ方向に使用

描画先指定（SetTargetObject 等）は前述の共通APIと同じです。

Camera3D / Camera2D / CameraRenderer / CameraController — カメラ

カメラも Light と同様に「パラメータ保持用コンポーネント（Camera3D/Camera2D）」と「Rendererへ情報を渡すコンポーネント（CameraRenderer）」に分かれています。位置・向きは同一オブジェクトの Transform から取得されます。

Camera3D

void SetFovY(float fovY); // 既定 0.45（ラジアン） void SetNearClip(float nearClip); void SetFarClip(float farClip); void SetAspectRatio(float aspectRatio); void SetOrthographic(bool orthographic); void SetOrthoSize(float orthoSize); // 平行投影時の縦半径

Camera2D

void SetSize(float width, float height); void SetNearClip(float nearClip); void SetFarClip(float farClip);

CameraRenderer

void SetPipelineName(const std::string &pipelineName); void SetBindVariableNames(const std::vector<std::string> &names); // 例: {"Vertex:gCamera3D", "Pixel:gCamera3D"} Vector3 GetWorldPosition() const; const Matrix4x4 &GetViewProjectionMatrix() const noexcept; float GetNearClip() const noexcept; float GetFarClip() const noexcept;

同一オブジェクトの Camera2D が見つかった場合は2D用の定数バッファレイアウトで、それ以外は Camera3D（無ければ既定値）で3D用の定数バッファとしてアップロードされます。バインド先変数名が未指定の場合、カメラの種類から "Vertex:gCamera2D"/"Pixel:gCamera2D" または "Vertex:gCamera3D"/"Pixel:gCamera3D" が既定で使われます。

CameraController — 複数ターゲットへの滑らかな追従

void AddFollowTarget(const UUID128 &objectID); void RemoveFollowTarget(size_t index); std::vector<FollowTarget> &GetFollowTargets() noexcept; void SetPositionOffset(const Vector3 &offset); void SetRotationOffset(const Vector3 &offset); // オイラー角、ラジアン void SetTargetFovY(float fovY); AxisStrength &GetMoveStrength() noexcept; AxisStrength &GetRotateStrength() noexcept; void SetFovLerpFactor(float factor);

同一オブジェクトの Camera3D を、複数の追従先オブジェクトへ軸ごとに（移動X/Y/Z・回転X/Y/Z個別に）滑らかに追従させます。追従先が1つも指定されていない場合は自分自身の Transform を追従先として扱います。複数の追従先が同じ軸を指定した場合は平均を取ります。

ウィンドウへの描画先コンポーネント（概要）

MeshRenderer 等の SetTargetObject() で指定する先には、描画結果の出力先となるコンポーネントを付与しておく必要があります。そのうち画面上のウィンドウとして表示する2種類が NormalWindowObject（通常ウィンドウ）と OverlayWindowObject（オーバーレイウィンドウ）で、共通基底 IWindowObjectComponent がウィンドウの生成・タイトル/サイズ設定・受信メッセージの通知（SetOnWindowMessage）を担います。詳細な使い方は 11_Window.html で扱います。

スクリプトからの利用
AngelScript側では ScriptComponentBehavior::OnWindowMessage(const WindowMessageInfo &in) として、同一オブジェクトのウィンドウ系コンポーネントが受信したメッセージを受け取れます。詳しくは Script/00_Index.html を参照してください。
