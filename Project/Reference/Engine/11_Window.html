ウィンドウ / オフスクリーン

KashipanEngine/Core/Window.h と KashipanEngine/Graphics/ 配下の各種描画先（Window / ScreenBuffer / ShadowMapBuffer）、およびそれらをオブジェクトから扱うためのコンポーネントについて解説します。

IRenderTarget インターフェース

Window / ScreenBuffer / ShadowMapBuffer はいずれも Graphics/IRenderTarget.h の IRenderTarget を実装しており、「何らかのGPU描画先」として共通のAPIで扱えます。

IRenderTarget

enum class RenderTargetKind { Window, ScreenBuffer, ShadowMapBuffer, RenderTargetKindCount }; virtual RenderTargetKind GetRenderTargetKind() const noexcept = 0; virtual std::string GetRenderTargetName() const = 0; virtual std::uint32_t GetRenderTargetWidth() const noexcept = 0; virtual std::uint32_t GetRenderTargetHeight() const noexcept = 0; virtual bool IsRenderTargetAvailable() const noexcept = 0; virtual void BeginDraw() = 0; virtual void EndDraw() = 0; virtual ID3D12GraphicsCommandList *GetCommandList() const = 0;

Window クラス

Core/Window.h の Window は final クラスで、生成はコンストラクタではなく静的ファクトリメソッドを使います。

生成

enum class WindowType { Normal, Overlay }; enum class WindowMode { Window, FullScreen }; enum class SizeChangeMode { None, Normal, FixedAspect }; static Window *CreateNormal(const std::string &title = "", int32_t width = 0, int32_t height = 0, DWORD style = 0, const std::string &iconPath = "./Assets/KashipanEngine/EngineLogo/engineLogo.ico"); static Window *CreateOverlay(const std::string &title = "", int32_t width = 0, int32_t height = 0, bool clickThrough = false, const std::string &iconPath = "./Assets/KashipanEngine/EngineLogo/engineLogo.ico");

CreateNormal は通常のOSウィンドウ、CreateOverlay は（クリック透過設定が可能な）オーバーレイウィンドウを生成します。

検索・存在確認

static Window *GetWindow(HWND hwnd); static Window *GetWindow(const std::string &title); static std::vector<Window *> GetWindows(const std::string &title); static size_t GetWindowCount(); static bool IsExist(HWND hwnd); static bool IsExist(Window *window); static bool IsExist(const std::string &title);

設定

void SetSizeChangeMode(SizeChangeMode sizeChangeMode); void SetWindowMode(WindowMode windowMode); void SetWindowTitle(const std::wstring &title); void SetWindowTitle(const std::string &title); void SetWindowSize(int32_t width, int32_t height); void SetWindowPosition(int32_t x, int32_t y); void SetWindowVisible(bool visible); void SetWindowParent(HWND parentHwnd, bool applyNative = true); void SetWindowParent(Window *parentWindow, bool applyNative = true); void SetWindowChild(HWND childHwnd, bool applyNative = true); void SetWindowChild(Window *childWindow, bool applyNative = true); void ClearWindowParent(bool applyNative = true); void ClearWindowChild(bool applyNative = true);

状態取得

int32_t GetClientWidth() const noexcept; int32_t GetClientHeight() const noexcept; float GetAspectRatio() const noexcept; POINT GetWindowPosition() const noexcept; bool IsActive() const noexcept; bool IsFocused() const noexcept; bool IsMoving() const noexcept; bool IsResizing() const noexcept; bool IsClosed() const noexcept; bool IsDestroyed() const noexcept; bool IsResized() const noexcept; bool IsMinimized() const noexcept; bool IsMaximized() const noexcept; bool IsVisible() const noexcept;

これらの Is* 系メソッドの多くは「このフレームに該当メッセージ（WM_ACTIVATE、WM_CLOSE 等）を受信したか」を HasMessage(UINT msg) で判定するもので、常時の状態ではなく1フレーム限りの通知として使う点に注意してください。

メッセージの横取り（インターセプト）

static bool IsInterceptableMessage(UINT msg) noexcept; bool SetMessageIntercepted(UINT msg, bool enabled); bool IsMessageIntercepted(UINT msg) const;

横取り対象のメッセージは受信の記録のみ行い、エンジン既定のイベント処理とOSの既定処理（DefWindowProc）を実行しなくなります。WM_DESTROY / WM_NCDESTROY / WM_QUIT は横取り不可です。

注意
WM_NCHITTEST や WM_SYSCOMMAND 全体等を横取りすると、ウィンドウの基本動作（ドラッグ移動・リサイズ等）が壊れます。

イベント登録

template<class TEvent, class... Args> void RegisterWindowEvent(Args&&... args); // 既定イベント型（値保持） template<class TEvent> void RegisterWindowEvent(std::unique_ptr<TEvent> handler); // 拡張イベント/既定イベント（unique_ptr） void UnregisterWindowEvent(UINT msg);

WindowDefaultEvent（Core/WindowsAPI/WindowEvents/DefaultEvents.h）が既定で用意されているイベント群、または IWindowEvent を継承した独自イベントを、対象メッセージ（kTargetMessage_）ごとに1つ登録できます。

ScreenBuffer — オフスクリーンレンダリング用バッファ

Graphics/ScreenBuffer.h の ScreenBuffer は IShaderTexture と IRenderTarget の両方を実装する final クラスで、カラー・深度のダブルバッファ構成を持ちます。TextureManager へも自動登録されるため、生成後は他の描画コンポーネントから通常のテクスチャと同様に参照できます。

ScreenBuffer 主要API

static ScreenBuffer *Create(std::uint32_t width, std::uint32_t height, const std::string &name = "", DXGI_FORMAT colorFormat = DXGI_FORMAT_B8G8R8A8_UNORM, DXGI_FORMAT depthFormat = DXGI_FORMAT_D24_UNORM_S8_UINT); static bool IsExist(ScreenBuffer *buffer); D3D12_GPU_DESCRIPTOR_HANDLE GetSrvHandle() const noexcept override; D3D12_GPU_DESCRIPTOR_HANDLE GetDepthSrvHandle() const noexcept; void NextPass(); // ポストエフェクト用のパス切り替え void RebindWriteTarget(); // 書き込み面を再度レンダーターゲットとして設定 bool Resize(std::uint32_t width, std::uint32_t height); bool SaveToFile(const std::string &filePath) const; void SetDepthWriteEnabled(bool enable) noexcept;

NextPass() / RebindWriteTarget() は ポストエフェクト のカスタム描画（RenderCustom）から使う低レベルAPIです。Resize() は呼び出し時点ではサイズを記憶するだけで、GPUリソースの再生成は実際に使用される際に1バッファずつ遅延して行われます（ちらつき防止のため）。

ShadowMapBuffer — シャドウマップ用バッファ

Graphics/ShadowMapBuffer.h の ShadowMapBuffer は深度のみを持つオフスクリーンバッファです。ScreenBuffer と異なりカラーバッファやダブルバッファ構成は持たず、Resize() は即座にGPUリソースを作り直します。

ShadowMapBuffer 主要API

static ShadowMapBuffer *Create(std::uint32_t width, std::uint32_t height, const std::string &name = "", DXGI_FORMAT depthFormat = DXGI_FORMAT_D32_FLOAT, DXGI_FORMAT srvFormat = DXGI_FORMAT_R32_FLOAT); static bool IsExist(ShadowMapBuffer *buffer); D3D12_GPU_DESCRIPTOR_HANDLE GetSrvHandle() const noexcept override; DepthStencilResource *GetDepthStencil() const noexcept; bool Resize(std::uint32_t width, std::uint32_t height);

オブジェクトから描画先を扱うコンポーネント

これらの描画先を EmptyObject に紐付けて扱うためのコンポーネントが Objects/Components/Render/ 配下に用意されています。いずれも COMPONENT_CATEGORY("Render", "RenderTarget") に分類されます。実際の描画コンポーネント（MeshRenderer 等）からこれらを「描画先」として指定する方法は 05_Rendering.html を参照してください。

IWindowObjectComponent — Window所有コンポーネントの基底

Window *GetWindow() const noexcept; void SetTitle(const std::string &title); const std::string &GetTitle() const noexcept; void SetSize(std::uint32_t width, std::uint32_t height); using WindowMessageCallback = std::function<void(const WindowMessageEvent &)>; void SetOnWindowMessage(WindowMessageCallback callback); bool SetMessageIntercepted(std::uint32_t msg, bool enabled); void CloseWindow();

ウィンドウが受信したメッセージを SetOnWindowMessage のコールバックへ通知する仕組みを持ち、ScriptComponent（07_Scripting.html）はこれをフックしてスクリプトの OnWindowMessage(const WindowMessageInfo &in) を呼び出します。

コンポーネント役割
NormalWindowObject通常ウィンドウ（Window::CreateNormal）を所有する。同一オブジェクトの Transform のワールド位置・スケールをウィンドウの位置・サイズへ毎フレーム反映する
OverlayWindowObjectオーバーレイウィンドウ（Window::CreateOverlay）を所有する。挙動は NormalWindowObject とほぼ同じ
ScreenBufferObjectScreenBuffer を所有する。名前・サイズの設定（SetName/SetSize）、画像保存（RequestSave、SetSaveDirectory/SetSaveFileNamePrefix/SetSaveFormat）、USE_IMGUI 環境ではプレビュー用ビューアウィンドウを持つ
ShadowMapObjectShadowMapBuffer を所有する。ScreenBufferObject と同様の名前・サイズ設定APIを持つ
シーン切り替え時の引き継ぎ
これらのコンポーネントは Finalize() 時に RenderTargetCarryOverRegistry へ自身のウィンドウ/バッファを一時的に預け、次のシーンの同名コンポーネントの LoadFromJson() で TryClaimCarriedOverWindow() 等により再利用されます。これにより、シーン切り替えのたびにウィンドウが一瞬でも破棄・再生成されてちらつくことを防いでいます。

使用例

#include <KashipanEngine.h>
using namespace KashipanEngine;

// コードから直接オーバーレイウィンドウを開く場合
Window *overlay = Window::CreateOverlay("HUD Overlay", 1280, 720, /*clickThrough=*/true);

// シーン上のオブジェクトへオフスクリーンバッファを付与する場合
auto *screenBufferObj = obj->AddComponent<ScreenBufferObject>();
screenBufferObj->SetName("MainView");
screenBufferObj->SetSize(1920, 1080);

実運用では NormalWindowObject / OverlayWindowObject / ScreenBufferObject / ShadowMapObject は シーンエディタ 上でオブジェクトへ追加するのが基本です。
