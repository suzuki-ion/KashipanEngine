ライフサイクルと衝突・ウィンドウイベント

ScriptComponentBehavior を実装したクラスに定義できるライフサイクル関数と、衝突・ウィンドウメッセージのコールバックへ渡される情報型をまとめます。

ScriptComponentBehavior（ライフサイクル）

スクリプト内で ScriptComponentBehavior インターフェースを実装したクラスを定義すると、モジュール内で最初に見つかったクラスがインスタンス化され、以下のメソッドが呼び出されます。全てのメソッドは省略可能で、定義されているものだけが呼ばれます。 

class Player : ScriptComponentBehavior {
    void Awake() {}                                   // インスタンス生成時に一度だけ
    void Start() {}                                    // ゲームループ中、最初のUpdate()の直前に一度だけ
    void Update() {}                                    // 毎フレーム
    void End() {}                                       // 終了時
    void OnCollisionEnter(const HitInfo &in hit) {}  // 衝突開始時
    void OnCollisionStay(const HitInfo &in hit) {}   // 衝突継続中（毎フレーム）
    void OnCollisionExit(const HitInfo &in hit) {}   // 衝突終了時
    void OnWindowMessage(const WindowMessageInfo &in info) {} // ウィンドウメッセージ受信時
}
関数呼ばれるタイミング
void Awake()コンポーネントの初期化時（スクリプトのコンパイル成功後、インスタンス生成直後）、および Reload() 成功後に一度（UnityのAwake相当）
void Start()ゲームループ中、そのインスタンスに対して最初に Update() が呼ばれる直前に一度だけ（UnityのStart相当。非アクティブのまま一度も Update() が呼ばれなければ実行されない）
void Update()毎フレーム
void End()終了時（コンポーネント削除・非アクティブ化・リロード時）
void OnCollisionEnter(const HitInfo &in hit)同オブジェクトのコライダーが他コライダーと接触し始めた時
void OnCollisionStay(const HitInfo &in hit)同オブジェクトのコライダーが他コライダーと接触し続けている間、毎フレーム
void OnCollisionExit(const HitInfo &in hit)同オブジェクトのコライダーが他コライダーとの接触を終えた時
void OnWindowMessage(const WindowMessageInfo &in info)同オブジェクトの NormalWindowObject/OverlayWindowObject 等のウィンドウがメッセージを受信した時（通知元コンポーネント情報付き）

衝突イベントは同オブジェクトに付いている全ての ICollider 派生コンポーネント（2D/3D両方）が対象です。C++側で既に衝突コールバックが設定されている場合、そのコールバックが先に呼ばれた後にスクリプト側が呼ばれます。高速に移動するオブジェクトが相手をすり抜けて衝突イベントが発生しない場合は、コライダーの連続衝突判定（CCD）を有効にしてください（詳細は 07_ColliderAndPostEffect.html）。

OnCollisionEnter/Stay/Exit と OnWindowMessage はコストがある
これらのコールバックは、内部で同オブジェクトの全コライダー（または全WindowObject系コンポーネント）へフックを張ることで実現されています。実装したメソッドを持つスクリプトだけがこのフック対象になるため、使わないなら定義しないほうが軽量です。
コライダーの追加/削除のタイミング
衝突コールバックのフックは毎フレームのコライダー数チェックで追従しますが、コライダーの追加とほぼ同時に発生した衝突は最初の1フレームだけ通知されないことがあります。

HitInfo

衝突メソッド（OnCollisionEnter/OnCollisionStay/OnCollisionExit）へ渡される衝突情報の値型です。

HitInfo（値型）

Vector3 normal; float penetration; Object@ selfObject; Object@ otherObject; Collider@ selfCollider; Collider@ otherCollider;

normal は「相手→自分」方向を向く押し出し法線です。penetration はめり込み量。selfCollider/otherCollider で「どのコライダーコンポーネント同士の衝突なのか」を特定できます。1つのオブジェクトに複数のコライダーが付いている場合の判別や、相手コライダーのトリガー状態・タグの確認に使用してください。Collider は全コライダー型の基底型で、cast<BoxCollider>(hit.otherCollider) のように具体的な型へダウンキャストできます（詳細は 07_ColliderAndPostEffect.html）。

WindowMessageInfo

OnWindowMessage へ渡されるウィンドウメッセージ情報の値型です。

WindowMessageInfo（値型）

WindowObject@ sourceComponent; uint message; uint64 wParam; int64 lParam;

sourceComponent で「どのウィンドウコンポーネントからの通知か」を特定できます。message と比較するための WM_KEYDOWN, WM_LBUTTONDOWN, WM_SIZE 等のウィンドウメッセージ定数（const uint）も一通りグローバルへ登録されています。WindowObject はウィンドウ系コンポーネントの基底型です。OnWindowMessage の詳細な仕様（通知の頻度・メッセージの横取り等）は 06_RenderAndWindow.html を参照してください。

実例: 衝突コールバックの使い方

Assets/Application/Scripts/Player.as は OnCollisionEnter/OnCollisionStay/OnCollisionExit の3つ全てを使い、地面判定・敵接触判定・押し戻しを行っています。 

void OnCollisionStay(const HitInfo &in hit) {
    if (hit.otherObject is null) return;
    if (hit.otherCollider !is null && hit.otherCollider.IsTrigger()) return;
    if (hit.otherCollider.GetTag() == groundColliderTag) {
        bool grounded = hit.normal.y > groundedThreshold;
        if (!hasGroundContact && grounded) {
            hasGroundContact = true;
            groundHitNormal = hit.normal;
            isOnSteepSlope = hit.normal.y < slideThreshold;
        } else if (!grounded) {
            // 壁・天井：法線方向の速度成分だけを打ち消す
            Vector3 wallNormal = hit.normal;
            wallNormal.z = 0.0f;
            float intoSurface = velocity.Dot(wallNormal);
            if (intoSurface < 0.0f) {
                velocity = velocity - wallNormal * intoSurface;
            }
        }

        // 押し戻し
        Transform@ tf = GetTransform();
        if (tf !is null) {
            Vector3 pushBack = hit.normal * hit.penetration;
            pushBack.z = 0.0f;
            if (grounded) pushBack.x = 0.0f;
            tf.SetTranslate(tf.GetTranslate() + pushBack);
        }
    }
}

このメソッドから読み取れる実践的なパターンをいくつか挙げます。

  • hit.otherCollider.GetTag() によるタグ比較でコライダーの種別を判定する（Tag groundColliderTag = Tag("GroundBox"); のようにあらかじめ構築しておいたタグと比較する）
  • hit.otherCollider.IsTrigger() でトリガー判定のコライダーは押し戻し処理から除外する
  • hit.normal * hit.penetration で押し戻しベクトルを作り、Transform へ直接加算して位置補正する

より詳しい実例（動く床への追従を含む）は 11_PlayerExample.html を参照してください。
