コンポーネント操作とグローバル関数

オブジェクトに対するコンポーネントの取得・追加・削除の方法と、ログ・時間・数学・入力・音声・モデル・ローカライズなど、オブジェクトを介さず直接呼び出せるグローバル関数をまとめます。

コンポーネントの取得・追加・削除

取得/追加したいコンポーネント型のハンドル変数（または配列）を引数に渡すと、型に応じたコンポーネントが取得/生成されます。

ハンドル引数には必ず @ を付ける
GetComponent / AddComponent / RemoveComponent は任意の型を受け取れるようAngelScriptの汎用引数（?&out / ?&in）で実装されています。この仕組みでは、渡す変数がハンドル型であっても呼び出し側で明示的に @ を付けないとハンドルとして扱われません（GetComponent(vel) ではなく GetComponent(@vel)）。@ を付け忘れると、渡した型の値そのものを構築しようとして No default constructor for object of type '...'. / No appropriate opAssign method found in '...' for value assignment というコンパイルエラーになります（コンポーネント型は値としての構築・代入をサポートしていないため）。これはAngelScript自体の仕様（dictionary.Set(key, @handle) 等と同じ）です。 
// 単体取得: 最初に見つかったコンポーネントを取得
Velocity@ vel;
if (GetOwnerObject().GetComponent(@vel)) {
    vel.AddVelocity(Vector3(0.0f, 5.0f, 0.0f));
}

// 全件取得: array<T@>@（配列自体もハンドルで宣言し、@ を付けて渡す）
array<AudioSource@>@ sources;
if (GetOwnerObject().GetComponents(@sources)) {
    for (uint i = 0; i < sources.length(); i++) {
        sources[i].Stop();
    }
}

// 追加: 渡した変数の型のコンポーネントを新規生成して追加する
BoxCollider@ col;
if (GetOwnerObject().AddComponent(@col)) {
    col.SetTrigger(true);
}

// 削除: 既に取得済みのハンドルを渡すとそのインスタンスを削除する
GetOwnerObject().RemoveComponent(@col);

// グローバル版は自身のオブジェクトが対象（obj.GetComponent(...) 等の省略形）
Transform@ tf;
GetComponent(@tf);
関数戻り値説明
bool Object::GetComponent(?&out)見つかった場合 true型に一致する最初のコンポーネントをハンドルへ格納
bool Object::GetComponents(?&out)成功した場合 true型に一致する全コンポーネントを array<T@> へ格納（0個でも配列は生成される）
bool Object::AddComponent(?&out)追加できた場合 true渡した変数の型のコンポーネントを新規生成して追加し、ハンドルへ格納する（最大追加数を超える等で失敗する場合がある）
bool Object::RemoveComponent(?&in)削除できた場合 true渡したハンドルが指すコンポーネントインスタンスを削除する
bool GetComponent(?&out)同上自身のオブジェクトを対象にした省略形
bool GetComponents(?&out)同上自身のオブジェクトを対象にした省略形
bool AddComponent(?&out)同上自身のオブジェクトを対象にした省略形
bool RemoveComponent(?&in)同上自身のオブジェクトを対象にした省略形
  • AddComponent で生成されたコンポーネントは規定値で初期化されます。既存コンポーネントの複製は Scene.CloneObject でオブジェクトごと複製してください（コンポーネント単体の複製はできません）。
  • RemoveComponent で削除した後、渡したハンドル自体は自動では null になりません。削除後に同じハンドルのメソッドを呼び出すと、削除済みコンポーネントへのアクセスとしてAngelScriptの例外になります（エンジンがクラッシュすることはなく、該当スクリプトの実行だけがそこで止まります）。
  • コンポーネント種別ごとに1オブジェクトへ追加できる最大数が決まっており（例: Transform は1個まで）、上限を超えて AddComponent を呼ぶと失敗し false が返ります。

実行コンテキストの取得（オブジェクト自身に関する関数）

これらはスクリプトの実行中、そのスクリプトをアタッチしているオブジェクトを暗黙の対象として動作するグローバル関数です。

関数説明
Object@ GetOwnerObject()このスクリプトがアタッチされているオブジェクトを取得する
Transform@ GetTransform()オーナーオブジェクトの Transform コンポーネントを取得する（無い場合は null。GetOwnerObject().GetTransform() の省略形）
Scene@ GetScene()現在のシーンを取得する
Object@ FindObject(const string &in name)シーン内から名前が一致する最初のオブジェクトを取得する（無い場合は null）
bool IsValidObject(Object@ obj)渡されたオブジェクトが現在も生存しているかを、シーンが保持する生存集合との照合で安全に判定する（[SerializeField]等で保持したハンドルが指す先が削除済みでも安全に呼べる。詳細は 02_SerializeField.html）

時間・ゲームループ制御

関数説明
float GetDeltaTime()前フレームからの経過時間（秒）を取得する
float GetGameSpeed()ゲームスピードを取得する
void SetGameSpeed(float)ゲームスピードを設定する
void RequestExitGameLoop()ゲームループの終了を要求する

dt は GetDeltaTime() * GetGameSpeed() のように求めるのが定石です。GetGameSpeed() を掛けておくことで、スロー演出やポーズ相当の速度変更に自動で追従します。

RequestExitGameLoop はエディター上では再生停止として扱われる
ゲーム実行時（エディター無しビルド）はゲームループを抜けてアプリケーションが終了しますが、エディター上ではエディター自体は閉じず、再生停止（Stopボタンと同じ動作）として扱われるため、ゲーム終了の動作確認にも安全に使用できます。Scene 型の RequestExitGameLoop() メソッドも同じ動作です（詳細は 04_ObjectSceneVariables.html）。

関数説明
float GetPI()円周率を取得する
ToDegrees(...) / ToRadians(...)ラジアン⇔度の変換。float/Vector2/Vector3/Vector4 オーバーロードあり
Clamp(value, min, max)value を min〜max の範囲に収める。float/Vector2/Vector3/Vector4 オーバーロードあり（成分ごとにクランプ）

<cmath> 相当のラッパー関数もグローバルへ登録されています。

float Abs(float);      int Abs(int);

float Floor(float);    float Ceil(float);     float Round(float);

float Min(float, float); float Max(float, float);
int   Min(int, int);     int   Max(int, int);

float Exp(float); float Ln(float); float Log10(float);

Player.as の TakeDamage() ではノックバック方向を決めるのに Sign() を、ApplyVelocity() では速度のクランプに Clamp() を使っています。数学型（Vector2/Vector3等）・Math::/Easing::/Random::名前空間については 08_MathAndUtility.html を参照してください。

入力コマンド

エンジンの InputCommand（Assets/KashipanEngine/InputCommand.json に保存される入力バインディング）を評価します。登録方法・仕組みの詳細は 08_Input.html を参照してください。

関数説明
bool IsCommandTriggered(const string &in action)コマンドの入力判定を取得する
float GetCommandValue(const string &in action)コマンドの評価値（スティック軸など -1.0〜1.0）を取得する
if (IsCommandTriggered("PlayerMoveLeft")) {
    moveDirection = GetCommandValue("PlayerMoveLeft");
}
isJumping = IsCommandTriggered("PlayerJump");

ローカライズ

Locales/ および Assets/Locales/ に置かれた翻訳データを参照します。ここで参照・変更するのはアプリケーション（ゲーム）側の表示言語で、エディター自身の表示言語（EditorPreferencesのコンボ）とは独立しています。Playモード中にスクリプトから言語を切り替えても、エディターUI自体の言語には影響しません。

関数説明
const string &Translation(const string &in key)指定キーの翻訳文字列を、現在のアプリケーション表示言語で取得する
const string &GetCurrentLanguage()現在のアプリケーション表示言語を取得する
void SetCurrentLanguage(const string &in)アプリケーション表示言語を切り替える。PlayerSettingsへ保存されるため、配布したゲームでも再起動後に選択言語が復元される
array<string>@ GetLoadedLanguages()読み込まれている言語コードの一覧を取得する
const string &GetLanguageDisplayName(const string &in languageCode)言語コードに対応する表示名（言語選択UI用）を取得する
class LanguageSelector : ScriptComponentBehavior {
    void Start() {
        // 例: 保存済み設定や起動時の判定で言語を切り替える
        SetCurrentLanguage("en-US");
    }

    void Update() {
        TextRenderer@ label;
        if (GetComponent(@label)) {
            label.SetText(Translation("ui.start_button")); // 現在言語での翻訳文字列
        }
    }
}
