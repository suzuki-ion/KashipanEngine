実例: Player.asを読み解く

Assets/Application/Scripts/Player.as は、移動・坂道判定・ジャンプ・被ダメージ・チェックポイント復帰までを1つのスクリプトで実装した、このエンジンにおけるスクリプティングの実践例です。全体は300行超あるため、ここでは要点を抜粋しながら解説します。

SerializeFieldでパラメータを外出しする

[Header("プレイヤーの基本設定")]

[SerializeField, Tooltip("移動速度")]
float moveSpeed = 0.1f;
[SerializeField, Tooltip("ジャンプ力")]
float jumpPower = 16.0f;
[SerializeField, Tooltip("重力")]
float gravity = 0.2f;
...
[Header("移動方向追従オブジェクト")]

[SerializeField, Tooltip("プレイヤーの移動方向の先へ配置するオブジェクト")]
Object@ movementTargetObject;

移動速度・ジャンプ力・重力・HP・ノックバック量など、調整が必要な値を全て [SerializeField] にすることで、C++の再ビルドはおろかスクリプトの再コンパイルすら不要に、インスペクター上の数値変更だけでゲームバランスを調整できます。Tooltip を添えておくと、他の開発者（あるいは未来の自分）がインスペクター上でパラメータの意味をすぐ把握できます。詳しくは 02_SerializeField.html を参照してください。

Update()で毎フレームの処理を段階分けする

void Update() {
    const float dt = GetDeltaTime() * GetGameSpeed();
    const bool wasGroundedAtFrameStart = isGrounded;

    InputEvent();
    UpdateGroundedState(dt);
    Landing();
    LateralMovement();
    Sliding(dt);
    Jumping(dt);
    UpdatePlatformInertia(dt, wasGroundedAtFrameStart);
    UpdateDamageCooldown(dt);
    CheckEnemyDamage();
    ApplyVelocity(dt);
    UpdateDamageFlash(dt);
    CheckDeath();
    UpdateMovementTarget();

    hasGroundContact = false;
    isCollidingWithEnemy = false;
}

dt は GetDeltaTime() * GetGameSpeed() で求めます。GetGameSpeed() を掛けておくことで、スロー演出やポーズ相当の速度変更に自動で追従します。Update() 本体はこの1フレーム分の処理を意味のある単位（入力・接地判定・移動・重力・被ダメージ…）の private メソッドへ分割して呼び出しているだけで、それぞれのメソッド自体はさほど複雑ではありません。大きなロジックは1つの関数に詰め込まず、こうして分割していくと見通しがよくなります。

OnCollisionStay()で地面判定・押し戻し・動く床への追従を行う

void OnCollisionStay(const HitInfo &in hit) {
    if (hit.otherObject is null) return;
    if (hit.otherCollider !is null && hit.otherCollider.IsTrigger()) return;
    if (hit.otherCollider.GetTag() == groundColliderTag) {
        bool grounded = hit.normal.y > groundedThreshold;
        if (!hasGroundContact && grounded) {
            hasGroundContact = true;
            groundHitNormal = hit.normal;
            isOnSteepSlope = hit.normal.y < slideThreshold;
        } else if (!grounded) {
            // 壁・天井：法線方向の速度成分だけを打ち消す
            Vector3 wallNormal = hit.normal;
            wallNormal.z = 0.0f;
            float intoSurface = velocity.Dot(wallNormal);
            if (intoSurface < 0.0f) {
                velocity = velocity - wallNormal * intoSurface;
            }
        }

        // 動く床への追従：地面のTransformとPreTransform（前フレーム値）の差分を使う
        if (grounded) {
            Transform@ groundTransform;
            PreTransform@ groundPreTransform;
            if (hit.otherObject.GetComponent(@groundTransform) && hit.otherObject.GetComponent(@groundPreTransform)) {
                groundDelta = groundTransform.GetTranslate() - groundPreTransform.GetPreviousTranslate();
            }
        }

        // 押し戻し
        Transform@ tf = GetTransform();
        if (tf !is null) {
            Vector3 pushBack = hit.normal * hit.penetration;
            pushBack.z = 0.0f;
            if (grounded) pushBack.x = 0.0f;
            tf.SetTranslate(tf.GetTranslate() + pushBack);
        }
    }
}

このメソッドから読み取れる実践的なパターンをいくつか挙げます。

  • hit.otherCollider.GetTag() によるタグ比較でコライダーの種別を判定する（Tag groundColliderTag = Tag("GroundBox"); のようにあらかじめ構築しておいたタグと比較する）
  • hit.otherCollider.IsTrigger() でトリガー判定のコライダーは押し戻し処理から除外する
  • hit.normal * hit.penetration で押し戻しベクトルを作り、Transform へ直接加算して位置補正する
  • 地面側の Transform と PreTransform（前フレームの値）の差分から動く床への追従量を求める（Velocity コンポーネントを直接見るのではなく差分ベースにすることで、地面がスクリプトから直接 Transform を書き換えるような動かし方をしていても正しく追従できる）

シーン変数によるチェックポイント連携

Checkpoint.as は接触時に自身の位置をシーン変数へ保存します。 

// Checkpoint.as
void TrySave(const HitInfo &in hit) {
    if (hit.otherObject is null) return;
    if (hit.otherCollider is null || hit.otherCollider.GetTag() != playerColliderTag) return;

    Transform@ tf = GetTransform();
    Scene@ scene = GetScene();
    if (tf is null || scene is null) return;

    int savedPriority;
    bool hasSaved = scene.GetVariable("CheckpointPriority", savedPriority);
    if (hasSaved && savedPriority > priority) return; // より優先度の高いチェックポイントは上書きしない

    scene.SetVariable("CheckpointPosition", tf.GetTranslate());
    scene.SetVariable("CheckpointPriority", priority);
}

Player.as 側は、HPが尽きたときにこの値を読み出してリスポーンします。 

// Player.as
void CheckDeath() {
    if (currentHp > 0) return;

    Transform@ tf = GetTransform();
    Scene@ scene = GetScene();
    Vector3 respawnPosition;
    bool hasCheckpoint = (scene !is null) && scene.GetVariable("CheckpointPosition", respawnPosition);
    if (tf !is null && hasCheckpoint) {
        tf.SetTranslate(respawnPosition);
    }

    velocity = Vector3(0.0f, 0.0f, 0.0f);
    currentHp = maxHp;
    damageCooldownTimer = damageCooldown; // リスポーン直後の無敵猶予として流用
}

このように、直接の参照関係を持たない2つのオブジェクト（チェックポイントとプレイヤー）が、文字列キーのシーン変数だけを介して疎結合に連携できる点がシーン変数の利点です。GetVariable は値が存在しない・型が一致しない場合に false を返すため、bool hasCheckpoint = ... のように戻り値を必ずチェックしてから使います。詳しくは 04_ObjectSceneVariables.html を参照してください。

被ダメージ演出とMeshRendererの色操作

void UpdateDamageFlash(const float dt) {
    if (damageFlashTimer <= 0.0f) return;
    damageFlashTimer -= dt;

    MeshRenderer@ meshRenderer;
    if (!GetComponent(@meshRenderer)) return;
    bool blinkOn = (int(damageFlashTimer / damageFlashInterval) % 2) == 0;
    if (blinkOn) {
        meshRenderer.SetInstanceColor(damageFlashColor);
        meshRenderer.SetInstanceColorBlendMode(0); // Override
    } else {
        meshRenderer.SetInstanceColor(Vector4(1.0f, 1.0f, 1.0f, 1.0f));
        meshRenderer.SetInstanceColorBlendMode(1); // Multiply（見た目に影響しない）
    }
}

無敵時間中、経過時間をダメージ点滅間隔で割った商の偶奇で点滅させています。MeshRenderer::SetInstanceColorBlendMode は整数でブレンドモード（0=Override, 1=Multiply, 2=Add, 3=Subtract）を指定するため、コメントで意味を残しておくと読みやすくなります。SkinnedMeshRenderer にも同じインスタンスカラーAPIがあるため、スキンメッシュのキャラクターでも同じ手法が使えます（Components/Render/SkinnedMeshRenderer.html）。

サンプルスクリプト全体像

上記の抜粋を踏まえた、最小構成のサンプルです。 

class Player : ScriptComponentBehavior {
    [SerializeField]
    float moveSpeed = 5.0f;

    [SerializeField]
    string jumpSound = "Sounds/jump.wav";

    Velocity@ velocity;

    void Start() {
        Log("Player start: " + GetOwnerObject().GetName());
        GetComponent(@velocity);
    }

    void Update() {
        Transform@ tf = GetTransform();
        if (tf is null) return;

        // 入力コマンドで左右移動
        float moveX = GetCommandValue("MoveX");
        Vector3 pos = tf.GetTranslate();
        pos.x += moveX * moveSpeed * GetDeltaTime();
        tf.SetTranslate(pos);

        // ジャンプ
        if (IsCommandTriggered("Jump") && velocity !is null) {
            velocity.AddVelocity(Vector3(0.0f, 8.0f, 0.0f));
            PlayAudio(jumpSound);
        }
    }

    void OnCollisionEnter(const HitInfo &in hit) {
        if (hit.otherObject !is null && hit.otherObject.GetName() == "Enemy") {
            LogWarning("敵と衝突: penetration=" + hit.penetration);
            GetScene().SetNextSceneName("GameOver");
            GetScene().ChangeToNextScene();
        }
    }

    void End() {
        Log("Player end");
    }
}
