GifSource

同オブジェクトの描画コンポーネント（SpriteRenderer/MeshRenderer等）が参照するテクスチャを、GIFアニメーションで差し替えるコンポーネントです。AudioSourceと同様の再生制御メソッドを持ちます。

メソッド説明
bool Play()再生する
void Stop() / bool Pause() / bool Resume()停止 / 一時停止 / 再開
bool IsPlaying() const / bool IsPaused() const再生中 / 一時停止中かどうか
void SetGifAssetPath(const string &in) / const string &GetGifAssetPath() const使用するGIFアセットのパス
void SetLoop(bool) / bool GetLoop() constループ再生
void SetPlayOnAwake(bool) / bool GetPlayOnAwake() const読み込み時に自動再生するかどうか
