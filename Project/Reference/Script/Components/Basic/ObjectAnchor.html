ObjectAnchor

参照先オブジェクトの範囲（メッシュ・スプライト・テキスト）の中の基準点へ、自身のTransformの位置を毎フレーム追従させるコンポーネントです。基準点は範囲に対する割合で指定し、2D・3Dのどちらにも使えます。

メソッド説明
void SetTargetObject(Object@) / Object@ GetTargetObject() const / string GetTargetObjectID() const参照先オブジェクトの設定/取得。自分自身や自分の子孫を指定した場合は追従しない
void SetBoundsSource(int) / int GetBoundsSource() const範囲の求め方。0=Auto（メッシュ・スプライト→テキスト→Transformの順）、1=Mesh（スプライト含む）、2=Text、3=Transform（1×1×1の箱）
int GetResolvedBoundsSource() const直近の追従で実際に使われた範囲の種類（Auto指定時は解決後の値。値の意味は上と同じ）
void SetAnchorPoint(const Vector3 &in) / const Vector3 &GetAnchorPoint() const範囲内の基準点。(0,0,0)=最小側の角 〜 (1,1,1)=最大側の角の割合（2DではX=左→右、Y=下→上）
void SetOffset(const Vector3 &in) / const Vector3 &GetOffset() const基準点からのオフセット（ワールド単位）
void SetOffsetInTargetSpace(bool) / bool GetOffsetInTargetSpace() consttrueでオフセットを参照先のワールド回転で回してから加える
void SetApplyAxes(bool, bool, bool) / void SetApplyX(bool) / void SetApplyY(bool) / void SetApplyZ(bool) / bool GetApplyX() const 等追従結果を反映する軸（自身の親から見たローカル座標の軸単位）。外した軸は現在の値を保つ
void SetFollowRotation(bool) / bool GetFollowRotation() consttrueで回転も参照先のワールド回転に合わせる
bool TryGetAnchorWorldPosition(Vector3 &out) const現在の設定での追従先（基準点＋オフセット）のワールド座標を求める。参照先が無い、または無効な場合はfalse

使用例

// 体力ゲージ（このオブジェクト）を、敵オブジェクトの頭上（範囲の上辺中央の少し上）に付ける
class HealthBarAnchor : ScriptComponentBehavior {
    void Start() {
        ObjectAnchor@ anchor;
        if (AddComponent(@anchor)) {
            anchor.SetTargetObject(FindObject("Enemy"));
            anchor.SetAnchorPoint(Vector3(0.5f, 1.0f, 0.5f));
            anchor.SetOffset(Vector3(0.0f, 0.3f, 0.0f));
        }
    }
}
