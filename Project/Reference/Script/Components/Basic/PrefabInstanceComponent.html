PrefabInstanceComponent

Prefabインスタンスのサブツリー根にのみ付与される、元のPrefabアセットとの対応関係を示すマーカーコンポーネントです。エディター上でPrefabをシーンへ配置した際に自動で付与され、通常は手動で追加するものではありません。

メソッド説明
string GetPrefabID() const対応するPrefabのIDを文字列で取得する
string GetPrefabPath() const対応するPrefabアセットのソースファイルパスを取得する（エディター実行時限定。未登録時は空文字）
