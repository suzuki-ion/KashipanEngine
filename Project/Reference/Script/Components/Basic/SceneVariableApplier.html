SceneVariableApplier

シーン変数の値を、同オブジェクトの他コンポーネントのパラメータへ適用するコンポーネントです。InputCommandApplier/KeyFrameAnimatorがfloat値のみを扱うのに対し、シーン変数が持つ型（Bool/Int/Float/Double/String/Vector2/3/4/Quaternion/Matrix4x4）をそのままバインド先へ適用できます。

メソッド説明
void SetVariableName(const string &in) / const string &GetVariableName() const読み取るシーン変数名の設定/取得
void SetVariableScope(int) / int GetVariableScope() constシーン変数のスコープ。0=Scene（現在のシーン内でのみ有効） / 1=Global（シーンをまたいで保持される）
bool WasApplied() const前回のUpdateで値の適用に（1件以上）成功したかどうか
