ScriptComponent

AngelScriptのスクリプトファイルをコンパイルして実行するコンポーネントです。

メソッド説明
void SetScriptPath(const string &in) / const string &GetScriptPath() constスクリプトパスの設定/取得
bool Reload()スクリプトを再コンパイルする
bool GetVariable(const string &in, ?&out) const指定名の [SerializeField] 変数の現在値を取得する（04_ObjectSceneVariables.html）
bool SetVariable(const string &in, ?&in)指定名の [SerializeField] 変数へ値を設定する
