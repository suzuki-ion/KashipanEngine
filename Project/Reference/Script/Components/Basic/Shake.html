Shake

オブジェクトを揺らすコンポーネントです。位置・回転それぞれXYZ軸ごとに有効/無効・振れ幅・速度・イージングを設定でき、各軸が独立にランダムな目標値へ向かって遷移し続けることで揺れを表現します。

処理タイミング（ProcessTiming）と適用方法（ApplyTarget）はどちらも整数値の列挙で指定します。

  • ProcessTiming: 0=Immediate（自身のUpdate内でその場処理する） / 1=DeferredEnd（既定。全オブジェクトのUpdate/衝突解決が終わった後にまとめて処理するため、他のスクリプトのTransform操作と競合しない）
  • ApplyTarget: 0=ToTransform（Transformへ直接オフセットを加算する。次フレーム以降は前回分を差し引いてから新しいオフセットを乗せるため、シェイクが終了すれば元のTransformの値に戻る） / 1=RenderOnly（既定。Transform自体は変更せず、描画時にのみオフセットを乗算する）

void Play(float duration = 0.0f)シェイクを開始する。durationを0以下にするとStop()を呼ぶまで無期限に再生する
void Stop()シェイクを停止する（ToTransform適用中だった場合、そのフレームでオフセットが差し引かれ元に戻る）
bool IsPlaying() const再生中かどうか
void SetProcessTiming(int) / int GetProcessTiming() const処理タイミングの設定/取得（上記参照）
void SetApplyTarget(int) / int GetApplyTarget() const適用方法の設定/取得（上記参照）
void SetPositionEnable(bool x, bool y, bool z)位置シェイクを有効にする軸を設定する
void SetPositionAmplitude(const Vector3 &in) / const Vector3 &GetPositionAmplitude() const位置の振れ幅
void SetPositionSpeed(const Vector3 &in) / const Vector3 &GetPositionSpeed() const位置が目標値へ向かう速度
void SetPositionEaseType(int) / int GetPositionEaseType() const位置遷移のイージング種類
void SetRotationEnable(bool x, bool y, bool z)回転シェイクを有効にする軸を設定する
void SetRotationAmplitude(const Vector3 &in) / const Vector3 &GetRotationAmplitude() const回転の振れ幅（度）
void SetRotationSpeed(const Vector3 &in) / const Vector3 &GetRotationSpeed() const回転が目標値へ向かう速度
void SetRotationEaseType(int) / int GetRotationEaseType() const回転遷移のイージング種類
