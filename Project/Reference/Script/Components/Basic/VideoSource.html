VideoSource

同オブジェクトの描画コンポーネント（SpriteRenderer/MeshRenderer等）が参照するテクスチャを、動画で差し替えるコンポーネントです。AudioSourceと同様の再生制御メソッドを持ちます。

メソッド説明
bool Play()再生する
void Stop() / bool Pause() / bool Resume()停止 / 一時停止 / 再開
bool IsPlaying() const / bool IsPaused() const再生中 / 一時停止中かどうか
void SetVideoAssetPath(const string &in) / const string &GetVideoAssetPath() const使用する動画アセットのパス
void SetLoop(bool) / bool GetLoop() constループ再生
void SetVolume(float) / float GetVolume() const音声ボリューム（0.0〜1.0）
void SetPlayOnAwake(bool) / bool GetPlayOnAwake() const読み込み時に自動再生するかどうか
void SetRouteAudioToAudioSource(bool) / bool GetRouteAudioToAudioSource() const動画の音声を同オブジェクトのAudioSource経由で再生する（3D空間音響等に載せたい場合）かどうか
