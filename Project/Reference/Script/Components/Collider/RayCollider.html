RayCollider

レイキャスト専用の3D用コライダーです。常駐形状を持たないためOnCollisionEnter等の衝突イベントは発生しませんが、CastRayを呼ぶとその場でレイキャストできます。コンポーネント共通メソッドと、コライダー共通メソッド（07_ColliderAndPostEffect.html参照）に加えて以下を持ちます。

メソッド説明
GetDirection/SetDirection（Vector3）レイの方向
GetMaxDistance/SetMaxDistance（float）レイの最大距離
bool CastRay(HitInfo &out)Direction/MaxDistanceで決まる経路上をその場でレイキャストし、命中していればtrueを返してhitへ情報を格納する。毎フレームではなく必要なタイミングだけ判定したい用途（照準・索敵等）に使用する
class Gun : ScriptComponentBehavior {
    void Update() {
        RayCollider@ ray;
        if (GetComponent(@ray) && IsCommandTriggered("Fire")) {
            HitInfo hit;
            if (ray.CastRay(hit)) {
                Log("命中: " + hit.otherObject.GetName());
            }
        }
    }
}
