RigidBody3D

ReactPhysics3Dへ委譲する3D用の物理ボディコンポーネントです（RigidBodyがベアボディを所有し、対象のコライダーコンポーネントがシェイプを取り付けます）。

メソッド説明
void SetMass(float) / float GetMass() const質量
void SetUseGravity(bool) / bool IsGravityEnabled() const重力の有効/無効
void SetVelocity(const Vector3 &in) / Vector3 GetVelocity() const速度
void SetSelectedCollider(Collider@) / Collider@ GetSelectedCollider() const同オブジェクトに複数のコライダーが付いている場合に、物理ボディへシェイプとして使うコライダーを選択する（nullを渡すと未選択に戻る）
array<Collider@>@ GetOwnerColliders() const同オブジェクトが持つ全コライダーコンポーネントを取得する（SetSelectedColliderの選択肢の列挙に使う）
void SetBodyType(int) / int GetBodyType() const物理ボディ種別（0:Static 1:Kinematic 2:Dynamic）
void SetInterpolate(bool) / bool IsInterpolateEnabled() const補間の有効/無効
void SyncFromTransform()現在のTransformの位置・回転を物理ボディへ反映する（Play開始時の同期用）
