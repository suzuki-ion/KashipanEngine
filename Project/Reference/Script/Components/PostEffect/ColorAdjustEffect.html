ColorAdjustEffect

ScreenBufferObjectが付与されたオブジェクトに追加すると、そのスクリーンバッファへエフェクトがかかるポストプロセスエフェクトです。

コンポーネント共通メソッドに加えて以下のGet/Setを持ちます。

メソッド
GetBrightness/SetBrightness, GetContrast/SetContrast, GetSaturation/SetSaturation, GetTemperature/SetTemperature（すべてfloat）, GetColorBalance/SetColorBalance（Vector3）
