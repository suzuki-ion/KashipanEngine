VignetteEffect

ScreenBufferObjectが付与されたオブジェクトに追加すると、そのスクリーンバッファへエフェクトがかかるポストプロセスエフェクトです。

コンポーネント共通メソッドに加えて以下のGet/Setを持ちます。

メソッド
GetCenter/SetCenter（Vector2）, GetColor/SetColor（Vector4）, GetIntensity/SetIntensity, GetInnerRadius/SetInnerRadius, GetSmoothness/SetSmoothness（float）
