CameraController2D

CameraControllerの2D版で、同一オブジェクトのCamera2Dを追従先へ滑らかに追従させます。追従に使うのは位置X/Yと画面内回転（Z軸）のみで、画角の代わりにwidth/height（表示範囲＝ズーム相当）の遷移を扱います。

メソッド説明
bool IsControllable() const同オブジェクトに Camera2D があるかどうか
void AddFollowTarget(Object@)追従先オブジェクトを追加する
void RemoveFollowTarget(uint index)追従先オブジェクトをインデックス指定で削除する
uint GetFollowTargetCount() const追従先オブジェクトの数を取得する
Object@ GetFollowTargetObject(uint index) const追従先オブジェクトをインデックス指定で取得する
void SetFollowPositionEnable(uint index, bool x, bool y) / void GetFollowPositionEnable(uint index, bool &out, bool &out) const位置追従の軸（X/Y）を設定/取得する
void SetFollowRotationEnable(uint index, bool) / bool GetFollowRotationEnable(uint index) const回転追従（画面内回転＝Z軸）の有効/無効を設定/取得する
void SetPositionOffset(const Vector2 &in) / const Vector2 &GetPositionOffset() const位置オフセット
void SetRotationOffset(float) / float GetRotationOffset() const回転オフセット（ラジアン、画面内回転＝Z軸のみ）
void SetTargetSize(const Vector2 &in) / const Vector2 &GetTargetSize() const目標のwidth/height（ズーム相当）
void SetMoveStrength(float) / float GetMoveStrength() const移動追従の強さ（0.0〜1.0）
void SetMoveStrengthPerAxis(const Vector2 &in) / Vector2 GetMoveStrengthPerAxis() const軸ごとの移動追従の強さ
void SetMoveStrengthUsePerAxis(bool) / bool GetMoveStrengthUsePerAxis() const移動追従の強さを軸ごとに使うかどうか
void SetRotateLerpFactor(float) / float GetRotateLerpFactor() const回転追従の強さ（0.0〜1.0）
void SetSizeLerpFactor(float) / float GetSizeLerpFactor() constサイズ遷移の強さ（0.0〜1.0）
