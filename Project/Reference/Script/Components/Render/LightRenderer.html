LightRenderer

同一オブジェクトのLightを実際に描画へ反映させるコンポーネントです。

メソッド説明
void SetPipelineName(const string &in) / const string &GetPipelineName() const使用パイプライン名
LightType GetLightType() const同オブジェクトの Light の種別を取得する
Light@ GetLight() const同オブジェクトの Light コンポーネントを取得する
Vector3 GetWorldPosition() constワールド座標を取得する
Vector3 GetWorldDirection() constワールド方向（+Z、発光面の法線。Boxは奥行き軸）を取得する
Vector3 GetWorldRight() constワールド右方向（+X、Rect/Boxの幅・Tubeの軸方向）を取得する
Vector3 GetWorldUp() constワールド上方向（+Y、Rect/Boxの高さ方向）を取得する
