NormalWindowObject

通常のOSウィンドウを1つ生成・管理するコンポーネントです。独自のメソッドは追加せず、WindowObject基底型の共通メソッドをそのまま持ちます。

WindowObject基底型の共通メソッド（SetTitle/SetSize/OnWindowMessage・メッセージの横取り等）は06_RenderAndWindow.htmlを参照してください。以下は独自メソッドを持たない具体的な実装です。
