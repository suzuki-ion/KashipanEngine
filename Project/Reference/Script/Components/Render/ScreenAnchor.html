ScreenAnchor

同一オブジェクトのTransformを、指定したCamera2Dの画面（width/height）上の基準点へ毎フレーム追従させるコンポーネントです。UI要素を画面端やコーナーに固定し、解像度が変化しても正しい位置を保ちたい場合に使います。対象のCamera2D側でSetAutoSyncSizeを有効にしておけば、描画先の解像度変化にも連動します。

メソッド説明
void SetCameraObject(Object@) / Object@ GetCameraObject() const / string GetCameraObjectID() const基準にするCamera2Dを持つオブジェクトの設定/取得
void SetAnchorPoint(const Vector2 &in) / const Vector2 &GetAnchorPoint() const画面上の基準点。(0,0)=画面左下 〜 (1,1)=画面右上の正規化座標
void SetOffset(const Vector2 &in) / const Vector2 &GetOffset() const基準点からのオフセット（Camera2Dのワールド単位＝Y上方向が正）
