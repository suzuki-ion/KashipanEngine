ScreenBufferViewport

ScreenBufferObject（オフスクリーン）の内容を、指定した描画先（Windowなど）へ2Dスプライトとして表示するコンポーネントです。内部でMeshFilter（"Rect2D"固定）とSpriteRendererを自動生成・管理し、新規の描画コードは持たず既存のSpriteRenderer描画パイプラインにそのまま乗せる薄いラッパーです。

メソッド説明
void SetSourceObject(Object@) / Object@ GetSourceObject() const / string GetSourceObjectID() const表示するScreenBufferObjectを持つオブジェクトの設定/取得
void SetDisplayCameraObject(Object@) / Object@ GetDisplayCameraObject() const / string GetDisplayCameraObjectID() constマウス座標変換の基準にするCamera2Dを持つオブジェクトの設定/取得
SpriteRenderer@ GetSpriteRenderer() const / MeshFilter@ GetMeshFilter() const内部で自動生成しているSpriteRenderer/MeshFilterを取得する（表示先の指定はGetSpriteRenderer().SetTargetObject()で行う）
void SetFitMode(int) / int GetFitMode() const描画先の解像度に対する自動フィット方法。0=None（何もしない） / 1=Stretch（アスペクト比を無視して描画先いっぱいに引き伸ばす） / 2=Letterbox（アスペクト比を保ったまま収まる最大サイズにする）。None以外を指定した場合、毎フレーム自身のTransform.Scale（X/Yのみ）を自動で書き換える
bool TryGetOffscreenMousePosition(Vector2 &out)表示先ウィンドウ上のマウス座標を、ソースScreenBufferObjectの解像度基準のピクセル座標（左上原点、X右・Y下方向）へ変換する。変換に成功し、かつマウスがスプライトの表示範囲内にある場合にtrueを返す
bool IsMouseOverOffscreen() constマウスカーソルが表示範囲内にあるかどうか
