ShadowMapObject

シャドウマップ専用のバッファ（ShadowMapBuffer）を1枚所有し、描画先として扱えるようにするコンポーネントです。ScreenBufferObjectとよく似ていますが、画像ファイル保存機能はありません。

メソッド説明
void SetName(const string &in) / const string &GetName() const管理用名前の設定/取得
void SetSize(uint width, uint height)バッファをリサイズする
