InstanceColorはMeshRenderer/SkinnedMeshRendererの両方に対応
SkinnedMeshRenderer にもインスタンスカラー（アルファ値のブレンドを含む）が実装されています。被ダメージ時の点滅演出など、色を一時的に上書き/合成したい場合に SetInstanceColor と SetInstanceColorBlendMode を組み合わせて使用してください。実例は 11_PlayerExample.html の被ダメージ演出を参照してください。
InstanceUv系はTextRendererには無い
MeshRenderer/SpriteRenderer/SkinnedMeshRendererのInstanceUv系メソッドは、マテリアルのuvTranslate等と合成されるUV変換行列を経由する。TextRendererはUV変換を使わず文字ごとのUV矩形（フォントアトラス参照）を直接使うため対象外。マテリアル側のUV変換とインスタンス側のUV変換の合成方法（UV Combine Mode）の詳細はEditor/Components/Render/SpriteRenderer.htmlを参照。
