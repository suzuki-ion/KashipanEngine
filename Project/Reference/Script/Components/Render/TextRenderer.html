TextRenderer

文字列を描画するコンポーネントです。

メソッド説明
void SetText(const string &in) / const string &GetText() const表示文字列の設定/取得
void SetMaterialName(const string &in)使用マテリアル名（テクスチャとUVはフォント側で上書き）
void SetInstanceColor(const Vector4 &in) / void SetInstanceColorBlendMode(int)マテリアル色へ適用するインスタンスカラー
void SetOutlineWidth(float) / void SetOutlineColor(const Vector4 &in)文字アウトラインの太さと色（水平/垂直揃えは TextHorizontalAlign/TextVerticalAlign 列挙）
InstanceUv系はTextRendererには無い
MeshRenderer/SpriteRenderer/SkinnedMeshRendererのInstanceUv系メソッドは、マテリアルのuvTranslate等と合成されるUV変換行列を経由する。TextRendererはUV変換を使わず文字ごとのUV矩形（フォントアトラス参照）を直接使うため対象外。マテリアル側のUV変換とインスタンス側のUV変換の合成方法（UV Combine Mode）の詳細はEditor/Components/Render/SpriteRenderer.htmlを参照。
