チュートリアル: シーンを作ってキャラクターを動かすまで

このチュートリアルでは、空のシーンを作るところから、オブジェクトを配置し、当たり判定を付け、AngelScriptでキャラクターを動かし、シーンを切り替えるところまでを、実際の手順に沿って一通り体験します。

前提知識

各手順では詳細を説明しすぎず、必要に応じて詳しいAPIリファレンスへリンクしています。まったくの初見でも進められますが、先に 01_Overview.html(エンジン概要)に目を通しておくと理解が早くなります。

このエンジンの基本的な考え方
KashipanEngineでは、シーンの内容(オブジェクト配置)はJSONとして保存され、通常はシーンエディタ(ImGuiベース、USE_IMGUIマクロが有効なDebug/Development構成でのみ利用可)で編集します。ゲームロジックはC++ではなくAngelScriptで書きます。このチュートリアルもその流れに沿って進めます。

目次

#タイトル内容
1シーンを作成する新しいシーンを作り、その保存形式(scene.json / object.json)を理解する
2シーンを登録するSceneList.jsonへの登録と、起動シーンの指定
3オブジェクトを作成するシーンにEmptyObjectを追加し、名前を付ける
4コンポーネントを追加するTransform・MeshFilter・MeshRendererを付けてオブジェクトを描画する
5当たり判定を付けるBoxColliderを追加し、タグと衝突判定の基礎を理解する
6スクリプトを書くAngelScriptファイルを作成し、ScriptComponentとしてアタッチする
7入力を設定するInputCommandでアクションを定義し、スクリプトから参照する
8アセットを読み込むテクスチャ・モデル・オーディオをコンポーネントに設定する
9シーンを切り替えるスクリプトやC++からシーン遷移を行う

準備ができたら、1. シーンを作成する から始めましょう。
