1. シーンを作成する

まずはゲームの舞台となる「シーン」を新規作成します。詳しいAPIは 02_Scenes.html を参照してください。

シーンエディタから作成する(推奨)

USE_IMGUIが有効なビルド(Debug/Development構成)でエンジンを起動すると、シーンエディタが利用できます。エディタの「Scene List」ウィンドウから新規シーンを作成すると、以下のファイルが自動生成されます。 

Assets/Scenes/<シーン名>.scene/
└── scene.json          … シーン自体の情報(シーンコンポーネント・シーン変数)
    (Objects/ フォルダはオブジェクトを追加すると作られる)

シーンJSONの中身

1シーン1フォルダの形式で、シーン直下の情報は scene.json に、各オブジェクトは Objects/<オブジェクトのUUID>/object.json に個別保存されます。複数人でシーンを編集しても、別々のオブジェクトを触っている限りファイルがコンフリクトしにくいのが利点です。実際の scene.json は次のような形です。 

{
    "sceneComponents": [
        { "type": "SceneRenderer",        "data": { "data": {}, "isActive": true, "priority": 1000, "tag": "" } },
        { "type": "SceneObjectCollider",  "data": { "data": {}, "isActive": true, "priority": 1,    "tag": "" } },
        { "type": "SceneScriptEngine",    "data": { "data": {}, "isActive": true, "priority": 1,    "tag": "" } },
        { "type": "SceneAudioPlayer",     "data": { "data": {}, "isActive": true, "priority": 500,  "tag": "" } },
        { "type": "ScenePreTransform",    "data": { "data": {}, "isActive": true, "priority": 1001, "tag": "" } }
    ],
    "sceneID": "75d12f47-b107-4a8e-88fb-217a67e2a17f",
    "sceneName": "GameScene",
    "sceneVariables": []
}

sceneComponentsには、そのシーンで使う機能(描画・当たり判定・スクリプト実行・オーディオ再生など)がシーンコンポーネントとして登録されています。新規シーンを作成すると、多くの場合これらの標準コンポーネントが最初から入った状態になります(詳細は02_Scenes.htmlのシーンコンポーネント一覧を参照)。sceneVariablesは、後述するスクリプト間で共有できるシーン変数の初期値です。

旧形式について
過去のバージョンでは1シーン1ファイル(Assets/Scenes/GameScene.jsonのような単一JSON)で保存していました。現在はこのバックアップ形式としてのみ残っており、通常はフォルダ形式(*.scene/)を使います。

コードから登録する場合

シーンはC++クラスとして継承して作るものではありません(Sceneクラスはfinalです)。既存のシーンJSONファイルをそのまま使う場合、あとでシーンの登録のときにSceneManager::RegisterSceneFileで紐付けます。
