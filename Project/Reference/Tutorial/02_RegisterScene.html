2. シーンを登録する

作成したシーンをエンジンに認識させ、起動時に読み込めるようにします。

SceneList.json への登録

シーンの一覧は既定で Assets/KashipanEngine/SceneList.json に保存されています。シーンエディタの「Scene List」ウィンドウで新規シーンを作成すると自動的にここへ追記されますが、中身は次のような単純なJSONです。 

{
    "scenes": [
        { "name": "GameScene", "filePath": "Assets/Scenes/GameScene.json" },
        { "name": "TestScene", "filePath": "Assets/Scenes/TestScene.json" }
    ],
    "startupScene": "GameScene"
}

nameはシーンを参照するときに使う識別子、filePathは読み込み元のファイル(またはフォルダ形式の*.scene)、startupSceneはゲーム起動時に最初に読み込まれるシーン名です。

コードから登録する

Application/AppInitialize.hの中で、GameEngine::Context経由でSceneManagerにアクセスし、コードから登録することもできます。 

#pragma once
#include <KashipanEngine.h>

namespace KashipanEngine {
inline void AppInitialize(const GameEngine::Context &context) {
    // 既存のシーンJSON/フォルダをシーン名に紐付けて登録する
    context.sceneManager->RegisterSceneFile("GameScene", "Assets/Scenes/GameScene.scene");

    // ファイルを介さず、JSONデータを直接渡して登録することもできる
    // context.sceneManager->RegisterScene("TitleScene", someFactoryDataJson);
}
}
