3. オブジェクトを作成する

シーンの中に、ゲームオブジェクトの入れ物である EmptyObject を1つ作成します。詳しいAPIは 03_GameObjects.html を参照してください。

シーンエディタでの作成

シーンエディタの Hierarchy(オブジェクト階層)ウィンドウ上で右クリックし「Create Empty Object」のような操作を行うと、名前のない空のオブジェクトがシーンへ追加されます。追加した後、名前を「Player」のようにわかりやすく変更しておきましょう。

保存されるファイル

オブジェクトを1つ作成すると、シーンフォルダの下に Objects/<新しいUUID>/object.json が新しく作られます。中身はこの時点ではまだコンポーネントを何も持たない、最小限の状態です。 

{
    "object": {
        "components": [],
        "editorOnly": false,
        "isActive": true,
        "name": "Player",
        "objectID": "3f6c1a2e-....",
        "tag": ""
    },
    "siblingIndex": 0
}

objectIDはUUID128で自動採番され、以降このオブジェクトを一意に識別するために使われます(親子関係の指定など、他のコンポーネントから参照される際もこのIDが使われます)。siblingIndexはヒエラルキー内での並び順です。

C++視点での対応API

これはエディタの内部的には次のAPI呼び出しに相当します(通常は直接呼ぶ必要はありません)。

EmptyObject *CreateEmptyObject(const std::string &name = "", const UUID128 &objectID = UUID128(), size_t index = MAXSIZE_T);
この時点ではまだ何も表示されない
コンポーネントを1つも持たないオブジェクトは、画面には何も描画されません。次の 4. コンポーネントを追加する でTransformと描画コンポーネントを追加します。
