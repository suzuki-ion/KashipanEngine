4. コンポーネントを追加する

作成したオブジェクトに、位置を持たせるTransformと、実際に画面へ表示するための描画コンポーネントを追加します。詳しいAPIは 04_ObjectComponents.html と 05_Rendering.html を参照してください。

Transformを追加する

Inspector(コンポーネントインスペクタ)ウィンドウの「Add Component」メニューから Transform を選びます。REGISTER_COMPONENT_OBJECT マクロで登録されているコンポーネントは、このメニューに自動的に列挙されます(詳細は04_ObjectComponents.html)。 

{
    "type": "Transform",
    "data": {
        "customData": {
            "translate": { "x": 0.0, "y": 1.0, "z": 0.0 },
            "rotate":    { "x": 0.0, "y": 0.0, "z": 0.0, "w": 1.0 },
            "scale":     { "x": 1.0, "y": 1.0, "z": 1.0 }
        },
        "isActive": true,
        "priority": 1,
        "tag": ""
    }
}

見た目を付ける: MeshFilter + MeshRenderer

3Dオブジェクトとして表示するには、どの形状を使うかを指定する MeshFilter と、実際に描画する MeshRenderer の組が必要です。MeshFilterには組み込みのプリミティブ形状(例: PrimitiveMesh-Box, PrimitiveMesh-UVSphere)か、読み込んだモデルのアセットパスを指定します。 

{
    "type": "MeshFilter",
    "data": { "customData": { "meshAssetPath": "PrimitiveMesh-Box" }, "isActive": true, "priority": 1, "tag": "" }
},
{
    "type": "MeshRenderer",
    "data": {
        "customData": {
            "materialName": "White",
            "pipelineName": "Object3D.Solid.BlendNormal",
            "targetObjectID": ""
        },
        "isActive": true,
        "priority": 900,
        "tag": ""
    }
}

pipelineNameには Assets/KashipanEngine/ 配下で定義されているパイプライン名を指定します。materialNameは 09_Assets.html のMaterialManagerで管理されているマテリアル名です。

C++視点での対応API

EmptyObject *player = scene->GetSceneObject("Player"); Transform *transform = player->AddComponent<Transform>(); transform->SetTranslate(Vector3(0.0f, 1.0f, 0.0f)); MeshFilter *meshFilter = player->AddComponent<MeshFilter>(); MeshRenderer *meshRenderer = player->AddComponent<MeshRenderer>(); meshRenderer->SetMaterialName("White"); meshRenderer->SetPipelineName("Object3D.Solid.BlendNormal");
2Dの場合
2D表示をしたい場合はMeshRendererの代わりにSpriteRendererやTextRendererを使います。詳細は05_Rendering.htmlを参照してください。
