4. コンポーネントを追加する

Playerへ位置と見た目を追加し、Scene Viewに3Dオブジェクトを表示します。

操作: Inspector / Scene View追加: Transform・MeshFilter・MeshRenderer目安: 5分

すぐ表示できる3Dオブジェクトを作る

最初は必要なコンポーネントがまとまったテンプレートを使うのが簡単です。前ページの空Playerを残して確認したい場合は、ここで作るオブジェクトをPlayerVisualとしてください。

  1. 3Dテンプレートを作るHierarchyの空白を右クリックし、Create Object›3D›Mesh Object を選びます。
  2. 名前をPlayerVisualへ変更する作成された項目を選び、Inspector上部のNameをPlayerVisualへ変更します。
  3. Transformを調整するTransformのTranslateを(0, 1, 0)、Scaleを(1, 1, 1)にします。
  4. Scene Viewで確認する選択中オブジェクトへギズモが表示されます。上部のTranslate / Rotate / Scaleで操作を切り替えられます。

各コンポーネントの役割

コンポーネント役割このページの設定
Transform位置・回転・大きさTranslate Yを1
MeshFilter描画するメッシュ形状PrimitiveMesh-Boxなど
MeshRendererマテリアルとパイプラインを使って描画既定値のまま開始

空のPlayerへ個別に追加する場合

  1. HierarchyでPlayerを選択します。
  2. Inspector下部のAdd Componentを押します。
  3. メニューからTransform、MeshFilter、MeshRendererを1つずつ追加します。
  4. MeshFilterのMesh Asset PathとMeshRendererの設定を、テンプレートで作ったPlayerVisualを参考に揃えます。
まずテンプレート、あとで個別追加
Mesh Objectは表示に必要な構成をまとめて作れます。個別のAdd Componentは、既存オブジェクトへ機能を足すときや構成を学ぶときに便利です。

うまく表示されないとき

  • Scene View上部でグリッドが見える位置までカメラを移動する
  • MeshFilterにメッシュが設定されていることを確認する
  • MeshRendererとTransformのActiveが有効になっていることを確認する
  • シーンにSceneRendererが登録されていることを確認する

各パラメーターと描画の詳細はオブジェクトコンポーネントと描画のリファレンスを参照してください。
