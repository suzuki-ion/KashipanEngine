5. 当たり判定を付ける

オブジェクトに BoxCollider を追加し、地面との当たり判定の土台を作ります。詳しいAPIは 06_Collision.html を参照してください。

BoxColliderを追加する

「地面」役のオブジェクトにBoxColliderを追加し、後でスクリプトから判別できるようにタグを付けます。実際のプロジェクトの地面オブジェクトでは、次のような設定になっています。 

{
    "type": "BoxCollider",
    "data": {
        "customData": {
            "center": { "x": 0.0, "y": 0.0, "z": 0.0 },
            "size":   { "x": 1.0, "y": 1.0, "z": 1.0 },
            "isTrigger": false,
            "continuousDetection": false,
            "syncPosition": [true, true, true],
            "syncRotation": [true, true, true],
            "syncScale":    [true, true, true]
        },
        "isActive": true,
        "priority": 1,
        "tag": "GroundBox"
    }
}

tagにはコンポーネント全体の共通プロパティであるTagを設定できます。ここでは "GroundBox" というタグを付けています。isTriggerをtrueにすると、押し戻し(物理的な反発)を行わず衝突の通知だけを受け取れるトリガー判定になります。

C++視点での対応API

EmptyObject *ground = scene->GetSceneObject("Ground"); BoxCollider *collider = ground->AddComponent<BoxCollider>(); collider->SetTag("GroundBox"); // サイズ・トリガー設定など、詳細は 06_Collision.html を参照

衝突の受け取り方の予告

コライダーの衝突結果はHitInfo構造体として通知されます。次の6. スクリプトを書くで、このタグを使って「今触れているのはさっき作った地面かどうか」を判定するコードを実際に書きます。 

// ScriptComponentBehavior 内(AngelScript)
Tag groundColliderTag = Tag("GroundBox");

void OnCollisionStay(const HitInfo &in hit) {
    if (hit.otherCollider.GetTag() == groundColliderTag) {
        // 地面と接地している
    }
}
