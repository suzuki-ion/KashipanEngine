6. スクリプトを書く

ここからが本番です。AngelScriptファイルを作成し、ScriptComponentとしてオブジェクトにアタッチして、実際に動くロジックを書きます。詳しいAPIは 07_Scripting.html を参照してください。

1. スクリプトファイルを作成する

Assets/Application/Scripts/ フォルダに、新しい .as ファイルを作成します。ここでは SimpleMover.as という名前にします。 

// Assets/Application/Scripts/SimpleMover.as
class SimpleMover : ScriptComponentBehavior {
    [SerializeField, Tooltip("移動速度")]
    float moveSpeed = 2.0f;

    void Update() {
        const float dt = GetDeltaTime() * GetGameSpeed();

        float moveDirection = 0.0f;
        if (IsCommandTriggered("MoveLeft"))  moveDirection -= GetCommandValue("MoveLeft");
        if (IsCommandTriggered("MoveRight")) moveDirection += GetCommandValue("MoveRight");

        Transform@ tf = GetTransform();
        Vector3 pos = tf.GetTranslate();
        pos.x += moveDirection * moveSpeed * dt;
        tf.SetTranslate(pos);
    }

    void OnCollisionStay(const HitInfo &in hit) {
        if (hit.otherCollider.GetTag() == Tag("GroundBox")) {
            // 地面に触れている間の処理
        }
    }
}

1つの.asファイルには、ScriptComponentBehaviorを継承したクラスを1つ定義します。Update()やOnCollisionStay()のようなメソッドは、エンジン側から自動的に呼ばれるライフサイクル関数です(一覧は07_Scripting.html)。

2. ScriptComponentをアタッチする

オブジェクトのInspectorから「Add Component」→ScriptComponentを選び、Script Pathに作成したファイルを指定します。保存されるJSONは次のようになります。 

{
    "type": "ScriptComponent",
    "data": {
        "customData": {
            "scriptPath": "Assets\\Application\\Scripts\\SimpleMover.as",
            "fields": {
                "moveSpeed": 2.0
            }
        },
        "isActive": true,
        "priority": 1,
        "tag": ""
    }
}

[SerializeField]を付けたメンバ変数はfieldsとしてシーンJSONに保存され、インスペクタから直接調整できます。[Tooltip("...")]などの属性はエディタでの見た目を補足するだけで、値の保存には影響しません。

3. 動作確認と再コンパイル

スクリプトを編集して保存した後は、ScriptComponent::Reload()(エディタ上では通常「Reload」ボタンなどに対応)で再コンパイルできます。[SerializeField]で保存済みの値は、変数名が一致していればリロード後も保持されます。構文エラーがある場合はGetLastError()でエラー内容を確認できます。

実例を読む
実際のプロジェクトにある Assets/Application/Scripts/Player.as は、移動・ジャンプ・坂道判定・被ダメージ・チェックポイント復帰まで実装した実例です。07_Scripting.html で解説しています。
