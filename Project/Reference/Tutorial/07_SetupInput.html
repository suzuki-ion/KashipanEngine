7. 入力を設定する

前の手順で使った "MoveLeft" / "MoveRight" という入力アクション名を、実際のキーに割り当てます。詳しいAPIは 08_Input.html を参照してください。

InputCommandでアクションを登録する

KashipanEngineの入力は、キーやボタンを直接見るのではなく、"MoveLeft"のようなアクション名を経由してマッピングするInputCommandの仕組みを使うのが基本です。Application/AppInitialize.hで登録できます。 

#pragma once
#include <KashipanEngine.h>

namespace KashipanEngine {
inline void AppInitialize(const GameEngine::Context &context) {
    context.inputCommand->RegisterCommand("MoveLeft",  Key::A,     InputState::Down);
    context.inputCommand->RegisterCommand("MoveRight", Key::D,     InputState::Down);
    context.inputCommand->RegisterCommand("MoveLeft",  Key::Left,  InputState::Down); // 同じアクションに複数キーを割り当ててもよい
    context.inputCommand->RegisterCommand("MoveRight", Key::Right, InputState::Down);
}
}

InputStateにはDown(押している間)、Trigger(押した瞬間)、Release(離した瞬間)があります。移動のような継続入力にはDown、ジャンプのような単発入力にはTriggerを使うのが典型的です。

設定の保存・読み込み

登録した内容は既定でAssets/KashipanEngine/InputCommand.jsonに保存・復元できます(InputCommand::SaveToJSON / LoadFromJSON)。一度設定したコマンド定義はこのファイルとして永続化されるため、次回起動時に再登録しなくても復元されます。

スクリプトから参照する

前の手順のSimpleMover.asで書いた次のコードは、まさにこのInputCommandのアクションをAngelScript側から参照しています。 

if (IsCommandTriggered("MoveLeft"))  moveDirection -= GetCommandValue("MoveLeft");
if (IsCommandTriggered("MoveRight")) moveDirection += GetCommandValue("MoveRight");

IsCommandTriggeredはそのフレームで条件を満たしたかどうか、GetCommandValueは入力の強さ(キーなら通常1.0、アナログスティックなら0.0〜1.0の値)を返します。
