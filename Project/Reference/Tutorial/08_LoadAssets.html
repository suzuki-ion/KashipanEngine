8. アセットを読み込む

見た目や音を差し替えるために、モデル・テクスチャ・オーディオといったアセットを読み込んでコンポーネントに設定します。詳しいAPIは 09_Assets.html を参照してください。

共通パターン: パス → ハンドル → コンポーネント

KashipanEngineの各種アセットマネージャ(TextureManager, ModelManager, AudioManagerなど)は、いずれも「アセットのパスを渡してハンドル(軽量な識別子)を受け取り、そのハンドルをコンポーネントに設定する」という共通の使い方をします。

モデルを読み込んで表示する

Assets/Application/Model/配下に置いたモデルファイルを、MeshFilterのmeshAssetPathに指定するだけで表示できます(4. コンポーネントを追加するで使ったプリミティブ形状の代わりに、実際のモデルファイルパスを指定するイメージです)。 

{
    "type": "MeshFilter",
    "data": { "customData": { "meshAssetPath": "Assets/Application/Model/Character/Character.gltf" }, "isActive": true, "priority": 1, "tag": "" }
}

オーディオを再生する

効果音やBGMはAudioManager::Loadでハンドルを取得し、AudioManager::Playで再生します。オブジェクトに紐付いた音源として扱いたい場合はAudioSourceコンポーネントを使います。 

// C++側での一例(通常はAudioSourceコンポーネント経由で使うことが多い)
SoundHandle jumpSe = AudioManager::Load("Assets/Application/Sound/Jump.wav");
AudioManager::PlayParams params;
params.handle = jumpSe;
PlayHandle handle = AudioManager::Play(params);
AudioManager::SetVolume(handle, 0.8f);

AngelScript側からもオーディオ再生APIが公開されているため、スクリプトのイベント(例えばジャンプした瞬間)に合わせて効果音を鳴らすといったことも可能です。詳細は09_Assets.htmlと07_Scripting.htmlを参照してください。

テクスチャを使う

2DのSpriteRendererや、モデルのマテリアルに使うテクスチャはTextureManagerで読み込みます。シーンエディタからマテリアルにテクスチャを割り当てる場合は、MaterialManagerで管理されているマテリアル設定の中でテクスチャパスを指定します。

アセットの置き場所
ゲーム側のアセットはAssets/Application/配下(Image, Model, Sound, Scripts等)に、エンジンの既定アセット(フォント・パイプライン定義など)はAssets/KashipanEngine/配下に置かれています。
