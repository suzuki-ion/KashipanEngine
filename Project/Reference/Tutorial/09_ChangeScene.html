9. シーンを切り替える

最後に、今作ったシーンから別のシーンへ切り替える方法を確認します。詳しいAPIは 02_Scenes.html を参照してください。

方法1: Sceneから次のシーンを予約する

Sceneクラスには「次のフレームで切り替えるシーン」を予約する仕組みがあります。スクリプトやゲームロジックの中から呼びやすい方法です。

void SetNextSceneName(const std::string &nextSceneName); bool ChangeToNextScene();
// C++からの例
scene->SetNextSceneName("ResultScene");
scene->ChangeToNextScene();

方法2: SceneManagerから直接切り替える

bool ChangeScene(const std::string &sceneName); bool HasPendingSceneChange() const;
context.sceneManager->ChangeScene("ResultScene");
切り替えは次フレーム反映
ChangeSceneを呼んだ瞬間にシーンが切り替わるわけではありません。呼び出した時点では「切り替え予約」がされるだけで、実際の切り替えは次のフレームの更新タイミングで行われます。同一フレーム内で切り替え後のシーンの状態を期待するコードは書けないので注意してください。HasPendingSceneChange()で予約状態を確認できます。

スクリプトから切り替える

AngelScript側ではGetScene()で現在のScene@を取得できるため、そこから同様にシーン変数の読み書きやシーン遷移の指示を行えます。例えば「プレイヤーがゴールに触れたらリザルトシーンへ」という処理は、ゴール判定用のオブジェクトに付けたスクリプトのOnCollisionEnter内で呼び出す形になります。 

void OnCollisionEnter(const HitInfo &in hit) {
    if (hit.otherCollider.GetTag() == Tag("Player")) {
        Scene@ scene = GetScene();
        if (scene !is null) {
            scene.SetNextSceneName("ResultScene");
            scene.ChangeToNextScene();
        }
    }
}
