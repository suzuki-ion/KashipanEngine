12. シーンを切り替える

Play モードで完成した操作を確認し、Scene List とスクリプトを使ったシーン遷移まで仕上げます。

操作の起点: Scene Editor / Scene List完成条件: Play とシーン遷移を確認

1. Play モードで完成状態を確認する

  1. Scene Editor の Play を押します。
  2. A / D キーによる Player の移動、Collider、描画を確認します。
  3. 必要に応じて Pause と Step Frame で 1 フレームずつ挙動を追います。
  4. 確認後は Stop を押して編集状態へ戻ります。
Play 中の変更は検証用です。Stop すると Play 開始前の編集状態へ戻るため、恒久的な調整は停止後に行ってシーンを保存してください。

2. 切り替え先を Scene List で確認する

  1. Window → Scene List を開きます。
  2. 遷移先のシーンが登録済みであることを確認します。未登録なら 2. シーンを登録する の手順で追加します。
  3. 一覧の Switch で手動切り替えを試し、対象シーンが正しく開くことを確認します。

3. スクリプトから切り替える

ゴール用オブジェクトの ScriptComponent で、衝突時に次のシーンを予約します。ResultScene は Scene List に登録した実際のシーン名へ置き換えてください。

void OnCollisionEnter(const HitInfo &in hit) {
    if (hit.otherCollider.GetTag() == Tag("Player")) {
        Scene@ scene = GetScene();
        if (scene !is null) {
            scene.SetNextSceneName("ResultScene");
            scene.ChangeToNextScene();
        }
    }
}
シーン遷移は次フレームで反映されます。
ChangeToNextScene() を呼んだ同じフレーム内で、切り替え後のシーンへアクセスしないでください。

完成チェック

  • シーンを作成し、Scene List に登録できた
  • オブジェクト、描画コンポーネント、Collider をエディターで設定できた
  • ScriptComponent と Input Command Editor で操作を追加できた
  • Assets を割り当て、Play モードで実行結果を確認できた
  • 別シーンへの切り替えを実装できた

各機能の型、引数、保存形式は API リファレンス から確認できます。
