12. ライトオブジェクトを作成する

Light Objectを追加し、光の種類・色・強さ・影と、ライトを適用する描画先を設定します。

操作の起点: Create Object → 3D追加: Light・LightRenderer描画先: MainScreen

1. Light Objectを作成する

  1. ライトテンプレートを選ぶHierarchyの空白を右クリックし、Create Object›3D›Light Object を選択します。
  2. 名前を変更するInspector上部のNameをKeyLightへ変更します。
  3. 向きを調整するDirectional、Spot、Rect、DiscではTransformのローカル+Z方向が光の向きになります。Scene Viewのライト表示を見ながらRotateを調整します。

2. Lightを設定する

Light ObjectテンプレートにはTransform、Light、LightRendererが自動で追加されます。最初はシーン全体を照らしやすいDirectionalから始めます。

  1. LightのTypeをDirectionalにします。
  2. Colorを白に、Intensityを1.0にします。
  3. Scene View上部のLightsを有効にし、ライトのアイコンと方向線を確認します。

ライトの種類

Type用途主に調整する項目
Directional太陽光のようにシーン全体を一定方向から照らすTransformのRotate、Intensity
Point電球のように一点から全方向へ照らすTranslate、Radius、Decay
Spotスポットライトのように円錐状に照らすDistance、Inner Angle、Outer Angle
Rect / Disc窓や面照明のような片面発光Distance、Source Width・HeightまたはRadius
Sphere / Tube / Box形状と大きさを持つ全方向または体積的な光源Radius、Source Size、Decay

3. LightRendererへ描画先を設定する

  1. LightRendererを展開します。
  2. TargetからMainScreenを選択します。
  3. Pipelineは空欄のまま全パイプラインへ適用するか、照明対象と同じObject3D.Solid.BlendNormalを選択します。
  4. MainScreen ViewerまたはPlayモードで、ライトのActiveを切り替えたときに明るさが変わることを確認します。

4. 影を有効にする

  1. Light内のShadowセクションでCast Shadowsを有効にします。
  2. Shadow Resolutionは最初に1024または2048を選択します。
  3. 影が表面から浮く場合はShadow Biasを下げ、縞状の影が出る場合は少し上げます。
  4. Directional、Point、SpotではShadow Softnessを上げると半影を柔らかくできます。
影は描画負荷が高い機能です。
複数ライトでCast Shadowsを有効にしたり、Shadow Resolutionを過度に高くしたりすると負荷が増えます。必要なライトだけで有効にしてください。
  • KeyLightにLightとLightRendererがある
  • Type、Color、Intensityを設定できる
  • LightRendererのTargetがMainScreenになっている
  • ViewerまたはPlayモードで照明結果を確認できる

各ライト型、面光源、シャドウAPIの詳細は描画コンポーネントのリファレンスを参照してください。
